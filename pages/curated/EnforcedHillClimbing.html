Enforced hill climbing

Algorithms AIMech:EnforcedHillClimbing DRAFT

This record's curation method is recorded as ai_assisted (curator Codex, model GPT-6). Its saved reviews are listed under Curation History.

A forward state-space search controller that repeatedly uses breadth-first search to find a state with a strictly smaller heuristic value, commits the intervening action path, and continues from that state until a zero-valued goal is reached or no improvement is reachable.
Definition Evidence
  • supports Source: The FF Planning System: Fast Plan Generation Through Heuristic Search · Locator: Section 5.1, Figure 3 and the complete FIFO escape-search description, PDF pp. 12–13 / printed pp. 264–265.
Identity Notes & Concept Scope The identity is the unpruned Figure 3 enforced hill-climbing controller in Hoffmann and Nebel 2001: complete FIFO escape to a strict heuristic improvement, with irreversible prefix commitment. It differs from strict immediate-neighbor hill climbing, its BFS subroutine, global best-first selection, stochastic-local-search families, STRIPS means–ends planning, learned RTA*/LRTA* backups, ILS and GLS. Full FF and its relaxed-plan heuristic, pruning and fallback composition are not aliases. Claims & Grounded Evidence

5 Claims
Mechanism #strict-macro-improvement
Start with an empty plan and the initial state. While the current state has nonzero heuristic value, perform breadth-first search from it for a state with strictly smaller heuristic value. If the search succeeds, append the actions on that path to the plan and make its endpoint current; if no such state can be reached, report failure. A zero-valued current state ends the procedure.
  • supports Source: The FF Planning System: Fast Plan Generation Through Heuristic Search · Locator: Section 5.1, Figure 3 and following description, PDF pp.12–13 / printed264–265.
Mechanism #breadth-first-escape
The described escape search uses a FIFO queue and a hash table of visited states. It evaluates the state removed from the front, accepts the first strict improvement over the episode’s starting value, and otherwise enqueues its successors. Exhausting reachable new states yields failure. With complete successor generation, breadth-first ordering makes the accepted improvement nearest by number of actions, subject to successor ordering among equal-depth alternatives.
  • supports Source: The FF Planning System: Fast Plan Generation Through Heuristic Search · Locator: Section 5.1, PDF p.13 / printed265, queue implementation and closest-better-successor description. The equal-depth qualification is a curator inference from FIFO ordering.
Mechanism #commitment-and-intermediate-states
The algorithm retains the chosen action prefix and does not undo a commitment merely to try a different improvement from an earlier episode. Strict improvement constrains the successive accepted episode endpoints; the intermediate states on an escape path need not improve at each action. This permits traversal of plateaus and initially worsening paths that a strict neighbor-improvement procedure would reject.
  • supports Source: The FF Planning System: Fast Plan Generation Through Heuristic Search · Locator: Section 5.1, PDF pp.12–13 / printed264–265, local minima/plateaus and Figure 3; Section 5.2, PDF p.13 / printed265, irreversible prefix commitment.
Scope #conditional-completeness
For the finite propositional planning setting and the unpruned complete breadth-first escape search, Proposition 4 establishes solution finding on dead-end-free tasks. The paper states the condition that the heuristic maps states to nonnegative integers and is zero exactly at goal states. Any non-goal committed state then has a reachable goal with smaller value, and accepted values decrease. This is a conditional result for the core controller, not a guarantee for FF’s additional pruning rules.
  • supports Source: The FF Planning System: Fast Plan Generation Through Heuristic Search · Locator: Section 5.2, Proposition 4 and qualification immediately after its proof, PDF pp.13–14 / printed265–266; Sections 6.1.1–6.1.2, PDF pp.18–19 / printed270–271.
Scope #controller-versus-full-ff
The controller consumes a heuristic and state-transition model. In FF it is combined with a relaxed-GRAPHPLAN heuristic and optional search restrictions. FF’s complete fallback discards the failed attempt and starts greedy best-first search from the original task, with helpful-actions and added-goal-deletion pruning disabled. That fallback composition is distinct from the enforced hill-climbing controller itself.
  • supports Source: The FF Planning System: Fast Plan Generation Through Heuristic Search · Locator: Section 2 and Figure 1, PDF p.3 / printed255; Section 5.2, PDF p.15 / printed267; Section 6 introduction and integration passages, PDF pp.16,19–21 / printed268,271–273.

⚠️ Curated Limitations & Negative Results

  • The controller can commit to a reachable dead end on a solvable task. Failure from that committed state does not establish that the original initial state has no solution, and the mere presence of some dead ends does not imply every run fails.
  • Helpful-actions pruning can remove every solution even on a dead-end-free task; added-goal-deletion pruning has a separate such counterexample. Therefore the core dead-end-free completeness statement cannot be transferred to these restricted FF search variants. Their empirical usefulness is not a completeness proof.
  • The nearest strict improvement is measured in number of actions in the breadth-first episode. It need not be the improvement with best heuristic value, the minimum weighted-cost escape, or a prefix of a globally shortest plan. Successor order can select different equal-depth improvements.
  • Each escape search can retain a substantial queue and visited-state table and may inspect all states reachable from its current start. No fixed lookahead budget, real-time bound, polynomial runtime, or completeness for arbitrary infinite spaces follows from the controller. A resource cutoff is an additional stopping rule.
  • The zero-heuristic stopping rule requires zero to identify exactly the goal states. The cited theorem is stated for nonnegative integer values and complete unpruned search; it is not asserted for arbitrary approximate goal tests, changing heuristic tables or restricted successor generation. Admissibility is not a premise of that theorem.
  • This record scope is the base search controller, not the full FF planner, the relaxed-plan heuristic, helpful-actions pruning, added-goal deletion, goal-agenda planning, or the 1971 STRIPS means–ends procedure. It does not perform LRTA*’s learned heuristic backups. The inspected planning formulation assumes a known deterministic transition model and fully specified states; no stochastic or partially observed extension is established here.
  • Assessment uses the 2001 author-hosted JAIR method, OCR with critical visual checks, and selected later sections of the same 2001 paper. The cited ISMIS-2000 predecessor, FF source implementation, and PDF pages26–38 were not inspected. No invention-priority, benchmark ranking, empirical speedup, or implementation-conformance claim is made.
