GlobalE and LocalE Entropy-Based Prompt Ordering

Algorithms AIMech:GlobalEAndLocalEEntropyBasedPromptOrdering DRAFT
Aliases: GlobalE and LocalE Prompt Ordering, GlobalE / LocalE Entropy-Based Demonstration Ordering, Entropy-Based Few-Shot Prompt Permutation Selection
A validation-free prompt ordering method for few-shot in-context learning that first generates an unlabeled probing set directly from the pretrained language model conditioned on the available training demonstrations, and then selects high-performing permutations of those demonstrations by maximizing either the global Shannon entropy of hard class predictions across the probing set (GlobalE) or the mean local predictive entropy per probing instance (LocalE).
Identity Notes & Concept Scope Distinct from post-hoc output probability calibration methods such as Contextual Calibration (AIMech:CalibrateBeforeUseContextualCalibration) and Domain-Conditional PMI (AIMech:PMIDCDomainConditionalPointwiseMutualInformation), which rescale label probabilities for a fixed prompt rather than ranking and selecting optimal permutations of in-context demonstrations. Also distinct from retrieval-based example selection methods that choose which examples to include per test query rather than ordering a fixed few-shot support set without any labeled development data.

Claims & Grounded Evidence

4 Claims
Mechanism #globale-locale-generative-probing-set-construction
To evaluate candidate prompt permutations without access to a labeled development set, the method prompts the pretrained language model with concatenated training demonstrations to sample artificial unlabeled probing inputs from the target task distribution.
  • supports Source: Fantastically Ordered Prompts and Where to Find Them: Overcoming Few-Shot Prompt Order Sensitivity · Locator: Section 3.1, p. 8089, Figure 2
Mechanism #globale-and-locale-entropy-scoring-equations
For each candidate permutation of the K demonstrations, GlobalE computes the Shannon entropy of the empirical distribution of argmax class predictions across the probing set to eliminate permutations that suffer from degenerate single-class collapse, whereas LocalE computes the average predictive distribution entropy across individual probing inputs.
  • supports Source: Fantastically Ordered Prompts and Where to Find Them: Overcoming Few-Shot Prompt Order Sensitivity · Locator: Section 3.2, pp. 8089-8090, Equations 2-5
Application #globale-locale-few-shot-order-sensitivity-application
GlobalE and LocalE are applied to few-shot text classification across GPT-2, GPT-3, and RoBERTa models, improving accuracy by an average of 13% over random orderings and drastically reducing variance across demonstration permutations without using labeled validation examples.
  • supports Source: Fantastically Ordered Prompts and Where to Find Them: Overcoming Few-Shot Prompt Order Sensitivity · Locator: Section 4 & Section 5, pp. 8090-8094, Tables 1-4
  • supports Source: Fantastically Ordered Prompts and Where to Find Them: Overcoming Few-Shot Prompt Order Sensitivity (Crossref metadata) · Locator: DBLP bibliographic record conf/acl/LuBMRS22
Limitation #globale-locale-factorial-permutation-cost-limitation
Exhaustively scoring all K! permutations scales factorially with the number of in-context examples K, requiring Monte Carlo subsampling of permutations when K is large and assuming that the true target class distribution is approximately balanced.
  • supports Source: Fantastically Ordered Prompts and Where to Find Them: Overcoming Few-Shot Prompt Order Sensitivity · Locator: Section 3.2 & Section 5, pp. 8089-8095

⚠️ Curated Limitations & Negative Results

  • Evaluating candidate permutations across the probing set requires additional forward inference passes proportional to the number of evaluated permutations times the probing set size.
  • Performant permutations selected for one language model or parameter scale do not reliably transfer to different model families or sizes.
