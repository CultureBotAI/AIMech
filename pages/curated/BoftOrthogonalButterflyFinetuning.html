Parameter-Efficient Orthogonal Finetuning via Butterfly Factorization (BOFT)

Algorithms AIMech:BoftOrthogonalButterflyFinetuning DRAFT
Aliases: BOFT, Butterfly Orthogonal Fine-Tuning, Orthogonal Butterfly Finetuning
Parameter-Efficient Orthogonal Finetuning via Butterfly Factorization (BOFT) is a multiplicative parameter-efficient fine-tuning method that adapts a frozen pretrained weight matrix W^0 in R^{d x n} via the orthogonal transformation z = W^T x = (R(m, b) W^0)^T x, where the orthogonal matrix R(m, b) in O(d) is factored as a product of m sparse butterfly orthogonal components: R(m, b) = prod_{i=1}^m B~^b_{(d, i)}. Each butterfly factor B~^b_{(d, i)} is a permutation of a block-diagonal orthogonal matrix whose 2 x 2 block of (b/2) x (b/2) submatrices is constrained to be orthogonal via the Cayley transform R_block = (I + Q)(I - Q)^{-1} with skew-symmetric Q = -Q^T, initialized at Q = 0 so R(m, b) = I_d at step 0. With block size b >= 2 and m <= log_2(d/b) + 1 levels, BOFT uses (1/2)(b - 1) d m trainable parameters per layer, subsumes block-diagonal OFT at m = 1, and generates dense orthogonal matrices across the full d x d space when m = log_2(d/b) + 1.
Identity Notes & Concept Scope Distinct from additive low-rank adapters such as LoRA (Hu et al., 2022) and DoRA (Liu et al., 2024), which add a low-rank update W_0 + B A that alters pairwise neuron angles (hyperspherical energy) rather than multiplying W^0 by an exact orthogonal matrix R^T R = I_d. Also distinct from single-stage block-diagonal Orthogonal Finetuning (OFT, Qiu et al., 2023), which corresponds to the degenerate m = 1 special case of BOFT and cannot mix coordinates across distinct b-dimensional blocks.

Claims & Grounded Evidence

4 Claims
Mechanism #r656-claim-butterfly-topology-expressivity-and-parameter-count
Interpreting dense d x d orthogonal matrix parameterization as complete bipartite graph connectivity across d input and d output nodes, BOFT's block butterfly factorization with m = log_2(d/b) + 1 stages and block size b >= 2 achieves dense all-to-all connectivity (and by Kaleidoscope matrix expressivity, full O(d) representation when stacked) using only (1/2)(b - 1) d log_2 d effective parameters instead of O(d^2) for full orthogonal or O(b d) for block-diagonal OFT.
  • supports Source: Parameter-Efficient Orthogonal Finetuning via Butterfly Factorization · Locator: Section 2, Figure 1, p. 3-4; Section 3, Equations (5)-(6), Theorem 1 & Remark 2, p. 5-6
Mechanism #r656-claim-hyperspherical-energy-preservation-and-spectral-norm
Because the product of orthogonal butterfly factors R(m, b) = prod_{i=1}^m B~^b_{(d, i)} remains strictly orthogonal (R(m, b)^T R(m, b) = I_d), multiplying a pretrained weight matrix W^0 by R(m, b) exactly preserves the pairwise cosine similarities (hyperspherical energy) among the columns (neurons) of W^0 as well as the singular value spectrum and spectral norm ||R(m, b) W^0||_2 = ||W^0||_2.
  • supports Source: Parameter-Efficient Orthogonal Finetuning via Butterfly Factorization · Locator: Section 1, p. 1-2; Section 2, Equation (1), p. 3; Section 4 (Intriguing Insights & Discussions), p. 6-7
Mechanism #r656-claim-multiplicative-dropout-for-butterfly-factors
Because standard element-wise dropout destroys the orthogonality of Cayley-parameterized butterfly blocks, BOFT introduces multiplicative dropout, which randomly selects a fraction p_2 of the 2 x 2 block-orthogonal submatrices in each butterfly component B~^b_{(d, i)} and replaces them with the b x b identity matrix I_b, preserving exact orthogonality of R(m, b) throughout regularized training.
  • supports Source: Parameter-Efficient Orthogonal Finetuning via Butterfly Factorization · Locator: Section 3 (Multiplicative Dropout for BOFT), p. 6
Limitation #r656-claim-merging-zero-inference-overhead-and-training-cost-limitation
Once training finishes, all m butterfly factors are multiplied into a single orthogonal matrix and folded into W = R(m, b) W^0 with zero inference latency overhead, but during training BOFT incurs sequential matrix multiplications and Cayley matrix inversions across m butterfly stages and requires dimensions d divisible by b * 2^{m-1}.
  • supports Source: Parameter-Efficient Orthogonal Finetuning via Butterfly Factorization · Locator: Section 3 (Identity Initialization & Inference Efficiency), p. 5; Appendix A & F, p. 16-21

⚠️ Curated Limitations & Negative Results

  • Incurs training-time computational and memory overhead from sequential multiplication of m butterfly matrices and b x b Cayley matrix inversions at each forward pass, although inference overhead is zero after merging R(m, b) into W^0.
  • Standard Radix-2 block butterfly factorization requires the adapted weight dimension d to be divisible by b * 2^{m-1}.
