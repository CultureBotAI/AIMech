Short-Dot Coded Sparse Dot Products for Straggler-Resilient Linear Transforms

Algorithms AIMech:ShortDotCodedSparseDotProductsForStragglerResilientLinearTransforms DRAFT
Aliases: Short-Dot, Short-Dot Codes, Short-Dot Coded Linear Transform
A straggler-resilient coded parallelization method for computing large linear transforms A x (with A in R^{M x N} and input x in R^N across P > M processors) that appends K - M auxiliary rows Z in R^{(K - M) x N} to A to form A_tilde = [A^T | Z^T]^T in R^{K x N} and multiplies by a P x K super-regular or Vandermonde encoding matrix B to produce F = B A_tilde in R^{P x N}, choosing each column z_j = -(B^{U_j}_{cols M+1:K})^{-1} B^{U_j}_{cols 1:M} A_j to enforce K - M cyclic zeros per column so that every processor's encoded row f_i^T has sparsity at most s = (N / P)(P - K + M) < N and any K out of P short dot products <f_i^{S_i}, x^{S_i}> suffice to linearly recover A x.
Identity Notes & Concept Scope Distinct from Maximum Distance Separable (MDS) coded matrix-vector multiplication (Lee et al., 2015/2018, which requires K = M processors to finish but forces every processor to store and compute a full N-length dot product) and from Polynomial / MatDot / Entangled Polynomial Codes (AIMech:PolynomialCodesForStragglerResilientHighDimensionalCodedMatrixMultiplication, AIMech:MatDotAndPolyDotCodesForStragglerResilientCodedMatrixMultiplication, AIMech:EntangledPolynomialCodesForStragglerResilientDistributedMatrixMultiplication, which encode dense block submatrices of two matrices A and B): Short-Dot (Dutta, Cadambe, & Grover, NeurIPS 2016 / IEEE TIT 2019) jointly encodes M rows into P sparse vectors of length s = (N/P)(P - K + M) by solving for K - M padded rows Z that annihilate cyclic (K - M)-subsets of rows in B A_tilde, trading a slightly higher recovery threshold K >= M for shorter per-worker dot products, reduced worker memory, and reduced input communication.

Claims & Grounded Evidence

3 Claims
Mechanism #short-dot-sparsity-and-k-recovery-construction
Given any M x N matrix A and straggler recovery threshold K in {M + 1, ..., P} (when P divides N), appending K - M rows z_j = -(B^{U_j}_{cols M+1:K})^{-1} B^{U_j}_{cols 1:M} A_j for cyclic zero-index sets U_j of size K - M yields a P x N encoded matrix F = B A_tilde in which every row f_i^T has sparsity at most s = (N / P)(P - K + M) and the first M rows of (B^V)^{-1} v_V recover A x from the short dot products v_V of any K-subset V of processors.

Scope #short-dot-near-optimal-sparsity-and-expected-time
Any P x N linear encoding F whose every K rows span the M rows of a generic M x N matrix A must have average row sparsity s_bar > (N / P)(P - K + M) - (M^2 / P) C(P, K - M + 1) = (N / P)(P - K + M) - o(N / P) for large N (Theorem 3, Eq. 6-7), proving Short-Dot is asymptotically sparsity-optimal; under shifted-exponential worker delays with M = P / log P and K = P - M / 2, Short-Dot achieves scaled expected time E[T_{SD}] / N = O(log(log P) / log P) -> 0 whereas MDS coding, repetition, and uncoded parallelization remain Omega(1) (Theorem 4, Eq. 13-17).

Limitation #short-dot-offline-encoding-and-real-vandermonde-limitation
Pre-processing matrix A into F requires solving N / P linear systems of size (K - M) x (K - M) (costing O((N / P)(K - M)^3 + 2 P K N) naively or O(N P log^2 P) with Vandermonde fast polynomial interpolation), making Short-Dot suited primarily to settings where A is known offline or reused across many input vectors x.

⚠️ Curated Limitations & Negative Results

  • Requires an offline pre-processing step of complexity O((N / P)(K - M)^3 + 2 P K N) or O(N P log^2 P) to encode the transform matrix A into F, which is only amortized when A is fixed across multiple online inputs x.
  • Tolerates fewer stragglers (P - K) than full-length (P, M)-MDS coding (P - M) because K > M workers must finish to compensate for shortened dot-product length s = (N / P)(P - K + M).
