VR-DIANA and SVRG-DIANA (Variance-Reduced Distributed Learning with Gradient Quantization)

Aliases: VR-DIANA, Variance-Reduced DIANA, DIANA-LSVRG, DIANA-SAGA, SVRG-DIANA
VR-DIANA and SVRG-DIANA are doubly variance-reduced distributed optimization algorithms for solving min_{x in R^d} f(x) = (1/n) sum_{i=1}^n f_i(x) with local finite-sum structure f_i(x) = (1/m) sum_{j=1}^m f_{ij}(x) across n workers using arbitrary unbiased omega-quantization operators Q: R^d -> R^d (satisfying E_Q[Q(v)] = v and E_Q[||Q(v) - v||_2^2] <= omega ||v||_2^2). At each iteration k, each worker i computes a local variance-reduced stochastic gradient g_i^k = grad f_{i, j_i^k}(x^k) - grad f_{i, j_i^k}(w_{i, j_i^k}^k) + mu_i^k via L-SVRG (Variant 1), SAGA (Variant 2), or multi-epoch SVRG (Algorithm 3), quantizes only the shifted difference Delta_hat_i^k = Q(g_i^k - h_i^k) relative to a local state h_i^k, updates h_i^{k+1} = h_i^k + alpha * Delta_hat_i^k, and enables the master to take the global step x^{k+1} = x^k - gamma * (h^k + (1/n) sum_{i=1}^n Delta_hat_i^k) that eliminates both local sampling variance and quantization variance without ever transmitting uncompressed gradients.

Identity Notes & Concept Scope Distinct from baseline DIANA (Mishchenko et al., 2019; Round 389), which does not incorporate local finite-sum variance reduction and only converges to an O(sigma^2 / (mu^2 * n)) neighborhood under stochastic gradients. Also distinct from ADIANA (Li et al., 2020; Round 390), which accelerates full-batch or L-SVRG DIANA via Nesterov momentum, and from QSVRG (Alistarh et al., 2017; Round 378), which requires broadcasting exact uncompressed full gradients at the start of every epoch.

Claims & Grounded Evidence

4 Claims
Mechanism #vr-diana-strongly-convex-linear-convergence
Under L-smoothness of each f_{ij}, convexity of f_{ij}, and mu-strong convexity of each f_i, VR-DIANA (Algorithm 2, L-SVRG and SAGA variants) and SVRG-DIANA (Algorithm 3) with alpha = 1/(omega + 1) and gamma = 1 / (L*(1 + 36*(omega + 1)/n)) contract the Lyapunov function psi^k = ||x^k - x^*||_2^2 + b*gamma^2*H^k + c*gamma^2*D^k at linear rate rho = min{mu / (L*(1 + 36*(omega + 1)/n)), alpha/2, 3/(8*m)}, reaching E[||x^k - x^*||_2^2] <= epsilon * psi^0 in O((kappa + kappa*omega/n + m + omega) log(1/epsilon)) iterations using only quantized uplink messages.
  • supports Source: Stochastic Distributed Learning with Gradient Quantization and Variance Reduction · Locator: Section 7.1 Theorem 2 and Corollary 2, p. 6; Appendix E.1 pp. 17-21; Appendix F.1 Theorem 6 and Corollary 5, p. 27
Mechanism #vr-diana-convex-and-nonconvex-rates
For general convex objectives (mu = 0), VR-DIANA achieves E[f(x^a) - f^*] <= epsilon in O(((1 + omega/n)*sqrt(m) + omega/sqrt(m)) / epsilon) iterations (Theorem 3, Corollary 3), and for smooth nonconvex objectives it achieves E[||grad f(x^a)||_2^2] <= epsilon in O((1 + omega/n)^{1/2} * (m^{2/3} + omega) / epsilon) iterations (Theorem 4, Corollary 4), matching unquantized variance-reduced rates whenever omega = O(min{n, m}) (convex) or omega = O(m^{2/3}) (nonconvex).
  • supports Source: Stochastic Distributed Learning with Gradient Quantization and Variance Reduction · Locator: Section 7.2 Theorem 3 and Corollary 3, Section 7.3 Theorem 4 and Corollary 4, Table 1, p. 7
Application #vr-diana-distributed-logistic-regression-application
Applied to distributed L2-regularized logistic regression on LIBSVM datasets (real-sim, Gisette, mushrooms, a5a) with l_infinity, l_2, and block random dithering, VR-DIANA (DIANA-SVRG, DIANA-SAGA, DIANA-LSVRG) converges linearly to machine precision (10^{-15}) while outperforming DIANA-SGD, QSVRG, and TernGrad-Adam in wall-clock time and data passes.
  • supports Source: Stochastic Distributed Learning with Gradient Quantization and Variance Reduction · Locator: Section 8 Experiments, Figures 1-3, pp. 8-9; Appendix A Figures 4-5, p. 12
Limitation #vr-diana-limitations
VR-DIANA requires unbiased omega-quantization operators (E_Q[Q(x)] = x) and maintains a d-dimensional shift vector h_i^k on each worker (plus an O(m*d) gradient table on each worker in the SAGA variant), and it assumes full worker participation and uncompressed downlink broadcasts of x^k from the central server.
  • supports Source: Stochastic Distributed Learning with Gradient Quantization and Variance Reduction · Locator: Section 4 Definition 4, p. 3; Section 6 Algorithm 2 and Section 6.2, pp. 5-6

⚠️ Curated Limitations & Negative Results

  • Requires unbiased omega-quantization operators (E_Q[Q(x)] = x) and does not directly handle biased contractive compressors such as Top-K without error feedback.
  • Variant 2 (DIANA-SAGA) requires O(m*d) local memory per worker to store the component gradient table grad f_{ij}(w_{ij}^k).
  • Assumes synchronous full worker participation and uncompressed server-to-worker broadcasts.
