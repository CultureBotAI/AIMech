Primal-Dual Witness Method and Sharp Thresholds for High-Dimensional Noisy Lasso Sparsity Recovery

Mathematical Methods AIMech:PrimalDualWitnessAndSharpThresholdsForHighDimensionalNoisyLassoSparsityRecovery DRAFT
Aliases: Sharp Thresholds for High-Dimensional and Noisy Sparsity Recovery Using l_1-Constrained Quadratic Programming (Wainwright 2009), Wainwright Primal-Dual Witness Method for Exact Signed Support Recovery of the Lasso, Sharp Sample Complexity Phase Transition n = 2s log(p - s) + s + 1 for Noisy Lasso Sparsity Recovery, Wainwright (2006/2009) Mutual Incoherence Threshold Theory for High-Dimensional Lasso Support Recovery
Primal-Dual Witness Method and Sharp Thresholds for High-Dimensional Noisy Lasso Sparsity Recovery is a convex-optimality and high-dimensional phase-transition analysis framework introduced by Wainwright (2009, IEEE Transactions on Information Theory 55(5):2183-2202, arXiv:math/0605740v1) for characterizing exact signed support recovery sgn(beta_hat) = sgn(beta*) of an s-sparse vector beta* in R^p (S = supp(beta*), |S| = s, N = |S^c| = p - s) from n noisy linear observations Y = X beta* + W (W ~ N(0, sigma^2 I_n)) via the Lasso min_{beta in R^p} {(1/(2n)) ||Y - X beta||_2^2 + lambda_n ||beta||_1} (Equation 3). Assuming X_S^T X_S is invertible, Lemma 1 (Equations 9a-9b, 10a-10b; Appendix A, Equations 35-36) reduces exact signed support recovery R(X, beta*, W, lambda_n) via Karush-Kuhn-Tucker primal-dual witness construction to two extreme order-statistic events: off-support dual feasibility M(V) := {max_{j in S^c} |V_j| <= lambda_n} (Equation 11) and on-support sign consistency beta*_S + U_S having sign b = sgn(beta*_S) (secured by M(U) := {max_{i in S} |U_i| <= rho_n := min_{i in S} |beta*_i|}, Equation 12). For random Gaussian ensembles X_k ~ N(0, Sigma) satisfying eigenvalue bounds Lambda_min(Sigma_{SS}) >= C_min > 0, Lambda_max(Sigma) <= C_max < +infty, ||(Sigma_{SS})^{-1}||_infty <= D_max (Equation 17), and mutual incoherence ||Sigma_{S^c S} (Sigma_{SS})^{-1}||_infty <= 1 - epsilon for epsilon in (0, 1] (Equation 18), Theorem 1 (Equations 20-21) establishes explicit threshold constants theta_l := (sqrt(C_max) - sqrt(C_max - 1/C_max))^2 / (C_max (2 - epsilon)^2) <= 1 and theta_u := C_max / (epsilon^2 C_min) >= 1 such that for any nu > 0, P[R(X, beta*, W, lambda_n)] -> 0 whenever n < 2(theta_l - nu) s log(p - s) + s + 1, whereas P[R(X, beta*, W, lambda_n)] -> 1 whenever n > 2(theta_u + nu) s log(p - s) + s + 1 and lambda_n -> 0 satisfies (n lambda_n^2) / log(p - s) -> +infty and (1/rho_n)[lambda_n + sqrt((log s)/n)] -> 0; for the standard Gaussian ensemble Sigma = I_p, theta_l = theta_u = 1, yielding the exact sharp threshold n = 2s log(p - s) + s + 1.

Mechanism #primal-dual-witness-kkt-characterization-and-deterministic-design-consistency
Assuming the s x s sub-Gram matrix X_S^T X_S on the true support S = supp(beta*) (|S| = s, N = |S^c| = p - s) is invertible, Lemma 1 (Section 2.1, p. 4, Equations 9a-9b, 10a-10b; proved in Appendix A, p. 18, Equations 35-36) establishes by solving the restricted KKT system (1/n) X_S^T X_S (beta_hat_S - beta*_S) - (1/n) X_S^T w = -lambda_n b (where b := sgn(beta*_S)) and substituting beta_hat_S = beta*_S + U into the off-support subgradient equation that there exists an optimal Lasso solution beta_hat achieving exact signed support recovery sgn(beta_hat) = sgn(beta*) if and only if the off-support dual variables V_j := X_j^T {X_S (X_S^T X_S)^{-1} lambda_n b - [X_S (X_S^T X_S)^{-1} X_S^T - I_n] (W/n)} satisfy M(V) := {max_{j in S^c} |V_j| <= lambda_n} (Equations 9a, 11) and the on-support perturbations U_i := e_i^T ((1/n) X_S^T X_S)^{-1} [(1/n) X_S^T W - lambda_n b] preserve the signs of beta*_S (Equations 9b, 10a, for which M(U) := {max_{i in S} |U_i| <= rho_n := min_{i in S} |beta*_i|}, Equation 12, is sufficient). For deterministic designs X with column norms ||X_j||_2^2 = n satisfying mutual incoherence ||X_{S^c}^T X_S (X_S^T X_S)^{-1}||_infty <= 1 - epsilon (epsilon in (0, 1]) and minimum eigenvalue Lambda_min((1/n) X_S^T X_S) >= C_min > 0 (Equations 14a-14b), Proposition 1 (Section 2.2, p. 6, Equation 15) proves P(R(X, beta*, W, lambda_n)) -> 1 whenever lambda_n -> 0 satisfies (n lambda_n^2) / log(p - s) -> +infty and (1/rho_n) {sqrt((log s)/n) + lambda_n ||((1/n) X_S^T X_S)^{-1}||_infty} -> 0.

Mechanism #sharp-sample-complexity-thresholds-and-noisy-versus-noiseless-scaling-separation
For random Gaussian designs X_k ~ N(0, Sigma) with unit diagonal satisfying Lambda_min(Sigma_{SS}) >= C_min > 0, Lambda_max(Sigma) <= C_max < +infty, ||(Sigma_{SS})^{-1}||_infty <= D_max < +infty (Equation 17), and population mutual incoherence ||Sigma_{S^c S} (Sigma_{SS})^{-1}||_infty <= 1 - epsilon for epsilon in (0, 1] (Equation 18), Theorem 1 (Section 3.1, pp. 8-9, Equations 20-21) defines the explicit thresholds theta_l := (sqrt(C_max) - sqrt(C_max - 1/C_max))^2 / (C_max (2 - epsilon)^2) <= 1 and theta_u := C_max / (epsilon^2 C_min) >= 1 and proves that as s, (n - s), (p - s) -> +infty, for any constant nu > 0: (a) if n < 2(theta_l - nu) s log(p - s) + s + 1, then P[R(X, beta*, W, lambda_n)] -> 0 for any non-increasing sequence lambda_n > 0; and (b) if n > 2(theta_u + nu) s log(p - s) + s + 1 and lambda_n -> 0 satisfies (n lambda_n^2) / log(p - s) -> +infty and (1/rho_n)[lambda_n + sqrt((log s)/n)] -> 0, then P[R(X, beta*, W, lambda_n)] -> 1. For the uniform (standard) Gaussian ensemble Sigma = I_{p x p} (C_min = C_max = 1, epsilon = 1), theta_l = theta_u = 1 so the threshold n = 2s log(p - s) + s + 1 is sharp; consequently, Corollaries 1 and 2 (pp. 9-10) prove that under linear sample scaling n = gamma p (gamma in (0, 1)), noisy Lasso fails with probability converging to 1 for any linear-fraction sparsity s = alpha p (requiring n > 2 alpha p log[(1 - alpha)p] + alpha p), in sharp contrast to noiseless Basis Pursuit.

⚠️ Curated Limitations & Negative Results

  • Mutual Incoherence and Minimum Signal Magnitude Conditions: Theorem 1 requires the population covariance Sigma to satisfy the l_infinity mutual incoherence condition ||Sigma_{S^c S} (Sigma_{SS})^{-1}||_infty <= 1 - epsilon for epsilon in (0, 1] (Equation 18) and the minimum active-set magnitude rho_n := min_{i in S} |beta*_i| to dominate lambda_n + sqrt((log s)/n) (Equation 21); when mutual incoherence fails, exact signed support recovery via the Lasso is not guaranteed even when Restricted Eigenvalue conditions permit l_2 estimation.
  • Threshold Gap for Non-Uniform Correlated Ensembles: While theta_l = theta_u = 1 yields a single sharp threshold for the isotropic Gaussian ensemble Sigma = I_p, for correlated Gaussian ensembles with C_max > 1 or epsilon < 1 (such as Toeplitz ensembles in Section 4, pp. 16-17, where theta_l < 1 < theta_u), Theorem 1 provides separate necessary (theta_l) and sufficient (theta_u) threshold constants.
  • Primary-Source Typographical Notes in Wainwright (2009, arXiv:math/0605740v1): Verified six self-correcting typographical details during full-text inspection and numerical verification: (1) Section 2.1 (p. 4, Lemma 1, Equation 9b) writes |beta*_S + U_S| > 0 (and Appendix A, p. 18, line 8 writes beta_hat_S != 0) whereas exact signed support recovery sgn(beta_hat_S) = sgn(beta*_S) requires sgn(beta*_S + U_S) = sgn(beta*_S) (secured by the sufficient condition M(U) = {max_{i in S} |U_i| <= rho_n} in Equation 12 when strict inequality holds) and Appendix A (p. 18, line 13) drops the minus sign when writing lambda z_hat_{S^c} = X_{S^c}^T X_S (X_S^T X_S)^{-1}[(1/n) X_S^T w - lambda sgn(beta*_S)] - (1/n) X_{S^c}^T w = -V_{S^c} (whereas line 10 has -lambda z_hat_{S^c} on the RHS so +lambda z_hat_{S^c} = +V_{S^c});
