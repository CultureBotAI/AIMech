Basis Learn (BL1, BL2, and BL3)

Aliases: Basis Learn, BL1 Basis Learn with Bidirectional Compression, BL2 Basis Learn with Partial Participation, BL3 Positive Semidefinite Basis Learn
A family of communication-efficient second-order distributed and federated optimization algorithms (BL1, BL2, and BL3) for minimizing f(x) = (1/n) sum_{i=1}^n f_i(x) that transforms each client i's local Hessian nabla^2 f_i(x) into a custom matrix basis {B_i^{jl}} of R^{d x d} or the symmetric matrix space S^d via nabla^2 f_i(x) = sum_{j,l} h_{jl}^i(nabla^2 f_i(x)) B_i^{jl} before applying lossy matrix compression. When local generalized linear model (GLM) data vectors {a_{ij}}_{j=1}^m lie in an r-dimensional subspace G_i subseteq R^d spanned by {v_{it}}_{t=1}^r ( transmitted once to the server at cost r d floats without revealing raw data a_{ij}), the outer-product basis V_{itl} = v_{it} v_{il}^T concentrates all non-zero Hessian coefficients into an r x r block gamma_{itl}(x) = (1/m) sum_{j=1}^m phi_{ij}''(a_{ij}^T x) alpha_{ijt} alpha_{ijl} (r^2 << d^2 floats). BL1 integrates custom-basis Hessian learning L_i^{k+1} = L_i^k + alpha C_i^k(h^i(nabla^2 f_i(z^k)) - L_i^k) with bidirectional model/gradient compression, while BL2 and BL3 extend basis learning to partial client participation using Frobenius-error shifting (BL2) or positive semidefinite basis decomposition (BL3).

Identity Notes & Concept Scope Distinct from standard-basis FedNL (which compresses dense d x d Hessian differences directly in the canonical matrix basis E_{jl} = e_j e_l^T) and from NewtonLearn (which requires revealing raw local data vectors a_{ij} to the server to send m scalar coefficients). Basis Learn sends only the r subspace basis vectors {v_{it}}_{t=1}^r once before training and learns the sparse r x r basis coefficient matrix L_i^k under bidirectional compression and partial participation.

Claims & Grounded Evidence

4 Claims
Mechanism #lossless-subspace-outer-product-hessian-basis-reduction
For any local generalized linear model f_i(x) = (1/m) sum_{j=1}^m phi_{ij}(a_{ij}^T x) whose feature vectors {a_{ij}}_{j=1}^m span an r-dimensional subspace G_i subseteq R^d with basis {v_{it}}_{t=1}^r (a_{ij} = sum_{t=1}^r alpha_{ijt} v_{it}), Equation (5) and Lemma B.1 show that the r^2 outer-product matrices V_{itl} = v_{it} v_{il}^T are linearly independent and represent nabla^2 f_i(x) = sum_{t,l=1}^r gamma_{itl}(x) V_{itl} exactly using only r^2 coefficients instead of d^2 entries, without revealing the local data vectors a_{ij} to the server.
  • supports Source: Basis Matters: Better Communication-Efficient Second Order Methods for Federated Learning · Locator: Section 2.3, Equations (4)-(5), Table 1, pp. 5-6; Appendix B.3, Lemma B.1, pp. 28-29
Mechanism #bl1-bidirectional-compressed-basis-learning-linear-and-superlinear-rates
In BL1 (Algorithm 1), each client i updates its basis-coefficient estimate L_i^{k+1} = L_i^k + alpha S_i^k with S_i^k = C_i^k(h^i(nabla^2 f_i(z^k)) - L_i^k), while the server updates H^{k+1} = H^k + (alpha / n) sum_{i=1}^n sum_{j,l} (S_i^k)_{jl} B_i^{jl}, takes the projected Newton step x^{k+1} = z^k - [H^k]_mu^{-1} g^k, and broadcasts compressed model differences v^k = Q^k(x^{k+1} - z^k). Theorems 4.9 and 4.10 prove condition-number-independent local linear convergence E[Phi_1^k] <= (1 - min{A_M, p}/2)^k Phi_1^0 and local superlinear convergence E[||x^{k+1} - x^*||^2 / ||x^k - x^*||^2] <= theta_1^k (A_M H^2 / (8 B M_1^2 mu^2) + 2 N_B R^2 / mu^2) Phi_2^0.
  • supports Source: Basis Matters: Better Communication-Efficient Second Order Methods for Federated Learning · Locator: Section 4, Algorithm 1, Theorems 4.9 and 4.10, pp. 9-10
  • supports Source: Basis Matters: Better Communication-Efficient Second Order Methods for Federated Learning (Crossref metadata) · Locator: Abstract
Application #bl2-and-bl3-partial-participation-and-composed-rank-r-unbiased-compressors
BL2 (Algorithm 2, Theorems 4.12-4.13) and BL3 (Algorithm 3, Theorems 5.4-5.5) unify custom matrix bases with partial client participation (sampling tau out of n clients per round) and guarantee positive definiteness without matrix eigenvalue projection via either Frobenius error shifts l_i^k I (BL2) or positive semidefinite symmetric basis matrices B_i^{jl} >= 0 (BL3), while Proposition 3.2 constructs a contractive matrix compressor C_2 of parameter delta = R / (d (omega_1 + 1)(omega_2 + 1)) by composing Rank-R SVD truncation with unbiased vector compressors Q_1^i, Q_2^i.
  • supports Source: Basis Matters: Better Communication-Efficient Second Order Methods for Federated Learning · Locator: Section 3, Lemma 3.1 and Proposition 3.2, pp. 7-8; Sections 4-5, Algorithms 2-3, pp. 11-15
Limitation #one-time-basis-transmission-and-full-rank-data-limitation
Basis Learn requires a one-time preprocessing step (such as local feature-matrix SVD) and initial transmission of the client basis matrices (costing r d floats per client in the GLM subspace setting), and its lossless dimension reduction from d^2 to r^2 diminishes when local data matrices have full rank r = d.
  • supports Source: Basis Matters: Better Communication-Efficient Second Order Methods for Federated Learning · Locator: Section 2.3, Table 1, pp. 5-6; Section 6.1, p. 17

⚠️ Curated Limitations & Negative Results

  • Requires an initial communication phase of O(r d) floats per client to share the local subspace basis with the server.
  • Local linear and superlinear convergence guarantees hold within an explicit neighborhood around the strongly convex minimizer x^*.
