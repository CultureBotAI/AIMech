SMITH: Siamese Multi-depth Transformer-based Hierarchical Encoder for Long-Form Document Matching

Architectures AIMech:SMITHSiameseMultiDepthTransformerBasedHierarchicalEncoder DRAFT
Aliases: SMITH Hierarchical Document Matching Encoder, Siamese Multi-depth Transformer-based Hierarchical Encoder, SMITH Dual-Encoder for Long-Form Document Matching
A two-tower Siamese ('Dual-Encoder') hierarchical Transformer architecture for long-to-long document semantic matching (Yang, Zhang, Li, Bendersky, & Najork, CIKM 2020) that packs natural sentences into L_d sentence blocks {S_1, ..., S_{L_d}} of max length L_s via greedy sentence filling, encodes tokens within each block using an L_1-layer sentence-level Transformer to extract L2-normalized block [CLS] embeddings h_i in R^H, contextualizes {h_1, ..., h_{L_d}} with an L_2-layer document-level Transformer to produce L2-normalized document embeddings E(d_s), E(d_c) scored by cosine similarity cos(E(d_s), E(d_c)), and pre-trains jointly with masked word prediction and dynamic in-batch masked sentence block contrastive prediction L_pretrain = L_sp + L_wp.
Identity Notes & Concept Scope Distinct from cross-encoder passage aggregation rankers such as PARADE (AIMech:PARADEPassageRepresentationAggregationForDocumentReranking, which jointly encodes query-passage pairs) and from RNN-based hierarchical document matchers such as HAN and SMASH RNN. SMITH is a representation-focused Siamese dual encoder supporting offline vector indexing up to 2,048 tokens, reducing self-attention memory complexity from O(b * A * L * N^2) to O(b * A * L * (L_s * N + (N / L_s)^2)) via greedy sentence filling and two-level Transformers.

Mechanism #smith-greedy-sentence-filling-and-two-level-transformer-mechanism
SMITH splits a document of length N into L_d = N / L_s blocks of max length L_s by greedily packing complete natural sentences into each block until adding the next sentence would exceed L_s, encodes each block with an L_1-layer sentence-level Transformer, and feeds the L2-normalized block representations plus block position embeddings into an L_2-layer document-level Transformer, reducing attention memory complexity from O(b * A * L * N^2) to O(b * A * L * (L_s * N + (N / L_s)^2)) (Eq. 3).

Mechanism #smith-dynamic-masked-sentence-block-pretraining-mechanism
During unsupervised pre-training, SMITH dynamically masks m randomly sampled sentence block vectors h_k per document with a learned mask vector h_hat, predicts contextual block vectors S_hat_j from the document-level Transformer, and minimizes the in-batch softmax cross-entropy L_sp = -(1/B) sum_{i=1}^B log(exp(S_hat_i h_i^T) / sum_{r=1}^B exp(S_hat_i h_r^T)) over all B = b * m masked blocks jointly with masked word prediction L_pretrain = L_sp + L_wp (Eqs. 4-7).

  • supports Source: Beyond 512 Tokens: Siamese Multi-depth Transformer-based Hierarchical Encoder for Long-Form Document Matching · Locator: masked_sentence_block_loss verification
Limitation #smith-siamese-no-early-cross-document-token-interaction-limitation
Because SMITH is a representation-focused Siamese dual encoder that encodes source and candidate documents independently into single vectors for offline ANN indexing, it cannot perform early token-by-token cross-attention between the two documents and requires tuning sentence-level Transformer depth L_1 against intermediate activation memory costs.
  • supports Source: Beyond 512 Tokens: Siamese Multi-depth Transformer-based Hierarchical Encoder for Long-Form Document Matching · Locator: Section 2, p. 3; Section 5.2.1, p. 8; Section 5.5, Table 6, p. 9

⚠️ Curated Limitations & Negative Results

  • As a Siamese dual-encoder architecture that compresses each document into a single dense vector before cosine similarity, SMITH cannot capture fine-grained cross-document token interactions prior to final pooling.
