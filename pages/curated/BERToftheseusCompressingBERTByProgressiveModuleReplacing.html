BERT-of-Theseus: Compressing BERT by Progressive Module Replacing

Algorithms AIMech:BERToftheseusCompressingBERTByProgressiveModuleReplacing DRAFT
Aliases: BERT-of-Theseus, Theseus Compression for BERT, Progressive Module Replacing for Transformer Compression
A distillation-loss-free Transformer compression algorithm ('Theseus Compression') that partitions a frozen N-layer predecessor network P = {prd_1, ..., prd_n} and a trainable M-layer successor network S = {scc_1, ..., scc_n} (with M < N) into n matched modules, stochastically replaces each predecessor module with its corresponding successor module during training forward passes via independent Bernoulli variables r_{i+1} ~ Bernoulli(p_d) so that y_{i+1} = r_{i+1} * scc_i(y_i) + (1 - r_{i+1}) * prd_i(y_i), increases the replacement probability according to a linear curriculum schedule p_d(t) = min(1, k*t + b) while optimizing only the standard task-specific objective, and subsequently fine-tunes the standalone successor S at p_d = 1.
Identity Notes & Concept Scope Introduced by Canwen Xu, Wangchunshu Zhou, Tao Ge, Furu Wei, and Ming Zhou (EMNLP 2020, pp. 7859-7869, arXiv:2002.02925, doi:10.18653/v1/2020.emnlp-main.633). Distinct from knowledge distillation methods such as TinyBERT (Round 800), MiniLM (Round 801), BERT-PKD (Round 802), DistilBERT (Round 803), and MobileBERT (Round 804): BERT-of-Theseus requires zero auxiliary feature-matching, attention-matching, or logit KL-divergence losses and no balancing hyperparameters between task and distillation losses, relying instead on closed-loop gradient interactions between frozen predecessor modules and trainable successor modules inside the hybrid computational graph.

Mechanism #r805-claim-stochastic-module-replacement-dynamics
Given a frozen predecessor P partitioned into n multi-layer modules {prd_1, ..., prd_n} and a successor S of n single-layer modules {scc_1, ..., scc_n}, BERT-of-Theseus samples independent binary indicators r_{i+1} ~ Bernoulli(p_d) at each module boundary i and computes y_{i+1} = r_{i+1} * scc_i(y_i) + (1 - r_{i+1}) * prd_i(y_i) (Eqs. 2-3), updating only successor parameters via backpropagation of the pure task cross-entropy loss L = CrossEntropy(y_hat, y) (Eq. 4) before a second successor-only fine-tuning phase (Eq. 5).

Mechanism #r805-claim-curriculum-schedule-and-lr-warmup-equivalence
To bridge the transition from hybrid module replacement to standalone successor inference, BERT-of-Theseus applies a linear curriculum replacement scheduler p_d(t) = min(1, k*t + b) (Eq. 6) with slope k > 0 and base probability b in (0, 1); in expectation over Bernoulli sampling, this curriculum scales the effective learning rate of each successor module as lr'(t) = min(1, k*t + b) * lr (Eq. 7), acting as an implicit module-level learning-rate warmup.

Application #r805-claim-glue-compression-performance
Compressing a 12-layer BERT-base predecessor into a 6-layer successor (1.94x inference speedup, 66M parameters), BERT-of-Theseus achieves a 78.6 macro-average score on the GLUE test benchmark, retaining 98.3% of the BERT-base teacher's performance and outperforming task-specific Vanilla KD (76.4), BERT-PKD (77.0), and pre-training DistilBERT (76.2 on the matched 8-task GLUE set).
  • supports Source: BERT-of-Theseus: Compressing BERT by Progressive Module Replacing · Locator: Section 3.3 (Experimental Results), Table 1 & Table 2, Pages 4-5
Limitation #r805-claim-inter-module-dimension-matching-limitation
Because each successor module scc_i must be a drop-in functional replacement for the corresponding predecessor module prd_i within the same forward pass, the input and output hidden dimensions of scc_i and prd_i must match at every module boundary, preventing arbitrary hidden-width reduction without additional adapter projections.
  • supports Source: BERT-of-Theseus: Compressing BERT by Progressive Module Replacing · Locator: Section 2.1 (Workflow of Theseus Compression, Equations 2-3), Page 2

⚠️ Curated Limitations & Negative Results

  • Each successor module scc_i must share identical input and output tensor dimensions with its replaced predecessor module prd_i at every module boundary.
  • Task-specific compression requires executing the two-stage progressive replacement and successor fine-tuning procedure for each target downstream task.
