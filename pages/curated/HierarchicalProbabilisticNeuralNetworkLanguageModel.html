Hierarchical probabilistic neural network language model

A neural next-word architecture that factors word probabilities along a binary vocabulary tree and shares a nonlinear branch predictor conditioned on context-word embeddings and a separate embedding of the current tree node.

Claims & Grounded Evidence

1 Claim
Mechanism #method
Concatenate the embeddings of the preceding context words into x, sharing their embedding matrix across all tree nodes. For internal node n, compute q_n=sigmoid(alpha_n+beta^T tanh(c+W x+U N_n)), where N_n is its separately learned node embedding, alpha_n is its scalar bias, and beta, c, W and U are shared parameters. The binary code for a target word chooses q_n or 1-q_n at each node; multiply those factors to obtain its normalized next-word probability. Training backpropagates the observed-word log loss through nodes on that path and their shared parameters. Although W x can be reused, tanh(c+W x+U N_n) generally differs by node. The reported tree starts from WordNet, selects one parent for multiply parented nodes and the most frequent sense per word, then makes nonbinary branches binary using corpus-based clustering. This hierarchy is a modeling choice, not a semantic-equivalence guarantee.

⚠️ Curated Limitations & Negative Results

  • Target evaluation work scales with path length and the branch-predictor cost. A logarithmic path requires suitable tree depth; producing the entire vocabulary distribution still requires at least linear output work.
  • The learned tree distribution is exactly normalized for its own parameters, but is not an equality-preserving numerical shortcut for a previously specified flat-softmax network.
  • Choosing one frequent WordNet sense loses other senses. Multiple leaves per word are discussed as an extension and require summed path probabilities; this record does not attribute that implementation to the original experiment.
  • Shared parameters reduce independent per-node parameterization but do not make the hidden activities identical at all nodes or establish convex learning or global convergence.
  • The accessed reissue PDF has unresolved references and a page-count discrepancy against its landing-page pagination; evidence is tied to the exact six-page file. No claimed speedup, test ranking or author-code behavior is certified.
