Faster Least Squares Approximation via Randomized Hadamard Preconditioning

Aliases: DMMS Faster Least Squares Approximation, Randomized Hadamard Preconditioned Sketch-and-Solve Least Squares, Fast Johnson-Lindenstrauss Least Squares Solver
Faster Least Squares Approximation via Randomized Hadamard Preconditioning is a randomized sketch-and-solve algorithm for overconstrained l_2 regression min_{x in R^d} ||b - A x||_2 (with n >> d) introduced by Drineas, Mahoney, Muthukrishnan, and Sarlos (2011) that beats the classical O(n d^2) QR/SVD complexity in O(n d log n + d^3 log^2 n / epsilon) time. Algorithm 1 preconditions the design matrix A and response b by a Randomized Hadamard Transform H D (where D = diag(sigma_1, ..., sigma_n) has i.i.d. Rademacher +/-1 signs and H is the normalized n x n Walsh-Hadamard matrix), uniformly samples and rescales r = O(d log n log(d log n) + d log n / epsilon) rows via S^T, and computes tilde{x}_opt = (S^T H D A)^+ S^T H D b. The analysis decouples the random projection X = S^T H D from the linear-algebraic perturbation via two deterministic structural conditions on the column orthonormal basis U_A of A and orthogonal residual b^perp = b - A x_opt (Equations 8-9): (i) sigma_min^2(X U_A) >= 1/sqrt(2) and (ii) ||U_A^T X^T X b^perp||_2^2 <= epsilon Z^2 / 2 (where Z = ||b^perp||_2), under which Lemma 1 and Lemma 2 prove both the residual bound ||b - A tilde{x}_opt||_2 <= (1 + epsilon) Z and the parameter error bound ||x_opt - tilde{x}_opt||_2 <= sqrt(epsilon) (kappa(A) sqrt(gamma^{-2} - 1)) ||x_opt||_2.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
For any n x d full-rank matrix A = U_A Sigma_A V_A^T, exact least-squares minimizer x_opt = A^+ b, and orthogonal residual b^perp = b - A x_opt with Z = ||b^perp||_2, Lemma 1 and Lemma 2 prove that whenever the sketching operator X satisfies Condition (8) sigma_min^2(X U_A) >= 1/sqrt(2) and Condition (9) ||U_A^T X^T X b^perp||_2^2 <= epsilon Z^2 / 2, the sketched normal equations obey (X U_A)^T X U_A z_opt = (X U_A)^T X b^perp where U_A z_opt = A(tilde{x}_opt - x_opt), yielding ||z_opt||_2^2 <= epsilon Z^2, ||b - A tilde{x}_opt||_2 <= (1 + epsilon) Z, and ||x_opt - tilde{x}_opt||_2 <= (sqrt(epsilon) / sigma_min(A)) Z <= sqrt(epsilon) (kappa(A) sqrt(gamma^{-2} - 1)) ||x_opt||_2.
  • supports Source: Faster Least Squares Approximation · Locator: Section 4.1, Structural Conditions (Equations 8-9), Lemma 1 (Equations 10-19), and Lemma 2 (Equations 20-21), pp. 6-8 of PDF (pp. 229-232)
  • supports Source: Faster Least Squares Approximation (arXiv abstract) · Locator: Abstract: (1+epsilon) residual and kappa(A) sqrt(gamma^{-2}-1) parameter approximation in O(nd log n) time
Scope #claim-02
Lemma 3 proves that applying the Randomized Hadamard Transform H D to any n x d orthonormal matrix U_A flattens all row leverage scores simultaneously to ||(H D U_A)_{(i)}||_2^2 <= (2 d log(40 n d)) / n for all i in [n] with probability at least 0.95, enabling uniform row sampling of r = max(48^2 d log(40 n d) log(100^2 d log(40 n d)), 40 d log(40 n d) / epsilon) rows in Algorithm 1 to satisfy both Conditions (8) and (9) in O(n d log r + r d^2) total time (Theorem 1).
  • supports Source: Faster Least Squares Approximation · Locator: Section 2, Theorem 1, p. 4 of PDF; Section 4.2, Lemma 3 (Equation 23), Lemma 4, and Lemma 5, pp. 8-13 of PDF
  • supports Source: Faster Least Squares Approximation (Crossref metadata) · Locator: Numerische Mathematik 117(2):219-249 bibliographic record
Limitation #claim-03
Without Randomized Hadamard preconditioning H D, uniform row sampling S^T A on a design matrix A with a spiky high-leverage row (||(U_A)_{(i)}||_2^2 = 1) misses that row with probability (1 - 1/n)^r, producing a rank-deficient sampled matrix sigma_min(S^T A) = 0 and singular normal equations; moreover, direct sketch-and-solve requires r = Omega(d / epsilon) rows scaling inversely with epsilon.
  • supports Source: Faster Least Squares Approximation · Locator: Section 1 and Section 4.2, Discussion of non-uniform leverage scores and 1/epsilon sample complexity of direct sketch-and-solve, pp. 2-5, 8-12

⚠️ Curated Limitations & Negative Results

  • Direct sketch-and-solve requires r = O(d log n / epsilon) rows scaling linearly in 1/epsilon, and parameter recovery error ||x_opt - tilde{x}_opt||_2 scales with the condition number kappa(A) and sqrt(gamma^{-2} - 1) when only a small fraction gamma of ||b||_2 lies in range(A).
