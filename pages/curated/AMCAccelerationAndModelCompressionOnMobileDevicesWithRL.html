AMC (AutoML for Model Compression and Acceleration on Mobile Devices)

Algorithms AIMech:AMCAccelerationAndModelCompressionOnMobileDevicesWithRL DRAFT
Aliases: AMC, AutoML for Model Compression, AMC Reinforcement Learning Channel and Fine-Grained Pruning
AMC (AutoML for Model Compression) is a reinforcement-learning-based neural network pruning framework that processes a pretrained network layer-by-layer using an 11-dimensional layer state vector s_t = (t, n, c, h, w, stride, k, FLOPs[t], reduced, rest, a_{t-1}) and a continuous-action Deep Deterministic Policy Gradient (DDPG) actor-critic agent to predict each layer's channel or fine-grained pruning sparsity ratio a_t in (0, 1], evaluates post-pruning validation accuracy without fine-tuning as a fast delegate reward, and supports both Resource-Constrained Compression (via duty-bounded action clamping W_duty = alpha*W_all - action_max*W_rest - W_reduced with R_err = -Error) and Accuracy-Guaranteed Compression (via R_FLOPs = -Error * log(FLOPs) or R_Param = -Error * log(#Param)).
Identity Notes & Concept Scope Distinct from hand-crafted sensitivity pruning heuristics (Li et al., 2016; He et al., 2017) that ignore cross-layer dependencies, distinct from Runtime Neural Pruning (Lin et al., 2017) which selects coarse 4-action dynamic channel groups per input image without reducing static model size, and distinct from HAQ (AIMech:HAQHardwareAwareAutomatedQuantizationWithMixedPrecision) which allocates mixed-precision quantization bitwidths rather than pruning sparsity ratios.

Mechanism #amc-continuous-ddpg-state-and-zero-finetuning-delegate-reward
AMC characterizes each layer L_t by the 11-dimensional state vector s_t = (t, n, c, h, w, stride, k, FLOPs[t], reduced, rest, a_{t-1}) (Eq. 1), predicts a continuous sparsity action a_t in (0, 1] via a DDPG actor with truncated-normal exploration mu'(s_t) ~ TN(mu(s_t | theta_t^mu), sigma^2, 0, 1) (Eqs. 2-3), and evaluates validation accuracy immediately after pruning all layers without fine-tuning as a correlated, zero-retraining proxy for final fine-tuned accuracy.
  • supports Source: AMC: AutoML for Model Compression and Acceleration on Mobile Devices · Locator: Section 3.2 (Automated Compression with Reinforcement Learning), Equations 1-3, pp. 5-6
  • supports Source: AMC: AutoML for Model Compression and Acceleration on Mobile Devices · Locator: amc_duty_constrained_sparsity and main
Mechanism #amc-resource-constrained-duty-clamping-and-accuracy-guaranteed-rewards
For resource-constrained compression, AMC uses reward R_err = -Error (Eq. 4) and enforces the target reduction ratio alpha via Algorithm 1 by bounding each layer's action to [W_duty / W_t, action_max] where W_duty = alpha*W_all - action_max*W_rest - W_reduced; for accuracy-guaranteed compression, AMC uses R_FLOPs = -Error * log(FLOPs) (Eq. 5) or R_Param = -Error * log(#Param) (Eq. 6).
  • supports Source: AMC: AutoML for Model Compression and Acceleration on Mobile Devices · Locator: Section 3.3 (Search Protocols) and Algorithm 1, Equations 4-6, pp. 6-7
  • supports Source: AMC: AutoML for Model Compression and Acceleration on Mobile Devices · Locator: amc_duty_constrained_sparsity and reward_accuracy_guaranteed
Application #amc-imagenet-resnet50-and-mobilenet-mobile-speedup
On ImageNet, AMC pushes ResNet-50 fine-grained compression from 3.4x to 5x without accuracy loss (automatically pruning 3x3 convolutions more aggressively than 1x1 convolutions), improves VGG-16 4x FLOPs pruning by 2.7% over hand-crafted policies, and achieves 1.81x-1.95x measured latency speedup on MobileNet on a Google Pixel 1 Android phone (and 1.53x on Titan XP GPU).
  • supports Source: AMC: AutoML for Model Compression and Acceleration on Mobile Devices · Locator: Section 4.2, Figures 3-5 and Tables 3-5, pp. 9-14
Limitation #amc-multi-stage-iterative-pruning-for-extreme-sparsity-limitation
Under extreme single-shot fine-grained compression (e.g., >=4x sparsity), validation accuracy without retraining collapses and ceases to provide an informative reward signal, requiring a multi-stage iterative prune-and-retrain schedule (e.g., four stages at 50%, 35%, 25%, and 20% density with 30 epochs of fine-tuning per stage).
  • supports Source: AMC: AutoML for Model Compression and Acceleration on Mobile Devices · Locator: Section 4.2 (Push the Limit of Fine-grained Pruning), pp. 9-10

⚠️ Curated Limitations & Negative Results

  • Zero-retraining validation accuracy becomes uninformative under extreme single-shot fine-grained compression ratios (>=4x), requiring multi-stage iterative AMC search and fine-tuning.
  • Fine-grained unstructured pruning policies require specialized sparse-matrix hardware accelerators (such as EIE or SCNN) to translate parameter sparsity into wall-clock inference speedup.
