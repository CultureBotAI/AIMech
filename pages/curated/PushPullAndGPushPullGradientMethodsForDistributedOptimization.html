Push-Pull and G-Push-Pull Gradient Methods for Distributed Optimization

Algorithms AIMech:PushPullAndGPushPullGradientMethodsForDistributedOptimization DRAFT
Aliases: Push-Pull and G-Push-Pull, Push-Pull Distributed Gradient Method, G-Push-Pull
A directed-graph distributed gradient tracking method and its asynchronous gossip extension (Pu, Shi, Xu, & Nedic 2021, Section II, Algorithm 1, Equation 2; Section IV, Algorithm 2) that updates decision variables via a row-stochastic pull matrix R (R 1 = 1) and gradient trackers via a column-stochastic push matrix C (1^T C = 1^T) according to x_{k+1} = R (x_k - alpha y_k) and y_{k+1} = C y_k + nabla F(x_{k+1}) - nabla F(x_k) with y_0 = nabla F(x_0) and uncoordinated diagonal step-size matrix alpha = diag(alpha_1, ..., alpha_n) >= 0.
Identity Notes & Concept Scope Distinct from Push-DIGing (AIMech:DigingAndPushDigingDistributedInexactGradientTrackingOverTimeVaryingGraphs, Nedic, Olshevsky, & Shi 2017), which uses only column-stochastic matrices C(k) for both state and tracker updates and requires maintaining and inverting an auxiliary Push-Sum eigenvector estimate V(k) = diag(v(k)) at every step, whereas Push-Pull combines row-stochastic R (pulling states) and column-stochastic C (pushing trackers) to eliminate eigenvector estimation altogether.

Claims & Grounded Evidence

4 Claims
Mechanism #r438-spanning-tree-root-unification-and-linear-convergence-theorem
Under Assumptions 1-4 — requiring only that the induced digraphs G_R and G_{C^T} share at least one common spanning-tree root i in R_R cap R_{C^T} with positive local step size alpha_i > 0 rather than strong connectivity — the left Perron eigenvector u^T R = u^T and right Perron eigenvector C v = v satisfy u^T v > 0 and effective step size alpha' = (1/n) sum_{i=1}^n u_i v_i alpha_i > 0 (Lemma 1, Remark 4), proving global linear convergence O(rho(A)^k) of both ||bar_x_k - x^*||_2 and ||x_k - 1 bar_x_k||_R while unifying peer-to-peer decentralized, master-slave centralized, and leader-follower semi-centralized architectures (Section II-B, Theorem 1).
  • supports Source: Push-Pull Gradient Methods for Distributed Optimization in Networks · Locator: Section II-B Unification of Different Types of Architecture & Section III Convergence Analysis (Lemma 1, Remark 4, Theorem 1), pp. 3-7
Mechanism #r438-g-push-pull-asynchronous-edge-gossip-linear-convergence
In G-Push-Pull (Section IV, Algorithm 2), randomly waking agents pull state variables from in-neighbors and push scaled tracker updates along active outgoing links using random matrices R_k and C_k with row-stochastic E[R_k] and column-stochastic E[C_k], achieving linear convergence in expectation for strongly convex smooth objectives (Theorem 2).
  • supports Source: Push-Pull Gradient Methods for Distributed Optimization in Networks · Locator: Section IV Gossip-like Push-Pull (G-Push-Pull, Algorithm 2, Theorem 2), pp. 8-11
Limitation #r438-out-degree-knowledge-and-deterministic-gradient-limitation
Constructing the column-stochastic push matrix C requires each agent i to know its out-degree |N_{C,i}^{out}| (or broadcast weights summing to 1 across out-neighbors), and the exact linear convergence rate O(rho(A)^k) requires deterministic local gradients.
  • supports Source: Push-Pull Gradient Methods for Distributed Optimization in Networks · Locator: Section II-A Equation 1 & Section VI Conclusions
Application #r438-directed-network-ridge-and-logistic-regression-application
Applied to distributed ridge regression and l_2-regularized logistic regression over directed cyclic and random networks under decentralized and semi-centralized leader-follower topologies.
  • supports Source: Push-Pull Gradient Methods for Distributed Optimization in Networks · Locator: Section V Numerical Examples (Figures 3-6), pp. 11-13

⚠️ Curated Limitations & Negative Results

  • Requires each agent to know its out-degree in G_C to maintain column-stochasticity of C.
  • Requires exchanging both state variables x_i and gradient trackers y_i per iteration.
