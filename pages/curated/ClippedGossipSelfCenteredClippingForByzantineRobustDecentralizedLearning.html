ClippedGossip Self-Centered Clipping for Byzantine-Robust Decentralized Learning

Algorithms AIMech:ClippedGossipSelfCenteredClippingForByzantineRobustDecentralizedLearning DRAFT
Aliases: ClippedGossip, Self-Centered Clipping, Byzantine-Robust ClippedGossip Decentralized Optimization
A Byzantine-robust decentralized consensus and stochastic optimization algorithm on an arbitrary communication graph G = (V, E) with regular nodes V_R (whose induced subgraph G_R has spectral gap gamma > 0) and Byzantine nodes V_B controlling adjacent mixing weight delta_i = sum_{j in V_B} W_{ij} <= delta_max around regular node i, in which each regular worker i updates local momentum m_i^{t+1} = (1 - alpha) m_i^t + alpha g_i(x_i^t), takes a half-step x_i^{t+1/2} = x_i^t - eta m_i^{t+1}, and aggregates neighbor models by clipping received vectors around its own local reference iterate x_i^{t+1/2} as x_i^{t+1} = sum_{j=1}^n W_{ij} (x_i^{t+1/2} + CLIP(x_j^{t+1/2} - x_i^{t+1/2}, tau_i^{t+1})) with CLIP(z, tau) = min(1, tau / ||z||_2) z.
Identity Notes & Concept Scope Distinct from server-based Byzantine clipping and bucketing aggregators (such as AIMech:BucketingForAgnosticByzantineRobustAggregationOnHeterogeneousDatasets and AIMech:CrflCertifiablyRobustFederatedLearningViaParameterClippingAndSmoothing) and from decentralized coordinate-wise trimmed-mean / median / Krum screening in BRIDGE (AIMech:BridgeByzantineResilientDecentralizedGradientDescent): ClippedGossip (also termed Self-Centered Clipping; He, Karimireddy, & Jaggi, 2022) clips each neighbor j's model relative to node i's own trusted state x_i^{t+1/2} weighted by doubly stochastic mixing weights W_{ij}, eliminating the requirement of an honest majority in every node's neighborhood and preserving information diffusion across sparse graph cuts (such as a dumbbell bridge) where coordinate-wise trimmed mean and geometric median stall.

Mechanism #clippedgossip-self-centered-consensus-contraction
By centering the clipping ball of radius tau_i = sqrt((1 / delta_i) sum_{j in V_R} W_{ij} E||x_i - x_j||_2^2) at node i's own model x_i and averaging z_{j->i} = x_i + CLIP(x_j - x_i, tau_i) with mixing weights W_{ij}, ClippedGossip contracts the average consensus variance Xi^t = (1 / |V_R|) sum_{i in V_R} E||x_i^t - x_bar^t||_2^2 <= (1 - gamma + c sqrt(delta_max))^2 rho^2 and bounds the mean shift by E||x_bar^{t+1} - x_bar^t||_2^2 <= c^2 delta_max rho^2 whenever delta_max < gamma^2 / c^2 (Theorem I, Theorem I', Eq. 24).

Scope #clippedgossip-nonconvex-spectral-gap-convergence-and-impossibility
For L-smooth non-convex objectives with bounded stochastic gradient variance sigma^2, inter-worker heterogeneity zeta^2, and Byzantine edge weight delta_max = O(gamma^2), ClippedGossip with local momentum alpha = 3 eta L reaches an O(delta_max zeta^2 / gamma^2) + epsilon stationary point in O((sigma^2 / (n epsilon^2))(1/n + delta_max) + zeta / (gamma epsilon^{3/2}) + sigma^{2/3} / (gamma^{2/3} epsilon^{4/3}) + 1 / (gamma epsilon)) iterations (Theorem III), matching the fundamental Omega(1) consensus impossibility lower bound on sparse cut-set topologies (Theorem II).

Limitation #clippedgossip-spectral-gap-threshold-and-dissensus-limitation
When the communication graph has a small spectral gap gamma relative to the maximum Byzantine edge weight delta_max (such that delta_max >= Omega(gamma^2)), Byzantine nodes launching a topology-aware dissensus attack x_j = x_i - eps_i (sum_{k in N_i cap V_R} W_{ik}(x_k - x_i)) / (sum_{j in N_i cap V_B} W_{ij}) across a graph bottleneck can block global consensus across components.

⚠️ Curated Limitations & Negative Results

  • Requires the maximum Byzantine edge weight delta_max to satisfy delta_max = O(gamma^2) relative to the spectral gap gamma of the regular subgraph G_R to guarantee global consensus contraction.
  • Under non-i.i.d. data heterogeneity zeta^2 > 0, converges to an O(delta_max zeta^2 / gamma^2) stationary neighborhood that grows inversely with the squared spectral gap gamma^2.
