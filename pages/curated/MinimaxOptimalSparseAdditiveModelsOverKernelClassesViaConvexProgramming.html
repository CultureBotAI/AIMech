Minimax-Optimal Sparse Additive Models Over Kernel Classes via Convex Programming

Mathematical Methods AIMech:MinimaxOptimalSparseAdditiveModelsOverKernelClassesViaConvexProgramming DRAFT
Aliases: Minimax-Optimal Rates for Sparse Additive Models Over Kernel Classes via Convex Programming (Raskutti, Wainwright, & Yu 2012), Doubly-Penalized (L2(Q_n), 1) and (H, 1) Second-Order Cone Program Sparse Additive Kernel Estimator, High-Dimensional RKHS Sparse Additive Model Minimax Rate and Global Boundedness Separation Framework, Raskutti-Wainwright-Yu Sparse Additive Kernel M-Estimator
Minimax-Optimal Sparse Additive Models Over Kernel Classes via Convex Programming is a non-parametric high-dimensional estimation and minimax analysis methodology introduced by Raskutti, Wainwright, and Yu (2012, Journal of Machine Learning Research 13:389-427, arXiv:1008.3654v2) for estimating s-sparse d-variate additive regression functions f*(x_1, ..., x_d) = sum_{j in S} f*_j(x_j) (|S| = s << d) over the class F_{d, s, H} = cup_{|S|=s} H(S) where each zero-mean univariate component f*_j belongs to the unit ball B_{H_j}(1) of a reproducing kernel Hilbert space (RKHS) H_j subset L^2(Q) with bounded univariate functions ||f_j||_infty <= c ||f_j||_H (Equations 5-6, 15). Given n i.i.d. observations y_i = mu + f*(x_i) + w_i (x_i ~ P = Q^d, w_i ~ N(0, 1)), the method minimizes the doubly-penalized least-squares cost functional L(f) = (1/(2n)) sum_{i=1}^n (y_i - y_bar_n - f(x_i))^2 + lambda_n ||f||_{n, 1} + rho_n ||f||_{H, 1} subject to f = sum_{j=1}^d f_j and ||f_j||_H <= 1 (Equations 8-10), combining an empirical (L^2(Q_n), 1) sparsity penalty ||f||_{n, 1} := sum_{j=1}^d ||f_j||_n with a Hilbert (H, 1) smoothness penalty ||f||_{H, 1} := sum_{j=1}^d ||f_j||_H, which reduces by the representer theorem to a polynomial-time second-order cone program (SOCP) in (R^n)^d over empirical kernel matrices K^j in R^{n x n} (Equation 11). In terms of the critical univariate rate nu_n > 0 solving 40 nu_n^2 >= Q_{sigma, n}(nu_n) := (1/sqrt(n)) [sum_{l=1}^infty min{nu_n^2, mu_l}]^{1/2} (Equations 12-13) and gamma_n := kappa max{nu_n, sqrt((log d)/n)} (Equation 14), Theorem 1 (Equation 16) and Theorem 2 (Equations 22-23) establish matching minimax upper and lower bounds M_P(F_{d, s, H}) = Theta((s log d)/n + s nu_n^2) in both L^2(P) and L^2(P_n) norms without requiring global boundedness of multivariate functions in F_{d, s, H}, while Theorem 3 and Corollary 3 (Equations 25-27) prove that imposing a global sup-norm bound ||f||_infty <= B over F*_{d, s, H}(B) strictly accelerates the minimax rate by a factor K_B(s, n) -> 0 whenever s = Omega(sqrt(n)).

Mechanism #doubly-penalized-socp-estimator-and-unbounded-rkhs-minimax-upper-bounds
For any additive function f = sum_{j=1}^d f_j with f_j in B_{H_j}(1) subset L^2(Q), the regularized M-estimator (Equations 8-10) minimizes L(f) = (1/(2n)) sum_{i=1}^n (y_i - y_bar_n - f(x_i))^2 + lambda_n sum_{j=1}^d ||f_j||_n + rho_n sum_{j=1}^d ||f_j||_H subject to ||f_j||_H <= 1 for all j = 1, ..., d. By the representer theorem, f_hat(z_1, ..., z_d) = sum_{i=1}^n sum_{j=1}^d alpha_hat_{ij} K^j(z_j, x_{ij}), reducing (10) to the polynomial-time second-order cone program (SOCP) in Equation (11) over weights alpha_j in R^n with alpha_j^T K^j alpha_j <= 1. Letting nu_n > 0 be the smallest positive root of 40 nu_n^2 >= Q_{sigma, n}(nu_n) := (1/sqrt(n)) [sum_{l=1}^infty min{nu_n^2, mu_l}]^{1/2} (Equations 12-13) and gamma_n := kappa max{nu_n, sqrt((log d)/n)} (Equation 14), for regularization parameters lambda_n >= 16 gamma_n and rho_n >= 16 gamma_n^2: (1) Lemma 1 (p. 15, Equation 30; proved via Gaussian concentration and peeling in Appendix B, pp. 24-27) bounds |(1/n) sum_{i=1}^n w_i Delta_hat_j(x_{ij})| <= 8 gamma_n^2 ||Delta_hat_j||_H + 8 gamma_n ||Delta_hat_j||_n uniformly over j = 1, ..., d; (2) Lemma 2 (p. 15, Equation 33; proved in Appendix C, p. 28) exploits decomposability of ||.||_{n, 1} and ||.||_{H, 1} to restrict the error Delta_hat = f_hat - f* to lambda_n ||Delta_hat||_{n, 1} + rho_n ||Delta_hat||_{H, 1} <= 4 lambda_n ||Delta_hat_S||_{n, 1} + 4 rho_n ||Delta_hat_S||_{H, 1} + (1/2) s gamma_n^2; and (3) Lemma 3 (p. 17, Equation 42; proved in Appendix D, pp. 29-31, by bounding E[g^4(x)] <= 4 delta_tilde_n^2 + 6 delta_tilde_n^4 <= 10 delta_tilde_n^2 across independent zero-mean components and applying Chung-Lu one-sided concentration with Sudakov minoration) certifies ||g||_n^2 >= ||g||_2^2 / 2 without global boundedness. Theorem 1 (p. 8, Equation 16) proves P[max{||f_hat - f*||_2^2, ||f_hat - f*||_n^2} >= C(s lambda_n^2 + s rho_n)] <= c_1 exp(-c_2 n gamma_n^2), yielding O((s log d)/n + s m / n) for rank-m kernels (Corollary 1, Equation 17) and O((s log d)/n + s n^{-2 alpha / (2 alpha + 1)}) for Sobolev kernels with mu_k ~ k^{-2 alpha}, alpha > 1/2 (Corollary 2, Equation 18).

Mechanism #sparse-additive-packing-entropy-and-matching-minimax-lower-bounds
For the sparse additive function class F_{d, s, H} with sparsity s <= d/4, Lemma 4 (Section 4.2.2, p. 19, Equations 45-46; proved in Appendix E, pp. 31-33, by constructing an (N+1)-ary Hamming code over S = {u in {0, 1, ..., N}^d : ||u||_0 = s} with pairwise Hamming distance >= s/2 and cardinality N* >= (1/2) ((d - s)/(s/2))^{s/2} N^{s/2} where N = M(delta / sqrt(s); B_H(1), ||.||_2) - 1) proves that the L^2(P) packing entropy of F_{d, s, H} scales as log M(delta; F_{d, s, H}, ||.||_2) = Theta(s log(d/s) + s log M(delta / sqrt(s); B_H(1), ||.||_2)). Combining Lemma 4 with generalized Fano mutual-information bounds (for logarithmic univariate metric entropy log M(epsilon; B_H(1), L^2(P)) ~ m log(1/epsilon), Equation 20) and Yang-Barron covering-entropy mutual-information bounds (for polynomial univariate metric entropy log M(epsilon; B_H(1), L^2(P)) ~ (1/epsilon)^{1/alpha}, Equation 21), Theorem 2 (Section 3.3, p. 10, Equations 22-23; proved in Sections 4.2.3-4.2.4, pp. 19-21) establishes that with probability greater than 1/2, the minimax L^2(P) risk M_P(F_{d, s, H}) := inf_{f_hat} sup_{f* in F_{d, s, H}} ||f_hat - f*||_2^2 is lower bounded by C {(s log(d/s))/n + s m / n} for rank-m classes and C {(s log(d/s))/n + s (1/n)^{2 alpha / (2 alpha + 1)}} for alpha-smooth Sobolev classes, matching Corollaries 1 and 2 up to constant factors throughout the sub-linear sparsity regime log d = O(log(d/s)).

Scope #global-boundedness-effective-dimension-reduction-and-minimax-rate-acceleration
When the additional global uniform boundedness condition sup_{f in F*_{d, s, H}(B)} ||f||_infty <= B (with B independent of s and d, as assumed in Koltchinskii & Yuan 2010) is imposed on sparse additive models over a Sobolev RKHS H with eigenvalues mu_k ~ k^{-2 alpha} (alpha > 1/2) and uniformly bounded eigenfunctions ||phi_k||_infty <= C, Lemma 10 (Appendix F, p. 33) exploits ||f||_infty = sum_{j in S} ||f_j||_infty on product domains to prove that the truncated Fourier coefficients satisfy sum_{j in S} sum_{k=1}^M |a_{j, k}| <= B sqrt(M), and Lemma 11 (p. 34, setting M = s^{1/alpha}) bounds the local Gaussian complexity over H(S, 2B) by 8 B C sqrt((s^{1/alpha} log s)/n). Defining delta_n := max{sqrt((s log(d/s))/n), B^{1/2} ((s^{1/alpha} log s)/n)^{1/4}} (Equation 25) and K_B(s, n) := B sqrt(log s) (s^{-1/(2 alpha)} n^{1/(4 alpha + 2)})^{2 alpha - 1} (Equation 26), Theorem 3 (Section 3.5, p. 12, Equation 27; proved in Section 4.3, pp. 21-22, via Lemmas 5-6) proves M_P(F*_{d, s, H}(B)) <= kappa^2 (1 + B) C s n^{-2 alpha / (2 alpha + 1)} (K_B(s, n) + n^{-1/(2 alpha + 1)} log(d/s)) with probability at least 1 - 2 exp(-c_1 n delta_n^2). Because K_B(s, n) -> 0 whenever s = Omega(sqrt(n)), Corollary 3 (p. 13) proves M_P(F_{d, s, H}) / M_P(F*_{d, s, H}(B)) -> +infty (for example, when alpha = 2 and s = Theta(n^{4/5}), M_P(F_{d, s, H}) = Omega(1) fails to vanish whereas M_P(F*_{d, s, H}(B)) = O(n^{-1/5} sqrt(log n)) -> 0), demonstrating that global boundedness is a stringent high-dimensional restriction.

⚠️ Curated Limitations & Negative Results

  • Independence Assumption Across Covariates and Additive Univariate Decomposition: As noted in Section 2.2 (p. 5) and Section 5 (p. 23), the L^2(P) norm decoupling ||f||_{L^2(P)}^2 = sum_{j=1}^d ||f_j||_{L^2(Q)}^2 and the fourth-moment expansion in Lemma 3 (Appendix D, p. 30) rely on the product-measure assumption P = Q^d (independent covariates x_1, ..., x_d) and purely univariate additive components without higher-order interaction hierarchies.
  • Univariate Sup-Norm Boundedness Condition: As stated in Section 3.2 (p. 8, Equation 15), Theorem 1 requires each function in the univariate RKHS unit ball B_H(1) to satisfy ||f_j||_infty <= c ||f_j||_H (which holds whenever the univariate kernel K is uniformly bounded on X x X), though it avoids any global sup-norm bound on the s-sparse sum f = sum_{j in S} f_j.
