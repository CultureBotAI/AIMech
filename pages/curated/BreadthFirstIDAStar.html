Breadth-first iterative-deepening A-star

Algorithms AIMech:BreadthFirstIDAStar DRAFT
Aliases: BFIDA*, Breadth-first iterative-deepening A*
An iterative-deepening heuristic graph-search algorithm that repeatedly runs breadth-first branch-and-bound within increasing hypothetical f=g+h cost bounds, beginning at the start-state f value, until a solution is found; the curated formulation uses unit edge costs and a nonnegative admissible heuristic with h(goal)=0.
Identity Notes & Concept Scope BFIDA* changes the inner traversal of cost-contour iterative deepening to breadth-first branch-and-bound. It is distinct from depth-first IDA*, depth-limited iterative-deepening DFS, and a single BFBnB search with a supplied incumbent bound. The memory implementation can use frontier or layered duplicate handling. Mechanism #search-procedure
Set T=f(start). Run breadth-first branch-and-bound admitting nodes with f≤T. If no goal is reached, restart with a larger T, such as the least f value excluded on the preceding pass; the paper also describes increments of one in its unit-cost setting. Repeat until a solution is found. Breadth-first traversal, admissible pruning and sufficient resources preserve a minimum-cost solution in this uniform-cost setting.

Limitation #analysis-conditions
The expansion-count theorems depend on growth assumptions, while breadth-first traversal restricts beneficial tie-breaking within a contour. Memory remains governed by the retained search frontier and duplicate-detection strategy.

⚠️ Curated Limitations & Negative Results

  • The hypothetical threshold is inclusive. Reusing strict incumbent pruning at T=f(start) without a retained solution would be a different procedure.
  • This method repeats breadth-first contours and retains frontier/duplicate information; it does not inherit the path-linear storage of depth-first IDA*.
  • The asymptotic node-expansion analysis assumes exponential growth of distinct nodes per iteration; the directed-graph result additionally constrains solution depth relative to stored layers. It is not an unconditional wall-clock optimum.
  • Large layers and tie contours can still be costly. Solvable finite-depth cases require sufficient memory; no universal termination guarantee on infinite unsolvable graphs is asserted.
