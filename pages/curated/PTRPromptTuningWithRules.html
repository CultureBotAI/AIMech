PTR Prompt Tuning with Rules

Algorithms AIMech:PTRPromptTuningWithRules DRAFT

Aliases: PTR, Prompt Tuning with Rules, Rule-Based Sub-Prompt Composition for Prompt Tuning, Conjunctive Normal Form Sub-Prompt Tuning
A prompt-tuning method for many-class text and relation classification that decomposes each target class y in Y into a conjunctive normal form (CNF) combination of first-order logic conditional functions f in F (such as unary entity-type predicates f_{e_s}(x, type), f_{e_o}(y, type) and binary relational predicates f_{e_s, e_o}(x, rel, y)), aggregates their sub-prompt templates into a multi-mask prompt T(x) = [T_{f_1}(x); ...; T_{f_n}(x)] optionally augmented with learnable continuous tokens, and optimizes the joint log-likelihood across all n masked positions: (1/|X|) sum_{x in X} log prod_{j=1}^n p([MASK]_j = phi_j(y) | T(x)).

Identity Notes & Concept Scope Distinct from single-mask prompt tuning methods such as PET (AIMech:PatternExploitingTraining), LM-BFF (AIMech:LMBFFBetterFewShotFineTuning), and KPT (AIMech:KPTKnowledgeablePromptTuningVerbalizer), which predict a single [MASK] position and cannot factorize many-class relation labels into composable entity-type and relational sub-prompts, and from TYP MARKER fine-tuning (Zhou & Chen, 2021), which requires gold human entity-type annotations and an extra task-specific classification layer.

Claims & Grounded Evidence

4 Claims
Mechanism #r724-claim-cnf-subprompt-composition
PTR formalizes many-class classification as a conjunction of unary and binary conditional functions—for example, decomposing 'person:parent' vs. 'organization:parent' into f_{e_s}(e_s, person/organization) AND f_{e_s,e_o}(e_s, 's parent was, e_o) AND f_{e_o}(e_o, person/organization)—and concatenates their sub-prompts into a template with n = 3 [MASK] tokens whose position-specific verbalizer probabilities phi_j(y) are multiplied: p(y|x) = prod_{j=1}^n p([MASK]_j = phi_j(y) | T(x)).
  • supports Source: PTR: Prompt Tuning with Rules for Text Classification · Locator: Section 3.1-3.3, Equations 1-6, Figure 2, Table 2, pp. 3-6
Mechanism #r724-claim-zero-extra-layer-or-type-annotation
Unlike entity-marker and typed-marker fine-tuning baselines that require gold human entity-type annotations and additional classification head parameters, PTR stimulates latent entity-type and relational knowledge directly through the pretrained MLM head using only PLM vocabulary label words and a small number of learnable continuous template tokens.
  • supports Source: PTR: Prompt Tuning with Rules for Text Classification · Locator: Section 3.3 & Section 4.4, Table 5, pp. 5, 7-8
Application #r724-claim-relation-extraction-application
On four many-class relation classification benchmarks (42-class TACRED, 42-class TACREV, 40-class ReTACRED, and 19-class SemEval 2010 Task 8) with RoBERTa-large, PTR achieves 72.4% (75.9% reversed), 81.4% (83.9% reversed), 90.9% (91.9% reversed), and 89.9% F1 respectively, outperforming knowledge-enhanced PLMs (SpanBERT, KnowBERT, MTB, LUKE) without external pre-training data and surpassing Typed Marker baselines in few-shot (K=8, 16, 32) regimes.
  • supports Source: PTR: Prompt Tuning with Rules for Text Classification · Locator: Section 4.3-4.4, Tables 4-6, Figure 3, pp. 6-9
Limitation #r724-claim-direction-sensitivity-limitation
PTR performance is highly sensitive to relation directionality and surface phrasing in sub-prompts—reversing inverse relations (such as converting (e_s, org:member_of, e_o) to (e_o, org:member, e_s)) changes TACRED F1 by 3.5 percentage points (from 72.4% to 75.9%) because pretrained language models do not encode bidirectional relations symmetrically—and requires manual domain decomposition of classes into logical predicates.
  • supports Source: PTR: Prompt Tuning with Rules for Text Classification · Locator: Section 4.2, Section 4.5, and Section 6, Table 7, pp. 6, 9-10

⚠️ Curated Limitations & Negative Results

  • Sensitive to directional asymmetry in pretrained language model representations: without manually reversing inverse relations (e.g., org:member_of), TACRED F1 is 3.5 points lower (72.4% vs. 75.9%), slightly trailing full-data Typed Marker fine-tuning (74.6%) when gold entity types are available.
  • Requires human domain knowledge to decompose target classes into conjunctive normal form predicates and sub-prompt label words.
