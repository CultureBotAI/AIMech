Pi-model

Algorithms AIMech:PiModel DRAFT
Aliases: Π-model
A semi-supervised classifier-training procedure that combines labeled cross-entropy with squared disagreement between two stochastic predictions of the same input from a shared-parameter network, propagating gradients through both predictions.
Identity Notes & Concept Scope The Greek Π notation is an identity alias for the Pi-model in Laine and Aila, not the generic AIO Model class. Its two contemporaneous stochastic predictions and two-sided gradient differ from temporal ensembling’s stored predictions, Mean Teacher’s weight-averaged stopped-gradient teacher, and SimSiam’s asymmetric stopped-gradient representation targets. This record describes a training algorithm, not a trained checkpoint or fixed network architecture. The inspected AIO SemiSupervisedLLM class specifically combines LLM pretraining with supervised fine-tuning; its related synonym self-training is not an exact identity for this method. AIO SelfsupervisedLearning excludes human-annotated labels, Distillation describes large-to-small compression, and RegularizationLayer is a layer: none supplies an equivalent class for this algorithm. Claims & Grounded Evidence

1 Claim
Mechanism #method
For each minibatch B, run each input twice through the same classifier parameters with independently sampled input augmentation and network noise, producing C-class probability vectors z_i and z_tilde_i. Minimize −(1/|B|) sum over labeled i in B of log z_i[y_i], plus w(t)/(C|B|) times sum over all i in B of ||z_i−z_tilde_i||². Algorithm 1 normalizes the labeled sum by the complete minibatch size, not the number of labeled examples. Both prediction branches contribute gradients to the shared parameters. Start the consistency weight at zero and ramp it up; the reported Gaussian schedule is an experimental choice. There is no persistent per-example target or separately EMA-updated teacher in this core procedure.

⚠️ Curated Limitations & Negative Results

  • The consistency objective assumes the chosen perturbations should preserve class identity; incorrect augmentations can impose inappropriate targets.
  • Agreement alone does not identify the correct classes; the stated classifier objective includes labeled cross-entropy and a consistency-weight ramp.
  • Architecture, augmentation strength, batch composition and weight schedule affect the instantiated training procedure; no accuracy improvement or universal schedule is asserted.
  • Only the declared source pages were inspected; this record does not claim a complete implementation or benchmark reproduction.
