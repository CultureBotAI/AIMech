AltMinPhase and SparseAltMinPhase (Resampled Alternating Minimization for Phase Retrieval)

Algorithms AIMech:AltMinPhaseAndSparseAltMinPhaseAlternatingMinimizationPhaseRetrieval DRAFT
Aliases: AltMinPhase (Alternating Minimization for Phase Retrieval), SparseAltMinPhase (Sparse Phase Retrieval via Alternating Minimization and CoSaMP), Netrapalli-Jain-Sanghavi Alternating Minimization Phase Retrieval
The first non-convex alternating minimization algorithm with provable global geometric convergence for phase retrieval and sparse phase retrieval (introduced by Praneeth Netrapalli, Prateek Jain, and Sujay Sanghavi in 2013/2015). Given magnitude measurements $y_i = |\langle a_i,x^*\rangle|$ ($i=1,\dots,m$), reformulating the measurement model with a diagonal unit-modulus phase matrix $C^* = \mathrm{diag}(\mathrm{Ph}(A x^*))$ yields $\min_{|C_{ii}|=1, x\in\mathbb{C}^n}\|A x - C y\|_2$ (Equation 1). *AltMinPhase* (Algorithm 1) initializes $x^0$ as the scaled leading eigenvector of the weighted covariance matrix $Y = \frac{1}{m}\sum_{\ell=1}^m y_\ell^2 a_\ell a_\ell^*$ (whose expectation $\mathbb{E}[Y] = \|x^*\|_2^2(I + 2\frac{x^*(x^*)^*}{\|x^*\|_2^2})$ has spectral gap 3 vs. 1), and at each iteration $t=0,\dots,T-1$ alternates between exact phase projection $C^{t+1} = \mathrm{diag}(\mathrm{Ph}(A^{(t+1)} x^t))$ and least-squares signal estimation $x^{t+1} = \arg\min_{x\in\mathbb{C}^n}\|A^{(t+1)} x - C^{t+1} y^{(t+1)}\|_2$ on a fresh sample batch $(A^{(t+1)},y^{(t+1)})$. By decomposing the true measurements as $y_i = c_i^*(a_i^\top x^*) = c_i^*(\alpha_t a_i^\top x^t - a_i^\top w^t)$ ($\langle x^t,w^t\rangle = 0$, $\|w^t\|_2 = \sqrt{1-\alpha_t^2}$), Lemma 4.3 proves that the phase-error vector $v_i^t = (c_i^t - c_i^*)y_i$ satisfies $\frac{1}{m}\|(A^{(t+1)})^* v^t\|_2 \le \frac{1}{2}\|w^t\|_2$ when $\mathrm{dist}(x^t,x^*) \le 1/6$, establishing per-step contraction $\mathrm{dist}(x^{t+1},x^*) \le \frac{3}{4}\mathrm{dist}(x^t,x^*)$ (Theorem 2.1) with $m = O(n\log^3 n(\log n + \log(1/\epsilon)))$ measurements. For $k$-sparse signals $x^*$, *SparseAltMinPhase* (Algorithm 2) selects support $\hat{S}$ from the top-$k$ marginal energy coordinates $\sum_{\ell=1}^m y_\ell^2 |a_{\ell j}|^2$ (whose gap separates $j\in S$ from $j\notin S$ whenever $|x_j^*| \ge \frac{C}{\sqrt{k}}\|x^*\|_2$, Lemma 5.1) or replaces least squares by CoSaMP, achieving $O((k^2\log n + k\log n\log(1/\epsilon)))$ sample complexity (Theorems 2.2–2.3).
Identity Notes & Concept Scope Resolved against all 442 pinned AIO concepts and 700 maintained AIMech concepts. Distinct from `AIMech:PhaseLiftConvexSemidefiniteProgrammingPhaseRetrieval` (Candes, Strohmer, & Voroninski 2013, which lifts $x^*\in\mathbb{C}^n$ to an $n\times n$ PSD matrix $X = x x^*$ solved by convex SDP in $O(n^3)$ per-step cost) and `AIMech:TruncatedAmplitudeFlowAndOrthogonalityPromotingInitializationForQuadraticEquations` (Wang, Giannakis, & Eldar 2018, which performs single-pool truncated subgradient steps on amplitude loss rather than alternating exact phase projection $C^{t+1}$ and exact least-squares/CoSaMP minimization across resampled batches).

Mechanism #claim-spectral-initialization-and-alternating-phase-least-squares-contraction
For Gaussian measurements $a_\ell\sim\mathcal{N}(0,I)$, the weighted covariance matrix $Y = \frac{1}{m}\sum_{\ell=1}^m y_\ell^2 a_\ell a_\ell^*$ has expectation $\mathbb{E}[Y] = \|x^*\|_2^2(I + 2\frac{x^*(x^*)^*}{\|x^*\|_2^2})$ so its top eigenvector $x^0$ achieves $\mathrm{dist}(x^0,x^*) \le c_0 < 1/6$ with $m_0 = O(n\log^3 n)$ samples (Lemma 4.1); from any iterate with $\|w^t\|_2 = \sqrt{1 - |\langle x^t,x^*\rangle|^2} \le 1/6$, the exact least-squares update $x^{t+1} = ((A^{(t+1)})^* A^{(t+1)})^{-1}(A^{(t+1)})^* C^{t+1} y^{(t+1)}$ satisfies $x^{t+1} = \alpha_t x^* - w^t + ((A^{(t+1)})^* A^{(t+1)})^{-1}(A^{(t+1)})^* v^t$ where the phase-disagreement indicator $\mathbf{1}_{c_i^t c_i^* = -1}$ occurs only when $|a_i^\top w^t| \ge \alpha_t|a_i^\top x^t|$, bounding $\frac{1}{m}\|(A^{(t+1)})^* v^t\|_2 \le \frac{1}{2}\|w^t\|_2$ (Lemma 4.3) and proving $\mathrm{dist}(x^{t+1},x^*) \le \frac{3}{4}\mathrm{dist}(x^t,x^*)$ (Theorem 2.1 & Lemma 4.2).

Mechanism #claim-sparse-altminphase-marginal-support-selection-and-cosamp-refinement
For a $k$-sparse vector $x^*\in\mathbb{R}^n$ with support $S = \mathrm{supp}(x^*)$, the marginal fourth-moment statistics $Z_j = \frac{1}{m}\sum_{\ell=1}^m y_\ell^2 |a_{\ell j}|^2$ satisfy $\mathbb{E}[Z_j] = \|x^*\|_2^2 + 2|x_j^*|^2$, so selecting the $k$ largest $Z_j$ exactly recovers $S$ using $m = O(k^2\log n)$ samples when $\min_{j\in S}|x_j^*| \ge \frac{C}{\sqrt{k}}\|x^*\|_2$ (Theorem 2.2 & Lemma 5.1); for arbitrary $k$-sparse signals without a minimum non-zero entry bound, *SparseAltMinPhase* (Algorithm 2) initializes on the active support of high-magnitude coordinates and replaces the least-squares step by $x^{t+1} = \mathrm{CoSaMP}(A^{(t+1)}/\sqrt{m}, C^{t+1} y^{(t+1)}/\sqrt{m}, k)$, achieving $\|x^T - c x^*\|_2 \le \epsilon\|x^*\|_2$ with $m = O(k^2\log n + k\log n\log(1/\epsilon))$ samples (Theorem 2.3 & Lemma 5.3).

Scope #claim-noise-robustness-and-quadratic-computational-scaling
Under noisy magnitude measurements $y = |A x^* + \eta|$ with $\|\eta\|_\infty \le \frac{\|x^*\|_2}{100\sqrt{n}}$ and $\|\eta\|_2 \le \frac{\sqrt{m}\|x^*\|_2}{100}$, Theorem 4.4 proves that AltMinPhase achieves $\mathrm{dist}(x^T,x^*) \le \epsilon + \frac{4\|\eta\|_2}{\sqrt{m}\|x^*\|_2}$ in $O(n^2\log^3 n(\log n + \log^2(1/\epsilon)))$ total arithmetic operations — quadratically faster in dimension $n$ than the $O(n^3/\epsilon^2)$ interior-point/first-order complexity of semidefinite programming relaxations such as PhaseLift.
  • supports Source: Phase Retrieval using Alternating Minimization · Locator: Section II, Table 1, p. 6; Section IV-A, Theorem 4.4, pp. 12-13
Limitation #claim-limitation-sample-splitting-polylog-overhead-and-quadratic-sparse-bottleneck
The theoretical proof of AltMinPhase relies on fresh independent measurement batches $(A^{(t+1)},y^{(t+1)})$ at each iteration to decouple $x^t$ from $A^{(t+1)}$, incurring an extra $O(\log^3 n\log(1/\epsilon))$ sample factor over the information-theoretic $O(n)$ threshold, while SparseAltMinPhase requires $m = \Omega(k^2\log n)$ samples for fourth-moment support identification rather than the information-theoretic $O(k\log(n/k))$ limit.
  • supports Source: Phase Retrieval using Alternating Minimization · Locator: Section II, Remarks on Theorem 2.1 & Theorem 2.3, pp. 4-6; Section VI Conclusions, p. 17

⚠️ Curated Limitations & Negative Results

  • Theoretical convergence analysis uses sample-splitting across $T = O(\log(1/\epsilon))$ disjoint measurement batches (requiring $m = O(n\log^3 n(\log n + \log(1/\epsilon)))$ i.i.d. Gaussian measurements), and sparse support initialization requires $m = \Omega(k^2\log n)$ samples.
