SPoT (Soft Prompt Transfer)

Algorithms AIMech:SPoTSoftPromptTransfer DRAFT
Aliases: Soft Prompt Transfer, SPoT Prompt Transfer, Targeted Soft Prompt Transfer with Prompt-Based Task Embeddings
A parameter-efficient prompt-based transfer learning methodology for frozen pre-trained language models that introduces an intermediate source prompt tuning stage to learn a continuous soft prompt on one or more source tasks and uses it to initialize target prompt tuning, coupled with a prompt-library retrieval algorithm that interprets early-checkpoint task prompts as task embeddings and ranks candidate source tasks via token cosine similarity.
Identity Notes & Concept Scope Introduced by Tu Vu, Brian Lester, Noah Constant, Rami Al-Rfou, and Daniel Cer (ACL 2022, arXiv:2110.07904). Distinct from vanilla Prompt Tuning (Lester et al., EMNLP 2021; AIMech Round 675), which initializes soft prompts from sampled vocabulary or class-label tokens directly on each target task without cross-task prompt transfer or prompt-based task embedding retrieval. Both generic SPoT (transferring a single multi-task or single-task source prompt to all target tasks) and targeted SPoT (retrieving top-k source prompts from a prompt library via Average-Token or Per-Token Average Cosine Similarity of 10K-step prompt checkpoints using Best of Top-k, Top-k Weighted Average, or Top-k Multi-task Mixture) are lumping-cohesive variants within this single record.

Claims & Grounded Evidence

4 Claims
Mechanism #spot-source-prompt-tuning-mechanism
SPoT introduces source prompt tuning as an intermediate stage between pre-training and target prompt tuning that optimizes a shared continuous prompt matrix rho in R^{L x E} (L = 100 tokens) prepended to embedded inputs while keeping the base model frozen, using the learned source prompt to initialize target prompt tuning and achieving +10.1 and +2.4 point average SuperGLUE accuracy gains over vanilla Prompt Tuning on T5 Base (220M) and T5 XXL (11B), matching or exceeding full ModelTuning across all model scales while tuning 27,000x fewer task-specific parameters (410K vs. 11B).

Mechanism #spot-task-embedding-similarity-mechanism
To predict task transferability without brute-force search, SPoT defines a task's embedding e^t as its prompt checkpoint after 10,000 prompt-tuning steps and measures similarity between tasks t^1, t^2 via either Cosine Similarity of Average Tokens sim(t^1, t^2) = cos((1/L) sum_i e^1_i, (1/L) sum_j e^2_j) or Per-token Average Cosine Similarity sim(t^1, t^2) = (1/L^2) sum_i sum_j cos(e^1_i, e^2_j), exploiting the ranked source prompts via Best of Top-k, Top-k Weighted Average sum_{r=1}^k alpha_r rho^{s_r} with alpha_r = sim(e^{s_r}, e^t) / sum_{l=1}^k sim(e^{s_l}, e^t), or Top-k Multi-task Mixture to eliminate 69% of the candidate source space while retaining 90% of the oracle transfer quality gain.
  • supports Source: SPoT: Better Frozen Model Adaptation through Soft Prompt Transfer · Locator: Section 3 Predicting task transferability, p. 5; Section 3.2 Defining task similarity through prompts, pp. 6-7; Section 3.3 Predicting transferability via similarity & Table 3, pp. 7-8
Application #spot-nlp-benchmark-application
Applied across GLUE, SuperGLUE, and a 26-task (160 source-target pair) transferability study spanning natural language inference, question answering, paraphrase/semantic similarity, sentiment analysis, and commonsense reasoning, where transferring MNLI -> CB reduces relative error by 58.9% (92.7 to 97.0) and Frozen T5 1.1 XXL + SPoT achieves 89.2 on the SuperGLUE test leaderboard.
  • supports Source: SPoT: Better Frozen Model Adaptation through Soft Prompt Transfer · Locator: Section 3.1 Measuring transferability, Table 2 & Figure 3, pp. 5-6; Appendix D Table 5, p. 17; Appendix E Tables 6-7, p. 19
Limitation #spot-negative-transfer-and-similarity-limitation
Mixing all source datasets indiscriminately (C4 + 55 supervised tasks) underperforms selective source mixtures such as GLUE due to task interference and negative transfer, and prompt-based task embedding cosine similarity does not capture all transferability factors such as source dataset size or task difficulty (showing non-significant correlation on 6 of 10 target tasks such as BoolQ where MNLI yields a 19.0% relative error reduction despite 0.4 cosine similarity).
  • supports Source: SPoT: Better Frozen Model Adaptation through Soft Prompt Transfer · Locator: Section 2.2 Effect of SPoT, p. 4; Section 3.3 Correlation between task similarity and task transferability, p. 8; Section 5 Limitations & Future work, p. 9; Appendix G Figure 8, p. 21

⚠️ Curated Limitations & Negative Results

  • Indiscriminately mixing all available source tasks (e.g., C4 plus 55 supervised tasks) degrades downstream accuracy relative to focused source mixtures due to task interference and negative transfer.
  • Prompt-based task embedding cosine similarity does not account for non-semantic transfer factors such as source dataset size and task complexity, exhibiting weak correlation with relative error reduction on several target tasks.
  • Best of Top-k retrieval requires running target prompt tuning k separate times on the target task, whereas single-run Top-k Weighted Average sacrifices a portion of the top-k oracle gain.
