Deep Gradient Compression (DGC with Momentum Correction and Momentum Factor Masking)

Algorithms AIMech:DeepGradientCompressionWithMomentumCorrection DRAFT
Aliases: Deep Gradient Compression, DGC, Top-k Gradient Sparsification with Momentum Correction and Factor Masking
A high-sparsity distributed gradient compression algorithm (Lin et al. 2018, Section 3, Algorithm 1) that transmits only the top-k magnitude entries (down to 0.1% density) of a locally accumulated velocity buffer while preserving dense momentum-SGD convergence via four coupled mechanisms: (1) Momentum Correction (u_{k,t} = m u_{k,t-1} + g_{k,t}, v_{k,t} = v_{k,t-1} + u_{k,t}, Eq. 6), which accumulates local momentum velocities rather than raw gradients; (2) Momentum Factor Masking (v_{k,t} <- v_{k,t} o (1 - Mask), u_{k,t} <- u_{k,t} o (1 - Mask), Eq. 8), which clears both the accumulator and momentum factor on transmitted coordinates; (3) local gradient clipping scaled by N^{-1/2} before accumulation; and (4) warm-up sparsity scheduling.
Identity Notes & Concept Scope Distinct from vanilla error-compensated Top-k SGD (AIMech:SparsifiedSgdWithErrorMemoryForKContractiveGradientCompression, Stich, Cordonnier, & Jaggi 2018), which analyses momentum-free local error memory e_{t+1} = e_t + eta g_t - C(e_t + eta g_t) without Momentum Correction (Eq. 6) or Momentum Factor Masking (Eq. 8).

Claims & Grounded Evidence

4 Claims
Mechanism #r421-momentum-correction-equivalence-to-dense-momentum-sgd
When coordinate (i) remains below the sparsification threshold for T consecutive steps before firing, naive local gradient accumulation v_{k,t} = v_{k,t-1} + g_{k,t} (Eq. 5) loses the geometric discounting factors sum_{tau=0}^{T-1 - t} m^tau on intermediate gradients compared to dense momentum SGD (Eq. 4), whereas Momentum Correction u_{k,t} = m u_{k,t-1} + g_{k,t}, v_{k,t} = v_{k,t-1} + u_{k,t} (Eq. 6-7, Appendix B) restores the exact cumulative step -eta sum_{t=0}^{T-1} u_t of dense momentum SGD.
  • supports Source: Deep Gradient Compression: Reducing the Communication Bandwidth for Distributed Training · Locator: Section 3.2 Momentum Correction (Equations 3-7, Figure 2) & Appendix B
Mechanism #r421-momentum-factor-masking-and-local-gradient-clipping-staleness-control
Zeroing both the velocity accumulator v_{k,t}^{(j)} and the momentum factor u_{k,t}^{(j)} on every transmitted coordinate j (Momentum Factor Masking, Eq. 8) prevents stale pre-transmission momentum from re-accumulating into v_{k,t+1}^{(j)} on subsequent steps, while scaling the local L2 gradient clipping threshold by N^{-1/2} preserves the global clipping norm across N workers (Section 3.3, Appendix C).
  • supports Source: Deep Gradient Compression: Reducing the Communication Bandwidth for Distributed Training · Locator: Section 3.3 Overcoming the Staleness Effect (Equation 8, Figure 3) & Appendix C
Limitation #r421-sparse-index-encoding-and-allgather-irregularity-limitation
Because each worker selects a different set of top-k coordinate indices, transmitting sparse updates requires sending both values and index offsets and preventing dense in-place ring AllReduce without sparse index reconstruction or hierarchical aggregation.
  • supports Source: Deep Gradient Compression: Reducing the Communication Bandwidth for Distributed Training · Locator: Section 3.1 Gradient Sparsification & Section 4 System Analysis
Application #r421-imagenet-resnet50-speech-recognition-and-language-modeling-application
Applied to distributed training of ResNet-50 and AlexNet on ImageNet, Penn Treebank LSTM language modeling, and AN4 speech recognition, achieving 277x to 597x gradient compression ratios without loss of validation accuracy.
  • supports Source: Deep Gradient Compression: Reducing the Communication Bandwidth for Distributed Training · Locator: Section 4 Experiments (Tables 1-4, Figures 4-7), pp. 5-9

⚠️ Curated Limitations & Negative Results

  • Requires maintaining two full-dimension O(d) local buffers (u_{k,t} and v_{k,t}) per worker.
  • Top-k threshold selection via random 0.1%-1% coordinate subsampling introduces an approximate quantile estimate at each step.
