AdaHessian (Adaptive Second-Order Optimizer)

Aliases: AdaHessian, AdaHessian Optimizer, Adaptive Hessian Diagonal Optimizer
An adaptive second-order stochastic optimization algorithm with O(d) memory complexity that approximates the Hessian diagonal at step t via Hutchinson's method D_t = z odot (H_t z) using a Rademacher vector z in {-1, +1}^d and a Hessian-free matrix-vector product H_t z = d(g_t^T z)/dtheta (Eqs. 8-9), smooths spatial variance via block-diagonal averaging of block size b, D_t^{(s)}[i b + j] = (1/b) sum_{r=1}^b D_t[i b + r] (Eq. 10), tracks a bias-corrected root-mean-square exponential moving average D_bar_t = sqrt(((1 - beta_2) / (1 - beta_2^t)) sum_{i=1}^t beta_2^{t-i} D_i^{(s)} odot D_i^{(s)}) (Eq. 11), and preconditions the bias-corrected gradient EMA m_t by v_t = (D_bar_t)^k for Hessian power 0 <= k <= 1 via theta_{t+1} = theta_t - eta_t m_t / v_t (Eq. 12, Algorithm 1).

Identity Notes & Concept Scope Distinct from Adam, AdamW, and RMSProp in that AdaHessian replaces the elementwise squared gradient g_i odot g_i in the second-moment accumulator with the squared spatially averaged Hutchinson Hessian diagonal D_i^{(s)} odot D_i^{(s)} raised to power k in [0, 1]. Distinct from Sophia in that AdaHessian performs block-diagonal spatial averaging across convolutional/attention blocks of size b, accumulates an RMS (L2) moving average of the Hessian diagonal rather than a linear EMA of max(h_t, 0), and applies unclipped power preconditioning m_t / (D_bar_t)^k.

Claims & Grounded Evidence

4 Claims
Mechanism #c-r592-hutchinson-diagonal-and-spatial-block-averaging
AdaHessian computes an unbiased Hessian diagonal estimate D = diag(H) = E[z odot (H z)] using a Rademacher vector z in {-1, +1}^d and a single Hessian-vector backpropagation H z = d(g^T z)/dtheta (Eqs. 8-9), and applies block-diagonal spatial averaging D^{(s)}[i b + j] = (1/b) sum_{r=1}^b D[i b + r] over blocks of size b (e.g., 3x3 convolutional kernels or attention rows, Eq. 10), preserving the strong-convexity spectral bounds alpha <= D_i^{(s)} <= beta and convergence rate (Eqs. 13-19) while reducing single-sample Hutchinson variance without extra computational cost.
  • supports Source: ADAHESSIAN: An Adaptive Second Order Optimizer for Machine Learning · Locator: Equations (8)-(10) & Figures 4-5, pp. 6-8; Appendix Descending Properties, Eqs. (13)-(19), p. 15
Mechanism #c-r592-rms-hessian-momentum-and-power-preconditioning
By maintaining a bias-corrected root-mean-square exponential moving average D_bar_t of the spatially averaged Hessian diagonal (Eq. 11) and preconditioning the gradient momentum m_t by v_t = (D_bar_t)^k (0 <= k <= 1, Eq. 12), AdaHessian smooths out misleading local curvature spikes on rugged non-convex loss surfaces (Figure 3) and exhibits high robustness to learning-rate scaling up to 10x on Transformer machine translation where AdamW diverges (Table 6).
  • supports Source: ADAHESSIAN: An Adaptive Second Order Optimizer for Machine Learning · Locator: Figure 3 & Equations (11)-(12), pp. 6-7; Table 6, p. 11
Application #c-r592-cv-nlp-recsys-empirical-gains
Using the same learning-rate schedule, warmup, weight decay, and (beta_1, beta_2) as first-order baselines, AdaHessian achieves +5.55% higher top-1 accuracy than Adam (+2.67% over AdamW) on ImageNet ResNet18, +0.13/+0.33 BLEU over AdamW on IWSLT14/WMT14, 2.7/1.0 lower perplexity on PTB/WikiText-103, +0.41 GLUE points on SqueezeBERT, and +0.032% test accuracy over AdaGrad on Criteo DLRM.
  • supports Source: ADAHESSIAN: An Adaptive Second Order Optimizer for Machine Learning · Locator: Abstract, p. 1; Tables 2-5 & Figure 6, pp. 8-10
Limitation #c-r592-second-backprop-overhead-limitation
Computing the Hessian-vector product H z via automatic differentiation requires a second backpropagation pass (2x theoretical FLOPs and 2.27x-2.91x measured per-iteration wall-clock time relative to Adam when run at every step), and PyTorch lacks native second-order backpropagation support for sparse embedding gradients.
  • supports Source: ADAHESSIAN: An Adaptive Second Order Optimizer for Machine Learning · Locator: Recommendation System section, p. 10; AdaHessian Overhead & Table 8, pp. 11-12

⚠️ Curated Limitations & Negative Results

  • Requires 2x theoretical FLOPs (and 2.27x-2.91x measured runtime vs Adam when computed every step) due to the second backpropagation pass needed for Hutchinson's Hessian-vector product, unless delayed Hessian updates are used.
  • Approximates the Hessian as a diagonal operator and therefore does not capture off-diagonal curvature rotations across distinct parameter coordinates.
