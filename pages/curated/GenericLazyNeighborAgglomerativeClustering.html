Generic lazy-neighbor agglomerative clustering

Algorithms AIMech:GenericLazyNeighborAgglomerativeClustering DRAFT
Aliases: Generic linkage algorithm (Müllner), GENERIC_LINKAGE
An agglomerative clustering algorithm that caches candidate nearest neighbors and lower bounds on row-minimum dissimilarities in a priority queue, rescanning a stale row only when necessary to certify the next globally closest pair before merging it.

6 Claims
Mechanism #candidate-lower-bounds
For each active row except the largest index, keep a candidate neighbor among higher-index clusters and a lower bound on that row’s minimum dissimilarity. Initialize the bounds by row scans and index them in a minimum-priority queue. Symmetry ensures these upper-triangular rows collectively contain a globally closest pair.

  • supports Source: fastcluster src/fastcluster.cpp · Locator: generic_linkage initialization, src/fastcluster.cpp lines940–1000 at the pinned commit
Mechanism #deferred-rescan-and-certification
Take a row with smallest queued bound. If its bound equals the actual distance to its candidate, the pair attains a global minimum. Otherwise rescan that row, raise its bound to the true row minimum, update the queue and reconsider the smallest entry. Candidate invalidation can therefore remain unresolved while its lower bound is larger than the current global minimum.

Mechanism #merge-and-cache-maintenance
After accepting a pair, record the merge, remove its smaller row index and reuse the larger index for the union. Update distances under the selected linkage using the premerge cluster sizes. Redirect references to the removed representative, lower bounds when a new distance is smaller, and recompute the merged row’s higher-index minimum when such a row exists. These updates preserve the lower-bound and attained-bound invariants.

Scope #inversions-and-linkage-scope
The method certifies a globally closest pair at each step without the nearest-neighbor-chain reducibility condition. It accommodates the paper’s centroid and median linkages, whose merge heights can decrease. Preserve their chronological merge dependencies rather than sorting those heights. Ties may select any valid closest pair; agreement with one fixed arbitrary tie convention is not required.

Scope #time-and-memory-boundaries
For the stored-matrix setting and constant-time scalar distance updates, the paper gives quadratic best-case time and a cubic worst-case upper bound because stale row minima may require repeated scans. The algorithm retains a writable quadratic-size distance matrix plus linear auxiliary storage for candidates, bounds and the indexed queue. Empirically near-quadratic timing does not establish a universal quadratic guarantee.

Limitation #literal-source-and-implementation-limits
The printed Figure3 updates the retained cluster size before passing sizes to its update formula and requests a higher-index minimum even at the terminal boundary. The later pinned matrix implementation saves both old sizes and guards that row update. Its lower-bound prose and operations imply bound≤true minimum despite a reversed sign in a comment. This record uses the supported invariant and those explicit boundaries rather than treating every printed line or code comment as an executable specification.

⚠️ Curated Limitations & Negative Results

  • This record covers the stored-matrix generic procedure of Section3.1. Section6’s fresh-lowest-label variant and vector-data implementations require separate implementation assessments; they are not asserted as interchangeable APIs.
  • A valid greedy hierarchy is the output contract. The method does not infer a cluster count or establish globally optimal fixed-count partitions. Linkage geometry and admissible dissimilarities remain requirements of the chosen criterion.
  • The paper’s generic applicability concerns distance-update formulas in its symmetric-dissimilarity setting. The inspected fastcluster implementation dispatches a fixed set of linkage rules; no arbitrary callback API is claimed.
  • A finite centroid/median example merges points (−1,0) and (1,0) at squared height 4, then merges (0,9/5) at height 81/25. Sorting those heights would violate the dependency on the earlier union.
  • All 29 pages of the primary paper were visually read. The complete matrix generic_linkage and indexed heap, relevant distance updates and specified wrapper passages were statically inspected at the pinned commit; no author code, empirical timing or floating-point behavior was executed.
  • Curator calculations verify the lower-bound/equality invariant and global merge admissibility for 3,645 four-object matrix/linkage cases and 243 Euclidean cases, plus inversion, history-dependent-update and one/two-object boundaries. Their reference implementation uses linear queue selection and does not measure the paper’s time or memory bounds.
