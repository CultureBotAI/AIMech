D-Adaptation (Learning-Rate-Free Optimization by Distance Lower Bounding)

Algorithms AIMech:DAdaptationLearningRateFreeOptimization DRAFT
Aliases: D-Adaptation, D-Adapted AdaGrad, D-Adapted SGD, D-Adapted Adam
A hyperparameter-free (learning-rate-free) optimization framework (Algorithms 1-5) for minimizing convex G-Lipschitz and deep learning objectives that automatically calibrates the base step size without backtracking line searches or extra function/gradient evaluations by maintaining a monotonically non-decreasing empirical lower bound d_k <= D on the unknown initial distance to a minimizer D = ||x_0 - x_*||. In Dual Averaging with D-Adaptation (Algorithm 1), at each step k the algorithm accumulates the distance-weighted dual gradient sum s_{k+1} = s_k + d_k g_k, updates the AdaGrad-Norm scale gamma_{k+1} = 1 / sqrt{sum_{i=0}^k ||g_i||^2}, computes the empirical lower bound hat{d}_{k+1} = (gamma_{k+1} ||s_{k+1}||^2 - sum_{i=0}^k gamma_i d_i^2 ||g_i||^2) / (2 ||s_{k+1}||) (Option I) or hat{d}_{k+1} = (sum_{i=0}^k d_i gamma_i langle g_i, s_i rangle) / ||s_{k+1}|| (Option II), sets d_{k+1} = max(d_k, hat{d}_{k+1}), updates x_{k+1} = x_0 - gamma_{k+1} s_{k+1}, and returns the weighted average hat{x}_n = (sum_{k=0}^n d_k x_k) / (sum_{k=0}^n d_k).
Identity Notes & Concept Scope Distinct from standard AdaGrad-Norm (which requires oracle knowledge of D = ||x_0 - x_*|| in gamma_k = D / sqrt{sum_{i=0}^k ||g_i||^2}), Polyak step size (which requires knowledge of the optimal value f_*), and coin-betting or DoG methods (which incur multiplicative sqrt{log(1 + D)} or log-factor penalties). D-Adaptation is the first parameter-free method for convex Lipschitz minimization to achieve the optimal asymptotic O(DG / sqrt{n+1}) rate with zero additional log factors.

Mechanism #exact-empirical-distance-lower-bound-and-asymptotic-constant-guarantee
Lemmas 5 and 6 and Theorem 7 (Section 2, Appendix A, pp. 24-25, and Appendix E.1, p. 44) prove that for any convex function f with minimizer x_* and D = ||x_0 - x_*||, the iterates of Algorithm 1 satisfy sum_{k=0}^n d_k (f(x_k) - f_*) <= D ||s_{n+1}|| - sum_{k=0}^n d_k gamma_k langle g_k, s_k rangle <= D ||s_{n+1}|| + sum_{k=0}^n (gamma_k / 2) d_k^2 ||g_k||^2 - (gamma_{n+1} / 2) ||s_{n+1}||^2, which guarantees hat{d}_{n+1}^{(I)} <= tilde{d}_{n+1}^{(II)} <= D at every step whenever d_0 <= D; furthermore, Theorem 24 (Appendix E, p. 43) proves that if ||x_n - x_*|| -> 0, then lim_{n -> infty} d_n >= D / (1 + sqrt{3}).

Mechanism #log-free-asymptotic-and-non-asymptotic-convex-lipschitz-convergence
Theorem 1 (Section 2, p. 3, and Appendix A.1, pp. 27-29) proves that for any convex G-Lipschitz function f and any initial guess d_0 <= D, Dual Averaging with D-Adaptation (Algorithm 1) satisfies f(hat{x}_n) - f_* <= 12 D G / sqrt{n+1} + 8 D G^2 / ((n+1)||g_0||) = O(D G / sqrt{n+1}) as n -> infty with no multiplicative logarithmic factors, while Theorem 2 (Appendix A.2, pp. 29-31) establishes the finite-step guarantee f(hat{x}_t) - f_* <= 16 D G log_{2+}(D / d_0) / sqrt{n+1} for n >= 2 log_2(D / d_0).

  • supports Source: Learning-Rate-Free Learning by D-Adaptation (Crossref metadata) · Locator: Bibliographic record (ICML 2023, PMLR 202:7449-7479)
Application #coordinate-wise-d-adapted-adagrad-sgd-and-adam-extensions
Section 3 (Algorithm 3, Theorem 4, Appendix C) extends D-Adaptation to coordinate-wise preconditioning in the l_infty norm D_infty = ||x_0 - x_*||_infty via hat{d}_{k+1} = (||s_{k+1}||_{A_{k+1}^{-1}}^2 - sum_{i=0}^k d_i^2 ||g_i||_{A_i^{-1}}^2) / (2 ||s_{k+1}||_1) achieving f(hat{x}_n) - f_* = O(p G_infty D_infty / sqrt{n+1}), and Section 6 (Algorithms 4 and 5, Appendix F) derives practical stochastic D-Adapted SGD and D-Adapted Adam rules using exponentially weighted moving averages s_{k+1} = sqrt{beta_2} s_k + (1 - sqrt{beta_2}) d_k gamma_k g_k and r_{k+1} = sqrt{beta_2} r_k + (1 - sqrt{beta_2}) d_k gamma_k langle g_k, s_k rangle_{A_{k+1}^{-1}}.
  • supports Source: Learning-Rate-Free Learning by D-Adaptation · Locator: Section 3, Algorithm 3, Theorem 4, pp. 5-6; Section 6, Algorithms 4-5, pp. 9-10; Appendices C and F, pp. 35-39, 44-46
Limitation #deterministic-convex-theory-scope-and-float16-initial-d0-underflow-limitation
The theoretical convergence guarantees of D-Adaptation (Theorems 1-4) are proven for deterministic convex Lipschitz objectives with d_0 <= D, and in 16-bit floating-point (float16) training, initializing d_0 below 10^{-8} can cause numerical underflow in the initial weighted gradient accumulator s_k.
  • supports Source: Learning-Rate-Free Learning by D-Adaptation · Locator: Section 4.2, p. 7; Section 7.7, p. 15

⚠️ Curated Limitations & Negative Results

  • Theoretical O(DG/sqrt{n+1}) guarantees hold for deterministic convex Lipschitz functions with initial lower bound d_0 <= D.
  • Maintains an additional d-dimensional dual accumulator vector s_k alongside standard optimizer states.
