MARINA Faster Non-Convex Distributed Learning with Compression

Aliases: MARINA, VR-MARINA, PP-MARINA, Faster Non-Convex Distributed Learning with Compression
A communication-efficient nonconvex distributed optimization method (MARINA, together with its variance-reduced finite-sum/online variant VR-MARINA and partial-participation variant PP-MARINA) for minimizing f(x) = (1/n) sum_{i=1}^n f_i(x) that constructs a biased SARAH/PAGE-style recursive gradient estimator g^{k+1} using an independent unbiased omega-quantizer Q at each worker: after updating x^{k+1} = x^k - gamma * g^k and drawing c_k ~ Bernoulli(p) (typically p = 1/(1 + omega)), each worker i transmits the exact gradient g_i^{k+1} = nabla f_i(x^{k+1}) if c_k = 1 or the compressed consecutive gradient difference g_i^{k+1} = g^k + Q(nabla f_i(x^{k+1}) - nabla f_i(x^k)) if c_k = 0, so the server average g^{k+1} = (1/n) sum_{i=1}^n g_i^{k+1} satisfies E[||g^{k+1} - nabla f(x^{k+1})||^2] <= (1 - p)||g^k - nabla f(x^k)||^2 + ((1 - p)*omega*L^2/n) E[||x^{k+1} - x^k||^2] and achieves O((Delta_0 * L / eps^2) * (1 + sqrt((1 - p)*omega / (p*n)))) iteration complexity (O((Delta_0 * L / eps^2) * (1 + omega / sqrt(n))) under p = 1/(1 + omega)), improving over DIANA by a factor of O(sqrt(omega)) without any bounded gradient dissimilarity assumption.

Identity Notes & Concept Scope Distinct from DIANA (AIMech:DianaDistributedLearningWithCompressedGradientDifferences, which forms an unbiased gradient estimator by compressing g_i^k - h_i^k against stored per-worker shift vectors h_i^k and achieves worse O(omega/n + omega^{2/3}/n^{2/3}) scaling in nonconvex optimization), from EF21 (AIMech:Ef21MarkovCompressorErrorFeedbackForHeterogeneousNonconvexOptimization, which supports biased contractive compressors without uncompressed synchronization rounds c_k = 1, whereas MARINA uses independent unbiased quantizers across workers to obtain a 1/sqrt(n) multi-node variance reduction factor), and from centralized PAGE/SARAH/SPIDER (AIMech:SARAHStochasticRecursiveGradientForFiniteSumOptimization and AIMech:SPIDERStochasticPathIntegratedDifferentialEstimatorForNonConvexOptimization, which do not compress worker-to-server communication). Claims & Grounded Evidence

4 Claims
Mechanism #r391-biased-recursive-difference-compression-and-lyapunov-descent
By compressing the consecutive gradient difference nabla f_i(x^{k+1}) - nabla f_i(x^k) with probability 1 - p and resetting g^{k+1} = nabla f(x^{k+1}) with probability p, MARINA's estimator error contracts as E||g^{k+1} - nabla f(x^{k+1})||^2 <= (1 - p)||g^k - nabla f(x^k)||^2 + ((1 - p)*omega*L^2/n) E||x^{k+1} - x^k||^2 (Eq. 8), and Theorem 2.1 / Corollary 2.1 prove that the Lyapunov potential Phi_k = f(x^k) - f_* + (gamma / (2*p)) ||g^k - nabla f(x^k)||^2 decreases monotonically for gamma <= 1 / (L*(1 + sqrt((1 - p)*omega/(p*n)))), achieving E||nabla f(x_hat^K)||^2 <= eps^2 in O((Delta_0 * L / eps^2) * (1 + omega / sqrt(n))) iterations and matching uncompressed gradient descent communication complexity whenever omega <= sqrt(n).
  • supports Source: MARINA: Faster Non-Convex Distributed Learning with Compression · Locator: Section 2 Algorithm 1, Equation 8, Theorem 2.1, Corollary 2.1, and Table 1, pp. 2-5
Mechanism #r391-pl-linear-convergence-and-vr-pp-marina-extensions
Under the Polyak-Lojasiewicz condition ||nabla f(x)||^2 >= 2*mu*(f(x) - f_*), Theorem 2.2 proves linear convergence O(max{1/p, (L/mu)*(1 + sqrt((1 - p)*omega/(p*n)))} log(Delta_0 / eps^2)), while VR-MARINA (Algorithms 2-3, Theorems 3.1-3.2) replaces full local gradients with minibatch difference estimators of size b' (recovering PAGE when n = 1, omega = 0) and PP-MARINA (Algorithm 4, Theorem 4.1) extends MARINA to r-out-of-n partial client participation.
  • supports Source: MARINA: Faster Non-Convex Distributed Learning with Compression · Locator: Section 2.2 Theorem 2.2, Section 3 Theorems 3.1-3.2, and Section 4 Theorem 4.1, pp. 5-8
Limitation #r391-periodic-uncompressed-sync-and-unbiased-quantizer-limitation
Requires an unbiased compression operator Q (so independent worker errors average down by 1/n) and periodic uncompressed gradient broadcasts with probability p = 1/(1 + omega) (or synchronous minibatch resets in VR-MARINA), unlike EF21 which transmits only compressed vectors at every round.
  • supports Source: MARINA: Faster Non-Convex Distributed Learning with Compression · Locator: Section 1.2 Definition 1.1 and Section 2.1 Algorithm 1 & Remark on communication cost, pp. 2-4
Application #r391-nonconvex-binary-classification-and-autoencoder-application
Applied to distributed nonconvex sigmoid binary classification on LIBSVM datasets (mushrooms, w8a, a9a, phishing) and neural network autoencoder training on MNIST with RandK sparsification and natural compression, outperforming DIANA, EF21, and uncompressed GD in total communicated bits.
  • supports Source: MARINA: Faster Non-Convex Distributed Learning with Compression · Locator: Section 5 Numerical Experiments, Figures 1-2 & Appendix B, pp. 8-9, 14-16

⚠️ Curated Limitations & Negative Results

  • Requires an unbiased quantizer Q so that independent worker quantization errors average down by 1/n.
  • Requires periodic uncompressed gradient transmissions with probability p (or large minibatch resets in VR-MARINA).
