FedFTG (Data-Free Global Model Fine-Tuning via Hard Sample Mining Knowledge Distillation)

Algorithms AIMech:FedFtgDataFreeGlobalModelFineTuningViaHardSampleMiningKnowledgeDistillation DRAFT
Aliases: FedFTG, Fine-Tuning Global Model via Data-Free Knowledge Distillation, Adversarial Hard-Sample Data-Free Federated Global Fine-Tuning
A server-side data-free knowledge distillation algorithm for non-IID federated learning (Zhang, Shen, Ding, Tao, & Duan 2022, Section 4, Equations 2-10, Algorithms 1-2) that fine-tunes the FedAvg-aggregated server model omega_t after each communication round by jointly training a conditional generator G(z, y; theta) -> x_tilde and the global model omega in an adversarial hard-sample mining minimax game: min_omega max_theta E_{z ~ N(0,I), y ~ p_t(y)} [L_{md} - lambda_{cls} L_{cls} - lambda_{dis} L_{dis}] (Equation 8), where L_{md} = sum_{k in S_t} alpha_t^{k,y} D_{KL}(sigma(f(x_tilde; omega)) || sigma(f(x_tilde; omega_t^k))) (Equations 3-4) measures prediction discrepancy between the global model and uploaded client models {omega_t^k}, L_{cls} = sum_{k in S_t} alpha_t^{k,y} L_{CE}(sigma(f(x_tilde; omega_t^k)), y) (Equations 5-6) enforces class-consistent synthetic semantics, L_{dis} = exp((1/Q^2) sum_{i,j} (-||x_tilde_i - x_tilde_j||_2 ||z_i - z_j||_2)) (Equation 7) prevents generator mode collapse, and p_t(y) = (sum_{k in S_t} n_k^y) / (sum_{y', k in S_t} n_k^{y'}) (Equation 9) and alpha_t^{k,y} = n_k^y / sum_{i in S_t} n_i^y (Equation 10) weight synthetic classes and local teacher ensembles by exact per-class client sample counts.
Identity Notes & Concept Scope Distinct from FedGen (AIMech:FedGenDataFreeKnowledgeDistillationForHeterogeneousFederatedLearning, Zhu, Hong, & Zhou 2021), which broadcasts a lightweight latent-feature generator to clients to regularize local training rather than adversarially mining hard input-space pseudo-samples x_tilde on the server to fine-tune the global model omega_t via minimax discrepancy maximization (Equation 8); and distinct from FedDF (AIMech:FedDfEnsembleDistillationForRobustModelFusionInFederatedLearning, Lin et al. 2020), which requires an external unlabeled proxy dataset on the server and uses uniform client logit averaging rather than data-free adversarial generation with class-specific ensemble weights alpha_t^{k,y} (Equation 10).

Claims & Grounded Evidence

4 Claims
Mechanism #r480-adversarial-hard-sample-mining-minimax-distillation-mechanism
In each round's I server fine-tuning iterations, FedFTG first updates the conditional generator G(z, y; theta) for I_g steps to maximize the weighted KL discrepancy L_{md} minus the semantic cross-entropy penalty lambda_{cls} L_{cls} and diversity loss lambda_{dis} L_{dis} (mining hard synthetic samples where the averaged global model omega disagrees with local teacher models {omega_t^k}), and then updates the global model omega for I_d steps to minimize L_{md} on those hard samples (Zhang et al. 2022, Section 4.1, Equations 3-8, Algorithm 2).
  • supports Source: Fine-Tuning Global Model via Data-Free Knowledge Distillation for Non-IID Federated Learning · Locator: Section 4.1 (Equations 3-8, Algorithm 2), pp. 4-5
Mechanism #r480-customized-label-sampling-and-class-level-ensemble-weighting-mechanism
To handle extreme non-IID label skew across active clients S_t, FedFTG samples synthetic labels according to the active corpus class proportion p_t(y) = (sum_{k in S_t} n_k^y) / (sum_{y', k in S_t} n_k^{y'}) (Equation 9) and assigns each local teacher k the class-conditional importance weight alpha_t^{k,y} = n_k^y / sum_{i in S_t} n_i^y (Equation 10), preventing clients with zero or few samples of class y from corrupting the ensemble teacher logits for class y (Zhang et al. 2022, Section 4.2, Equations 9-10, Table 4).
  • supports Source: Fine-Tuning Global Model via Data-Free Knowledge Distillation for Non-IID Federated Learning · Locator: Section 4.2 (Equations 9-10), p. 5, and Section 5.3 (Table 4), p. 7
Application #r480-plug-and-play-server-finetuning-for-federated-optimizers-application
Applied both standalone and as a plug-and-play server-side fine-tuning module on top of FedAvg, FedProx, FedDyn, and MOON on Dirichlet-skewed CIFAR-10, CIFAR-100, Tiny-ImageNet, and MNIST/FEMNIST benchmarks (Zhang et al. 2022, Section 5, Tables 1-4, Figures 3-5).
  • supports Source: Fine-Tuning Global Model via Data-Free Knowledge Distillation for Non-IID Federated Learning · Locator: Section 5.1-5.3 (Tables 1-4, Figures 3-5), pp. 6-8
Limitation #r480-class-count-disclosure-and-server-generator-compute-limitation
Requires clients to report their per-class sample counts {n_k^y} (or requires estimating them via synthetic forward passes) to compute p_t(y) and alpha_t^{k,y}, and adds I * (I_g + I_d) server-side generator-and-teacher forward/backward passes per communication round (Zhang et al. 2022, Section 4.2, p. 5).
  • supports Source: Fine-Tuning Global Model via Data-Free Knowledge Distillation for Non-IID Federated Learning · Locator: Section 4.1-4.2 (Algorithm 2, Equations 9-10), pp. 4-5

⚠️ Curated Limitations & Negative Results

  • Incurs additional server-side computation to train the conditional generator G(.; theta) and evaluate all |S_t| uploaded client models on synthetic batches.
  • Requires either client-reported per-class sample counts n_k^y or approximate pseudo-label count estimation to form class-level teacher weights alpha_t^{k,y}.
