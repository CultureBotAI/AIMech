FedAwS (Federated Averaging with Spreadout for Positive-Only Labels)

Algorithms AIMech:FedAwsFederatedAveragingWithSpreadoutForPositiveOnlyLabels DRAFT
Aliases: FedAwS, Federated Averaging with Spreadout
A federated multi-class and extreme-classification training algorithm (Yu, Rawat, Menon, & Kumar 2020, Section 3, Equations 7-8, Algorithm 1) for settings where each client i holds only positive examples of its own class(es) and cannot share data or other clients' class embeddings: clients locally minimize only the positive alignment loss l_pos(f(x), y) = d(w_y, g_theta(x))^2 on the shared input encoder g_theta and local class embedding w_y, while the central server prevents trivial embedding collapse after averaging by applying a geometric spreadout regularizer reg_sp(W) = sum_{c in [C]} sum_{c' != c} (max(0, nu - d(w_c, w_{c'})))^2 (Equation 7) or its top-k closest-negative variant reg_sp^top(W) (Equation 8) to the class embedding matrix W.
Identity Notes & Concept Scope Distinct from standard FedAvg and from FedProto (AIMech:FedProtoFederatedPrototypeLearningAcrossHeterogeneousClients, Tan et al. 2022), which assume each client observes multi-class labeled examples locally so negative classes are separated by client-side cross-entropy rather than learning from positive-only single-class client data via a server-side geometric spreadout regularizer on class embeddings.

Claims & Grounded Evidence

4 Claims
Mechanism #r450-server-spreadout-prevents-positive-only-collapse-mechanism
When clients only have access to positive examples of class i and minimize l_pos(f(x), i) = d(w_i, g_theta(x))^2, naive FedAvg collapses all class embeddings w_1, ..., w_C and encoder outputs g_theta(x) to a single point; applying the server-side spreadout regularizer reg_sp(W) (Eq. 7) or stochastic negative mining reg_sp^top(W) over the k closest classes N_k(c) (Eq. 8) enforces pairwise separation margin nu without transmitting negative examples or full class matrices to clients.
  • supports Source: Federated Learning with Only Positive Labels · Locator: Section 3.1 Failure of Vanilla FedAvg & Section 3.2 FedAwS (Equations 7-8, Algorithm 1), pp. 10948-10950
Mechanism #r450-contrastive-loss-surrogate-equivalence-bound
Lemma 1, Proposition 2, and Theorem 1 (Section 4, Equations 13-21, pp. 10950-10952) prove that cosine contrastive loss l_ccl is a valid multi-class classification surrogate and that for balanced classes with weight lambda = 1/C, the FedAwS objective approximates l_ccl within |l_ccl(f(x), y) - l_sp(f(x), y)| <= (1 + 2*nu) ||w_y - g_theta(x)||_2, vanishing as positive examples align with their class embeddings.
  • supports Source: Federated Learning with Only Positive Labels · Locator: Section 4 Theoretical Justification (Propositions 1-2, Lemma 1, Theorem 1, Equations 13-21), pp. 10950-10952
Limitation #r450-quadratic-pairwise-class-cost-and-margin-tuning-limitation
Full pairwise spreadout regularization reg_sp(W) costs O(C^2 d) per server step when the number of classes C is large (requiring top-k negative mining reg_sp^top in Eq. 8), and performance depends on selecting the margin hyperparameter nu and top-k neighborhood size.
  • supports Source: Federated Learning with Only Positive Labels · Locator: Section 3.2 Stochastic Negative Mining (Equation 8) & Section 5.2 Ablation Studies, pp. 10949-10954
Application #r450-user-verification-and-extreme-multilabel-federated-application
Applied to positive-only federated classification on CIFAR-10, CIFAR-100, and extreme multi-label classification datasets (AmazonCat-13K, WikiLSHTC-325K, Amazon-670K).
  • supports Source: Federated Learning with Only Positive Labels · Locator: Section 5 Experiments (Tables 1-4, Figures 2-3), pp. 10952-10955

⚠️ Curated Limitations & Negative Results

  • Requires the central server to hold and update all C class embeddings W = [w_1, ..., w_C].
  • Theoretical contrastive surrogate equivalence (Theorem 1) assumes small positive alignment residual ||w_y - g_theta(x)||_2.
