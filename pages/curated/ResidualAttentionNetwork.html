Residual Attention Network

Architectures AIMech:ResidualAttentionNetwork DRAFT
Aliases: RAN (residual attention)
A convolutional-network architecture that stacks attention modules combining trunk features with learned bottom-up and top-down masks through residual attention gating.
Identity Notes & Concept Scope This record covers the 2017 architecture with its canonical mixed sigmoid masks and attention residual learning. It is a network construction rather than a single attention block, trained model or generic ResNet. Named depths such as Attention-56 and Attention-92 configure this architecture; constrained channel/spatial mask variants are not silently substituted for the selected mixed-mask procedure. Claims & Grounded Evidence

1 Claim
Mechanism #method
Stack attention modules at successive network stages. Within a module, a trunk branch computes convolutional features while a mask branch pools down to broader context and upsamples through a top-down path, with skip connections between scales. The source uses max pooling, bilinear interpolation, intermediate feature-processing units, two final 1-by-1 convolutions and an elementwise sigmoid to form a mask matching the trunk tensor in spatial positions and channels. Combine them as one-plus-mask multiplied elementwise by the trunk output. This retains the trunk signal when the mask approaches zero while allowing input-dependent relative emphasis. The source composes these modules with feature-processing units and a classifier; numbers of modules, stage widths, branch depths and basic units are architecture choices. The bottom-up/top-down process is implemented in a single feedforward computation, not an iterative recurrent feedback loop.

⚠️ Curated Limitations & Negative Results

  • Attention residual learning uses (1+M)*T, not raw-input addition x+M*T and not the naive product M*T. A near-zero mask preserves the trunk output T, which need not equal the module input x. Residual units within the trunk are a separate architectural choice.
  • For the selected sigmoid mask, one-plus-mask lies between one and two for finite real logits. Immediate trunk magnitudes are therefore not attenuated; noise suppression in the source is a relative or network-level interpretation. The source’s L2-normalized channel-mask variant does not necessarily obey these sigmoid bounds.
  • The gradient formula with factor M in Equation2 describes the naive product. For fixed mask and separate trunk parameters, the residual formulation instead has factor1+M. It does not by itself prevent an erroneous-label gradient or guarantee robustness, gradient stability or monotonically improving accuracy with depth.
  • Masks are learned feature weights, not calibrated object probabilities or causal explanations. The paper’s classification and noisy-label experiments have specific conditions; detection/segmentation are proposed follow-up applications. No benchmark superiority, unlimited depth or author-code execution is asserted.
