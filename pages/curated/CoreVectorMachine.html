Core vector machine

Algorithms AIMech:CoreVectorMachine DRAFT
Aliases: CVM
An approximate kernel training algorithm that reformulates supported constant-diagonal simplex quadratic programs as minimum enclosing balls and repeatedly enlarges a core subset with a violating point while reoptimizing its ball.
Identity Notes & Concept Scope This record denotes the original Tsang-Kwok-Cheung CVM procedure and its stated L2 SVM reformulation, with exhaustive and practical sampled-search distinctions. It does not conflate every SVM loss, generalized CVM, core vector regression, core vector data description or BVM. Claims & Grounded Evidence

8 Claims
Mechanism #constant-diagonal-reduction
For feature vectors with a positive-semidefinite kernel, the minimum-enclosing-ball dual maximizes sum_i alpha_i*K_ii-alpha^T*K*alpha over nonnegative coefficients summing to one. Its center is the feature combination defined by alpha. If K_ii is constant kappa, this differs from maximizing -alpha^T*K*alpha only by kappa. Dropping the diagonal term for a nonconstant-diagonal kernel changes the optimization. Kernel normalization additionally requires positive self-similarities and changes the feature geometry.
  • supports Source: Core Vector Machines: Fast SVM Training on Very Large Data Sets · Locator: Sections 2-4.1, printed pp365-372 / PDF pp3-10, Equations 1-19 and CVM iteration
Mechanism #specific-l2-svm
The binary formulation minimizes ||w||²+b²-2*rho+C*sum_i xi_i² subject to y_i*(w^T*phi(x_i)+b)>=rho-xi_i, with C>0 and labels +/-1. Its transformed kernel is Ktilde_ij=y_i*y_j*(k_ij+1)+delta_ij/C, with constant diagonal kappa+1+1/C when k_ii=kappa. The simplex dual maximizes -alpha^T*Ktilde*alpha. Recover w=sum_i alpha_i*y_i*phi(x_i), b=sum_i alpha_i*y_i and xi_i=alpha_i/C. This uses squared slack loss and penalized bias; it is not every L1-hinge or unpenalized-bias SVM. The source also derives an L2 one-class formulation, which has a different transformed kernel.
  • supports Source: Core Vector Machines: Fast SVM Training on Very Large Data Sets · Locator: Sections 3.2.1-3.2.2, printed pp368-370 / PDF pp6-8; binary formulation and recovery in Equations 12-17 and following transformed-feature display
Mechanism #growing-core-reoptimization
For 0<epsilon<=1, maintain a subset of transformed observations and its exact minimum enclosing ball. If any training feature lies farther than (1+epsilon) times the current radius, add a farthest such feature and recompute the subset MEB; stop only when all features satisfy the bound. Kernel expansions compute distances without explicit feature coordinates. Added core observations are not deleted, although their optimized coefficients can become zero; core membership is not identical to final support-vector membership. The practical implementation uses warm-started SMO for the inner problem.
  • supports Source: Core Vector Machines: Fast SVM Training on Very Large Data Sets · Locator: Sections 2-4.1, printed pp365-372 / PDF pp3-10, Equations 1-19 and CVM iteration
Limitation #radius-and-shifted-objective-guarantee
With exact subset optimization and exhaustive outside-point checking, the final core radius R satisfies R<=R_star<=(1+epsilon)*R. For the stated simplex quadratic program, the corresponding relative approximation is on the shifted objective p_star+kappa_tilde=R_star². It is not a relative guarantee on the unshifted SVM objective, classifier labels or test accuracy. Finite inner-solver and outer termination tolerances must be distinguished.

Limitation #sampled-search-is-not-global-certification
The implementation samples 59 observations to approximate the farthest-point search and repeats probabilistic checks near termination. Under independent sampling with replacement, 59 draws hit the farthest 5 percent with probability about 0.9515, but miss a single violating observation among 1000 with probability about 0.9427. These curator calculations distinguish a rank-sampling statement from a certificate that every point is enclosed; they do not diagnose the historical random generator or reproduce the implementation.
  • supports Source: Core Vector Machines: Fast SVM Training on Very Large Data Sets · Locator: Section 4.1.2, printed p371 / PDF p9; Section 6 introduction and footnote 5, printed p376 / PDF p14; curator calculations in research/discovery/core-ball-vector-boundaries.py
Limitation #qualified-computational-cost
The paper derives O(n/epsilon²+1/epsilon^4) work for full farthest-point scans with its stated core-size and inner-QP cost model, treating kernel evaluations as constant cost. Its O(1/epsilon²) auxiliary QP workspace bound excludes the input dataset. Practical implementations store the input and may use caches; approximate sampling and numerical solves alter what is certified. Fixed-epsilon bounds do not establish unconditional sample-size-independent total runtime or memory.

Limitation #historical-critique-and-disagreement
Loosli and Canu report sensitivity and reproduction difficulties for selected checkers experiments using the CVM v1.1 Linux binary downloaded in April 2006, alongside specific LIBSVM and SimpleSVM comparisons. Their analysis discusses inner and outer stopping rules and makes an equivalence assumption for part of the derivation. The authors’ reply is retained as abstract-only context: it disputes parts of the stopping analysis and attributes some behavior to historical sampling. Neither account is treated as a universal verdict on every CVM implementation, and the reply’s full derivation was unavailable here.

Scope #identity-and-empirical-boundary
CVM is an approximate training procedure for supported kernel quadratic programs, not a synonym for generic SVM, a learned classifier instance, support-vector data description or BVM. BVM replaces repeated core MEB optimization with fixed-radius center movement and optional radius refinement. The original and critique experiments involve selected datasets, regularization, kernels, software, tolerances and hardware; no universal runtime or accuracy advantage, current implementation validation or reproduced benchmark is asserted.
