Tree-size estimation by partial backtracking

Algorithms AIMech:PartialBacktrackingTreeEstimation DRAFT
Aliases: Purdom partial-backtracking estimator
A randomized backtracking-tree estimator that explores a uniformly selected subset of successors at each visited branching point and uses inverse inclusion weights to estimate the total cost of candidate examinations in the corresponding complete fixed search.

Claims & Grounded Evidence

5 Claims
Mechanism #basic-subset-weighting
The basic variant chooses m of a candidate values without replacement, with 1 <= m <= a when a is positive. Its sequential remaining-count selection produces a uniform subset. Each selected candidate receives its parent weight multiplied by a/m, contributes its examination cost and is tested for feasibility before recursion. For a finite fixed tree under the stated conditional sampling rule, the weighted estimate preserves the expected complete examination cost. A branch with no candidates terminates.
  • supports Source: Tree Size by Partial Backtracking · Locator: Section 2, PDF pp. 5–6, B1–B6 and expectation discussion
Mechanism #modified-pretesting
The modified variant first tests every candidate at a visited parent and charges these tests using the parent weight. It then forms the feasible set, samples m of its a members uniformly without replacement and propagates weight a/m into their descendants. Testing all candidates can avoid choosing a failed branch, but adds work even when only a few feasible children are followed. Basic and modified variants have different sampling populations and cost-accounting order.
  • supports Source: Tree Size by Partial Backtracking · Locator: Section 2, PDF pp. 6–7, M1–M5
Scope #count-target-and-scope
The target cost may include failed feasibility tests, so it need not equal the number of feasible expanded nodes. The displayed algorithm initializes the accumulated cost to zero and omits a root test, while the later theoretical singleton-tree convention counts a root. Count conventions must therefore be specified. Sampling multiple branches retains omitted-branch uncertainty: a finite partial traversal does not certify that no solution or deep subtree exists, and node-test counts are not universal wall-clock costs.
  • supports Source: Tree Size by Partial Backtracking · Locator: Sections 1–3, PDF pp. 3–9; Section 4, PDF pp. 14–15
Limitation #efficiency-and-variance-scope
The report studies a finite random binary-tree family and a policy that sometimes explores both successors instead of one. Its efficiency measure combines expected work with expected sampling variance conditional on a tree. This is distinct from variance of true tree sizes across the random family. Full traversal can remove sampling variance while remaining costly; the report’s depth-scheduling advice and historical experiments do not establish a universally optimal sampling policy or finite-sample accuracy guarantee.
  • supports Source: Tree Size by Partial Backtracking · Locator: Section 3, PDF pp. 8–13; Section 4 and Tables 1–2, PDF pp. 14–18; Figures 2–4, pp. 21–23
Limitation #printed-analysis-and-version
The inspected February 1977 report contains printed analysis inconsistencies. Its displayed tree-size variance recurrence fails the two-level binary-tree case, and the work-distribution recurrence’s literal bracketing loses branching probability mass when both successors are always selected. Displayed policy expressions also conflict with the stated balance equation. These are qualifications on this scanned report, not findings about uninspected implementation code or the later journal version; the record does not certify those formulas or an optimal schedule.
  • supports Source: Tree Size by Partial Backtracking · Locator: Section 3, PDF pp. 9–11; report cover, PDF p. 1

⚠️ Curated Limitations & Negative Results

  • This record retains basic and modified variants together; neither is score-threshold beam pruning, conditional-model CDP prediction, IDA* threshold control or Chen-style weighted-stratum representative merging.
  • The sampling subset must have the stated conditional inclusion probabilities, and weights must match the actual sample size. Uniform weighting is not valid for arbitrary adaptive or preferential selection.
  • Candidate-test counts, feasible-tree counts, root conventions and variable examination costs must not be interchanged. Tree path occurrences are not automatically deduplicated graph states.
  • Historical matrix-multiplication results include a nine-node discrepancy between prose and an exhaustive table count; the larger problem has no exact comparison count. No numerical benchmark replication or universal performance claim is made.
  • All 23 pages of the February 1977 TR60 scan were visually inspected. Institutional metadata lists 1978-11, but equivalence to the later journal text is unverified. Author software was not inspected or executed; constructed finite examples test boundaries only.
