Convolutional Block Attention Module

Layers & Modules AIMech:ConvolutionalBlockAttentionModule DRAFT
Aliases: CBAM
A convolutional feature refinement component that sequentially applies learned channel attention and then spatial attention to an intermediate feature tensor.
Identity Notes & Concept Scope This record covers the canonical channel-first CBAM configuration from the 2018 paper. It is a reusable component rather than a complete CNN, detector or gradient-based explanation method. Spatial-first, parallel, channel-only and alternative pooling configurations are separately assessed variants, not silent replacements of this selected procedure. Claims & Grounded Evidence

2 Claims
Mechanism #method
Compute global spatial average and maximum descriptors for every channel. Pass both through the same two-layer bottleneck MLP, with ReLU after its reduction layer, sum the resulting channel logits and apply sigmoid. Broadcast the channel weights over space and multiply them into the input tensor. From this channel-refined tensor, compute average and maximum maps over the channel axis, concatenate these two spatial maps, apply a convolution with a 7-by-7 kernel and sigmoid, then multiply the spatial weights across all channels. Thus the second attention stage depends on the output of the first, rather than being computed in parallel from the original tensor. The paper’s residual example applies the component before skip addition; the learned component also operates during inference.

Scope #implementation-convention
The pinned author implementation follows channel-then-spatial gating with average/max channel descriptors sharing one MLP. Its spatial path uses a bias-free 7-by-7 convolution followed by batch normalization and sigmoid, with no intervening ReLU. Optional pooling choices and no_spatial are exposed as code configurations. This static inspection does not establish runtime compatibility or reproduction of a trained checkpoint.

⚠️ Curated Limitations & Negative Results

  • Average and maximum channel descriptors share the same MLP parameters. The sum occurs before sigmoid, not between independently sigmoid-normalized channel weights. Spatial pooling runs over channels, whereas the channel stage pools over spatial positions.
  • Reversing the stages or computing both from the original input generally changes the transformation. The spatial kernel and reduction ratio were selected empirically; the pinned implementation exposes alternative pooling and a channel-only switch, which are not the canonical configuration asserted here.
  • Independent sigmoid gates need not sum to one. Each multiplicative gate attenuates immediate feature magnitude; relative emphasis is not an absolute amplification guarantee. The learned weights add parameters and computation.
  • The source’s Grad-CAM visualizations and selected-image user study do not certify causal faithfulness, calibrated object probabilities or universal interpretability. CBAM itself is not Grad-CAM or a complete object detector, and no benchmark improvement or hardware-independent speed claim is curated.
