Hidden Markov tree

Model Families AIMech:HiddenMarkovTree DRAFT
Aliases: HMT
A latent-variable model on a fixed rooted tree in which hidden states factor into a root distribution and conditionally independent parent-to-child transitions, with observations emitted independently by their corresponding hidden states.
Identity Notes & Concept Scope This record uses the classical independent-emission meaning of hidden Markov tree, exemplified by the inspected quadtree image model. The tree describes stochastic dependencies between sites or scales; it is not a decision tree, a hierarchical mixture-of-experts gate tree or the within-time hierarchy of a hidden Markov decision tree. It is a restricted pairwise Markov tree with kernels A(x_child|x_parent)*b(y_child|x_child). Some pairwise-tree literature uses hidden Markov tree more broadly for a Markov hidden marginal with correlated observations; that broader usage is not equated with this independent-emission definition. A path is an HMM special case; branching is permitted. Claims & Grounded Evidence

1 Claim
Mechanism #method
Specify a normalized root law pi(x_r), normalized transitions A_s(x_s|x_parent(s)) and normalized local emissions b_s(y_s|x_s). Then p(x,y)=pi(x_r)*product_nonroot A_s*product_s b_s. At a site without an observation use emission factor1. For finite hidden states, an upward likelihood message is L_s(x_s)=b_s(y_s|x_s)*product_child_t sum_(x_t) A_t(x_t|x_s)*L_t(x_t). The root posterior is proportional to pi*L_r, and each child posterior conditional is proportional to A_t*L_t for fixed parent. Propagating the root posterior downward gives node and edge marginals. Replacing child sums with maxima and retaining maximizing states yields joint MAP by backtracking; independently maximizing node marginals gives MPM and can select a different configuration. Exact node and edge posterior expectations permit an EM parameter update for a specified, properly normalized tree model. The source instantiates the tree as a quadtree, with optional observation levels and optional parameter tying across scales.

⚠️ Curated Limitations & Negative Results

  • The record is scoped to independent child transitions and independent site emissions on a fixed finite rooted tree. Coupled siblings, loopy graphs, correlated emissions and learned topology require additional constructions. A causal tree factorization here expresses conditional probability, not intervention semantics.
  • Generic dense transitions with K hidden states require O(number_of_edges*K^2) arithmetic for the sum-product pass; linearity in sites assumes a fixed state count. Source complexity statements linear in K are not adopted for arbitrary dense kernels. Positive evidence and careful support handling are required; numerical scaling reduces but does not eliminate all numerical risks.
  • The source’s Equation(10) omits the complement needed for a minimized Hamming loss, and Figure4 prints argmin where Equation(11) correctly uses argmax of a posterior. Its preliminary prior pass requires root-to-leaf order. This record uses consistent sum-product/max-product semantics rather than those literal displays.
  • For Equation(17)’s shared same-state transition probability theta, the unconstrained EM update is expected same-state edge count divided by edge count. Equations(26)–(27) print an extra state-count divisor, conflicting with the earlier theta>1/K restriction. Active parameter constraints, zero expected counts and emission degeneracy need separate treatment.
  • The exact posterior factorization in Equation(29) supports ancestral sampling after subtree messages. The experimental H-MCEM uses a local-observation conditioning shortcut and constructed coarse observations; those samples are not certified exact draws from the original posterior. SMAP is a different loss with an approximate procedure, not an alias for exact joint MAP or MPM.
  • Quadtree image priors can create location-dependent block artifacts. EM remains initialization-sensitive and need not find a global optimum. The selected synthetic, flood and microscopy examples establish application context, not universal segmentation superiority, a modern benchmark or a reproduced implementation.
