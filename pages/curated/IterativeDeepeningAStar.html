Iterative-deepening A-star search

Algorithms AIMech:IterativeDeepeningAStar DRAFT
Aliases: IDA*, Iterative-deepening-A*
A heuristic search algorithm that repeats depth-first passes bounded by f=g+h, starting with the start-state heuristic and raising each cutoff to the smallest value that exceeded the preceding cutoff.
Identity Notes & Concept Scope IDA-star is the cost-threshold variant of iterative deepening. The g value is the cost of the current search path and h estimates remaining cost. It does not maintain A-star’s complete open and closed lists, and its cutoff is not simply a depth limit. Claims & Grounded Evidence

2 Claims
Mechanism #search-procedure
Within each pass, expand along a depth-first path until g+h exceeds the current cutoff. Track the smallest exceeded value to set the next pass’s cutoff, then restart from the initial state; depth-first traversal state replaces the complete A-star frontier.
  • supports Source: Depth-First Iterative-Deepening: An Optimal Admissible Tree Search · Locator: Section 6, printed pp. 103–105 / PDF pp. 7–9; threshold update and qualified heuristic analysis
Limitation #regeneration-and-order
The later paper corroborates the minimum-exceeded-value threshold update and explains that iterative deepening need not follow best-first order with a nonmonotone cost function. It also identifies tree cases with many distinct costs in which regeneration overhead is substantial.
  • supports Source: Linear-Space Best-First Search: Summary of Results · Locator: Previous Work, printed pp. 533–534 / PDF pp. 1–2; Theoretical Results, printed p. 536 / PDF p. 4

⚠️ Curated Limitations & Negative Results

  • Lowest-cost solution arguments require an admissible heuristic and suitable search/termination assumptions; arbitrary heuristic estimates are not certified here.
  • The method regenerates search paths. Many distinct cutoff values or duplicate routes can impose substantial additional work; this record does not claim the same runtime or expansion count as A-star on every graph.
  • With a nonmonotone evaluation function, iterative deepening does not in general visit newly expanded nodes in best-first order within a cutoff.
  • The original journal paper has an access-limited 1986 erratum. Its basic procedure is corroborated by the 1992 primary paper; the 1985 global asymptotic-optimality theorem is not asserted.
