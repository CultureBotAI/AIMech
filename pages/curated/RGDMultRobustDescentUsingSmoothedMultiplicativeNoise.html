RGDMult Robust Descent Using Smoothed Multiplicative Noise

Algorithms AIMech:RGDMultRobustDescentUsingSmoothedMultiplicativeNoise DRAFT
Aliases: RGDMult, Robust Gradient Descent with Smoothed Multiplicative Noise, Smoothed Multiplicative Noise Robust Descent
A robust first-order stochastic optimization algorithm that minimizes population risk under heavy-tailed data distributions by perturbing model parameters with multiple independent draws of unit-mean multiplicative noise per outer iteration, estimating perturbed gradients on mini-batches via a coordinate-wise Catoni-type M-estimator, and aggregating the inner perturbed gradient estimates with a second Catoni M-estimator to bound excess multiplicative-noise variance by 1/m.
Identity Notes & Concept Scope No AIO class represents RGDMult or smoothed multiplicative-noise Catoni robust gradient descent; ArtificialNeuralNetwork (AIO:ArtificialNeuralNetwork) is the closest broad match covering neural and statistical learning models trained with multiplicative-noise descent.

Claims & Grounded Evidence

4 Claims
Mechanism #catoni-coordinatewise-m-estimator-gradient-concentration
RGDMult estimates each coordinate of the gradient by solving a Catoni-type M-estimation root equation with a bounded soft-truncation influence function psi, achieving sub-Gaussian concentration around the true population gradient under only finite variance.
  • supports Source: Robust descent using smoothed multiplicative noise · Locator: Section 2.1, Equations 3-4 and Lemma 1, pp. 2-3
Mechanism #smoothed-multiplicative-noise-variance-shrinking
Averaging gradient evaluations across m independent draws of unit-mean multiplicative parameter noise per iteration preserves the expected multiplicatively perturbed objective while shrinking the excess multiplicative-noise variance term by a factor of 1/m.
  • supports Source: Robust descent using smoothed multiplicative noise · Locator: Section 2.2, Theorem 4 and Equations 5-6, p. 3; Section 3, Algorithm 1, p. 4
Application #heavy-tailed-statistical-risk-minimization-application
RGDMult is applied to empirical and population risk minimization under heavy-tailed data and gradient distributions where standard empirical-mean gradient descent and unsmoothed Bernoulli dropout suffer from high variance.
  • supports Source: Robust descent using smoothed multiplicative noise · Locator: Section 1, pp. 1-2; Section 4, Figures 2-4, pp. 5-7
Limitation #coordinatewise-catoni-dimension-scaling-limitation
Because the Catoni M-estimator is applied coordinate-wise across d parameters and union-bounded over coordinates, the high-probability gradient estimation error bound scales with sqrt(d log(d/delta)/n) and requires solving d scalar root-finding problems per step.
  • supports Source: Robust descent using smoothed multiplicative noise · Locator: Section 2.1, Lemma 1 and Remark 3, pp. 2-3; Section 3, Algorithm 1, p. 4
