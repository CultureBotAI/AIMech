Catalyst Universal Acceleration for First-Order Optimization

Aliases: Lin-Mairal-Harchaoui Catalyst Generic Acceleration Scheme, Inexact Accelerated Proximal Point Envelope for Finite-Sum Optimization, Catalyst Acceleration for SAG, SAGA, SVRG, SDCA, and MISO
Catalyst Universal Acceleration for First-Order Optimization is a generic outer-loop inexact accelerated proximal point framework introduced by Lin, Mairal, and Harchaoui (2015, 2018) that accelerates a broad class of first-order and incremental finite-sum optimization algorithms M (such as SAG, SAGA, SVRG, SDCA, MISO, and randomized coordinate descent) on composite objectives min_{x in R^p} {F(x) := f(x) + psi(x)} (where f is mu-strongly convex and L-smooth, or convex with mu = 0). At outer step k, Algorithm 1 forms the better-conditioned (mu + kappa)-strongly convex auxiliary proximal subproblem G_k(x) = F(x) + (kappa / 2)||x - y_{k-1}||_2^2 around the extrapolated center y_{k-1}, computes an approximate minimizer x_k approx argmin_x G_k(x) using the inner method M up to tolerance G_k(x_k) - G_k^* <= epsilon_k, updates alpha_k in (0, 1) via the Nesterov quadratic equation alpha_k^2 = (1 - alpha_k) alpha_{k-1}^2 + q alpha_k with q = mu / (mu + kappa), and extrapolates y_k = x_k + beta_k (x_k - x_{k-1}) with beta_k = alpha_{k-1}(1 - alpha_{k-1}) / (alpha_{k-1}^2 + alpha_k). Using canonical quadratic estimate sequences (Lemmas A.6-A.8, Equations 20-28) and a discrete Gronwall-type quadratic sequence inequality (Lemma A.10), Theorem 3.1 proves that when epsilon_k = (2/9)(F(x_0) - F^*)(1 - rho)^k with rho < sqrt(q), the outer loop achieves the accelerated linear rate F(x_k) - F^* <= (8 / (sqrt(q) - rho)^2)(1 - rho)^{k+1}(F(x_0) - F^*); balancing the inner and outer work via kappa = L / (n + 1) - mu reduces total finite-sum gradient complexity from O((n + L/mu) log(1/epsilon)) to tilde{O}((n + sqrt(n L / mu)) log(1/epsilon)).

Identity Notes & Concept Scope Distinct from Regularized Nonlinear Acceleration of Fixed-Point Iterations (`AIMech:RegularizedNonlinearAccelerationOfFixedPointIterations`), which extrapolates a post-hoc trajectory of fixed-point iterates via Tikhonov-regularized residual Gram inversion without modifying the inner objective, and from specific inner variance-reduced solvers that require custom algorithm-specific momentum couplings. Specifically captures the Catalyst black-box proximal wrapper G_k(x) = F(x) + (kappa/2)||x - y_{k-1}||^2, the canonical estimate-sequence recurrences (Equations 20-28), warm-start inner-loop complexity bounds (Proposition 3.2), and optimal smoothing parameter selection kappa = O(L / n) for finite-sum optimization.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
For any sequence {x_k} and parameter q = mu / (mu + kappa), the canonical estimate sequence defined by gamma_k = (1 - alpha_{k-1}) gamma_{k-1} + alpha_{k-1} mu (Equation 20) and v_k = ((1 - alpha_{k-1}) gamma_{k-1} v_{k-1} + alpha_{k-1} mu x_k - alpha_{k-1} kappa (y_{k-1} - x_k)) / gamma_k (Equation 21) under the Algorithm 1 recurrence alpha_k^2 = (1 - alpha_k) alpha_{k-1}^2 + q alpha_k and y_k = x_k + beta_k (x_k - x_{k-1}) with beta_k = alpha_{k-1}(1 - alpha_{k-1}) / (alpha_{k-1}^2 + alpha_k) satisfies the exact algebraic identities gamma_k = (kappa + mu) alpha_{k-1}^2 (Equation 27), v_k = (x_k - (1 - alpha_{k-1}) x_{k-1}) / alpha_{k-1} (Equation 28), and (1 - alpha_k) gamma_k v_k - alpha_k kappa y_k + alpha_k(1 - alpha_k)(kappa + mu) x_k = 0 (Lemma A.8).
  • supports Source: A Universal Catalyst for First-Order Optimization · Locator: Appendix A.1, Lemmas A.6, A.7, and A.8 (Equations 20-28), pp. 11-14
  • supports Source: A Universal Catalyst for First-Order Optimization (arXiv abstract) · Locator: Abstract: Generic acceleration scheme based on inexact accelerated proximal point iterations
Mechanism #claim-02
When F is mu-strongly convex and each inner subproblem G_k(x) is solved to accuracy G_k(x_k) - G_k^* <= epsilon_k = (2/9)(F(x_0) - F^*)(1 - rho)^k with rho < sqrt(q) = sqrt(mu / (mu + kappa)), Theorem 3.1 guarantees F(x_k) - F^* <= (8 / (sqrt(q) - rho)^2)(1 - rho)^{k+1}(F(x_0) - F^*); when mu = 0 (convex F) and alpha_0 = (sqrt(5) - 1)/2, the multiplier sequence lambda_k = prod_{i=0}^{k-1}(1 - alpha_i) satisfies 2 / (k + 2)^2 <= lambda_k <= 4 / (k + 2)^2 for all k >= 0 (Lemma B.3), yielding O(1 / k^2) outer convergence for decaying errors epsilon_k = 2(F(x_0) - F^*) / (9(k + 2)^{4 + eta}) (Theorem 3.3).
  • supports Source: A Universal Catalyst for First-Order Optimization · Locator: Section 3.2-3.4, Theorems 3.1 and 3.3, pp. 4-5; Appendix A.2, Lemma A.10 and Proof of Theorem 3.1, pp. 14-16; Appendix B, Lemma B.3, p. 19
  • supports Source: A Universal Catalyst for First-Order Optimization (Crossref metadata) · Locator: Abstract: Catalyst achieves optimal convergence rates in strongly convex and convex settings with explicit control of inexactness
Limitation #claim-03
If the inner-loop optimization error epsilon_k fails to decay fast enough (e.g., constant non-decaying inner error epsilon_k = epsilon_0 > 0), the error accumulation term sum_{j=1}^k sqrt(2 lambda_k / lambda_j * epsilon_j) in Proposition A.9 prevents convergence to F^* and causes the outer iterate sequence to stall above an error floor.
  • supports Source: A Universal Catalyst for First-Order Optimization · Locator: Appendix A.2, Proposition A.9 (Equation 29), p. 14; Appendix B, Proposition B.2 (Equation 35), p. 18

⚠️ Curated Limitations & Negative Results

  • Incurs a logarithmic inner-loop factor log(L / mu) in total complexity due to solving sequence of auxiliary subproblems G_k(x), and requires tuning the smoothing parameter kappa and inner stopping criterion.
