FFA-LoRA: Federated Freeze-A Low-Rank Adaptation

Algorithms AIMech:FfaLoraFederatedFreezeALowRankAdaptation DRAFT
Aliases: FFA-LoRA, Federated Freeze A LoRA, Federated Freeze-A Low Rank Adapters, FFA-LoRA and QVP Adapters
A parameter-efficient and differentially private federated fine-tuning algorithm (Federated Freeze A LoRA / FFA-LoRA; Sun, Li, Li, and Ding, ICLR 2024) that re-parameterizes each adapted weight matrix W in R^{d x k} as W = W_0 + B A_0 with B in R^{d x r} initialized to zero (B_0 = 0) and A_0 in R^{r x k} initialized from a random Gaussian (or orthogonal/SVD) distribution and kept strictly frozen throughout local training and server aggregation. By updating and aggregating only B, FFA-LoRA halves the trainable parameter count and communication cost relative to vanilla LoRA, eliminates the server-side cross-client aggregation error ((1/n) sum_i B_i) A_0 = (1/n) sum_i (B_i A_0) (Eq. 4), removes the quadratic non-Gaussian DP-SGD noise amplification term xi_B xi_A so injected noise enters linearly as xi_B A_0, and achieves dynamics invariant to the LoRA scaling factor alpha (equivalent to the alpha -> infinity limit of vanilla LoRA, Theorem 1).
Identity Notes & Concept Scope Distinct from vanilla federated LoRA / FedIT (Zhang et al., 2023; Kuang et al., 2023), which jointly trains both low-rank matrices A and B on each client and averages them separately on the server—incurring the bilinear aggregation error (1/2)(B_1 + B_2)(1/2)(A_1 + A_2) != (1/2)(B_1 A_1 + B_2 A_2) (Eq. 3) and quadratic DP-SGD noise amplification xi_B xi_A. Distinct from FLoRA (AIMech:FloraStackingBasedFederatedHeterogeneousLowRankAdaptation; Wang et al., NeurIPS 2024), which trains both A_k and B_k on clients and eliminates cross-term aggregation noise by stacking A_k vertically and B_k horizontally on the server rather than freezing A_0 globally across clients. Also encompasses the authors' ultra-low-budget QVP Adapter extension W = W_0 + Q_0 V P_0 with frozen Q_0 in R^{d x r}, P_0 in R^{r x k} and trainable zero-initialized V in R^{r x r} (Appendix A.4, p. 16).

Claims & Grounded Evidence

4 Claims
Mechanism #ffa-lora-exact-linear-aggregation-and-dp-noise-linearization-mechanism
By fixing the randomly initialized projection matrix A_0 in R^{r x k} and updating only the zero-initialized matrix B in R^{d x r}, FFA-LoRA makes the weight increment Delta W_i = B_i A_0 linear in the trainable parameters so server FedAvg satisfies W_tilde^+ = W_0 + ((1/2)(B_1 + B_2)) A_0 = W_0 + (1/2)(B_1 A_0 + B_2 A_0) = W^+ with zero bilinear cross-term error (Eq. 4, p. 5), and under DP-SGD perturbations xi_B updates W_0 + (B + xi_B) A_0 = W_0 + B A_0 + xi_B A_0 without the quadratic noise cascade term xi_B xi_A of vanilla LoRA (Section 3, p. 4; Section 4, p. 6).
  • supports Source: Improving LoRA in Privacy-preserving Federated Learning · Locator: Section 3 Discordances 1-2, Eq. (3), Figure 1, pp. 4-5; Section 4, Eq. (4), pp. 5-6
Scope #ffa-lora-infinite-alpha-limit-and-lipschitz-smoothness-preservation-scope
Theorem 1 (p. 6; proof in Appendix A.2, pp. 13-14) proves that for identical initial weight W_0 + B_0 A_0 and learning rate scaling eta_alpha = eta_1 / alpha^2, the local update trajectory {W_{alpha_LoRA}^k} of vanilla LoRA converges to the alpha-invariant trajectory {W_{alpha_FFA}^k} of FFA-LoRA in the limit lim_{alpha_LoRA -> inf} W_{alpha_LoRA}^k = W_{alpha_FFA}^k (Eq. 5); moreover, Theorem 2 (Appendix A.1, p. 13) proves that if F(W, D) is L-Lipschitz smooth in W and ||A_0||_F <= C, then F(W_0 + B A_0) is (L C^2)-Lipschitz smooth with respect to B, whereas joint (A, B) LoRA has no global Lipschitz smoothness constant.
  • supports Source: Improving LoRA in Privacy-preserving Federated Learning · Locator: Section 4 Theorem 1, Eq. (5), p. 6; Appendix A.1 Theorem 2, p. 13; Appendix A.2 Proof for Theorem 1, pp. 13-14
Limitation #ffa-lora-frozen-random-subspace-expressivity-at-very-low-rank-limitation
Because row subspace A_0 in R^{r x k} is frozen at random initialization, FFA-LoRA cannot rotate A_0 toward task-specific right singular vectors and exhibits slightly lower non-private accuracy than equal-rank vanilla LoRA at very small rank r = 2 (e.g., 88.56% vs 91.76% on QNLI at r = 2 in Table 4, p. 9, though outperforming LoRA when compared at equal trainable parameter count r_FFA = 2 r_LoRA).
  • supports Source: Improving LoRA in Privacy-preserving Federated Learning · Locator: Section 5.2 Ablation Study, Tables 3-4, pp. 8-9; Appendix A.4 Table 6, p. 16
Application #ffa-lora-differentially-private-federated-llm-and-vit-fine-tuning-application
Applied to privacy-preserving (DP-SGD with eps in {1, 3, 6}, delta = 10^-5) and non-IID cross-silo federated fine-tuning of RoBERTa-Large on GLUE (MNLI, SST-2, QQP, QNLI), LLaMA-7B on GSM-8K mathematical reasoning, and Vision Transformer (ViT) on Food-101.
  • supports Source: Improving LoRA in Privacy-preserving Federated Learning · Locator: Section 5 Experiments, Tables 1-4, pp. 6-9; Appendix A.3 Table 5 & Appendix A.7 Table 8, pp. 14-17

⚠️ Curated Limitations & Negative Results

  • Freezing A_0 restricts the row space of the weight update Delta W = B A_0 to the fixed random r-dimensional subspace spanned by A_0, which can underperform trainable-A LoRA in non-private settings when r is very small (e.g., r = 2 in Table 4, p. 9).
  • Cannot reduce the trainable parameter count per adapted layer below d + k (rank r = 1) unless replaced by the doubly-projected QVP Adapter variant W_0 + Q_0 V P_0, which trades off accuracy for smaller parameter budgets (Appendix A.4, Table 6, p. 16).
  • Requires all participating clients to share the same rank r and frozen projection matrix A_0 during aggregation (Section 4, p. 5).
