Gradient Descent Avoidance of Strict Saddle Points via Stable Manifold Theorem

Mathematical Methods AIMech:GradientDescentAvoidanceOfStrictSaddlePointsViaStableManifoldTheorem DRAFT
Aliases: Lee-Simchowitz-Jordan-Recht Gradient Descent Converges to Minimizers, Almost-Sure Strict-Saddle Avoidance via Center-Stable Manifold Theorem, Diffeomorphic Gradient Descent Flow on Strict-Saddle Landscapes
Gradient Descent Avoidance of Strict Saddle Points via Stable Manifold Theorem is a dynamical-systems and non-convex optimization analysis introduced by Lee, Simchowitz, Jordan, and Recht (2016) proving that deterministic gradient descent x_{k+1} = g(x_k) = x_k - alpha grad f(x_k) with constant step size 0 < alpha < 1 / L on any twice continuously differentiable, L-gradient-Lipschitz function f: R^d -> R converges to a strict saddle point x^* (where grad f(x^*) = 0 and lambda_min(grad^2 f(x^*)) < 0) only from a set of initial conditions W_s of Lebesgue measure zero. The proof proceeds in two key steps: Proposition 4.5 proves via the proximal envelope and inverse function theorem that for 0 < alpha < 1 / L the gradient map g(x) = x - alpha grad f(x) is a global bi-Lipschitz C^1 diffeomorphism whose Jacobian Dg(x) = I - alpha grad^2 f(x) has det(Dg(x)) != 0 everywhere and satisfies lambda_max(Dg(x^*)) = 1 - alpha lambda_min(grad^2 f(x^*)) > 1 at every strict saddle x^*; Theorem 4.1 then applies the Shub (1987) Local Center-Stable Manifold Theorem (Theorem 4.2) to show that the local stable set W_{loc}^{cs}(x^*) is a C^1 submanifold of codimension at least 1 (hence Lebesgue measure zero), and countable pullbacks union_{k>=0} g^{-k}(W_{loc}^{cs}) preserve measure zero even when the strict saddle set A^* is uncountably infinite via Lindelof's lemma.
Identity Notes & Concept Scope Distinct from Perturbed Gradient Descent for Escaping Saddle Points in Hessian-Lipschitz Optimization (`AIMech:PerturbedGradientDescentForEscapingSaddlePointsInHessianLipschitzOptimization`), which modifies gradient descent by injecting uniform ball perturbations to achieve polynomial tilde{O}(1/epsilon^2) worst-case runtime, whereas Lee et al. (2016) analyze unmodified deterministic gradient descent with random initialization via the diffeomorphic Center-Stable Manifold Theorem. Also captures the explicit 2D degenerate-saddle counterexample f(x,y) = x^2/2 + y^4/4 - y^3/3 where an open plot of initial conditions (0,1) x (-2,0) converges to a non-strict saddle point.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
For any C^2 function f: R^d -> R with L-Lipschitz gradient and step size 0 < alpha < 1 / L, the gradient descent map g(x) = x - alpha grad f(x) is a global C^1 diffeomorphism whose inverse is the single-valued proximal operator of h(x) = -alpha f(x) + ||x||_2^2 / 2, and whose differential Dg(x^*) = I - alpha grad^2 f(x^*) at any strict saddle point x^* has at least one eigenvalue strictly greater than 1, ensuring that the set of initial conditions converging to any strict saddle point has Lebesgue measure zero.
  • supports Source: Gradient Descent Converges to Minimizers · Locator: Section 4.1, Theorem 4.1, Theorem 4.2, and Proposition 4.5, pp. 5-7
  • supports Source: Gradient Descent Converges to Minimizers (arXiv abstract) · Locator: Abstract: Gradient descent with random initialization converges to a strict saddle point with probability zero via the Stable Manifold Theorem
Mechanism #claim-02
In the quadratic model f(x) = (1/2) x^T H x with indefinite invertible Hessian H having k > 0 negative eigenvalues, gradient descent x_{t+1} = (I - alpha H) x_t converges to the saddle point 0 if and only if x_0 lies in the (d-k)-dimensional subspace E_s spanned by eigenvectors with positive eigenvalues, whereas any nonzero projection onto the unstable subspace E_u grows geometrically as (1 - alpha lambda_i)^t with 1 - alpha lambda_i > 1.
  • supports Source: Gradient Descent Converges to Minimizers · Locator: Section 3, Motivating Quadrics (Proposition 3.1), pp. 4-5
  • supports Source: Gradient Descent Converges to Minimizers (Crossref metadata) · Locator: Abstract: Analysis of unstable eigendirections and measure-zero stable manifolds for gradient descent
Limitation #claim-03
The strict-saddle condition lambda_min(grad^2 f(x^*)) < 0 and the step-size bound alpha < 1 / L are both necessary: for the C^2 function f(x, y) = x^2 / 2 + y^4 / 4 - y^3 / 3, the point (0, 0) is a degenerate (non-strict) saddle point with Hessian diag(1, 0), and every initial condition in the positive-measure open rectangle (0, 1) x (-2, 0) converges under gradient descent to the saddle point (0, 0) rather than the local minimum (0, 1).
  • supports Source: Gradient Descent Converges to Minimizers · Locator: Appendix A, Necessity of Strict Saddle Assumption, pp. 10-11

⚠️ Curated Limitations & Negative Results

  • Provides an asymptotic almost-sure guarantee without polynomial-time escape bounds (trajectories initialized exponentially close to the stable manifold can take arbitrarily many iterations to escape), and fails at degenerate saddles where lambda_min(grad^2 f(x^*)) = 0.
