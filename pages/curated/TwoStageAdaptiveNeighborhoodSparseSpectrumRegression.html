Two-stage adaptive-neighborhood sparse-spectrum regression

Algorithms AIMech:TwoStageAdaptiveNeighborhoodSparseSpectrumRegression DRAFT
A query-specific sparse-spectrum regression procedure that fits a variational model to Euclidean neighbors, reselects neighbors from the full training set using squared posterior-mean inverse-lengthscales, and refits a second local model for prediction.

Claims & Grounded Evidence

5 Claims
Mechanism #local-fitting-context
For scalar responses y_i at inputs x_i in R^d, Tan et al. use m fixed standard-normal spectral draws s_r and paired features cos((s_r elementwise x_i)^T*lambda) and sin((s_r elementwise x_i)^T*lambda). The 2m coefficients have a conditional Gaussian prior and observations have Gaussian noise. A shared vector lambda controls all features; its Gaussian variational factor has mean mu_lambda and may have full covariance. The local models in Section 6 use the paper’s adaptive nonconjugate variational message-passing Algorithm 2. This is a specified approximate fitting routine, without a convergence or exact-posterior guarantee.
  • supports Source: Variational inference for sparse spectrum Gaussian process regression · Locator: Sections 2–4, Equations 4–5 and variational family, PDF pp. 3–7; Section 6 local fits, PDF p. 8
Mechanism #two-stage-selection
Given N finite training pairs D={(x_i,y_i)}, a fixed query x_star and an integer neighborhood size k with 1<=k<=N, select the k closest training inputs by Euclidean distance, forming index set N1. Fit local model M1 to the pairs indexed by N1. Let mu_lambda be the posterior-mean vector from M1 and define d_mu(x_star,x_i)=sqrt(sum_l mu_lambda_l^2*(x_star_l-x_i_l)^2). Select k nearest inputs from the entire original training set D using this weighted distance, forming N2; N2 is not restricted to N1. Fit a fresh local model M2 to the pairs indexed by N2 and use its variational posterior for prediction at x_star. These steps assume the local fits produce valid finite variational parameters; neighbor ties require a specified implementation convention.
  • supports Source: Variational inference for sparse spectrum Gaussian process regression · Locator: Section 6, two numbered stages and Equation 16, PDF p. 8
Mechanism #distance-interpretation
The weights in Equation 16 are squares of the first fit’s posterior means, (E_q[lambda_l])^2, rather than posterior second moments E_q[lambda_l^2]. The latter would add Var_q(lambda_l) and generally select different neighbors. Although the source calls lambda a lengthscale, Equation 1 uses exp(-0.5*sum_l lambda_l^2*h_l^2), so its magnitude is an inverse-lengthscale parameter. Larger magnitude makes a fixed input displacement farther in the adapted distance; a zero posterior mean removes that coordinate from this distance even if its posterior variance is large. This is a plug-in neighborhood rule, not Bayesian averaging of neighborhood memberships.
  • supports Source: Variational inference for sparse spectrum Gaussian process regression · Locator: Section 2, Equation 1, PDF p. 3; signed lambda and relevance discussion, PDF p. 4; Section 6, Equation 16 and interpretation, PDF p. 8
Scope #query-specific-prediction
Repeat the two local fits separately for each requested prediction location. The second fitted variational distribution, not the first fit or an average of neighboring responses, supplies the predictive inference. The source uses approximate integration of the Gaussian observation model under variational factors for coefficients, lambda and noise scale. Query-local fitting allows different neighborhoods and smoothing/noise estimates at different locations; the construction does not itself provide a single joint posterior covariance across all query locations.
  • supports Source: Variational inference for sparse spectrum Gaussian process regression · Locator: Section 5, Equation 15, PDF pp. 7–8; Section 6, PDF p. 8
Limitation #two-stage-boundary
The published neighborhood procedure stops after two fits. The authors advise against repeatedly adapting the neighborhood because expansion and contraction can cycle; there is no asserted fixed-point guarantee. Their experiments also apply the same neighborhood construction to point-estimate SSGP fits by replacing mu_lambda with fitted lambda estimates. That comparator does not possess the variational posterior over lambda and is distinguished from this record’s variational instantiation.
  • supports Source: Variational inference for sparse spectrum Gaussian process regression · Locator: Section 6, summary after the two numbered stages, PDF p. 8

⚠️ Curated Limitations & Negative Results

  • The distance is a pseudometric when one or more mean-derived weights vanish, and all inputs tie if every weight vanishes. No universal tie-break, minimum effective neighborhood size, rescaling convention or fallback for invalid local fits is specified here. Small neighborhoods and poorly scaled or irrelevant inputs can impair fitting.
  • The neighborhood rule uses only squared posterior means. It does not propagate the first fit’s full lengthscale uncertainty into neighbor selection, nor does a small weight establish exact posterior variable exclusion. Sign changes leave this diagonal distance unchanged; this does not assert sign invariance of every finite-feature model at fixed spectral draws.
  • Nonconjugate variational fixed-point updates can have local optima or fail to improve the bound; the source explicitly does not guarantee convergence. Half-Cauchy scale-factor normalizers require one-dimensional integration. Detailed adaptive-step initialization/rollback notation and an executable author implementation remain separate pending audits; the neighborhood rule is not presented as a verified fitting implementation.
  • Query-specific finite spectral fits need not equal conditioning a single coherent nonstationary GP. The variational predictive mixture is generally not Gaussian; moment-based evaluation does not establish exact mixture shape or calibrated intervals. Neighbor search, preprocessing, failed fits and repeated query fits prevent inferring constant total cost from a fixed k.
  • The source’s spectral-density covariance prose below Equation 3 conflicts with its displayed kernel and subsequent reparameterization; this record follows Equations 1, 4 and 16. The predictive-variance display has a feature-transpose inconsistency, so no unqualified copy of that display is used as mechanism evidence.
  • All preprint pages were read; the publisher page supplied bibliographic confirmation and a subscription preview, not the complete journal text. The author page returned HTTP 502. No author implementation was located in the bounded code-search queries, which is not an exhaustive absence claim. No author code, model fitting, training, paid access or benchmark was run. Exact finite curator arithmetic checks only the distance boundary at supplied illustrative parameters. The record remains DRAFT.
