Complete Karmarkar–Karp

Algorithms AIMech:CompleteKarmarkarKarp DRAFT
Aliases: CKK
A complete anytime algorithm for two-way number partitioning that first follows Karmarkar–Karp differencing, then explores complementary sum branches over residual subpartitions, retaining the best partition and using sound bounds or exhaustive search to certify optimality.

This two-way complete anytime algorithm searches relative subpartition orientations by differencing and summing the largest residuals. It is distinct from the irreversible KK heuristic, complete greedy item assignment, generic DFS and discrepancy-order search. Multiway extensions remain separate leads. Claims & Grounded Evidence

6 Claims
Mechanism #difference-and-sum-branches
At a search state, select the two largest nonnegative residuals a>=b. The preferred child replaces them by a-b, representing opposite orientations of their partial partitions; the other replaces them by a+b, representing the same orientation. Keep residuals ordered and visit difference before sum in the source’s depth-first formulation. Repeated relative-orientation decisions cover all two-way partitions up to overall bin exchange. Bookkeeping is required to reconstruct original item assignments; this is not the complete greedy algorithm’s assignment of one raw item at a time.
  • supports Source: A Complete Anytime Algorithm for Number Partitioning · Locator: Sections2.6–3, manuscript PDF/printed pp.8–13; Section11 pp.27–28
Mechanism #dominance-and-parity
For a current largest residual a with remaining-residual sum r, any completion has residue at least max(0,a-r). If a>=r, placing all remaining residuals opposite a attains a-r, so the subtree can be solved directly; a lower bound no better than the incumbent also permits pruning. With exact integer weights, all attainable residues have the parity of the original total, allowing immediate optimality certification at0 for an even total or1 for an odd total. This parity stopping rule is not a generic real-valued tolerance rule.
  • supports Source: A Complete Anytime Algorithm for Number Partitioning · Locator: Section2.7 pruning and perfect partitions, manuscript PDF/printed pp.11–12; Section3 inherited CKK pruning, pp.12–13; curator exact-integer boundary calculations
Limitation #anytime-versus-optimal
The first difference-only solution has the KK residue; subsequent search may improve the incumbent, whose residue never increases. A time or node limit can return a useful feasible partition without proving optimality. Certification requires a matching valid lower bound or completion of the remaining search with sound pruning. Improvement is not guaranteed at each step, and the best partition need not be unique. In a constructed8,7,6,5,4 example, KK gives2 and complete search reaches0; stopping after one search node retains an uncertified2.
  • supports Source: A Complete Anytime Algorithm for Number Partitioning · Locator: Section3 pp.12–13; Section6 pp.17–19; Section12 pp.28–29; constructed sign-enumeration and interruption checks
Limitation #complexity-and-representation
The complete binary search has depth n-1 and can require exponentially many nodes. Depth-first organization supports a linear-space implementation with compact state and undo bookkeeping, but copying every residual list along the recursion is not itself a linear-space guarantee. Numeric bit complexity is separate from node counts. The source uses sorted arrays and special small-state termination in its implementation; these details do not turn exact partitioning into a polynomial-time algorithm.
  • supports Source: A Complete Anytime Algorithm for Number Partitioning · Locator: Section3 pp.12–13; Section4 pp.14–16, especially implementation notes and small-state termination
Scope #subset-sum-reduction-scope
For nonnegative weights of total s and a feasible subset-sum target c in[0,s], replace c by s-c when c<s/2 and append d=2c-s>=0. The augmented instance has a zero-residue two-way partition exactly when the original has a subset with the adjusted target, and complementation recovers the original target when needed. A nonzero optimum rules out that target only after optimality is certified; an interrupted positive incumbent does not. This decision reduction does not assert equality between nonzero partition residue and the original subset-sum error.
  • supports Source: A Complete Anytime Algorithm for Number Partitioning · Locator: Section10, manuscript PDF/printed pp.26–27; direct interpretation of the stated reduction
Scope #historical-evaluation-boundaries
The reported C implementations compare CKK and complete greedy search on uniform random integer instances using a SunUltraSparcModel1. Fixed precision changes the probability of a perfect partition and can make larger sampled instances easier; this is not monotone or universal hardness. Figure6 averages improvement ratios over100 trials with50 48-bit numbers, reporting large gains from continued search. Those distribution-, precision- and hardware-specific results do not guarantee arbitrary instances finish quickly. Three-way experiments and discrepancy-order variants are described separately from this two-way depth-first identity.
  • supports Source: A Complete Anytime Algorithm for Number Partitioning · Locator: Sections4–6 and Figures5–6, manuscript PDF/printed pp.14–19; Sections7–8 and Figures7–8 pp.19–26

⚠️ Curated Limitations & Negative Results

  • Scope is the two-way, nonnegative, finite-instance depth-first formulation. Multiway composition, cardinality constraints and discrepancy ordering require separate identity assessment.
  • Sound optimality claims assume exact arithmetic or rigorously conservative bounds. A floating-point near-zero residual is not automatically an exact certificate.
  • Anytime availability begins with a complete feasible partition; a limited run need not improve KK or establish optimality. Stored reconstruction information is required to return the actual partition.
  • The inspected primary is the31-page27June1997 manuscript. The later1998 journal DOI supplies bibliographic linkage, not a claim that final journal text or source code was inspected.
  • All manuscript pages were read; small exact-integer checks were executed without author-code or historical performance replication. They illustrate boundaries rather than prove the general completeness theorem.
