TernGrad (Stochastic Ternary Gradient Quantization for Distributed Deep Learning)

Algorithms AIMech:TernGradTernaryGradientsForDistributedDeepLearning DRAFT
Aliases: TernGrad, Stochastic Ternary Gradient Quantization, Ternary Gradients for Distributed Deep Learning
An unbiased stochastic ternary gradient quantization scheme for distributed synchronous SGD (Wen et al. 2017, Section 3, Equations 4-7) that compresses each worker's gradient vector g_t into ternary levels {-1, 0, +1} scaled by s_t = max_k |g_{tk}| = ||g_t||_infty via g_tilde_t = s_t * sign(g_t) o b_t where each coordinate Bernoulli mask b_{tk} in {0, 1} is sampled independently with probability P(b_{tk} = 1 | g_t) = |g_{tk}| / s_t, combined with layer-wise scalars and coordinate clipping |g_{tk}| <= c * sigma_t to bound the maximum magnitude s_t.
Identity Notes & Concept Scope Distinct from deterministic sign-based compression SignSGD (AIMech:SignSgdAndMajorityVoteCompressedNonconvexOptimization, Bernstein et al. 2018), which maps coordinates deterministically to {-1, +1} without zero level or unbiased probabilistic rounding, and from multi-level L2-norm quantized SGD QSGD (AIMech:QsgdQuantizedStochasticGradientDescentWithEliasCoding, Alistarh et al. 2017), which normalizes by the Euclidean norm ||g_t||_2 rather than the infinity norm s_t = ||g_t||_infty with layer-wise sigma-clipping.

Claims & Grounded Evidence

4 Claims
Mechanism #r417-unbiased-ternary-rounding-and-infinity-l1-variance-identity
Conditioned on g_t, TernGrad satisfies E[g_tilde_{tk} | g_t] = s_t sign(g_{tk}) (|g_{tk}| / s_t) = g_{tk} and coordinate second moment E[g_tilde_{tk}^2 | g_t] = s_t |g_{tk}| = ||g_t||_infty |g_{tk}|, yielding total quantization variance E[||g_tilde_t - g_t||_2^2 | g_t] = ||g_t||_infty ||g_t||_1 - ||g_t||_2^2 and almost-sure convergence under light-tailed bounded-variance assumptions (Section 4, Theorem 1).
  • supports Source: TernGrad: Ternary Gradients to Reduce Communication in Distributed Deep Learning · Locator: Section 3.1 Ternary Quantization (Eqs. 4-6) & Section 4 Convergence Analysis (Assumption 3, Theorem 1, Appendix A)
Mechanism #r417-layer-wise-quantization-and-sigma-gradient-clipping-variance-reduction
Replacing a single model-wide scalar s_t = ||g_t||_infty with per-layer scalars s_t^{(l)} = ||g_t^{(l)}||_infty (Section 3.2) and clipping coordinate outliers to [-c sigma_t, +c sigma_t] with c = 2.5 before quantization (Section 3.3, Eq. 7) shrinks the maximum scalar s_t and reduces the variance inflation factor kappa = max(|g_t|) / |g_t| across heterogeneous network layers.
  • supports Source: TernGrad: Ternary Gradients to Reduce Communication in Distributed Deep Learning · Locator: Section 3.2 Layer-wise Ternarizing & Section 3.3 Gradient Clipping (Eq. 7, Figures 2-3), pp. 1512-1514
Limitation #r417-parameter-localization-for-unshared-random-seeds-and-clipping-bias-limitation
In parameter-server topologies where parameters are evenly sharded across workers, sharing a random seed for b_t allows floating-point scalars s_t to be omitted during worker-to-server push only if each parameter tensor is localized to a single server shard (Section 3.1); additionally, pre-quantization gradient clipping introduces a small truncation bias when |g_{tk}| > c sigma_t.
  • supports Source: TernGrad: Ternary Gradients to Reduce Communication in Distributed Deep Learning · Locator: Section 3.1 Parameter Localization & Section 3.3 Gradient Clipping
Application #r417-alexnet-googlenet-and-vgg-imagenet-distributed-training-application
Applied to distributed synchronous SGD training of LeNet, CifarNet, AlexNet, GoogLeNet, and VGG-A on MNIST, CIFAR-10, and ImageNet, achieving 3.04x communication speedup without accuracy loss.
  • supports Source: TernGrad: Ternary Gradients to Reduce Communication in Distributed Deep Learning · Locator: Section 5 Experiments (Tables 1-3, Figures 4-6), pp. 1515-1518

⚠️ Curated Limitations & Negative Results

  • Requires layer-wise scaling and gradient clipping (c = 2.5 sigma) to prevent large coordinate outliers from inflating the infinity-norm scalar s_t = ||g_t||_infty.
  • Requires 2 bits per coordinate in general when encoding {-1, 0, +1} without entropy coding.
