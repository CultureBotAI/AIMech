Sequential kernelized independence testing by betting

Mathematical Methods AIMech:SequentialKernelizedIndependenceTestingByBetting DRAFT
Aliases: SKIT, Sequential Hilbert-Schmidt Independence Criterion Test by Betting, HSIC-SKIT, COCO-SKIT and KCC-SKIT, Symmetry-Based Sequential Kernel Independence Test
A sequential nonparametric independence hypothesis testing framework (Podkopaev, Blobaum, Kasiviswanathan, & Ramdas 2023, ICML / PMLR 202:27957-27993, arXiv:2212.07383) that tests whether streaming paired random variables Z_t = (X_t, Y_t) on general spaces X x Y are statistically independent (H_0 : P_{XY} = P_X x P_Y against H_1 : P_{XY} != P_X x P_Y) under arbitrary optional stopping and time-varying marginal distributions by pairing consecutive draws (Z_{2t-1}, Z_{2t}) with their coordinate-swapped pseudo-observations tilde{Z}_{2t-1} = (X_{2t-1}, Y_{2t}), tilde{Z}_{2t} = (X_{2t}, Y_{2t-1}) to evaluate predictable witness functions from reproducing kernel Hilbert spaces G x H — instantiated via the Hilbert-Schmidt Independence Criterion (HSIC), the Constrained Covariance (COCO), or the Kernel Canonical Correlation (KCC), or via symmetry-preserving odd, sequential signed-rank, and predictive betting payoffs for unbounded kernels — and updating a wealth martingale K_t = prod_{i=1}^t (1 + lambda_i f_i(Z_{2i-1}, Z_{2i})) via the Online Newton Step (ONS) strategy so that stopping at tau = inf{t >= 1 : K_t >= 1/alpha} controls nonasymptotic anytime Type-I error P_{H_0}(tau < infty) <= alpha and achieves power-one consistency with variance-adaptive exponential log-wealth growth.

Mechanism #hsic-swap-payoff-betting-martingale-linear-time-norm-and-ons-growth-rate
For characteristic reproducing kernel Hilbert spaces G on X (kernel k, feature map phi) and H on Y (kernel l, feature map psi) satisfying sup_x k(x,x) <= 1 and sup_y l(y,y) <= 1 (Assumption 1), HSIC-SKIT pairs consecutive observations Z_{2t-1} = (X_{2t-1}, Y_{2t-1}) and Z_{2t} = (X_{2t}, Y_{2t}) with coordinate-swapped pseudo-samples tilde{Z}_{2t-1} = (X_{2t-1}, Y_{2t}) and tilde{Z}_{2t} = (X_{2t}, Y_{2t-1}) to form the F_{t-1}-predictable normalized witness payoff f_t(Z_{2t-1}, Z_{2t}) = (1/2) <hat{g}_t, (phi(X_{2t}) - phi(X_{2t-1})) x (psi(Y_{2t}) - psi(Y_{2t-1}))>_{G x H} in [-1, 1] where hat{g}_t = (hat{mu}_{XY} - hat{mu}_X x hat{mu}_Y) / ||hat{mu}_{XY} - hat{mu}_X x hat{mu}_Y||_{G x H} (Equations 9–14, Proposition 1), whose denominator norm ||hat{mu}_{XY}^{(t)} - hat{mu}_X^{(t)} x hat{mu}_Y^{(t)}||_{G x H} = sqrt((1/(2t)^2) tr(K^{(t)} L^{(t)}) - (2/(2t)^3) 1_{2t}^T K^{(t)} L^{(t)} 1_{2t} + (1/(2t)^4)(1_{2t}^T K^{(t)} 1_{2t})(1_{2t}^T L^{(t)} 1_{2t})) is updated in O(t) time per step by caching tr(K^{(t)} L^{(t)}), K^{(t)} 1_{2t}, and L^{(t)} 1_{2t} (Appendix F.2, Equations 49–53); coupling f_t with the Online Newton Step (ONS) betting strategy lambda_t in [-1/2, 1/2] (Algorithm 2) yields a test martingale K_t = prod_{i=1}^t (1 + lambda_i f_i(Z_{2i-1}, Z_{2i})) satisfying P_{H_0}(exists t >= 1 : K_t >= 1/alpha) <= alpha, P_{H_1}(tau < infty) = 1 (Theorem 1), and variance-adaptive asymptotic log-wealth growth rate liminf_{t->infty} (log K_t)/t >= (E[f*]/4)(min(E[f*] / E[(f*)^2], 1)) >= HSIC(P_{XY}; G, H) / 4 (Theorem 2, Appendix B.2 Lemmas 8–11), outperforming the 3-observations-per-step reduction to two-sample testing (Section 1(i), Remark 1, Appendix A.2 Figure 7).

Mechanism #time-varying-instantaneous-independence-validity-and-simultaneous-shift-counterexample
Under non-stationary time-varying streams Z_t = (X_t, Y_t) ~ P_{XY}^{(t)} testing the instantaneous independence null H_0 : P_{XY}^{(t)} = P_X^{(t)} x P_Y^{(t)} for all t >= 1 against H_1 : exists t >= 1 with P_{XY}^{(t)} != P_X^{(t)} x P_Y^{(t)} (Equations 2–3), where batch permutation tests fail even when only X_t drifts over time (Example 1), HSIC-SKIT preserves nonasymptotic Type-I error P_{H_0}(exists t >= 1 : K_t >= 1/alpha) <= alpha whenever each consecutive pair (Z_{2t-1}, Z_{2t}) satisfies conditional exchangeability of either (X_{2t-1}, X_{2t}) or (Y_{2t-1}, Y_{2t}) given F_{t-1} and conditional cross-independence X_{2t-1} _||_ Y_{2t} | F_{t-1}, X_{2t} _||_ Y_{2t-1} | F_{t-1} (Assumption 2, Theorem 3, Appendix B.2.2 Equations 45–46, holding in particular whenever at most one marginal distribution changes between 2t-1 and 2t as in Equations 18–19); conversely, Appendix D Example 3 proves that forbidding simultaneous shifts in both marginals is necessary: if X_{2t-1}, Y_{2t-1} ~ Ber(1/2) independently and X_{2t}, Y_{2t} ~ (1/2) Ber(1/2) independently under linear kernels with fixed witness g(x, y) = x y, then E[f_t(Z_{2t-1}, Z_{2t}) | F_{t-1}] = (1/2)(1/4 - 1/2)(1/4 - 1/2) = 1/32 != 0 despite instantaneous independence at both 2t-1 and 2t.

Mechanism #spectral-coco-and-kcc-generalized-eigenvalue-skit-and-cholesky-normalization
For spectral kernel independence criteria including the Constrained Covariance (COCO) and Kernel Canonical Correlation (KCC), factorized predictable witnesses hat{g}_t in G and hat{h}_t in H are constructed from the leading generalized eigenvector (alpha, beta) of the centered Gram matrices tilde{K} = H K H and tilde{L} = H L H solving the generalized eigenproblem [0, (1/n) tilde{K} tilde{L}; (1/n) tilde{L} tilde{K}, 0] [alpha; beta] = gamma [tilde{K} + kappa_1 I, 0; 0, tilde{L} + kappa_2 I] [alpha; beta] (Equations 20 and 47), rescaled to enforce ||hat{g}_t||_G^2 = alpha^T tilde{K} alpha <= 1 and ||hat{h}_t||_H^2 = beta^T tilde{L} beta <= 1 (Equations 22–23, 48) so that the factorized payoff f_t(Z_{2t-1}, Z_{2t}) = (1/2)(hat{g}_t(X_{2t}) - hat{g}_t(X_{2t-1}))(hat{h}_t(Y_{2t}) - hat{h}_t(Y_{2t-1})) lies in [-1, 1] and satisfies E_{H_0}[f_t(Z_{2t-1}, Z_{2t}) | F_{t-1}] = 0, guaranteeing P_{H_0}(exists t >= 1 : K_t >= 1/alpha) <= alpha under ONS betting (Algorithm 3, Theorem 4, Appendix B.3, Appendix D Remark 6); for computational tractability, incomplete Cholesky factorization K approx G_1 G_1^T of rank M << 2t with nuclear-norm error ||K - G_1 G_1^T||_* <= delta bounds the witness norm via alpha_0^T H K H alpha_0 <= alpha_0^T H G_1 G_1^T H alpha_0 + delta ||H alpha_0||_2^2, preserving ||hat{g}_t||_G <= 1 in O(M^2 t) time (Appendix F.1, lines 1301–1334).

Mechanism #symmetry-based-skit-payoffs-for-unbounded-kernels
When the kernels k and l are unbounded (violating Assumption 1, e.g., linear kernels k(x, x') = x x'), Proposition 2 proves that under H_0 (or Assumption 2) the unnormalized witness contrast W_t = <hat{g}_t, (phi(X_{2t}) - phi(X_{2t-1})) x (psi(Y_{2t}) - psi(Y_{2t-1}))>_{G x H} = hat{g}_t(X_{2t}, Y_{2t}) + hat{g}_t(X_{2t-1}, Y_{2t-1}) - hat{g}_t(X_{2t}, Y_{2t-1}) - hat{g}_t(X_{2t-1}, Y_{2t}) (Equation 25) is conditionally symmetric around zero given F_{t-1} (W_t | F_{t-1} =^d -W_t | F_{t-1}, Appendix B.4), enabling three bounded symmetry-based payoffs in [-1, 1] with E_{H_0}[f_t(W_t) | F_{t-1}] = 0: (1) composition with any odd bounded function phi_odd : R -> [-1, 1] normalized by a predictable scale N_{t-1} such as f_t^odd(W_t) = tanh(W_t / N_{t-1}) (Equation 26), (2) the sequential signed-rank payoff f_t^rank(W_t) = sign(W_t) rk(|W_t|) / t where rk(|W_t|) = sum_{i=1}^t 1{|W_i| <= |W_t|} (Equation 27), and (3) the composition-of-bets predictive payoff f_t^pred(W_t) = (2 p_t(|W_t|) - 1)_+ (1 - 2 ell_t(W_t)) driven by an online sign-prediction probability p_t(|W_t|) and 0-1 loss ell_t(W_t) (Equation 28), each yielding an anytime-valid SKIT with P_{H_0}(exists t >= 1 : K_t >= 1/alpha) <= alpha (Theorem 5, Algorithm 4).

⚠️ Curated Limitations & Negative Results

  • Although caching tr(K^{(t)} L^{(t)}), K^{(t)} 1_{2t}, and L^{(t)} 1_{2t} reduces each step-t plug-in HSIC witness payoff evaluation from O(t^2) to O(t) (Appendix F.2, Equations 49–53), accumulating t steps still incurs O(t^2) total memory and time unless a sliding window, minibatching, or low-rank incomplete Cholesky approximation is used (Section 3, Appendix F.1).
  • Under non-stationary time-varying streams Z_t ~ P_{XY}^{(t)}, SKIT's anytime Type-I error guarantee for testing instantaneous independence H_0 : P_{XY}^{(t)} = P_X^{(t)} x P_Y^{(t)} requires that at most one marginal distribution shifts between consecutive observations 2t-1 and 2t (or that Assumption 2's conditional exchangeability holds); if both marginals P_X^{(t)} and P_Y^{(t)} shift simultaneously at every odd/even step, the swap-based witness payoff can have nonzero conditional expectation under H_0 (Appendix D, Example 3, where E[f_t | F_{t-1}] = 1/32).
  • For spectral COCO-SKIT and KCC-SKIT (Section 3, Theorem 4) and symmetry-based SKITs with unbounded kernels (Section 4, Theorem 5), nonasymptotic anytime Type-I error <= alpha is rigorously guaranteed, but formal power-one consistency and exponential wealth growth rate theorems analogous to Theorems 1–2 are established only for the bounded-kernel HSIC-SKIT plug-in witness (Section 3 Remark 3, Section 4).
  • All 1,368 lines of Podkopaev, Blobaum, Kasiviswanathan, & Ramdas (2023, arXiv:2212.07383) were read.
