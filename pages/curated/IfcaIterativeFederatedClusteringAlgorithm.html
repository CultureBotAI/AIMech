Iterative Federated Clustering Algorithm (IFCA)

Algorithms AIMech:IfcaIterativeFederatedClusteringAlgorithm DRAFT
Aliases: IFCA, Iterative Federated Clustering Algorithm, Clustered Federated Learning via Alternating Minimization
An alternating minimization framework for clustered federated learning (IFCA, Algorithm 2) over m clients partitioned into k unknown latent data distributions D_1,...,D_k with cluster-specific minimizers theta_1^*,...,theta_k^*, where in each round t the server broadcasts all k candidate cluster models {theta_j^{(t)}}_{j=1}^k to participating clients M_t, each client i in M_t estimates its cluster identity via empirical loss minimization j_hat_i = argmin_{j in [k]} F_i(theta_j^{(t)}) (encoded as one-hot r_{i,j}), and the server updates each cluster model theta_j^{(t+1)} by aggregating local gradients or local SGD iterates exclusively over clients assigned to cluster j (optionally sharing weights across early representation layers).
Identity Notes & Concept Scope Distinct from single-global-model federated optimization (FedAvg, FedProx, SCAFFOLD) and from per-client personalized federated learning such as pFedMe (AIMech:PFedMePersonalizedFederatedLearningWithMoreauEnvelopes), Per-FedAvg (AIMech:PerFedAvgModelAgnosticMetaLearningForPersonalizedFederatedLearning), Ditto (AIMech:DittoFairAndRobustPersonalizedFederatedMultiTaskLearning), and FedRep (AIMech:FedRepExploitingSharedRepresentationsForPersonalizedFederatedLearning), which maintain n distinct client models or heads rather than inferring discrete latent cluster memberships S_1,...,S_k and learning k shared cluster-level models.

Claims & Grounded Evidence

4 Claims
Mechanism #r405-linear-model-exponential-clustering-accuracy-and-geometric-contraction
For k-cluster Gaussian linear models y_i = X_i theta_{j^*}^* + epsilon_i with minimum cluster separation Delta = min_{j != j'} ||theta_j^* - theta_{j'}^*||_2 and initialization ||theta_j^{(0)} - theta_j^*||_2 <= alpha * Delta (alpha < 1/2), Lemma 1 bounds the per-client cluster misclassification probability by c_1 exp(-c_2 n' (alpha * rho / (rho + 1))^2) where rho = Delta^2 / sigma^2, and Theorem 1 (with Corollary 1) proves geometric contraction ||theta_j^{(t+1)} - theta_j^*||_2 <= (1/2) ||theta_j^{(t)} - theta_j^*||_2 + c_2 (sigma / p) sqrt(d / (m n')) + c_3 Delta exp(-c_4 (alpha * rho / (rho + 1))^2 n'), reaching near-minimax statistical error O(sigma sqrt(d / N) + exp(-Omega(n'))) in logarithmic rounds.
  • supports Source: An Efficient Framework for Clustered Federated Learning · Locator: Section 4.2 Linear Models (Lemma 1, Theorem 1, Corollary 1) & Appendix B, pp. 5-6
Mechanism #r405-strongly-convex-smooth-contraction-guarantee
For lambda-strongly convex and L-smooth population objectives F^j(theta) with bounded stochastic variance eta^2 and initialization ||theta_j^{(0)} - theta_j^*||_2 <= alpha * sqrt(lambda / L) * Delta, Lemma 3 and Theorem 2 (with Corollary 2) prove that IFCA contracts at rate ||theta_j^{(t+1)} - theta_j^*||_2 <= (1 - p * lambda / (8 L)) ||theta_j^{(t)} - theta_j^*||_2 + varepsilon_0 and converges to small error varepsilon in T = (8 L / (p * lambda)) log(2 dist_0 / varepsilon) rounds.
  • supports Source: An Efficient Framework for Clustered Federated Learning · Locator: Section 4.3 Strongly Convex and Smooth Functions (Assumptions 1-3, Lemma 3, Theorem 2, Corollary 2) & Appendix C, pp. 6-7
Limitation #r405-k-fold-downlink-broadcast-and-initialization-separation-limitation
Broadcasting all k cluster models to participating clients increases per-round server-to-client downlink communication by a factor of k (partially mitigated by weight sharing in early neural layers), and theoretical convergence requires knowledge of k, minimum cluster separation Delta = tilde{Omega}(max{sigma / sqrt(n'), sqrt(d / (m n'))}), and good initialization within basin radius alpha * Delta.
  • supports Source: An Efficient Framework for Clustered Federated Learning · Locator: Section 3.2 Algorithm 2, Section 3.3 Practical Implementation with Weight Sharing, and Section 4.2-4.3 (Theorems 1-2), pp. 4-7
Application #r405-rotated-mnist-cifar10-and-femnist-clustered-fl-application
Evaluated on clustered Mixture-of-Linear-Regressions, Rotated MNIST and Rotated CIFAR-10 (with k = 2 and k = 4 rotation clusters), and Federated EMNIST with weight sharing, significantly outperforming global FedAvg, local-only training, and one-shot clustering baselines.
  • supports Source: An Efficient Framework for Clustered Federated Learning · Locator: Section 5 Experiments (Figures 2-3, Tables 1-2), pp. 7-9

⚠️ Curated Limitations & Negative Results

  • Requires broadcasting k candidate models on the downlink in each round unless early layers are shared.
  • Theoretical guarantees require cluster separation Delta above a threshold and initialization near the true cluster centers.
