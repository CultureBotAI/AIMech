Attention-Based Convolutional Neural Network

Architectures AIMech:AttentionBasedConvolutionalNeuralNetwork DRAFT
Aliases: ABCNN
A sentence-pair neural architecture that uses cross-sentence distance affinities to add attention feature channels before convolution, reweight local pooling after convolution, or combine both stages when deriving pair-dependent sentence representations.

Semantic matching covered 104 AIO and 66 native definitions, with every matched definition read. 7 full annotated AIO node/edge/generated contexts and 3 full native records were inspected. This is Yin and colleagues’ named sentence-pair ABCNN, using reciprocal-distance affinities with input-feature and pooling attention variants. It is not the bilinear/max/softmax Attentive Pooling Network, CBAM channel/spatial refinement, PointNet set pooling, ABC-CNN visual QA or every later model reusing the acronym. ABCNN-1, -2 and -3 remain explicitly different variants.

Claims & Grounded Evidence

6 Claims
Mechanism #shared-sentence-convolution
The sentence-pair backbone shares convolutional parameters across the two inputs. Wide zero-padded convolution with tanh produces local feature maps; window pooling returns a sequence of features for another block, and global average pooling supplies sentence representations used for similarity features. The formal presentation pads sentences to a common maximum length, while diagrams also illustrate unequal sentence lengths. This is an order-sensitive sentence encoder rather than an unordered set representation.
  • supports Source: ABCNN: Attention-Based Convolutional Neural Network for Modeling Sentence Pairs · Locator: Section 3, PDF pp. 3–4, Figures 1–2; Section 4, pp. 5–7, Figure 3
Mechanism #input-attention-variant
ABCNN-1 computes cross-sentence affinities between input feature columns, using the reported reciprocal-one-plus-Euclidean-distance match function. Learned projections of the affinity matrix and its transpose produce attention feature maps. Each is stacked with its sentence representation as an extra convolution input channel. Although the notation uses W0 and W1, footnote 1 says their weights are shared in the implementation.
  • supports Source: ABCNN: Attention-Based Convolutional Neural Network for Modeling Sentence Pairs · Locator: Section 4, PDF pp. 4–6, Equation 1, Figure 3(a) and footnote 1
Mechanism #pool-attention-and-combined-variants
ABCNN-2 computes affinities after convolution, sums each row or column to obtain per-unit weights, and uses these in local weighted-sum pooling. The displayed formula includes no softmax or division by the sum of weights, despite the attention-based average-pooling terminology. Duplicating fixed counterpart feature columns can therefore scale the other sentence’s weights and pooled values. ABCNN-3 combines the input-attention and pooling-attention stages. The printed square s-by-s affinity shape in the ABCNN-2 paragraph does not match the expanded convolution lengths shown in Figure 3; this record follows the dimensions of the compared feature maps and width-w pooling, without asserting uninspected code conventions.
  • supports Source: ABCNN: Attention-Based Convolutional Neural Network for Modeling Sentence Pairs · Locator: Section 4, PDF pp. 5–7, Figures 3(b)–3(c) and unnumbered attention-pooling formula; constructed sum and dimension examples
Scope #staged-training-and-feature-heads
The reported experiments keep pretrained word embeddings fixed, train convolution-pooling blocks layerwise while freezing preceding blocks, and collect similarity features from multiple representation levels. Depending on the task, a separately trained linear SVM or logistic regression classifier uses these neural features together with specified linguistic features. This staged, feature-augmented protocol is not a claim that every reported result comes from one jointly trained neural head or from word embeddings alone.
  • supports Source: ABCNN: Attention-Based Convolutional Neural Network for Modeling Sentence Pairs · Locator: Section 5, PDF pp. 7–10, Common Training Setup and Layerwise Training; task-specific setups in Sections 5.1–5.3 and Table 2
Limitation #task-specific-comparison-boundaries
WikiQA answer selection, MSRP paraphrase identification and SICK textual entailment have different splits, filters, metrics and feature sets. WikiQA keeps questions with a correct answer and truncates long answers; MSRP uses swapped-pair augmentation, and SICK uses original and non-overlapping sentence versions. The strongest tabulated variants use extra features, and corresponding feature-removal results are weaker. The reported MSRP improvement over its comparator is not statistically significant, and additional depth is not uniformly better on every metric. These experiments do not establish universal architectural superiority or unanswerable-question detection.
  • supports Source: ABCNN: Attention-Based Convolutional Neural Network for Modeling Sentence Pairs · Locator: Sections 5.1–5.3, PDF pp. 8–10, Tables 2–6 and footnotes 4, 6 and 7
Limitation #attention-and-scope-limits
The attention values express cross-sentence similarity and feature weighting, not a normalized one-to-one word alignment. Feature maps depend on the counterpart sentence, so the construction does not guarantee independently precomputable sentence embeddings. The selected entailment visualization illustrates learned responses but does not prove causal explanation or general coreference resolution. ABCNN-1, ABCNN-2 and ABCNN-3 are variants of this named sentence-pair architecture; similarly named visual-question-answering or later attention-CNN systems are not automatically the same concept.
  • supports Source: ABCNN: Attention-Based Convolutional Neural Network for Modeling Sentence Pairs · Locator: Section 4, PDF pp. 5–7; Section 5.3 and Figure 4, pp. 10–11; Conclusions, pp. 11–12

⚠️ Curated Limitations & Negative Results

  • This record denotes Yin and colleagues’ named sentence-pair ABCNN, not every attention-based CNN. Its three numbered variants are not interchangeable aliases.
  • Printed attention-matrix shapes and pooling-index notation are interpreted using the declared feature dimensions and window width. No author implementation was inspected to settle edge conventions.
  • Training stages, feature augmentation, task-specific splits and non-significant comparisons limit empirical conclusions; attention visualization is not causal validation.
  • All fourteen pages of arXiv1512.05193v4 were visually read, including figures, tables, footnotes and references. No author code, training, benchmark replication or other source version was inspected. DRAFT remains.
