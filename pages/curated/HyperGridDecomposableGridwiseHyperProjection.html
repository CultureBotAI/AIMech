HyperGrid (Grid-wise Decomposable Hyper Projections for Multi-Task Transformers)

Aliases: HyperGrid, HyperGrid Transformer, Grid-wise Decomposable Hyper Projections, HyperGrid-LG, HyperGrid-GL, HyperGrid-L2
A multi-task Transformer projection architecture that pools the sequence task-prefix token into X in R^{d_m}, forms a d_r x d_c gating matrix via the sigmoid outer product of two decomposable vectors—either Local-Local (L_r X)(L_c X)^T, Local-Global (L_r X) G_c^T, or Global-Local G_r (L_c X)^T—tiles that gate across blocks of size (d_m / d_r) x (d_f / d_c) via a repeat operator psi(.), and applies residual element-wise weight gating Y_i = H_i(X_{i-1}, W_i) + W_i(X_{i-1}) to the second position-wise feed-forward layer of each Transformer block.

Identity Notes & Concept Scope Introduced by Yi Tay, Zhe Zhao, Dara Bahri, Donald Metzler, and Da-Cheng Juan (ICLR 2021, arXiv:2007.05891). Distinct from post-FFN adapter hypernetworks such as HyperFormer (Karimi Mahabadi et al., ACL 2021; AIMech Round 703) and self-attention prompt hypernetworks such as HyperPrompt (He et al., ICML 2022; AIMech Round 706), as well as post-ReLU Output Gating (Section 7.3, Eq. 7): HyperGrid gates the pre-existing second FFN weight matrix W_i in R^{d_m x d_f} in 2D grid regions with negligible parameter overhead (d_m d_r + d_c in the LG variant). All four HyperGrid composition variants (L, L^2, LG, and GL) are covered within this single record.

Claims & Grounded Evidence

4 Claims
Mechanism #hypergrid-decomposable-outer-product-weight-gating-mechanism
Given first-token (task-prefix) pooled representation X in R^{d_m} and the second positional FFN weight matrix W in R^{d_m x d_f}, HyperGrid segments W into (d_m / d_r) x (d_f / d_c) blocks by computing a d_r x d_c gate via sigmoid outer products—Local-Local H_{L^2}(X) = psi(sigma((L_r X)(L_c X)^T)) odot W (Eq. 3), Local-Global H_{LG}(X) = psi(sigma((L_r X) G_c^T)) odot W (Eq. 4), or Global-Local H_{GL}(X) = psi(sigma(G_r (L_c X)^T)) odot W (Eq. 5)—where psi(.) repeats the d_r x d_c matrix d_m / d_r times along rows and d_f / d_c times along columns, and combines the gated transformation with the pretrained FFN layer via residual addition Y_i = H_i(X_{i-1}, W_i) + W_i(X_{i-1}) (Eq. 6).
  • supports Source: HyperGrid: Efficient Multi-Task Transformers with Grid-wise Decomposable Hyper Projections · Locator: Section 3.1.1 Decomposable Gridwise Projections, Figure 1 & Eqs. 3-5, pp. 3-4; Section 3.2 Multi-Task Fine-tuning of Pretrained Transformers, Figure 2 & Eq. 6, pp. 4-5
Scope #hypergrid-layer-parameter-complexity-and-weight-vs-output-gating-scope
At each Transformer layer, HyperGrid adds d_m d_r + d_c parameters in the LG setting, d_r + d_f d_c parameters in the GL setting, and d_m d_r + d_f d_c parameters in the L^2 setting (Section 3.2, p. 5), and gating FFN weights prior to the residual output consistently outperforms post-ReLU Output Gating Y = max(W x + b, 0) odot (sigma(U X) 1^T) (Eq. 7), which suffers a net accuracy loss on SuperGLUE (-0.2% to -1.2% in Table 3).
  • supports Source: HyperGrid: Efficient Multi-Task Transformers with Grid-wise Decomposable Hyper Projections · Locator: Section 3.2 Parameter Costs, p. 5; Section 4.2.2 Effect of Modeling Choices, Table 3, p. 6; Section 7.3 Comparing with Output Gating, Eq. 7, pp. 13-14
Application #hypergrid-unified-glue-and-superglue-multitask-application
Co-trained as a single unified multi-task model across all 16 GLUE and SuperGLUE tasks, HyperGrid improves T5-Base SuperGLUE dev score from 73.55 to 75.30 (+2.7%) and T5-Large SuperGLUE dev score from 80.04 to 81.56 (+1.9%), and on the official GLUE and SuperGLUE test servers a single T5-11B HyperGrid (LG, 32 x 128) model achieves 89.4 on GLUE and 87.7 on SuperGLUE using 16x fewer total parameters (11B vs. 176B) than single-task fine-tuned T5-11B.
  • supports Source: HyperGrid: Efficient Multi-Task Transformers with Grid-wise Decomposable Hyper Projections · Locator: Section 4.2.1 Tables 1-2, pp. 5-6; Section 4.2.3 Table 4, p. 7; Section 4.2.5 Performance on Test Set, Tables 5-6, p. 8
Limitation #hypergrid-full-model-co-training-and-grid-size-sensitivity-limitation
HyperGrid updates all backbone Transformer parameters jointly with the HyperGrid projections during multi-task fine-tuning (requiring 64 to 128 TPU v3 chips for Large/3B/11B models) and exhibits sensitivity to the choice of fan-in d_r and fan-out d_c grid dimensions, with intermediate fan-out sizes around d_c = 64-128 underperforming both fine-grained (d_c = 32) and coarse (d_c = 256) grid partitions.
  • supports Source: HyperGrid: Efficient Multi-Task Transformers with Grid-wise Decomposable Hyper Projections · Locator: Section 3.2 Fine-tuning, p. 4; Section 4.2.4 Effect of Grid Size on Performance, Figures 3-9, pp. 7-8; Section 7.2 Experiment Settings, p. 13

⚠️ Curated Limitations & Negative Results

  • Fine-tunes the entire Transformer backbone alongside the HyperGrid parameters rather than keeping the backbone frozen.
  • Performance varies non-monotonically with the fan-in (d_r) and fan-out (d_c) grid-size hyperparameters.
