Aliases: Fast Bayesian Optimization on Large Data Sets
A Bayesian hyperparameter optimization algorithm that jointly chooses a model configuration and training-data subset size using surrogate models of loss and evaluation cost, directing evaluations toward information about the best configuration on the full dataset.
Definition Evidence
  • supports Source: Fast Bayesian Optimization of Machine Learning Hyperparameters on Large Datasets · Locator: Sections2–3.4, PDF pp.2–5, especially Section3.1 kernels, Equation7 and Algorithm1 on PDFp.4, and incumbent/initialization details on PDFp.5
Identity Notes & Concept Scope FABOLAS treats dataset size as an environmental evaluation variable while retaining the full dataset as the optimization target. It differs from Gaussian-process regression alone, fixed-fidelity Bayesian optimization, a discrete multi-task optimizer with manually selected task sizes, and Hyperband’s predetermined resource brackets. The paper method and the separately pinned RoBO implementation are recorded as distinct source versions. Claims & Grounded Evidence

2 Claims
Mechanism #method
Model loss and computational cost as functions of configuration and dataset fraction, using Gaussian-process surrogates with a kernel over configuration coordinates and a finite-rank basis over size. Begin with evaluations of configurations on small subsets. Select the next configuration/size pair using an entropy-search acquisition focused on the minimizer at full dataset size; the paper divides its information criterion by predicted evaluation cost plus optimization overhead. Evaluate the selected pair, observe loss and cost, and update the models. Select the incumbent among configurations already evaluated by projecting their predicted loss to the full dataset, rather than requiring each candidate to have been evaluated there. The paper integrates surrogate hyperparameters using MCMC and describes DIRECT/CMA-ES acquisition optimization; the inspected code has separate implementation choices.
  • supports Source: Fast Bayesian Optimization of Machine Learning Hyperparameters on Large Datasets · Locator: Sections2–3.4, PDF pp.2–5, especially Section3.1 kernels, Equation7 and Algorithm1 on PDFp.4, and incumbent/initialization details on PDFp.5
Mechanism #pinned-implementation
In the inspected RoBO revision, dataset counts are mapped to a normalized log2 coordinate between the selected minimum and maximum; proposed coordinates are transformed back and rounded to integer counts. Quadratic loss and linear cost basis functions operate on that transformed coordinate, while both observed objective values and costs are logged. The outer function uses a Latin-hypercube initial design and RandomSampling acquisition maximizer. Its marginalized acquisition update passes no overhead keyword, so the per-unit-cost estimator sets overhead to zero and divides by the exponentiated predicted log-cost mean. These are static observations of this revision, not claims of equality with the original experiments or executable compatibility.

⚠️ Curated Limitations & Negative Results

  • Extrapolation depends on the adequacy of the loss-versus-size and cost models. Small subsets need not preserve the ranking at full size, and the returned projected incumbent need not have a confirming full-data evaluation or optimal test performance.
  • The paper’s loss basis (1,(1-s)^2) allows a monotonic latent trend at fixed configuration but does not by itself force that trend to decrease when coefficient signs are unconstrained. Its polynomial-cost interpretation also depends on the size coordinate: log-cost affine in raw relative size is exponential in that coordinate; the pinned code instead uses normalized log dataset counts.
  • The pinned code logs both objective and cost, applies Latin-hypercube initialization and a RandomSampling acquisition optimizer, and leaves the acquisition overhead at zero through the inspected call chain. Those choices are not silently attributed to the paper’s algorithm. Positive objective/cost values and compatible parameter settings are required by that source; static inspection is not a runtime result.
  • No universal speedup, exact information-gain computation or independent calibration result is asserted. The full entropy-search implementation and the paper’s supplementary experiments were not audited.
