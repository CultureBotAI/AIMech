GCFL+ (Gradient Sequence Dynamic Time Warping Clustered Federated Graph Classification)

Algorithms AIMech:GcflPlusGradientSequenceDynamicTimeWarpingClusteredFederatedGraphClassification DRAFT
Aliases: GCFL+, GCFL Plus, Graph Clustered Federated Learning Plus, Gradient Sequence Dynamic Time Warping Clustered Federated Graph Classification
GCFL+ is a dynamic clustered federated graph classification algorithm for clients holding structure- and feature-heterogeneous (non-IID) graph datasets that tracks a multi-variate time-series matrix Q in R^{n x d} of each client's GNN gradient norms ||Delta theta_i^t|| over the latest d communication rounds and, whenever a cluster's weighted mean gradient norm falls below a stationarity threshold (delta_mean < varepsilon_1) while its maximum client gradient norm exceeds a heterogeneity threshold (delta_max > varepsilon_2), computes a pairwise Dynamic Time Warping (DTW) distance matrix beta_k(p, q) = dist(Q(p, :), Q(q, :)) and recursively bi-partitions the cluster via the Stoer-Wagner minimum cut algorithm.
Identity Notes & Concept Scope Introduced by Han Xie, Jing Ma, Li Xiong, and Carl Yang in 'Federated Graph Classification over Non-IID Graphs' (NeurIPS 2021, pages 18839-18852; arXiv:2106.13423). Extends vanilla GCFL (Section 4 of the same paper), which bi-partitions client clusters using single-round gradient cosine similarities and is vulnerable to fluctuating GNN gradient norms across rounds; distinct from Euclidean Clustered Federated Learning (CFL, Sattler et al. 2020), which does not track multi-round DTW gradient-norm sequences or analyze GNN Laplacian/feature perturbation bounds; and distinct from FedSage+ (Zhang et al. NeurIPS 2021), which addresses node classification on disjoint subgraphs with missing links.

4 Claims
Mechanism #gcfl-plus-stationarity-and-heterogeneity-bipartition-criteria
At each communication round t, GCFL and GCFL+ evaluate for each client cluster C_k whether the weighted average GNN update norm approaches a stationary point, delta_mean = ||sum_{i in [n]} (|G_i|/|G|) Delta theta_i|| < varepsilon_1 (Equation 4), while individual client updates remain divergent, delta_max = max(||Delta theta_i||) > varepsilon_2 > 0 (Equation 5), triggering top-down cluster bi-partitioning C_k -> {C_{k1}, C_{k2}} via the Stoer-Wagner minimum cut algorithm and maintaining cluster-specific GNN parameters theta_k^{t+1} = theta_k^t + sum_{i in [n_k]} Delta theta_{k,i}^t (Equation 7).
  • supports Source: Federated Graph Classification over Non-IID Graphs · Locator: Section 4.3, Equations (4)-(7), pages 5-6
Mechanism #gcfl-plus-dtw-gradient-norm-sequence-distance-matrix
To overcome single-round GNN gradient-norm fluctuations in vanilla GCFL (Figure 1a), the server in GCFL+ maintains a rolling time-series matrix Q in R^{n x d} of client gradient norms ||Delta theta_i^t|| over a window of length d (optionally standardized via Q'(i, :) = Q(i, :) / std(Q(i, :)), Equation 20) and computes the cluster pairwise distance matrix beta_k(p, q) = dist(Q(p, :), Q(q, :)) using Dynamic Time Warping (DTW, Equation 8) to drive Stoer-Wagner bi-partitioning.
  • supports Source: Federated Graph Classification over Non-IID Graphs · Locator: Section 5.1-5.2, Figure 1 and Equation (8), page 7; Appendix D, Equation (20), page 17
Mechanism #gcfl-plus-bourgain-sgc-structure-and-feature-gradient-bounds
Using Bourgain's metric embedding theorem (Theorem 4.1) on Simple Graph Convolutions f(L, X) = softmax(L^K X Theta) with normalized Laplacian L = D_tilde^{-1/2} A_tilde D_tilde^{-1/2}, Propositions 4.1-4.3 prove that the squared weight difference ||Theta' - Theta||_2^2 is upper-bounded by the graph structure perturbation ||L' - L||_2^2 <= epsilon_L (Equation 12), the node feature perturbation ||X' - X||_2^2 <= epsilon_X (Equation 16), and the task embedding perturbation ||Y_i - Y_j||_2^2 <= epsilon_Y (Equation 19), theoretically justifying that GNN gradient clustering reduces intra-cluster graph structure and feature heterogeneity.
  • supports Source: Federated Graph Classification over Non-IID Graphs · Locator: Section 4.4, Theorem 4.1 and Propositions 4.1-4.3, page 6; Appendix B, Equations (9)-(19), pages 15-16
Limitation #gcfl-plus-threshold-tuning-and-unencrypted-gradient-limitation
GCFL+ requires offline validation tuning of the stopping and splitting thresholds (varepsilon_1, varepsilon_2) (where overly large varepsilon_2 collapses to single-cluster FedAvg and overly small varepsilon_2 fragments clients into singleton clusters), and transmits unencrypted client GNN gradients without formal differential privacy or cryptographic aggregation.
  • supports Source: Federated Graph Classification over Non-IID Graphs · Locator: Section 6.2, pages 8-9; Section 7, page 10

⚠️ Curated Limitations & Negative Results

  • Requires selecting the stationarity threshold varepsilon_1 and heterogeneity splitting threshold varepsilon_2 via offline validation rounds; setting varepsilon_2 too small fragments clients into singleton clusters.
  • Relies on gradient-norm time series Q in R^{n x d}, which discards directional cosine information between client gradient vectors when computing the DTW distance matrix beta_k.
