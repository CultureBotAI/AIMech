Berrut Approximated Coded Computing for Straggler-Resilient Non-Polynomial Distributed Computation

Algorithms AIMech:BerrutApproximatedCodedComputingForStragglerResilientNonPolynomialDistributedComputation DRAFT
Aliases: Berrut Approximated Coded Computing, BACC, Berrut Rational Coded Computing
A numerically stable straggler-resilient coded computing scheme over the real numbers R for approximately evaluating arbitrary (possibly non-polynomial) functions f: V -> U across K input data blocks X = (X_0, ..., X_{K-1}) using N + 1 worker nodes, in which the master encodes the dataset via Berrut's pole-free barycentric rational interpolant u(z) = sum_{i=0}^{K-1} (((-1)^i / (z - alpha_i)) / sum_{j=0}^{K-1} ((-1)^j / (z - alpha_j))) X_i at first-kind Chebyshev nodes alpha_j = cos((2j + 1) pi / (2K)), assigns coded shares X_hat_r = u(z_r) at second-kind Chebyshev nodes z_r = cos(r pi / N) to workers r in {0, ..., N}, and decodes f(X_j) approx r_{Berrut, F}(alpha_j) in O(|F|) time from any subset F of n + 1 = N + 1 - s non-straggling worker evaluations f(u(z_tilde_i)) using Berrut's rational interpolant r_{Berrut, F}(z) = sum_{i=0}^n (((-1)^i / (z - z_tilde_i)) / sum_{j=0}^n ((-1)^j / (z - z_tilde_j))) f(u(z_tilde_i)).
Identity Notes & Concept Scope Distinct from Lagrange Coded Computing (AIMech:LagrangeCodedComputingForResilientSecureAndPrivateDistributedLearning, which is restricted to multivariate polynomials of degree deg(f), requires a hard recovery threshold of (K - 1) deg(f) + 1 workers, and suffers exponential Vandermonde ill-conditioning over R): Berrut Approximated Coded Computing (BACC, Jahani-Nezhad & Maddah-Ali, IEEE TPAMI 2023) replaces polynomial interpolation with Berrut's alternating-sign barycentric rational interpolant over first- and second-kind Chebyshev nodes, enabling straggler-resilient approximate evaluation of arbitrary non-polynomial functions (such as deep neural network gradients) from any number of surviving workers with a logarithmically bounded Lebesgue constant.

Mechanism #bacc-pole-free-chebyshev-rational-encoding-and-decoding
BACC encodes K data blocks at first-kind Chebyshev nodes alpha_j = cos((2j + 1) pi / (2K)) via u(z) in Eq. 18 (satisfying u(alpha_j) = X_j exactly), evaluates f(u(z_r)) at second-kind Chebyshev nodes z_r = cos(r pi / N), and reconstructs r_{Berrut, F}(z) from any surviving worker subset F in O(|F|) operations (Eq. 21) without real poles for any distribution of surviving nodes (Lemma 1).

Scope #bacc-logarithmic-lebesgue-constant-and-straggler-error-bound
For any subset X_n of n + 1 = N + 1 - s surviving workers at second-kind Chebyshev nodes (with s < N - 2), the worst-case Lebesgue constant occurs when the s stragglers are consecutive (Lemma 6) and is bounded logarithmically by Lambda_n <= (((s + 1)(s + 3) pi^2 / 4) + 1)(1 + pi^2 (s + 1) ln(N - s)) (Theorem 7); for g(z) = f(u(z)) in C^2[-1, 1], the uniform approximation error satisfies ||r_{Berrut, F}(z) - g(z)|| <= 2(1 + R) sin((s + 1) pi / (2N)) (||g''|| + ||g'||) with R = (s + 1)(s + 3) pi^2 / 4 (Theorem 9).
  • supports Source: Berrut Approximated Coded Computing: Straggler Resistance Beyond Polynomial Computing · Locator: Section IV Lemma 6, Theorem 7, Corollary 8, & Theorem 9 p. 7-8 Eq. 22; Appendix VIII p. 16-19
Limitation #bacc-approximation-bias-and-consecutive-straggler-limitation
Unlike exact finite-field coded computing, BACC returns an approximate evaluation whose error Bound 2(1 + R) sin((s + 1) pi / (2N)) grows cubically with the number of consecutive stragglers s via R = (s + 1)(s + 3) pi^2 / 4 when s becomes a large fraction of N.
  • supports Source: Berrut Approximated Coded Computing: Straggler Resistance Beyond Polynomial Computing · Locator: Section IV Lemma 6 & Theorem 9 p. 7-8; Section V Fig. 2 & Fig. 5 p. 9-11

⚠️ Curated Limitations & Negative Results

  • Produces an approximate rather than exact evaluation of f(X_j), with error scaling as O((s + 1)^3 sin((s + 1) pi / (2N))) when s consecutive Chebyshev worker nodes straggle.
  • Does not by itself provide information-theoretic data privacy against curious workers without additional random noise padding.
