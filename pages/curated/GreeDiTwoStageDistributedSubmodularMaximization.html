GreeDi Two-Stage Distributed Greedy Submodular Maximization

Algorithms AIMech:GreeDiTwoStageDistributedSubmodularMaximization DRAFT
Aliases: GreeDi Protocol for Distributed Submodular Maximization, Two-Round MapReduce Greedy Submodular Maximization, Mirzasoleiman-Karbasi-Sarkar-Krause GreeDi Algorithm
GreeDi Two-Stage Distributed Greedy Submodular Maximization is a communication-efficient two-round parallel/MapReduce protocol introduced by Mirzasoleiman, Karbasi, Sarkar, and Krause (2013, 2016) for maximizing a submodular function f : 2^V -> R_+ subject to cardinality or general hereditary constraints zeta across m machines. In Stage 1, the ground set V is partitioned into V_1, ..., V_m and each machine i independently runs the standard greedy algorithm (or a tau-approximate black-box solver X) on V_i to select a candidate subset A_i^{gc}[kappa]; in Stage 2, a single reducer merges B = union_{i=1}^m A_i^{gc}[kappa], runs the greedy/black-box solver on B to obtain A_B^{gc}[kappa], and outputs A^{gd}[m, kappa] = argmax{f(A_{max}^{gc}[kappa]), f(A_B^{gc}[kappa])}.
Identity Notes & Concept Scope Distinct from AIMech:StochasticGreedyLinearTimeMonotoneSubmodularMaximization (Round 348), which accelerates centralized sequential greedy selection by random subsampling on a single machine, and from AIMech:SieveStreamingAndSieveStreamingPlusPlusForSubmodularMaximization (Round 350), which processes elements in a single streaming pass using Geometric marginal-gain thresholds. Also distinct from AIMech:ContinuousGreedyAndMultilinearExtensionForMatroidSubmodularMaximization (Round 349), which solves continuous multilinear relaxations over matroid polytopes centrally rather than two-round distributed MapReduce partitioning.

Mechanism #r359-claim-tight-worst-case-and-random-partition-bounds
For any monotone submodular function f under an arbitrary partition of V into m sets, the intractable local-optimum merge protocol (Algorithm 1) satisfies the tight bound f(A^d[m, k]) >= (1 / min(m, k))*f(A^c[k]) with a matching entropy upper bound f(A^c[k]) = min(m, k)*f(A^d[m, k]) (Theorem 3, Appendix A.1), while two-stage GreeDi (Algorithm 2) with local budget kappa >= k guarantees f(A^{gd}[m, kappa]) >= ((1 - e^{-kappa/k}) / min(m, k))*f(A^c[k]) (Theorem 4), generalizes to f(A^{Xd}[m, zeta]) >= (tau / min(m, rho([zeta])))*f(A^c[zeta]) for any tau-approximate solver X over hereditary constraints zeta of maximum independent size rho([zeta]) (Algorithm 3, Theorem 12), and achieves average-case E[f(A^{gd}[m, k])] >= ((1 - 1/e)/2)*f(A^c[k]) under uniform random partitioning without geometric assumptions (Theorem 11).

Mechanism #r359-claim-metric-lipschitz-and-dense-neighborhood-guarantees
For set functions that are lambda-Lipschitz with respect to a metric d on V under equal-size element matchings, |f(S) - f(S')| <= lambda * sum_{i=1}^k d(e_i, e_i') (Definition 5)—including Gaussian process mutual information with lambda = L*k^3 for L-Lipschitz kernels (Proposition 6) and d^alpha-dissimilarity clustering utility with lambda = alpha*R^{alpha-1} (Proposition 7)—if elements are randomly partitioned onto m machines and each optimal element e_i in A^c[k] has an alpha-neighborhood N_alpha(e_i) of size at least k*m*log(k / delta^{1/m}), then with probability at least 1 - delta, GreeDi achieves f(A^{gd}[m, kappa]) >= (1 - e^{-kappa/k})*(f(A^c[k]) - lambda*alpha*k) (Theorem 8, and Theorem 13 for locally replaceable constraints zeta).

Mechanism #r359-claim-large-sample-growth-function-and-decomposable-objective-bounds
When V consists of n >= 8*k*m*log(k/delta^{1/m}) / (beta * g(varepsilon / (lambda*k))) i.i.d. samples from a metric space with probability density >= beta and ball-volume growth function g(alpha), GreeDi achieves f(A^{gd}[m, kappa]) >= (1 - e^{-kappa/k})*(f(A^c[k]) - varepsilon) with probability at least 1 - delta (Theorem 9); furthermore, for decomposable submodular functions f(S) = (1/|V|)*sum_{i in V} f_i(S) evaluated purely locally on each machine's partition V_i, when n >= max(n_0, m*log(delta/(4m))/varepsilon^2) with ln(n)/n <= varepsilon^2/(m*k), GreeDi achieves f(A^{gd}[m, kappa]) >= (1 - e^{-kappa/k})*(f(A^c[k]) - 2*varepsilon) (Theorem 10, and Theorem 15 for general hereditary constraints).
