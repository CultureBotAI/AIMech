Frequent Directions Deterministic Row-Update Matrix Sketching via Singular-Value Shrinkage

Algorithms AIMech:FrequentDirectionsDeterministicMatrixSketching DRAFT
Aliases: Tail-Residual Frequent Directions Sketching, Fast-FrequentDirections, Space-Optimal FrequentDirections Rank-k Projection Sketch
Frequent Directions (FrequentDirections and Fast-FrequentDirections) is a deterministic row-update streaming matrix sketching algorithm introduced by Liberty (2013) and analyzed with tight relative-error and space-optimality bounds by Ghashami, Liberty, Phillips, and Woodruff (2015, 2016). Given an input matrix A in R^{n x d} streamed one row a_i at a time, the algorithm maintains a sketch B in R^{ell x d} (or R^{2*ell x d} in Fast-FrequentDirections) by inserting incoming rows into zero-valued rows of B, computing the SVD [U, Sigma, V] = svd(B) once B has no zero rows, setting delta_i = sigma_ell^2, and shrinking all squared singular values via B <- sqrt(max(Sigma^2 - delta_i I, 0)) * V^T so that at least the last row of B (or last ell + 1 rows in Fast-FrequentDirections) is zeroed out while reducing ||B||_F^2 at least ell times faster than any single unit direction.
Identity Notes & Concept Scope Distinct from AIMech:FrequentDirectionsDeterministicStreamingMatrixSketching (Round 330, Liberty KDD 2013), which established only the flat-spectrum Frobenius covariance error bound ||A^T A - B^T B||_2 <= 2||A||_F^2/ell without rank-k tail residuals or relative-error projection bounds; this record captures Ghashami, Liberty, Phillips, and Woodruff's (2015, 2016) tail-residual relative-error covariance and rank-k projection analysis (||A^T A - B^T B||_2 <= ||A - A_k||_F^2/(ell - k), ||A - pi_B^k(A)||_F^2 <= (ell/(ell - k))||A - A_k||_F^2) and matching Grassmannian/Index space-optimality lower bounds. Also distinct from AIMech:NoisyPowerMethodForStreamingAndDifferentiallyPrivatePCA (Round 356) and AIMech:StreamingPCANearOptimalFiniteSampleOjaAlgorithm (Round 357), which are randomized iterative subspace estimators rather than deterministic Misra-Gries-style singular-value shrinkage sketches.

Mechanism #r363-claim-three-shrinkage-properties-and-covariance-projection-bounds
Let Delta = sum_{i=1}^n delta_i be the total squared singular mass subtracted during FrequentDirections (Algorithms 2.1 and 3.1); the sketch B satisfies three invariants for every unit vector x in R^d: (Property 1) ||Ax||^2 - ||Bx||^2 >= 0 (A^T A >= B^T B), (Property 2) ||Ax||^2 - ||Bx||^2 <= Delta, and (Property 3) Delta*ell <= ||A||_F^2 - ||B||_F^2; bootstrapping Property 3 on the top-k singular vectors y_1, ..., y_k of A yields Delta*(ell - k) <= ||A - A_k||_F^2, proving that for all 0 <= k < ell, 0 <= ||A^T A - B^T B||_2 <= Delta <= ||A - A_k||_F^2 / (ell - k) (Theorem 1.1) and ||A - pi_B^k(A)||_F^2 <= (1 + k/(ell - k))*||A - A_k||_F^2 (Theorem 1.2).

Mechanism #r363-claim-fast-amortized-runtime-and-mergeable-summaries
Fast-FrequentDirections (Algorithm 3.1) doubles the sketch buffer to 2*ell x d and triggers SVD plus shrinkage by delta = sigma_ell^2 only once every ell + 1 row insertions (zeroing the last ell + 1 rows), reducing total running time from O(n*d*ell^2) to O((n/ell)*d*ell^2) = O(n*d*ell) with O(d*ell) amortized (and worst-case via active/maintenance double buffering) update time per row (Theorem 1.5, Section 3.2); moreover, sketches B_1, B_2 of A_1, A_2 are mergeable by running Algorithm 3.1 on B' = [B_1; B_2], preserving Properties 1-3 with Delta = Delta_1 + Delta_2 + delta (Section 3.1).

Mechanism #r363-claim-matching-space-lower-bounds-for-covariance-and-subspace-sketching
Via packing on the Grassmannian manifold (Kapralov-Talwar / Absil-Edelman-Koev), any matrix sketch B satisfying ||A^T A - B^T B||_2 <= ||A - A_k||_F^2 / (ell - k) (or <= varepsilon*||A - A_k||_F^2 with ell = ceil(k + 1/varepsilon)) requires Omega(d*ell) = Omega(d*k + d/varepsilon) bits of space (Theorems 1.3 and 4.1); furthermore, a one-way communication reduction from the Index problem on B = [I, R; e_{i_1}, ..., e_{i_k}] using the singular value 2 + zeta (where zeta = (sqrt(5) - 1)/2 approx 0.618) of rank-2 pairs Z_ell = (e_{i_ell} + R_{i_ell}, e_{i_ell}) proves that any row-update streaming algorithm outputting a rank-k projection P with ||A - AP||_F^2 <= (1 + varepsilon)*||A - A_k||_F^2 with probability >= 2/3 requires Omega(k*d/varepsilon) bits of space (Theorems 1.4 and 4.2, Lemma 4.1), establishing that FrequentDirections with ell = ceil(k + k/varepsilon) is space-optimal up to logarithmic word-size factors.

⚠️ Curated Limitations & Negative Results

  • Requires O(n*d*ell) floating-point operations (dominated by periodic SVD computations on 2*ell x d matrices), which is slower in wall-clock runtime than O(nnz(A)) CountSketch/feature-hashing embeddings when input matrices are extremely sparse, and operates in the row-update streaming model rather than general entry-wise turnstile streams with arbitrary deletions (Section 5, p. 18; Section 6.3, p. 23).
