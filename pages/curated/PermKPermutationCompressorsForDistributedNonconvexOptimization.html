PermK Permutation Compressors for Distributed Nonconvex Optimization

Algorithms AIMech:PermKPermutationCompressorsForDistributedNonconvexOptimization DRAFT
Aliases: PermK, PermK Permutation Compressor, Permutation Compressors for Distributed Nonconvex Optimization
A family of correlated n-node unbiased random sparsification operators C = (C_1, ..., C_n) (PermK) that jointly generate a random permutation pi of coordinates (when d >= n, with d = q*n and k = q) or nodes (when n >= d, with n = q*d and k = 1) so that each worker i transmits a disjoint block of coordinates scaled by d/k, satisfying the negative-correlation AB-inequality E[||(1/n) sum_{i=1}^n C_i(x_i) - (1/n) sum_{i=1}^n x_i||^2] <= A * (1/n) sum_{i=1}^n ||x_i||^2 - B * ||(1/n) sum_{i=1}^n x_i||^2 with A = B = 1 (when d >= n) or A = B = (d - 1) / (n - 1) (when n >= d).
Identity Notes & Concept Scope Introduced by Rafal Szlendak, Alexander Tyurin, and Peter Richtarik (ICLR 2022; arXiv:2110.03300). Distinct from independent RandK sparsification, where each node independently samples k coordinates yielding B = 0 and A = (d - k) / (n * k) without inter-node variance cancellation; and distinct from MARINA (Gorbunov et al., ICML 2021; Round 391), which provides the variance-reduced distributed framework analyzed under independent compressors whereas PermK introduces the AB-assumption and negatively correlated permutation compressors that strictly improve MARINA's theoretical complexity.

Claims & Grounded Evidence

4 Claims
Mechanism #permk-coupled-permutation-sparsification-and-exact-input-variance-mechanism
When d = q*n, PermK samples a uniform random permutation pi of {1, ..., d} and assigns worker i the coordinate block {pi_{q(i-1)+1}, ..., pi_{q*i}} scaled by n, achieving exact variance E[||(1/n) sum_{i=1}^n C_i(x_i) - x_bar||^2] = (1/n) sum_{i=1}^n ||x_i||^2 - ||x_bar||^2 = IV_1({x_i}) (Theorem 1, A = B = 1); when n = q*d, PermK partitions the n workers into d groups of size q via a random permutation of {1, ..., n} so each worker transmits 1 coordinate scaled by d, achieving exact variance ((d - 1) / (n - 1)) * IV_1({x_i}) (Theorem 3, A = B = (d - 1) / (n - 1)).
  • supports Source: Permutation Compressors for Provably Faster Distributed Nonconvex Optimization · Locator: Section 2 Proposition 1, Section 4 Definitions 1-2 & Theorems 1 and 3, pp. 3, 5-6
Scope #permk-marina-hessian-variance-acceleration-scope
Under the AB-assumption and the Hessian-variance quantity L_+-^2 = sup_{x != y} ((1/n) sum_i ||grad f_i(x) - grad f_i(y)||^2 - ||grad f(x) - grad f(y)||^2) / ||x - y||^2 <= L_+^2 - L_-^2 (Definition 3), Theorem 5 and Corollaries 1-2 prove that MARINA with PermK achieves step size gamma <= 1 / (L_- + sqrt(((1 - p)/p) * ((A - B) * L_+^2 + B * L_+-^2))), improving communication and oracle complexity over independent RandK by up to sqrt(n) when d >= n and sqrt(d) when n >= d.
  • supports Source: Permutation Compressors for Provably Faster Distributed Nonconvex Optimization · Locator: Section 5 Definition 3, Section 6 Theorem 5, Corollaries 1-2, & Table 2, pp. 6-8
Limitation #permk-shared-prng-seed-and-divisibility-handling-limitation
Implementing PermK without central coordination overhead requires all workers to share a synchronized pseudo-random permutation seed across rounds, and when n does not divide d (or d does not divide n), residual coordinates must be handled via block-diagonal concatenation or RandR padding (Appendix F).
  • supports Source: Permutation Compressors for Provably Faster Distributed Nonconvex Optimization · Locator: Section 4.1-4.2 & Appendix F Generalizations when n does not divide d, pp. 5-6, 26-29
Application #permk-marina-nonconvex-quadratic-and-autoencoder-training-application
Applied within MARINA to distributed nonconvex logistic regression with nonconvex regularizer on w8a and mushRoom datasets, homogeneous/heterogeneous quadratic optimization with controlled Hessian variance, and autoencoder training on MNIST.
  • supports Source: Permutation Compressors for Provably Faster Distributed Nonconvex Optimization · Locator: Section 7 Experiments, Figures 1-2, pp. 8-9

⚠️ Curated Limitations & Negative Results

  • Requires synchronized pseudo-random permutation generation across participating workers.
  • Requires full worker participation in the permutation partition at each compressed communication round.
