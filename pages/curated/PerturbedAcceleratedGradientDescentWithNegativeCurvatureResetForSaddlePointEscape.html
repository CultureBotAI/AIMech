Perturbed Accelerated Gradient Descent with Negative-Curvature Reset for Escaping Saddle Points

Aliases: Perturbed Accelerated Gradient Descent (PAGD), Jin-Netrapalli-Jordan Accelerated Saddle-Point Escape Algorithm, Single-Loop Hamiltonian and Negative-Curvature-Exploitation AGD
Perturbed Accelerated Gradient Descent with Negative-Curvature Reset for Escaping Saddle Points (PAGD) is a single-loop, Hessian-free momentum optimization algorithm introduced by Jin, Netrapalli, and Jordan (2018) for minimizing ell-smooth, rho-Hessian-Lipschitz nonconvex functions f : R^d -> R that finds an epsilon-second-order stationary point (||grad f(x)|| <= epsilon and lambda_min(grad^2 f(x)) >= -sqrt(rho * epsilon)) in O~((ell^{1/2} rho^{1/4} (f(x_0) - f^*) / epsilon^{7/4}) log^6(d ell Delta_f / (rho epsilon delta))) gradient evaluations (Theorem 3), strictly improving upon the O~(epsilon^{-2}) complexity of Perturbed Gradient Descent without requiring nested proximal loops or Hessian-vector products. PAGD (Algorithm 2) augments Nesterov's accelerated gradient descent (y_t = x_t + (1 - theta) v_t, x_{t+1} = y_t - eta grad f(y_t), v_{t+1} = x_{t+1} - x_t with eta = 1 / (4 ell) and momentum parameter theta = 1 / (4 sqrt(kappa)) where kappa = ell / sqrt(rho * epsilon)) with two mechanisms: (1) uniform ball perturbation x_t <- x_t + xi_t (xi_t ~ Unif(B_0(r))) whenever ||grad f(x_t)|| <= epsilon and no perturbation occurred in the last T = O~(sqrt(kappa)) steps, and (2) Negative Curvature Exploitation (NCE, Algorithm 3) triggered whenever f(x_t) <= f(y_t) + <grad f(y_t), x_t - y_t> - (gamma / 2)||x_t - y_t||^2 (with gamma = theta^2 / eta), which resets momentum v_{t+1} = 0 and either stays at x_t if ||v_t|| >= s = gamma / (4 rho) or steps to argmin_{x in {x_t +/- s v_t / ||v_t||}} f(x) if ||v_t|| < s. Progress is certified via a computable discrete Hamiltonian E_t = f(x_t) + ||v_t||^2 / (2 eta) (Equation 1) that monotonically decreases on every mild-nonconvexity AGD step (Lemma 4) and every NCE step (Lemma 5), together with an improve-or-localize bound sum_{tau=t+1}^{t+T} ||x_tau - x_{tau-1}||^2 <= (2 eta / theta)(E_t - E_{t+T}) (Corollary 6).

Identity Notes & Concept Scope Distinct from Perturbed Gradient Descent for Escaping Saddle Points in Hessian-Lipschitz Optimization (`AIMech:PerturbedGradientDescentForEscapingSaddlePointsInHessianLipschitzOptimization`), which uses unaccelerated gradient descent (theta = 1) and requires O~(epsilon^{-2}) iterations rather than O~(epsilon^{-7/4}) via Hamiltonian momentum accumulation and NCE resets, and from Accelerated Gradient and Negative Curvature Exploitation for Non-Convex Optimization (`AIMech:AcceleratedGradientAndNegativeCurvatureExploitationForNonConvexOptimization`), which is a nested-loop algorithm combining Lanczos negative-curvature search with proximal regularized subproblems rather than a single-loop purely gradient-based perturbed AGD method.

Claims & Grounded Evidence

3 Claims
Mechanism #r352-claim-hamiltonian-monotonic-decrease-and-nce-reset
For any ell-smooth, rho-Hessian-Lipschitz function f with learning rate eta <= 1 / (2 ell) and momentum parameter theta in [2 eta gamma, 1/2], the discrete Hamiltonian E_t = f(x_t) + ||v_t||^2 / (2 eta) decreases on every AGD step where f(x_t) >= f(y_t) + <grad f(y_t), x_t - y_t> - (gamma / 2)||x_t - y_t||^2 holds according to E_{t+1} <= E_t - (theta / (2 eta))||v_t||^2 - (eta / 4)||grad f(y_t)||^2 (Lemma 4); conversely, when strong negative curvature violates this condition (where standard AGD can increase E_t, Appendix A.1), Negative Curvature Exploitation (Algorithm 3) guarantees E_{t+1} <= E_t - min{s^2 / (2 eta), (1/2)(gamma - 2 rho s) s^2} (Lemma 5).
  • supports Source: Accelerated Gradient Descent Escapes Saddle Points Faster than Gradient Descent · Locator: Section 4.1, Equations 4-6 and Lemmas 4-5, pp. 9-10; Appendix A and A.1, pp. 16-18
Mechanism #r352-claim-improve-or-localize-and-accelerated-eigenvalue-dynamics
Telescoping Lemma 4 yields the improve-or-localize bound sum_{tau=t+1}^{t+T} ||x_tau - x_{tau-1}||^2 <= (2 eta / theta)(E_t - E_{t+T}) (Corollary 6), confining non-improving trajectories to a local ball of radius O(sqrt(epsilon / rho)) where quadratic eigen-decomposition shows that AGD with theta = Theta(1 / sqrt(kappa)) contracts strongly convex directions at rate 1 - Theta(1 / sqrt(kappa)) (Lemma 27) and amplifies negative-curvature escape directions lambda <= -sqrt(rho * epsilon) at rate mu_1(A) >= 1 + Theta(1 / sqrt(kappa)) versus 1 + Theta(1 / kappa) for GD (Section 4.2, Lemma 30).
  • supports Source: Accelerated Gradient Descent Escapes Saddle Points Faster than Gradient Descent · Locator: Section 4.2, Corollary 6 and Eigen-direction analysis, pp. 10-11; Appendix C.2-C.3, Lemmas 27 and 30, pp. 36, 40
Mechanism #r352-claim-single-loop-seven-fourths-sosp-complexity
With hyperparameters eta = 1/(4 ell), theta = 1/(4 sqrt(kappa)), gamma = theta^2 / eta, s = gamma / (4 rho), and T = sqrt(kappa) chi c where kappa = ell / sqrt(rho * epsilon), PAGD decreases the Hamiltonian by at least Omega~(sqrt(epsilon^3 / rho)) every 2T steps in both large-gradient (Lemma 7) and negative-curvature saddle regimes (Lemma 8 via twin-trajectory coupling Lemma 18), finding an epsilon-second-order stationary point with probability at least 1 - delta in O((ell^{1/2} rho^{1/4} (f(x_0) - f^*) / epsilon^{7/4}) log^6(d ell Delta_f / (rho epsilon delta))) iterations (Theorem 3).
  • supports Source: Accelerated Gradient Descent Escapes Saddle Points Faster than Gradient Descent · Locator: Section 3, Equation 3 and Theorem 3, p. 8; Section 4.3, Lemmas 7-11, pp. 11-12; Appendix B.2-B.4, Lemmas 16-18, pp. 21-31

⚠️ Curated Limitations & Negative Results

  • Requires exact full-batch gradient evaluations and knowledge of both the gradient Lipschitz constant ell and Hessian Lipschitz constant rho to set the learning rate eta, momentum damping theta, and NCE curvature threshold gamma (Section 3, Equation 3).
