Catoni-style heavy-tailed confidence sequences

Mathematical Methods AIMech:CatoniStyleHeavyTailedConfidenceSequences DRAFT
Aliases: Catoni Supermartingale Confidence Sequence for Heavy-Tailed Means, Infinite-Variance p-Catoni Confidence Sequence, Stitched Catoni Law-of-the-Iterated-Logarithm Confidence Sequence, Dubins-Savage and Delyon Self-Normalized Heavy-Tailed Confidence Sequences
A family of nonasymptotic, anytime-valid sequential confidence sequences (Wang & Ramdas 2023, building on Catoni 2012) for the conditional mean mu of potentially heavy-tailed real-valued stochastic processes (X_t)_{t>=1} knowing only an upper bound sigma^2 on the conditional variance E[(X_t - mu)^2 | F_{t-1}] <= sigma^2 (or more generally knowing only a p-th central moment bound E[|X_t - mu|^p | F_{t-1}] <= v_t for 1 < p <= 2 when the variance is infinite), constructed by applying Ville's maximal inequality to the nonnegative Catoni supermartingales M_t^C = prod_{i=1}^t exp(phi(lambda_i(X_i - mu)) - lambda_i^2 sigma^2 / 2) and N_t^C = prod_{i=1}^t exp(-phi(lambda_i(X_i - mu)) - lambda_i^2 sigma^2 / 2) for any influence function phi satisfying -log(1 - x + x^2/2) <= phi(x) <= log(1 + x + x^2/2) (or the p-Catoni influence function -log(1 - x + |x|^p/p) <= phi_p(x) <= log(1 + x + |x|^p/p)) with predictable tuning sequence (lambda_t)_{t>=1}, yielding connected root-finding intervals CI_t^C = {m in R : |sum_{i=1}^t phi(lambda_i(X_i - m))| <= sum_{i=1}^t lambda_i^2 sigma^2 / 2 + log(2/alpha)} (and stitched intervals CI_t^{Cstch}) that achieve logarithmic dependence O(log(1/alpha)) in the error level alpha, match the optimal law-of-the-iterated-logarithm rate O(sqrt(t^{-1} log log t)) for finite variance, and attain width O_tilde(t^{-(p-1)/p} log(1/alpha)) for infinite-variance distributions with 1 < p < 2.

Mechanism #catoni-influence-supermartingale-and-tightness-necessity
For any sequence of random variables (X_t)_{t>=1} satisfying E[X_t | F_{t-1}] = mu and E[(X_t - mu)^2 | F_{t-1}] <= sigma^2, any predictable positive sequence (lambda_t)_{t>=1}, and any influence function phi satisfying -log(1 - x + x^2/2) <= phi(x) <= log(1 + x + x^2/2) (such as the narrowest choice phi(x) = log(1 + x + x^2/2) for x >= 0 and -log(1 - x + x^2/2) for x < 0), the inequality exp(+-phi(lambda_i(X_i - mu))) <= 1 +- lambda_i(X_i - mu) + lambda_i^2(X_i - mu)^2 / 2 implies that M_t^C = prod_{i=1}^t exp(phi(lambda_i(X_i - mu)) - lambda_i^2 sigma^2 / 2) and N_t^C = prod_{i=1}^t exp(-phi(lambda_i(X_i - mu)) - lambda_i^2 sigma^2 / 2) are nonnegative supermartingales with initial value 1 (Lemma 8) and that CI_t^C = {m in R : |sum_{i=1}^t phi(lambda_i(X_i - m))| <= sum_{i=1}^t lambda_i^2 sigma^2 / 2 + log(2/alpha)} is a connected (1 - alpha)-confidence sequence (Theorem 9); conversely, Proposition 16 proves this variance condition is tight because if E[(Y_t - mu)^2 | F_{t-1}] = v_t > (1 + 2 kappa) sigma^2 on an event S in F_{t-1} of positive probability, there exists lambda_t > 0 for which E[exp(phi(lambda_t(Y_t - mu)) - lambda_t^2 sigma^2 / 2) | F_{t-1}] > 1 on S.

Mechanism #comparison-with-dubins-savage-and-delyon-self-normalized-confidence-sequences
While the Dubins-Savage confidence sequence CI_t^{DS} = [sum_{i=1}^t lambda_i X_i / sum_{i=1}^t lambda_i +- (2/alpha - 1 + sigma^2 sum_{i=1}^t lambda_i^2) / sum_{i=1}^t lambda_i] (Theorem 2, derived from Lemma 1's linear supermartingale inequality P(exists t : S_t >= a + b V_t) <= 1/(1 + a b)) suffers polynomial width dependence O(1/alpha) (or O(alpha^{-1/2}) when tuned to alpha), and the Self-Normalized confidence sequence CI_t^{SN} (Lemma 5, Theorem 7, derived from Delyon's inequality exp(x - x^2/6) <= 1 + x + x^2/3 via M_t^{SN} = prod_{i=1}^t exp(lambda_i(X_i - mu) - lambda_i^2(X_i - mu)^2 / 6 - lambda_i^2 sigma^2 / 3)) achieves O(log(1/alpha)) scaling by placing the quadratic empirical-variance term -(lambda_i^2/6)(X_i - mu)^2 in the exponent at the cost of producing a disconnected three-component union of intervals L_t^{SN} U M_t^{SN} U U_t^{SN} (complement of two anticonfidence intervals when the quadratic discriminants D^+, D^- are positive), the Catoni-style confidence sequence CI_t^C simultaneously preserves connected single-interval topology [u_t, l_t] and logarithmic O(log(1/alpha)) width scaling.

Mechanism #nonasymptotic-quadratic-width-bound-and-stitched-iterated-logarithm-rate
Using the cubic upper bound phi(x) <= x - x^2/2 + x^3/3, Theorem 10 proves that whenever the weighted empirical variance sigma_hat_i^2 = (X_i - mu_hat)^2 around mu_hat = sum_{i=1}^t lambda_i X_i / sum_{i=1}^t lambda_i satisfies the discriminant condition Delta_t = (sum_{i=1}^t lambda_i)^2 - 2(sum_{i=1}^t lambda_i^3)(sum_{i=1}^t lambda_i^2 sigma_hat_i^2 + sum_{i=1}^t lambda_i^2 sigma^2 / 2 + log(2/alpha)) >= 0, the roots [u_t, l_t] of CI_t^C exist and have half-width bounded deterministically by the smaller quadratic root rho_t = (sum_{i=1}^t lambda_i - sqrt(Delta_t)) / sum_{i=1}^t lambda_i^3 (Appendix B.4, Equations 34 and 72–76), which yields O(sqrt(t^{-1} log t)) shrinkage under predictable plugin tuning lambda_t = Theta(1/sqrt(t log t)) (Corollary 10.1) and attains the optimal law-of-the-iterated-logarithm rate O(sqrt(t^{-1} log log t)) via geometric epoch stitching CI_t^{Cstch} = cap_{s=1}^t I_s in Section 6.2 (Corollary 10.2, Lemma 17).

Mechanism #infinite-variance-p-catoni-supermartingale-confidence-sequences
When the conditional variance is infinite but the conditional p-th central moment is bounded by E[|X_t - mu|^p | F_{t-1}] <= v_t for known 1 < p < 2, replacing the quadratic Catoni influence function with the p-Catoni influence function satisfying -log(1 - x + |x|^p/p) <= phi_p(x) <= log(1 + x + |x|^p/p) makes M_t^{Cp} = prod_{i=1}^t exp(phi_p(lambda_i(X_i - mu)) - lambda_i^p v_i / p) and N_t^{Cp} = prod_{i=1}^t exp(-phi_p(lambda_i(X_i - mu)) - lambda_i^p v_i / p) nonnegative supermartingales (Lemma 13) and yields the connected confidence sequence CI_t^{Cp} = {m in R : |sum_{i=1}^t phi_p(lambda_i(X_i - m))| <= sum_{i=1}^t lambda_i^p v_i / p + log(2/alpha)} (Theorem 14), whose half-width is bounded via the inequality |x + y|^p <= |x|^p + 4|y|^p + p y |x|^{p-1} sgn(x) (Lemma 21) and root analysis of g(r) = 4 A r^p - B r + C (Lemmas 19–20) to contract at rate O_tilde(t^{-(p-1)/p} log(1/alpha)) when lambda_t = Theta_tilde(t^{-1/p}) (Theorem 15, Corollary 15.1).

⚠️ Curated Limitations & Negative Results

  • Constructing valid Catoni-style (or p-Catoni) confidence sequences requires a known a priori upper bound sigma^2 on the conditional variance E[(X_t - mu)^2 | F_{t-1}] <= sigma^2 (or a known upper bound v_t on the p-th central moment E[|X_t - mu|^p | F_{t-1}] <= v_t); by Bahadur-Savage-style impossibility and Proposition 16, if the true variance exceeds (1 + 2 kappa) sigma^2 on a positive-probability event, the Catoni process ceases to be a supermartingale and anytime coverage can fail (Section 2, Section 7, Appendix B.3).
  • At very small sample sizes t before the discriminant condition Delta_t >= 0 of Theorem 10 is satisfied (for example when a single extreme outlier makes sum_{i=1}^t lambda_i(X_i - m) fail to cross the threshold within the quadratic regime or whenphi is chosen from a bounded influence family), root-finding must be performed numerically via bisection/Newton-Raphson and bounded influence functions phi can yield infinite confidence intervals at small t (Section 6, Remark 2, Theorem 10).
  • Under adversarial contamination where an epsilon-fraction of observations come from an arbitrary corrupting distribution with unbounded moments, standard Catoni-style confidence sequences can be biased unless modified to incorporate Huber-robust contamination budgets (Section 10, Wang & Ramdas 2023 AISTATS).
