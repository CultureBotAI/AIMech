Sparsified Stochastic Gradient Descent with Error Memory for k-Contractive Gradient Compression

Algorithms AIMech:SparsifiedSgdWithErrorMemoryForKContractiveGradientCompression DRAFT
Aliases: Mem-SGD, Sparsified SGD with Memory, k-Contractive Error-Compensated SGD, Top-k SGD with Error Feedback Memory
An error-compensated stochastic gradient descent optimization algorithm (Mem-SGD) that compresses each step's scaled stochastic gradient plus accumulated local residual memory m_t using a possibly biased k-contraction operator comp_k: R^d -> R^d satisfying E ||x - comp_k(x)||^2 <= (1 - k/d) ||x||^2 (such as deterministic top-k magnitude selection or scaled random-k coordinate sparsification), updating the iterate via x_{t+1} = x_t - g_t with g_t = comp_k(m_t + eta_t * grad f_{i_t}(x_t)) and retaining the untransmitted residual m_{t+1} = m_t + eta_t * grad f_{i_t}(x_t) - g_t so that the perturbed virtual sequence x_tilde_t = x_t - m_t evolves via exact uncompressed stochastic gradient steps and recovers the asymptotic O(G^2 / (mu * T)) convergence rate of uncompressed SGD.
Identity Notes & Concept Scope Distinct from unbiased stochastic quantization (AIMech:QsgdQuantizedStochasticGradientDescentWithEliasCoding, which requires E[Q(g)] = g and cannot analyze biased deterministic Top-k sparsification), from 1-bit sign compression without contractive residual bounds (AIMech:SignSgdAndMajorityVoteCompressedNonconvexOptimization), from EF21 Markov gradient-difference compression (AIMech:Ef21MarkovCompressorErrorFeedbackForHeterogeneousNonconvexOptimization, which compresses gradient differences grad f_i(x^{t+1}) - g_i^t rather than step-scaled gradient plus error memory), and from low-rank matrix subspace compression (AIMech:PowerSgdLowRankGradientCompressionWithErrorFeedback). No pinned AIO class covers k-contractive sparsified SGD with error memory or its perturbed virtual-iterate convergence guarantee.

Mechanism #r379-k-contraction-and-virtual-iterate-invariance
Under Definition 2.1 and Lemma A.1, both deterministic top_k magnitude selection and random k-coordinate sampling satisfy the k-contraction property E ||x - comp_k(x)||^2 <= (1 - k/d) ||x||^2; by accumulating the compression error m_{t+1} = m_t + eta_t * grad f_{i_t}(x_t) - g_t where g_t = comp_k(m_t + eta_t * grad f_{i_t}(x_t)), Algorithm 1 ensures that the virtual sequence x_tilde_t = x_t - m_t evolves via x_tilde_{t+1} = x_tilde_t - eta_t * grad f_{i_t}(x_t) with zero cumulative information loss.
  • supports Source: Sparsified SGD with Memory · Locator: Section 2 Definition 2.1, Section 3 Proof Sketch, and Appendix A Lemma A.1, pp. 3-5, 12
Mechanism #r379-memory-norm-bound-and-uncompressed-leading-rate
Under L-smoothness, mu-strong convexity, and bounded second moment E ||grad f_i(x_t)||^2 <= G^2, Lemma 3.2 and Lemma A.2 prove that the error memory stays bounded as E ||x_t - x_tilde_t||^2 = E ||m_t||^2 <= 4 * eta_t^2 * ((d^2 - k^2) / k^2) * G^2 (tightened to (2*d/k)*(1 - k/d)*eta_t^2*G^2), yielding Theorem 2.2's convergence rate E[f(x_bar_T)] - f(x*) <= O(G^2 / (mu * T)) + O((d/k)^2 * kappa * G^2 / (mu * T^2)) + O((d/k)^3 * G^2 / (mu * T^3)) whose leading O(1/T) term is independent of the compression ratio k/d.
  • supports Source: Sparsified SGD with Memory · Locator: Theorem 2.2, Lemma 3.2, and Appendix A Lemma A.2, pp. 4-6, 12-13
Limitation #r379-bounded-gradient-and-delay-shift-limitation
The convergence analysis of Mem-SGD relies on the uniform second-moment gradient bound E ||grad f_i(x_t)||^2 <= G^2 and requires an initial stepsize delay parameter a = Omega((d/k) * kappa) so that eta_t = 8 / (mu * (a + t)) changes slowly enough to contract the error memory norm.
  • supports Source: Sparsified SGD with Memory · Locator: Section 2 Theorem 2.2, Section 3 Lemma 3.2, and Section 6 Conclusion, pp. 3-6, 8
Application #r379-communication-efficient-sparse-training-application
Applied to communication-efficient stochastic optimization of multiclass logistic regression and regularized least-squares models with 10x to 1000x gradient sparsification (top-1 and top-k).
  • supports Source: Sparsified SGD with Memory · Locator: Section 5 Numerical Experiments, Figures 1-2, pp. 7-8

⚠️ Curated Limitations & Negative Results

  • Requires a uniform second-moment bound E ||grad f_i(x_t)||^2 <= G^2 on stochastic gradients to bound the error memory norm ||m_t||^2.
  • Stepsize schedule eta_t = 8 / (mu * (a + t)) requires an initial warm-up shift a >= max(2*kappa, 4*d/k) proportional to the compression factor d/k.
