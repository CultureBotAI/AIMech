Robust continuous clustering

Algorithms AIMech:RobustContinuousClustering DRAFT
Aliases: RCC clustering
A clustering algorithm that optimizes one representative per observation using squared data fidelity and robust attraction along a neighborhood graph, then extracts groups from thresholded connectivity between the optimized representatives.

Claims & Grounded Evidence

6 Claims
Mechanism #robust-representative-objective
For observations x_i and representatives u_i initially equal to x_i, minimize one half of the summed squared data residuals plus lambda/2 times the weighted graph-edge penalties rho(||u_p-u_q||). The demonstrated Geman–McClure penalty is rho(y)=mu*y^2/(mu+y^2), with mu>0. Its influence decreases for sufficiently large separations, allowing weak intergroup connections to contribute less than under a quadratic attraction penalty.
  • supports Source: Robust continuous clustering · Locator: Formulation, PDF pp.1–2, Equations1–4
Mechanism #neighborhood-and-degree-weights
The paper constructs a mutual k-nearest-neighbor graph and augments it with a spanning tree of the k-nearest-neighbor graph. Its reported setting uses k=10 and cosine similarity for neighbor selection; an edge weight is average node degree divided by the geometric mean of its endpoint degrees. These graph choices and weights are separate from Euclidean representative differences in the objective. The pinned Python graph builder computes batched pair distances and partial neighbor sorting; it is not the approximate-neighbor implementation described in the paper.
  • supports Source: Robust continuous clustering · Locator: SI Methods, Connectivity Structure and Implementation, PDF p.7, EquationS1
  • supports Source: RCC author implementation: Toolbox/edgeConstruction.py · Locator: Toolbox/edgeConstruction.py, lines91–139,142–180
Mechanism #line-process-and-linear-solve
Introduce a nonnegative line variable l for each edge. For fixed representatives, its minimizing value is (mu/(mu+||u_p-u_q||^2))^2. For fixed line variables, representatives solve a weighted graph-Laplacian linear system: using columns for observations, U(I+lambda*A)=X. With nonnegative edge weights and lambda>=0, I+lambda*A is positive definite. These exact block subproblems do not establish a global optimum of the nonconvex joint objective or certify approximate numerical solves.
  • supports Source: Robust continuous clustering · Locator: Optimization, PDF pp.2–3, Equations2,4–8
  • supports Source: RCC author implementation: RCC.m · Locator: RCC.m, lines70–84,116–128
Scope #continuation-and-stopping
The method uses graduated nonconvexity: reduce the robust scale mu during optimization and update lambda using the ratio of data and graph spectral norms. Changing these parameters changes the objective, so fixed-objective descent cannot be transferred silently to the whole schedule. The printed loop condition combines small objective change with an iteration condition using OR; the pinned MATLAB implementation instead uses a bounded for-loop and explicit continuation or break decisions. The code initializes mu from the maximum retained edge length, whereas the supplementary description uses the median.
  • supports Source: Robust continuous clustering · Locator: Optimization and Algorithm1, PDF p.3; SI Methods, PDF p.7
  • supports Source: RCC author implementation: RCC.m · Locator: RCC.m, lines37–56,68–103
Mechanism #thresholded-component-extraction
Final labels are connected components after comparing representative distances with an edge-derived threshold; the number of clusters is not an input to the RCC objective. The supplement describes pairwise threshold connectivity, while the pinned assignment routine tests only the supplied original graph edges. The implementation also filters near-duplicate edges when deriving thresholds and distinguishes a capped scale sample from the uncapped one-percent threshold sample. These conventions can change the resulting partition and are not asserted to be equivalent.
  • supports Source: Robust continuous clustering · Locator: Algorithm1, PDF p.3; SI Methods, Initialization and Output, PDF p.7
  • supports Source: RCC author implementation: RCC.m · Locator: RCC.m, lines37–48,108–111
  • supports Source: RCC author implementation: assignment.m · Locator: assignment.m, lines1–13
Scope #variant-and-implementation-scope
RCC-DR jointly learns a sparse low-dimensional representation and clustering and is a distinct extension, not an alias for the base RCC procedure. The author README distinguishes the released MATLAB accuracy implementation from a faster C++ implementation used for reported runtime measurements. Those measurements and the extension’s results are not transferred to this base record.

⚠️ Curated Limitations & Negative Results

  • The nonconvex objective, continuation, graph construction and threshold extraction each impose scope boundaries. Neither an exact fixed-line solve nor a decreasing fixed-parameter block step proves a globally optimal partition.
  • The released MATLAB solver uses PCG tolerance1e-2 and at most100 iterations per feature, and discards its returned status. Static inspection does not certify numerical convergence or exact monotonicity.
  • Zero graph norms, too few retained nonduplicate edges, disconnected neighbor graphs and unexpected index conventions require separate handling. The pinned MATLAB code initializes edge endpoint variables only when the input edge list has minimum index zero; generic one-based input is not certified.
  • The paper and inspected implementation differ in robust-scale initialization, threshold sampling, output edge scope and neighbor-search implementation. No single default configuration is silently attributed to both.
  • Finite curator arithmetic checks20 line-process cases and81 two-point fixed-parameter updates, plus a constructed difference between all-pair and original-edge extraction. The extraction example is not claimed to arise during an author RCC run.
  • The published evaluations include dataset-specific preprocessing and parameter selection. In particular, graph preprocessing for text datasets uses a PCA dimension equal to the number of ground-truth classes; this does not establish a wholly label-independent benchmark pipeline.
  • All11 pages of the author-hosted main paper and supplement and the cited pinned source files were read. No author code, data, training, MATLAB/C++ execution or benchmark replication was performed; external solver internals and evaluation utilities were not audited.
