Aliases: FoH
A classification model family comprising separately parameterized harmoniums for each class, with binary text features and Gaussian image features coupled to Gaussian latent variables and compared through normalized class-conditional likelihoods.
Definition Evidence
  • supports Source: Harmonium Models for Semantic Video Representation and Classification · Locator: Sections 3.1-3.2, PDF pp.3-5, Figure 2 and Equations 3.1-3.7
Identity Notes & Concept Scope Scoped to the FoH construction in Yang and colleagues' semantic-video manuscript. Each labeled class owns its parameters and latent coordinates; a categorical class selector has a prior distribution. This differs from the shared label-coupled hierarchical harmonium, an unsupervised single harmonium followed by an SVM, and the earlier unbounded Poisson-text dual-wing specialization. Claims & Grounded Evidence

3 Claims
Mechanism #class-specific-modalities
For a selected class y, each word-presence variable is Bernoulli with logit alpha_i^y+sum_k W_ik^y h_k. The demonstrated image-feature conditional is Gaussian with identity covariance and mean beta^y+U^y h. Hidden variables given all text/image features and the class are independent unit-Gaussian variables with mean (W^y)^T x+(U^y)^T z. Separate class parameters produce separate latent coordinates; topic positions across classes are not inherently aligned.
  • supports Source: Harmonium Models for Semantic Video Representation and Classification · Locator: Section 3.2, PDF pp.4-5, Equations 3.2-3.5; Section 3.4, pp.6-7
Limitation #proper-gaussian-domain
For the identity-covariance construction, the Gaussian image/hidden precision must be positive definite; equivalently I-U^y(U^y)^T must be positive definite in every class. Binary word variables add bounded-state linear terms and do not repair an unstable Gaussian coupling. Proper-looking conditional normals alone do not establish a proper joint. The record restricts the probability-model definition to this admissible domain and does not certify that the historical fitting procedure enforced it.
  • supports Source: Harmonium Models for Semantic Video Representation and Classification · Locator: Section 3.2, PDF p.5, Equations 3.3-3.6; Appendix, p.12
Mechanism #class-normalized-decision
Integrating Gaussian hidden variables gives class-specific visible log mass F_y(x,z)=alpha^y dot x+beta^y dot z-||z||^2/2+||(W^y)^T x+(U^y)^T z||^2/2. Class posterior scores require pi_y exp(F_y)/Z_y. Assuming uniform class priors removes pi_y but not the separate class normalizers Z_y. In a one-word, one-image-feature example, unnormalized scores favor the second class while normalized densities favor the first. Each class can be fitted from its labeled examples; adding a class does not require sharing its latent coordinates with existing classes.
  • supports Source: Harmonium Models for Semantic Video Representation and Classification · Locator: Sections 3.2 and 3.4, PDF pp.5-7, Equations 3.6-3.7 and scalability discussion

⚠️ Curated Limitations & Negative Results

  • The manuscript acknowledges hidden partition functions but does not give a complete operational recipe for estimating and comparing every class normalizer. Raw energy comparison is not certified as probability comparison; no omission in uninspected author code is alleged.
  • The Appendix adds quantities as log-partitions but displays integrals without the required logarithms. The compatible main joint and standard exponential-family algebra determine this record, rather than that inconsistent display. Gaussian color features are a modeling approximation to physical histogram observations.
  • Fully factorized mean field and short-chain CD approximate learning statistics. The manuscript's broad CD-to-maximum-likelihood convergence statement is not accepted as a general guarantee. Sampling schedules and stability safeguards remain implementation details not fully specified by the paper.
  • Main model comparisons use the five largest TRECVID categories, 1078 shots, an equal training/test split and selected latent sizes. The broader collection has 15 classes and 2468 shots. Selected topic examples and classification curves do not prove universal semantic accuracy, causality or generalization. No historical implementation or benchmark was run.
