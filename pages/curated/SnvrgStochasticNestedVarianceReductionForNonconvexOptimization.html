SNVRG (Stochastic Nested Variance Reduction) for Non-Convex Optimization

Aliases: SNVRG, Stochastic Nested Variance Reduction, One-Epoch-SNVRG, SNVRG+Neon2
Stochastic Nested Variance Reduction (SNVRG) is a multi-level hierarchical variance-reduced stochastic gradient algorithm for non-convex finite-sum and online optimization introduced by Zhou, Xu, and Gu (2018, 2020). In each outer epoch of One-Epoch-SNVRG (Algorithm 1), SNVRG maintains K + 1 nested reference points (x_tilde^{(0)}, ..., x_tilde^{(K)}) and nested semi-stochastic gradients (g^{(0)}, ..., g^{(K)}) governed by loop-length multipliers (s_1, ..., s_K) with S_l = prod_{i=l+1}^K s_i and geometric mini-batch sizes B_l. At inner step j in {0, ..., prod_{i=1}^K s_i - 1}, let l = min{i : 0 == j mod S_i} be the deepest triggered level: SNVRG resets reference point x_tilde^{(l)} = x_j, updates level l via the nested control-variate difference g^{(l)} = g^{(l-1)} + nabla f_{B_l}(x_tilde^{(l)}) - nabla f_{B_l}(x_tilde^{(l-1)}) (where g^{(0)} = nabla f_{B_0}(x_tilde^{(0)})), synchronizes all finer levels x_tilde^{(i)} = x_j and g^{(i)} = g^{(l)} for i = l+1, ..., K, and takes an unnormalized constant-step gradient update x_{j+1} = x_j - eta * g^{(K)} with eta = O(1/L).

Identity Notes & Concept Scope Distinct from two-level SVRG (which corresponds to K = 1 in SNVRG and requires O(n^{2/3} * varepsilon^{-2}) or O(varepsilon^{-10/3}) gradient complexity) and distinct from SPIDER (Round 345, Fang et al. 2018), which updates at every step using the immediate predecessor x_{j-1} and requires accuracy-dependent normalized step sizes eta = O(varepsilon / L), whereas SNVRG uses K = O(log n) or O(log(1/varepsilon)) nested reference levels with a large constant step size eta = 1/(6L) and adapts automatically across the full-gradient, Polyak-Lojasiewicz, and non-convex stationary regimes.

Claims & Grounded Evidence

3 Claims
Mechanism #r372-claim-nested-variance-telescoping-and-epoch-descent-lemma
Because each nested level difference nabla f_{B_l}(x_tilde^{(l)}) - nabla f_{B_l}(x_tilde^{(l-1)}) is conditionally unbiased for nabla F(x_tilde^{(l)}) - nabla F(x_tilde^{(l-1)}) given x_tilde^{(l)} and x_tilde^{(l-1)}, the top-level variance decomposes across the K levels as E||g^{(K)} - nabla F(x_j)||_2^2 <= E||g^{(0)} - nabla F(x_tilde^{(0)})||_2^2 + L^2 * sum_{l=1}^K B_l^{-1} * E||x_tilde^{(l)} - x_tilde^{(l-1)}||_2^2 (Lemma 17); setting s_l = 2, B_l = 68 * 4^l * K (with K = floor(1/2 * log_2 B_0)), and constant step size eta = 1/(6L) bounds the per-step trajectory drift so that One-Epoch-SNVRG (Algorithm 1) achieves E[F(x_S) - F(x_0)] <= -(S/(32*L)) * E||nabla F(x)||_2^2 + (68*S/(32*L)) * I(B_0 < n) * sigma^2 / B_0 using at most 3 * B_0 * (1 + K) stochastic gradient evaluations per epoch of length S = 2^{K+1} (Lemma 4).
  • supports Source: Stochastic Nested Variance Reduction for Nonconvex Optimization · Locator: Section 3-4, Algorithm 1 and Lemma 4, pp. 6-8, 12; Appendix A.1, Proof of Lemma 4 and Lemmas 17-19, Equations (A.1)-(A.17), pp. 26-32
Mechanism #r372-claim-finite-sum-online-and-polyak-lojasiewicz-convergence-rates
For finite-sum and online L-smooth non-convex objectives (Algorithm 2), setting B_0 = min{68*sigma^2/varepsilon^2, n} and S = (B_0/2)^{1/2} yields E||nabla F(x_out)||_2 <= varepsilon in O((Delta_F*L*varepsilon^{-2} * min{sigma/varepsilon, n^{1/2}} + min{sigma^2/varepsilon^2, n}) * log(2 + min{sigma^2/varepsilon^2, n})) = O_tilde(min(n + n^{1/2}*varepsilon^{-2}, varepsilon^{-3})) stochastic gradient evaluations, simultaneously outperforming GD O(n*varepsilon^{-2}), SGD O(varepsilon^{-4}), and SVRG O(min(n + n^{2/3}*varepsilon^{-2}, varepsilon^{-10/3})) with a single parameter-free constant step size eta = 1/(6L) (Theorem 5, Corollary 6, Table 1); furthermore, if F satisfies the local mu-Polyak-Lojasiewicz condition 1/2 * ||nabla F(x)||_2^2 >= mu * (F(x) - F(x^*)), SNVRG (Algorithm 3) achieves F(x_out) - F(x^*) <= varepsilon in O_tilde(min{n + kappa*n^{1/2}, kappa*sigma*varepsilon^{-1/2} + sigma^2*varepsilon^{-1}} * log(1/varepsilon)) where kappa = L/mu, beating SVRG's O((n + kappa*n^{2/3})*log(1/varepsilon)) when kappa >= n^{1/2} without knowing mu inside One-Epoch-SNVRG (Theorem 9, Corollary 10).

Application #r372-claim-snvrg-neon2-local-minima-and-glauber-dynamics-mcmc
Coupling One-Epoch-SNVRG with Neon2 negative-curvature extraction in SNVRG+Neon2 (Algorithm 4.1 / Algorithm 4.2) finds an (varepsilon_g, varepsilon_H)-second-order stationary point (||nabla F(x)||_2 <= varepsilon_g, lambda_min(nabla^2 F(x)) >= -varepsilon_H) in O_tilde(varepsilon_g^{-3} + varepsilon_H^{-5} + varepsilon_g^{-2}*varepsilon_H^{-3}) online and O_tilde(n*varepsilon_H^{-1.5} + n^{3/4}*varepsilon_H^{-3.5} + n^{1/2}*varepsilon_g^{-2} + n + varepsilon_H^{-5}) finite-sum stochastic gradient evaluations (Theorems 13 and 15, Corollaries 14 and 16); applied to non-convex robust linear regression and multi-class neural networks on CIFAR-10/MNIST/SVHN and to variance-reduced Glauber dynamics for Ising models, SNVRG converges faster than SGD, SVRG, and SCSG.
  • supports Source: Stochastic Nested Variance Reduction for Nonconvex Optimization · Locator: Section 1, Table 2, p. 3; Section 5-7, Algorithms 4.1-4.2, Theorems 13 and 15, Corollaries 14 and 16, and Figures 2-4, pp. 16-24; Appendix B-C, pp. 35-56

⚠️ Curated Limitations & Negative Results

  • Incurs a logarithmic factor O(log(min(sigma^2/varepsilon^2, n))) in stochastic gradient complexity due to maintaining K = floor(1/2 * log_2 B_0) nested reference levels and their associated memory O(K * d), and in the second-order regime when varepsilon_H = O(varepsilon^{1/2}) has an O_tilde(varepsilon^{-3.5}) mixed term (Remark 7, p. 13; Section 5, p. 19).
