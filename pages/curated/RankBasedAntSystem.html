Rank-based Ant System

Algorithms AIMech:RankBasedAntSystem DRAFT
Aliases: ASrank
An Ant System variant that weights pheromone deposits from a selected number of the current iteration’s best tours by rank and adds a separate reinforced contribution from the best-so-far tour.
Identity Notes & Concept Scope This record denotes ASrank in the inspected 1997 working paper. It differs from unweighted all-ant deposits, elitist Ant System’s all-ant-plus-archive deposits, and MAX–MIN’s single-best bounded-trail update. Rank determines which ants contribute and their additional weights, but inverse tour length remains in the deposit; the rule is not purely ordinal. Claims & Grounded Evidence

1 Claim
Mechanism #method
Construct traveling-salesman tours using Ant System’s feasible-city probabilities proportional to tau^alpha*eta^beta with eta=1/d, and retain the best-so-far tour. Sort the m current tours by nondecreasing positive length L_1<=...<=L_m. In the displayed rule choose an integer elite weight sigma with 1<=sigma<=m+1, so the top sigma−1 current tours are available. Update each edge by rho*tau plus the sum, over ranks mu=1..sigma−1 whose tours use the edge, of (sigma−mu)*Q/L_mu, plus sigma*Q/L_best if the best-so-far tour uses that edge. Rho is trail retention, so 1−rho is the evaporated fraction. The archive contribution is added separately even when the same tour also contributes through a current rank. Reconstruct new tours using the resulting trails for the next iteration; the paper’s update does not add MAX–MIN trail bounds or the ACS local rule.
  • supports Source: A New Rank Based Version of the Ant System - A Computational Study · Locator: Sections2.2–3.2, PDF pp.7–11 / printed pp.4–8, Equations1–4; conclusion PDF pp.15–16 / printed pp.12–13

⚠️ Curated Limitations & Negative Results

  • The displayed sum requires enough current ants and a declared integer sigma; sigma=1 leaves only the best-so-far contribution. Ties in tour length need a rank assignment or tie policy, which can matter when tied tours use different edges.
  • Rank weighting still multiplies inverse positive tour cost. An increasing transformation or constant shift of costs can preserve ranks while changing deposits, heuristic weights and the search trajectory. Calling the algorithm rank-based does not establish invariance to arbitrary fitness transformations.
  • The retained best tour is a search memory, not a certified optimum. Strong elite weighting and vanishing trails can reduce exploration. Evaporation and rank selection do not provide the positive support bounds of MAX–MIN, and no finite-run global-optimality guarantee is asserted.
  • Positive distances/costs, finite normalizers, initialization, heuristic exponents, edge symmetry, stopping and numerical behavior need explicit configuration. The 1997 working paper’s small benchmark comparison is not assumed identical to every later implementation or the 1999 journal text.
