Tabu search for SAT (TSAT)

The SAT-specific basic tabu-search method described by Mazure, Saïs and Grégoire in 1997, which systematically excludes recently flipped variables using a fixed-length chronological FIFO list, updates that list after each flip and permits no aspiration override in the surrounding GSAT assignment-search setting.

Claims & Grounded Evidence

5 Claims
Scope #gsat-model-finding-context
TSAT is introduced in the GSAT model-finding setting for CNF formulas, using complete Boolean assignments and single-variable flips. The surrounding GSAT presentation uses random initial assignments, per-attempt flip budgets and an outer attempt budget; its best-score flip can have zero or negative gain. Figure 3 is explicitly basic GSAT and is not a complete dedicated TSAT pseudocode.
  • supports Source: Tabu Search for SAT · Locator: PDF pp. 1–3 / printed pp. 281–283, introduction, Random Walk Strategy GSAT and Figure 3.
Mechanism #systematic-fifo-variable-exclusion
TSAT maintains a fixed-length, chronologically ordered FIFO list of flipped variables. A variable in the tabu list is forbidden from being flipped again while it remains listed. The list is updated every time a flip is made, so the restriction systematically tracks recent variable changes rather than being applied only after a detected local minimum.
  • supports Source: Tabu Search for SAT · Locator: PDF p. 3 / printed p. 283, Restricting randomness, fixed-length chronological FIFO and update on every flip.
Mechanism #no-aspiration-and-attribute-memory
The described basic TSAT uses no aspiration criterion: a favorable clause score does not by itself override tabu status. Its list stores variables rather than complete forbidden truth assignments. Thus the memory restricts move attributes and does not constitute a set of all previously visited search states.
  • supports Source: Tabu Search for SAT · Locator: PDF p. 3 / printed p. 283, Restricting randomness, no aspiration and variable rather than interpretation storage.
Mechanism #random-walk-branch-distinction
TSAT removes the additional random-walk branch used by RWS-GSAT and instead applies the systematic tabu restriction. This does not mean that every choice becomes deterministic. The paper retains the random-start GSAT setting and discusses random basic-GSAT ties, without restating a complete TSAT tie or reset specification.
  • supports Source: Tabu Search for SAT · Locator: PDF pp. 1–3 / printed pp. 281–283, abstract, GSAT/RWS-GSAT setting and Restricting randomness; PDF p. 4 conclusion.
Scope #versioned-gsat-tabu-selector
In the separately versioned UBCSAT 1.0.0 archive, the unweighted GSAT/TABU registration cites Mazure, Saïs and Grégoire’s CP95 work. Its PickGSatTabu selector filters variables using the last-change cutoff, scans the non-tabu variables for a minimum cached score, and selects uniformly when several candidates tie for that minimum. These are static implementation details of that archive, not certification that it reproduces every convention of the 1997 experimental program.
  • supports Source: UBCSAT 1.0.0 source archive: GSAT/TABU selector in src/gsat-tabu.c · Locator: Archive member src/gsat-tabu.c, unweighted AddGSatTabu registration lines 30–43 and PickGSatTabu lines 58–106; exact member hash retained in source metadata.

⚠️ Curated Limitations & Negative Results

  • The 1997 presentation does not supply a complete dedicated TSAT pseudocode. Initialization and reset of tabu memory, ties, the discrete tenure boundary and empty-admissible-set behavior need explicit operational conventions. Figure 3 is basic GSAT; later implementation choices must not be silently substituted for the original account.
  • A declared integer tenure and variable universe are needed. For n>0 variables and a tabu set of at most T distinct variables, 0≤T<n ensures that some variable is admissible. If T≥n, all variables can become tabu without an intervening reset. The inspected paper gives no general all-tabu fallback or aspiration escape; a fitted fractional tenure also needs an integer convention.
  • Finite unsuccessful search is not an UNSAT certificate, and recent-variable exclusion does not prove global cycle freedom or eventual success. On the unsatisfiable conjunction of all four two-variable clauses, every flip has zero gain; tenure one can permit alternating x,y flips that revisit an assignment after four steps and an augmented assignment/list state after the fifth, absent an intervening cutoff or reset. This is a hand boundary example, not an observed run.
  • The best admissible flip need not improve the clause score, and a useful move can be tabu. No-aspiration TSAT differs from tabu configurations with aspiration, adaptive tenure or longer-term intensification and diversification. Constant-time circular FIFO access does not establish constant-time evaluation of all flips or constant-time search.
  • The displayed linear formula for an experimentally best tabu-list length is a fit for the reported random K-SAT studies, not a universal optimum, theorem, rounding rule or guarantee for structured SAT. The paper identifies dynamic lengths and structured examples as further work; no fixed tenure is mandated here for every problem.
  • Table 1 reports time and flip averages on solved instances, with solved percentages relative to an approximately 50% expected satisfiable subset at the phase transition. These denominators and the common C/Linux/Pentium platform, budgets and tested distributions limit interpretation. The comparisons do not establish universal speedups, exact satisfiable-instance success rates or whole-solver complexity, and no benchmark was reproduced.
  • The CP95 reference, the 1997 paper and later GSAT/TABU documentation remain distinct versions. The inspected UBCSAT selector has no explicit zero-candidate branch before reading candidate index zero; complete infrastructure and runtime behavior were not audited, so no observed implementation failure is asserted. The earlier timid TSAT and the clause-focused WalkSAT/TABU/null-move variants are not aliases of this scoped method.
