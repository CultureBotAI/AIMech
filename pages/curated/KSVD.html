K-SVD

Algorithms AIMech:KSVD DRAFT
A dictionary-learning algorithm that alternates sparse coding of training samples with sequential updates of each dictionary atom and its active coefficients using a leading rank-one singular-value approximation of the support-restricted reconstruction residual.
Identity Notes & Concept Scope Scoped to the original sparsity-constrained K-SVD dictionary-learning algorithm, not a trained dictionary, every sparse-coding procedure, approximate K-SVD or BatchOMP. Fixed-dictionary pursuits do not identify its sequential support-restricted atom/coefficient update. The pinned SparseLearning class has broader sparse-dictionary synonyms and neural representation-learning typing; related_match avoids equivalence and unsupported inheritance. Claims & Grounded Evidence

6 Claims
Mechanism #sparse-coding-and-dictionary-objective
For finite real training data Y with n rows and N sample columns, a dictionary D with K unit-norm columns, and a coefficient matrix X with K rows and N columns, the sparsity-constrained formulation minimizes ||Y-DX||_F^2 subject to at most T0 nonzero coefficients in each sample column of X. The source targets overcomplete dictionaries. Each iteration first holds D fixed and obtains sparse sample codes with a chosen approximation procedure, then updates the atoms and their associated coefficients. An exact solution of the combinatorial sparse-coding problem is not assumed.
  • supports Source: K-SVD: An Algorithm for Designing Overcomplete Dictionaries for Sparse Representation · Locator: Section IV.B–C, PDF pp. 6–7 / printed pp. 4316–4317, Equations 17, 19–20 and Figure 2
Mechanism #active-sample-residual-restriction
For atom k, hold the other atom/row products fixed and form E_k=Y-sum_{j!=k} d_j x_j^row. The active sample set is Omega_k={i in 1..N: X[k,i]!=0}. Restrict E_k to these sample columns before computing its rank-one approximation. This set uses the sample range N specified in Figure 2; the K upper bound printed in Equation 22 is an indexing discrepancy. Updating the unrestricted residual instead can introduce nonzero coefficients outside this set and violate a sample sparsity budget. Restriction preserves those outside coefficients as zero.
  • supports Source: K-SVD: An Algorithm for Designing Overcomplete Dictionaries for Sparse Representation · Locator: Section IV.C, PDF p. 7 / printed p. 4317, Equations 21–23 and Figure 2; original support and sample-index examples in research/discovery/ksvd-boundaries.py
Mechanism #joint-rank-one-and-sequential-update
For a nonempty active set, write its restricted residual as U Sigma V^T. Choose a leading left singular vector as the new unit atom and sigma_1 times the corresponding right singular vector, transposed, as its active coefficient row. Scatter this row back to the active sample positions and leave the other positions zero. Newly fitted active coefficients may themselves be zero, so the support can shrink. The source sweep updates atoms sequentially and uses the newest coefficients in subsequent residuals. A later sparse-coding stage may select new supports; fixed-support atom sweeps alone cannot introduce new active positions.
  • supports Source: K-SVD: An Algorithm for Designing Overcomplete Dictionaries for Sparse Representation · Locator: Section IV.B–C, PDF pp. 6–7 / printed pp. 4316–4317, support discussion and Figure 2; original sequential-residual example in research/discovery/ksvd-boundaries.py
Limitation #conditional-block-descent
With the active set and all other atom/row products fixed, the leading singular triplet gives a least-squares rank-at-most-one approximation of the restricted residual. The preceding atom and row are feasible for that block, so an exact update cannot increase the total squared reconstruction error. This conditional property does not guarantee descent after arbitrary feasible sparse recoding. The source proposes comparing the best fit on the previous support with the new pursuit fit and retaining the better one. Nonincreasing objective values alone do not establish convergence of iterates to a local minimizer; the source’s stronger convergence inference is not adopted here.
  • supports Source: K-SVD: An Algorithm for Designing Overcomplete Dictionaries for Sparse Representation · Locator: Section IV.C, PDF pp. 7–8 / printed pp. 4317–4318, rank-one update and convergence/safeguard discussion before Section IV.D; original exact block and deliberately poor feasible-recoding examples in research/discovery/ksvd-boundaries.py
Limitation #empty-zero-and-nonunique-blocks
An empty active sample set supplies no data to determine the atom, so keeping or replacing an unused atom requires an additional policy. The source discusses replacing unpopular atoms as an implementation heuristic. For a nonempty zero residual block, zero coefficients are optimal and any unit atom gives the same loss. Repeated positive leading singular values can give distinct equally optimal rank-one fits: for the two-by-two identity residual, either coordinate direction gives squared error 1. Simultaneously changing an atom and its coefficient row signs preserves their product. These block facts do not establish an identifiable learned dictionary.
  • supports Source: K-SVD: An Algorithm for Designing Overcomplete Dictionaries for Sparse Representation · Locator: Figure 2, PDF p. 7 / printed p. 4317; Section IV.E, PDF p. 8 / printed p. 4318, unused-atom heuristic; explicit curator degeneracy and sign calculations derived from the block objective in research/discovery/ksvd-boundaries.py
Scope #one-atom-coding-and-kmeans-boundary
Using one atom per sample while allowing a free scalar coefficient gives the source’s gain-shape setting. It does not alone identify ordinary k-means. Fixing the nonzero coefficient to 1 and allowing an unconstrained representative instead yields a centroid subproblem. That is different from the usual unit-norm atom update with a freely fitted coefficient: on the single sample (2,0), the unconstrained centroid (2,0) has zero error, the fixed-one unit representative (1,0) has error 1, and the unit atom (1,0) with coefficient 2 again has zero error. The source analogy therefore requires the stated coefficient and normalization conventions.
  • supports Source: K-SVD: An Algorithm for Designing Overcomplete Dictionaries for Sparse Representation · Locator: Section IV.A, PDF pp. 5–6 / printed pp. 4315–4316, and Section IV.D, PDF p. 8 / printed p. 4318, Equation 24 and fixed-one discussion; original normalization example in research/discovery/ksvd-boundaries.py

⚠️ Curated Limitations & Negative Results

  • This record covers the original sparsity-constrained algorithm, not a particular trained dictionary or an exact sparse-coding solver. The source’s error-constrained alternative, approximate K-SVD updates and BatchOMP implementations are not automatically the same operational identity. The existing BatchOMP/K-SVD source-family lead remains partly unresolved.
  • Equation 15 on PDF p. 6 also prints a sample sum with upper bound K instead of N. Equations 6–7 on PDF p. 3 display positive density exponents inconsistent with Equation 8 in background about a different method. Those background formulas are not adopted as K-SVD mechanisms. The Equation 22 sample-index caveat is retained in the active-set claim.
  • The fixed DC atom in Section VI’s image application is a configuration, not a universal algorithm requirement. Empty-support handling, pursuit choices, numerical SVD behavior, stopping rules and atom-replacement policies require implementation choices beyond the core block equations.
  • Curator exact arithmetic uses small constructed matrices with supplied SVD certificates; some examples use square dictionaries to expose algebraic boundaries. It does not validate numerical SVD software, run author code, reproduce a benchmark or establish recovery, uniqueness, global convergence or a general speed advantage.
