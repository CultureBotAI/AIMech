Maximum coding likelihood estimation

Algorithms AIMech:MaximumCodingLikelihoodEstimation DRAFT
Aliases: Coding likelihood estimation, Coding maximum likelihood estimation
A conditional parameter-estimation method that selects mutually non-neighboring sites in a Markov field and maximizes their joint conditional likelihood, which factors into sitewise full conditionals given the remaining observed sites.
Identity Notes & Concept Scope This record uses the classical independent-site coding method of Besag. Coding selects a graph-independent subset; it does not encode features, compress data or learn sparse representations. Shifted or alternative coding sets can give additional dependent estimates. Extensions using conditionally dependent blocks require their joint conditional likelihoods rather than this independent-singleton product. The method is distinct from multiplying all site conditionals as pseudolikelihood and from state updates in ICM or Gibbs sampling. Claims & Grounded Evidence

1 Claim
Mechanism #method
For a compatible positive Markov-field model with observed configuration x, choose a nonempty set S containing no neighboring pair and let C be its complement. Conditional on X_C=x_C, the variables in S are mutually independent, so L_S(theta;x_S|x_C)=product_(i in S) p_theta(x_i|x_(-i)). Maximize its log over valid theta. The complement supplies conditioning values even though its own site likelihood factors are omitted. A rectangular four-neighbor graph admits checkerboard coding; adding diagonal interactions requires another independent-set design, such as the source’s four shifted patterns. Changing the selected set changes the conditional likelihood. The full-site pseudolikelihood equals the product of coding likelihoods for a partition into independent sets, but maximizing that product differs in general from averaging separately fitted parameters.

⚠️ Curated Limitations & Negative Results

  • The factorization needs a valid graph and the stated joint conditional-independence property. It is not justified by spatial distance alone or by arbitrary, incompatible local distributions. Hard support constraints require separate treatment beyond the positive-model construction.
  • Choosing a large independent set need not yield a unique selection or the most informative estimator. Conditioning omits some likelihood information while retaining the complement as covariates; it does not literally discard all white-site observations.
  • Estimates and tests from shifted coding patterns reuse the same configuration and are generally dependent. Combining them requires a justified procedure; neither naive independent-test calibration nor an arithmetic average of estimates is automatically optimal.
  • Conditional likelihood-ratio comparisons require comparable selected dependent sites and conditioning sets. The source warns against comparing fits based on different codings as if they were the same likelihood. Ordinary asymptotic approximations still require identifiability, information and regularity conditions.
  • The source’s unconstrained coding estimates can violate the intended joint-model parameter restrictions. A conditional objective may be finite where the full Gaussian field is invalid, so the parameter domain must be enforced. Averaging happened to yield admissible values in some reported examples and is not a general repair.
  • The inspected plant and wheat data illustrate estimation and model diagnostics, while exposing model inadequacy and aggregation effects. They do not prove general efficiency or spatial prediction accuracy. No empirical data fitting, author implementation or benchmark was reproduced.
