PowerSGD Low-Rank Subspace Iteration Gradient Compression with Error Feedback

Aliases: PowerSGD, Low-Rank Gradient Compression via Subspace Iteration, Warm-Start Power Iteration SGD with Error Feedback
A distributed low-rank gradient compression algorithm (PowerSGD) that reshapes each parameter tensor's error-compensated gradient matrix Delta_w = g_{t,w} + e_{t,w} in R^{n x m} on worker w in [W], computes a single warm-started rank-r block power iteration step via P_w = Delta_w Q, all-reduces P = (1/W) sum_{w=1}^W P_w, orthonormalizes the columns of P via Gram-Schmidt, computes Q_w = Delta_w^T P, all-reduces Q = (1/W) sum_{w=1}^W Q_w, reconstructs the rank-r update Delta_hat = P Q^T, and stores the local post-compression residual e_{t+1,w} = Delta_w - P Q_w^T, exploiting the linearity of matrix-subspace projections to aggregate compressed updates via all_reduce in O((n + m)*r) communication with exact single-worker equivalence.

Claims & Grounded Evidence

4 Claims
Mechanism #r381-single-multi-worker-allreduce-linearity-equivalence
Lemma 3 proves that because both projection steps P_w = Delta_w Q and Q_w = Delta_w^T P are linear in Delta_w for shared right and left factors Q and P, averaging P_w and Q_w via two all_reduce operations yields P Q^T = (1/W) sum_{w=1}^W P Q_w^T = C((1/W) sum_{w=1}^W Delta_w) and average error (1/W) sum_{w=1}^W e_{t+1,w} = (1/W) sum_{w=1}^W Delta_w - C((1/W) sum_{w=1}^W Delta_w), making W-worker distributed PowerSGD mathematically identical to single-worker PowerSGD on the exact averaged gradient while avoiding O(W) all_gather communication.
  • supports Source: PowerSGD: Practical Low-Rank Gradient Compression for Distributed Optimization · Locator: Section 2.1, Algorithm 1, and Lemma 3 (Single/Multi-worker Equivalence), pp. 2-4
Mechanism #r381-warm-start-subspace-iteration-and-post-compression-momentum
Theorem I shows that subspace iteration on M in R^{n x m} with singular values sigma_1 >= ... >= sigma_r > sigma_{r+1} converges to the top-r eigenspace at geometric rate O((sigma_{r+1}/sigma_r)^t), motivating warm-starting Q from the previous step's factor; furthermore, Algorithm 2 applies momentum after compression so that the update satisfies (1/W) sum_w Delta(x_t) = (1 + lambda/(1 - lambda)) * (x_0 - x_{T+1}), preserving exact telescoping cancellation in error-feedback convergence analysis.
  • supports Source: PowerSGD: Practical Low-Rank Gradient Compression for Distributed Optimization · Locator: Section 2.2, Section 2.3 Algorithm 2, and Appendix A Theorem I, pp. 3-4, 11-12
Limitation #r381-uncompressed-rank1-bias-vector-limitation
One-dimensional parameter tensors (such as bias vectors and batch-normalization scale/shift parameters) cannot be reshaped into higher-dimensional matrices for rank-r factor compression and must be communicated uncompressed via standard all_reduce.
  • supports Source: PowerSGD: Practical Low-Rank Gradient Compression for Distributed Optimization · Locator: Section 2.1 Table 1 and Matrix Shapes paragraph, p. 3
Application #r381-distributed-cnn-and-transformer-training-application
Applied to multi-GPU distributed training of ResNet-50 on ImageNet and Transformer language models on WikiText-2, achieving up to 65x-129x gradient compression and 55% communication-time reduction without test accuracy degradation.
  • supports Source: PowerSGD: Practical Low-Rank Gradient Compression for Distributed Optimization · Locator: Section 3 Experiments, Tables 2-4 and Figures 2-4, pp. 4-7

⚠️ Curated Limitations & Negative Results

  • Requires local Gram-Schmidt orthonormalization of an n x r matrix and two all_reduce operations per layer at each training step.
  • 1D bias and normalization vectors cannot be low-rank factored and must be transmitted uncompressed.
