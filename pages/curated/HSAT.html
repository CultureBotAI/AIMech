A GSAT variant that breaks ties among best-scoring variable flips by choosing the variable flipped least recently in the current attempt, using a fixed arbitrary order for ties among never-flipped variables.
Definition Evidence
  • supports Source: Towards an Understanding of Hill-climbing Procedures for SAT · Locator: PDF1–2 / printed28–29, GenSAT/GSAT framework and candidate score; PDF4 / printed31, Memory section defining HSAT and IHSAT
Identity Notes & Concept Scope HSAT changes the choice among the global GSAT best-score candidates; it does not choose the globally oldest variable regardless of score. The history is local to the current attempt, unlike clause-weight or near-solution reuse across attempts. It does not impose a tabu exclusion or prohibit an immediate repeat when that variable is the only best candidate. IHSAT changes the candidate set using the indifferent ISAT rule and is a distinct variant. The deterministic tie rule does not make the complete HSAT procedure deterministic because its GSAT initialization remains randomized. Claims & Grounded Evidence

1 Claim
Mechanism #method
Start an attempt with a random complete assignment as in GSAT and initialize the attempt-local flip history. If the formula is not satisfied, evaluate each variable by the change in the total number of satisfied clauses caused by flipping it. Form the set of variables with greatest score increase, including zero or negative best gains when no improving flip exists. Among those candidates, choose the one whose last flip in the current attempt was longest ago. Variables never flipped in that attempt are treated as oldest; when several such variables are candidates, use an arbitrary fixed ordering. Flip the chosen variable, update its timestamp and continue within the declared attempt budget. New attempts reset the current-attempt history. The source retains the GenSAT outer attempts and GSAT candidate-score rule while changing the picking rule.

⚠️ Curated Limitations & Negative Results

  • The 1993 paper provides empirical comparisons, not a general convergence, polynomial-time or universal performance guarantee. Its conjectures about the importance of randomness and greediness are experimental claims on studied tasks.
  • The fixed ordering for never-flipped ties must be declared. Selecting the oldest variable outside the best-score candidate set, using a tabu tenure, or retaining timestamps across attempts changes the stated method.
  • The GenSAT pseudocode checks satisfaction before each flip. A final permitted flip needs an explicitly declared post-flip check if an implementation is to return a model found exactly at that boundary; finite unsuccessful search does not prove UNSAT.
  • Attempt budgets, formula representation and score-update costs remain implementation parameters. Historical information is bookkeeping rather than necessarily a learning task; no author solver or benchmark was executed.
