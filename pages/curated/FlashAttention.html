FlashAttention

Algorithms AIMech:FlashAttention DRAFT
An exact attention computation algorithm using tiling and recomputation to reduce transfers between GPU memory levels.
Identity Notes & Concept Scope The original dense exact-attention algorithm, not a distinct trained model, a generic attention layer, or its separately described block-sparse approximation.

Claims & Grounded Evidence

1 Claim
Mechanism #mechanism
Blocks of queries, keys and values are processed with running softmax statistics; intermediate attention values can be recomputed during the backward pass.
  • supports Source: FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness · Locator: Sections 3.1–3.2 and Algorithm 1, PDF/printed pp. 4–6

⚠️ Curated Limitations & Negative Results

  • The block-sparse extension and later FlashAttention versions are outside this record.
  • Reduced memory traffic does not establish a universal wall-clock speedup; no hardware-independent performance claim is made.
