End-to-End Memory Network

Aliases: MemN2N, End-to-End Memory Networks
A neural architecture that answers a query through one or more differentiable soft-attention reads over separately embedded input and output memories, updating a query state between reads and learning from the final prediction loss.

Claims & Grounded Evidence

6 Claims
Mechanism #soft-memory-read
For a supplied finite buffer of memories x_i and a query q, form input-memory embeddings m_i=A*x_i, a query embedding u=B*q and output-memory embeddings c_i=C*x_i. Normalize the dot products u^T*m_i with softmax, read o=sum_i p_i*c_i, and predict an answer through softmax(W*(o+u)). The memory read is a weighted combination rather than a hard selection of one supporting fact. The input and output embedding matrices have distinct roles.
  • supports Source: End-To-End Memory Networks · Locator: Section 2.1, PDF pp. 1–2, Equations 1–3 and Figure 1
Scope #hops-and-tying
Multiple hops update the query state and reread memory before producing an answer. The displayed update is u^(k+1)=u^k+o^k. Adjacent tying sets A^(k+1)=C^k, B=A^1 and W^T=C^K, whereas layer-wise tying shares A and C across hops and uses a learned linear query transform H in u^(k+1)=H*u^k+o^k. These are distinct configurations; a computational hop is not necessarily a new observed input time step.
  • supports Source: End-To-End Memory Networks · Locator: Section 2.2, PDF pp. 2–3, Equation 4 and tying descriptions
Scope #word-and-memory-order
Bag-of-words sentence embeddings lose word order. The position-encoding variant instead weights word-embedding coordinates by a deterministic function of word position and sentence length. Separate learned temporal embeddings encode memory position, with sentences indexed from the most recent backward. Permuting complete key/value pairs leaves a single soft read unchanged, but moving a sentence while retaining position-dependent temporal embeddings generally changes its key and value.
  • supports Source: End-To-End Memory Networks · Locator: Section 4.1, PDF pp. 4–5, sentence representation and temporal encoding; direct permutation consequence
Scope #supervision-and-training
Cross-entropy training backpropagates through soft memory reads and does not require the supporting-fact labels used by the compared strongly supervised Memory Network. This remains supervised answer prediction, not unsupervised learning or a guarantee of a correct reasoning chain. The QA experiments use validation data, random restarts and a linear-start option that initially removes memory softmax operations before restoring them; the ordinary soft-read equations do not describe that initial phase.
  • supports Source: End-To-End Memory Networks · Locator: Sections 2.1 and 3, PDF pp. 2–3; Section 4.2, p. 5, training and linear-start descriptions
Limitation #finite-buffer-and-slot-boundaries
The QA implementation described in the paper keeps the latest 50 sentences in memory even when a problem contains more sentences. Learned embeddings and multiple reads do not supply unlimited context or the arbitrary dynamic write-head operations of a Neural Turing Machine. Adding or duplicating an unmasked memory slot can change the softmax denominator and readout. A zero-valued padding embedding alone does not imply that its attention slot is excluded, especially when temporal embeddings are added.
  • supports Source: End-To-End Memory Networks · Locator: Section 2.1, PDF p. 2; Sections 4.1–4.2, pp. 4–5, temporal encoding, memory limit and null-word constraint; Section 6, p. 8; direct constructed slot examples
Limitation #evaluation-and-output-scope
The paper evaluates synthetic bAbI question answering and separately configured word-level language models. QA variants differ in sentence encoding, initialization, training set size and joint training; multiple-word answers are encoded as one output-vocabulary entry. The language model instead reads previous words with a constant query, uses layer-wise tying and a partly rectified hidden state, and predicts the next word. Selected task errors and perplexities do not demonstrate universal reasoning, monotonic gains from more hops or superiority across all compared configurations. Visualization heatmaps are not causal explanations; Figure 3 rescales each row to a maximum of one.
  • supports Source: End-To-End Memory Networks · Locator: Sections 4–5, PDF pp. 4–8, Tables 1–2 and Figures 2–3; Section 6, p. 8

⚠️ Curated Limitations & Negative Results

  • This is the named end-to-end soft-read architecture, distinct from the original Memory Network framework and its hard-retrieval MemNN instantiation.
  • External memory here is a supplied finite buffer with learned embeddings; no unlimited storage, general dynamic write controller or exact reasoning algorithm is established.
  • QA and language-model configurations have different queries, tying, encodings, nonlinearities and output protocols.
  • All nine primary proceedings pages were visually read. Supplement, other versions and author code were not inspected. Constructed algebraic examples do not train or replicate a model. DRAFT remains.
