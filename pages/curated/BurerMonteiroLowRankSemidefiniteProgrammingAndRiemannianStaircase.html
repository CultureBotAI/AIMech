Burer-Monteiro Low-Rank Semidefinite Programming and Riemannian Staircase

Aliases: Smooth Burer-Monteiro Riemannian SDP Factorization, Boumal-Voroninski-Bandeira Benign Non-Convexity above the Barvinok-Pataki Bound, Riemannian Staircase for Low-Rank Semidefinite Programming
Burer-Monteiro Low-Rank Semidefinite Programming and Riemannian Staircase is a non-convex Riemannian optimization framework analyzed by Boumal, Voroninski, and Bandeira (2016, 2019) that solves linear semidefinite programs min_{X in S^{n x n}} <C, X> subject to A(X) = b, X >= 0 (with m linear constraints) by substituting the rank-p factorization X = Y Y^T with Y in R^{n x p} on the constraint set M_p = {Y in R^{n x p} : A(Y Y^T) = b}. Under regularity assumptions verifying that M_p is a smooth Riemannian submanifold of R^{n x p} with compact quotient M_p / O(p) (such as the Oblique manifold M_p = {Y : (Y Y^T)_{ii} = 1} for Max-Cut, Z_2/SO(d) synchronization, and community detection SDPs), Lemma 2.1 and Lemma 2.2 show that every first-order Riemannian critical point Y has a unique closed-form dual multiplier vector mu(Y) and dual slack matrix S(Y) = C - A^*(mu(Y)) satisfying S(Y) Y = 0 and Riemannian Hessian quadratic form <dot{Y}, Hess g(Y)[dot{Y}]> = <dot{Y}, S(Y) dot{Y}>. Lemma 2.4 proves that any column-rank-deficient second-order critical point (rank(Y) < p, Hess g(Y) >= 0) satisfies S(Y) >= 0 and is therefore globally optimal for the SDP, while Theorem 1.2 and Theorem 1.4 establish via Sard's theorem and dimensional transversality that when p(p+1)/2 > m (the Barvinok-Pataki bound), for generic cost matrices C (outside a set of Lebesgue measure zero) the non-convex landscape on M_p has NO spurious local minima: every second-order Riemannian critical point Y is globally optimal.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
Under Assumption 1.1 on the smooth manifold M_p = {Y in R^{n x p} : A(Y Y^T) = b}, Lemma 2.1 and Lemma 2.2 prove that at any first-order Riemannian critical point Y in M_p, the dual slack matrix S(Y) = C - A^*(mu(Y)) satisfies S(Y) Y = 0 and <dot{Y}, Hess g(Y)[dot{Y}]> = <dot{Y}, S(Y) dot{Y}> for all dot{Y} in T_Y M_p; consequently, Lemma 2.4 proves that if Y is column-rank-deficient (exists z in R^p, ||z||_2 = 1 with Y z = 0) and second-order critical (Hess g(Y) >= 0 on T_Y M_p), then dot{Y} = u z^T lies in T_Y M_p for every u in R^n with u^T S(Y) u = <dot{Y}, Hess g(Y)[dot{Y}]> >= 0, certifying S(Y) >= 0 and global optimality of X = Y Y^T for the SDP.
  • supports Source: The non-convex Burer-Monteiro approach works on smooth semidefinite programs · Locator: Section 2, Lemmas 2.1, 2.2, 2.3, and 2.4, Equations 4-10, pp. 4-6
  • supports Source: The non-convex Burer-Monteiro approach works on smooth semidefinite programs (arXiv abstract) · Locator: Abstract: global optimality of second-order critical points for smooth SDPs when p(p+1)/2 > m
Scope #claim-02
Theorem 1.2, Theorem 1.4, and Theorem 3.1 prove that when the factorization rank p satisfies the Barvinok-Pataki inequality p(p+1)/2 > m (where m is the number of linear constraints), the affine space of cost matrices C admitting any full-column-rank first-order critical point has dimension at most m + np - p(p+1)/2 < np = dim M_p + m, which by Sard's theorem has Lebesgue measure zero in S^{n x n}; thus for almost all C, every second-order critical point Y in M_p is rank-deficient (rank(Y) < p) and globally optimal.
  • supports Source: The non-convex Burer-Monteiro approach works on smooth semidefinite programs · Locator: Section 1.1, Theorems 1.2 and 1.4, Inequality 3, pp. 3-4; Section 3, Theorem 3.1 and Proof, pp. 6-8
  • supports Source: The non-convex Burer-Monteiro approach works on smooth semidefinite programs (Crossref metadata) · Locator: Communications on Pure and Applied Mathematics 73(3):581-608 bibliographic record
Limitation #claim-03
When the factorization rank p lies below the Barvinok-Pataki threshold (p(p+1)/2 <= m, such as p = 2 for the frustrated 5-cycle Max-Cut SDP where m = 5), M_p can possess spurious full-rank critical points where S(Y) has strictly negative eigenvalues lambda_min(S(Y)) < 0, requiring the Riemannian staircase to increment p -> p + 1 and escape along the lifted negative-curvature tangent vector dot{Y} = u e_{p+1}^T.
  • supports Source: The non-convex Burer-Monteiro approach works on smooth semidefinite programs · Locator: Section 1.1 and Section 2, Discussion of Barvinok-Pataki bound p(p+1)/2 > m and Riemannian staircase escape via Lemma 2.4, pp. 3-5

⚠️ Curated Limitations & Negative Results

  • Guaranteed absence of spurious local minima for generic cost matrices C holds above the Barvinok-Pataki threshold p(p+1)/2 > m (so p = Theta(sqrt(m))) and requires the Linear Independence Constraint Qualification (LICQ) so that M_p is a smooth submanifold.
