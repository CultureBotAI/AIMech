LoRA-GA

Algorithms AIMech:LoRAGA DRAFT
Aliases: Low-Rank Adaptation with Gradient Approximation, Low-Rank Gradient Approximation LoRA Initialization, Gradient-Aligned SVD LoRA Initialization
A low-rank adaptation initialization algorithm that aligns the initial update direction of a low-rank adapter product eta B A with the first-step full fine-tuning weight update by initializing A_init and B_init from disjoint top-2r singular vectors of the sampled loss gradient nabla_W L under forward-and-backward scale-stable normalization.
Identity Notes & Concept Scope Distinct from AIMech:LowRankAdaptation (which uses Kaiming uniform initialization for A and zeros for B, restricting the initial update to rank r) and from AIMech:PissaPrincipalSingularValuesAndSingularVectorsAdaptation (PiSSA, which decomposes the pre-trained weight matrix W_0 via SVD rather than the task loss gradient nabla_W L). LoRA-GA (Shaowen Wang, Linxi Yu, & Jian Li, NeurIPS 2024, arXiv:2407.05000) minimizes ||eta^2 (nabla_W L A_init^T A_init + B_init B_init^T nabla_W L) - zeta nabla_W L||_F (Equation 3). Given SVD nabla_W L = U S V^T, Theorem 3.1 proves that choosing disjoint index sets I_A = {1, ..., r} and I_B = {r+1, ..., 2r} with A_init = (sqrt(zeta)/eta) V_{[1:r]}^T and B_init = (sqrt(zeta)/eta) U_{[r+1:2r]} produces the exact rank-2r Eckart-Young-Mirsky optimal Frobenius approximation zeta sum_{i=1}^{2r} sigma_i u_i v_i^T. Combined with Theorem 3.2's scale-stability analysis (eta = alpha / sqrt(r) and zeta = (alpha^2 / gamma^2) sqrt(d_out) / r^2), LoRA-GA sets A_init = (d_out^{1/4} / gamma) V_{[1:r]}^T, B_init = (d_out^{1/4} / gamma) U_{[r+1:2r]}, and adjusts the frozen base weight to W_init = W_0 - eta B_init A_init via layer-by-layer backward hooks.

Claims & Grounded Evidence

4 Claims
Mechanism #loraga-disjoint-2r-gradient-svd-eckart-young-optimality
Because the first-step update of eta B A is proportional to eta^2 (nabla_W L A_init^T A_init + B_init B_init^T nabla_W L) (Lemma 3.1), initializing A_init and B_init with disjoint singular vector sets I_A = {1..r} and I_B = {r+1..2r} of nabla_W L = U S V^T yields zeta sum_{i=1}^{2r} sigma_i u_i v_i^T, achieving the exact Eckart-Young optimal rank-2r Frobenius approximation to the scaled full-fine-tuning gradient zeta nabla_W L (Theorem 3.1).
  • supports Source: LoRA-GA: Low-Rank Adaptation with Gradient Approximation · Locator: Section 3.2 (Gradient Approximation, Lemma 3.1 & Theorem 3.1) & Appendix A.1, pp. 4-5, 12
Mechanism #loraga-non-zero-initialization-scale-stability-and-o1-layerwise-memory
Under η = alpha / sqrt(r), setting zeta = (alpha^2 / gamma^2) sqrt(d_out) / r^2 so that A_init = (d_out^{1/4}/gamma) V_{[1:r]}^T and B_init = (d_out^{1/4}/gamma) U_{[r+1:2r]} guarantees forward second-moment stability Theta_{r, d_out, d_in}(1) (Theorem 3.2), while subtracting eta B_init A_init from W_0 and discarding each layer's gradient immediately during the backward hook keeps initialization memory at O(1) layer overhead.
  • supports Source: LoRA-GA: Low-Rank Adaptation with Gradient Approximation · Locator: Section 3.3-3.4 (Definition 3.1, Theorem 3.2, Algorithm 1), Section 4.4 (Table 5) & Appendix A.2, pp. 5-6, 9, 12-14
Application #loraga-application-glue-t5-and-llama2-math-code-chat
Without altering the LoRA forward architecture or training loop, LoRA-GA accelerates convergence by 2x-4x over vanilla LoRA, improving T5-Base GLUE average accuracy by +5.69 points (87.77% vs. 82.08%) and boosting LLaMA-2-7B by +11.52% on GSM8K (53.60% vs. 42.08%), +5.05% on HumanEval (19.81% vs. 14.76%), and +0.34 on MT-Bench.
  • supports Source: LoRA-GA: Low-Rank Adaptation with Gradient Approximation · Locator: Section 4.1-4.3 (Tables 1-4, Figure 2), pp. 6-9
Limitation #loraga-limitation-double-adapter-checkpoint-storage-and-aspect-ratio-asymmetry
Because W_frozen = W_0 - eta B_init A_init depends on the non-zero initial adapters, LoRA-GA requires double the adapter checkpoint storage (saving both (A_init, B_init) and the trained (A, B) to reconstruct W' from an unmodified shared base model W_0), and no single scalar zeta can simultaneously make both forward and backward scales exact Theta(1) when d_out / d_in diverges.
  • supports Source: LoRA-GA: Low-Rank Adaptation with Gradient Approximation · Locator: Appendix A.2 (Equations 5-6, p. 14) & Appendix F (Limitations, p. 18)

⚠️ Curated Limitations & Negative Results

  • Requires storing both the initial adapter pair (A_init, B_init) and the final adapter pair (A, B)—doubling adapter checkpoint storage—whenever the base weights W_0 are kept unmodified across tasks.
  • Cannot simultaneously guarantee exact Theta_{r, d_out, d_in}(1) forward and backward variance with a single scalar zeta when the layer aspect ratio d_out / d_in is not Theta(1).
  • Incurs a one-time initialization pass (forward-backward over a sampled calibration batch plus per-layer SVD) prior to fine-tuning.
