TKL: Transformer-Kernel Model with Local Self-Attention for Long Document Retrieval

Aliases: TKL Long-Document Ranking Model, Transformer-Kernel for Long Text, Local Self-Attention Transformer-Kernel Model
A long-document neural re-ranking architecture (Hofstätter, Zamani, Mitra, Craswell, & Hanbury, SIGIR 2020) that contextualizes document token sequences d_{1:m} (up to thousands of tokens) in fixed-size moving windows of width w with overlap o using a multi-layer highway Transformer—reducing self-attention complexity from O(L^2) to O(L * w) and skipping pure-padding windows—computes cosine similarity RBF kernel activations K_{i,j}^k = exp(-(cos(q_i, d_j) - mu_k)^2 / (2 sigma^2)), sums activations within sliding saturation regions K_i^{r,k} = sum_{j=r}^{r+r_size} K_{i,j}^k, applies a learned query-salience conditioned power saturation function K_hat_i^{r,k} = a_i * (K_i^{r,k})^{1/b_i} - c_i, and aggregates the resulting relevance topography s^r via top-local-max_{t,f}(s^r) W_s over the top-t non-overlapping local maxima and their f immediate neighbors.

Identity Notes & Concept Scope Distinct from the short-text TK model (AIMech:TKTransformerKernelModelForReRanking, which applies full self-attention over the first ~200 tokens and uses fixed log saturation over the entire document). TKL introduces overlapping local self-attention windows with minibatch padding-chunk skipping, a learned non-linear power saturation function conditioned on query-term salience e_i and region token count c_len, and two-stage local/global topography pooling via top-local-max_{t,f}.

Claims & Grounded Evidence

3 Claims
Mechanism #tkl-windowed-local-attention-and-salience-saturation-mechanism
TKL contextualizes document tokens in overlapping windows of width w and overlap o (concatenating interior slices d_hat_{1:m} = [TF(d_{1:w+o})_{1:w}; TF(d_{w-o:2w+o})_{o:-o}; ...] and skipping pure-padding windows), computes RBF kernel activations K_{i,j}^k, sums them in sliding windows of size r_size, applies the learned power saturation K_hat_i^{r,k} = a_i * (K_i^{r,k})^{1/b_i} - c_i conditioned on query-term salience e_i (initialized with IDF) and region token count c_len, and scores the top-t non-overlapping local maxima and their f neighboring regions via s = top-local-max_{t,f}(s^r) W_s.
  • supports Source: Local Self-Attention over Long Text for Efficient Document Retrieval · Locator: Section 3, Equations (1)-(7), p. 2
  • supports Source: Local Self-Attention over Long Text for Efficient Document Retrieval · Locator: sliding_windows_non_pad, learned_saturation, and top_local_max verification
Scope #tkl-long-document-bias-mitigation-scope
By extending contextualized kernel pooling to 2,000-4,000 document tokens and detecting relevant regions beyond the 500th word, TKL significantly improves nDCG@10 and MRR@10 over TK on TREC 2019 Deep Learning Track document ranking while mitigating the under-retrieval bias against longer relevant documents.
  • supports Source: Local Self-Attention over Long Text for Efficient Document Retrieval · Locator: Section 1, Figure 1, p. 1; Section 5, Tables 1-2, Figures 2-3, pp. 3-4
Limitation #tkl-window-boundary-context-limitation
Because TKL restricts document self-attention to local sliding windows of width w with overlap o rather than full document-wide attention, long-range contextual dependencies across distant paragraphs cannot interact during token contextualization and are only aggregated at the relevance topography stage.
  • supports Source: Local Self-Attention over Long Text for Efficient Document Retrieval · Locator: Section 1, p. 1; Section 3, Equation (1), p. 2

⚠️ Curated Limitations & Negative Results

  • Restricting document self-attention to local sliding windows of width w prevents direct token-level contextualization across distant sections of a document.
