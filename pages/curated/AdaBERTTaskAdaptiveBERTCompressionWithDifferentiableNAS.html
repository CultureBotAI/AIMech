AdaBERT (Task-Adaptive BERT Compression with Differentiable Neural Architecture Search)

Algorithms AIMech:AdaBERTTaskAdaptiveBERTCompressionWithDifferentiableNAS DRAFT
Aliases: AdaBERT, Task-Adaptive BERT Compression with Differentiable Neural Architecture Search, AdaBERT Attentive Hierarchical Probe Distillation NAS
AdaBERT is a task-adaptive BERT compression framework that uses differentiable Neural Architecture Search (NAS) to jointly optimize a macro stacking layer count K in {1, ..., K_max} and a shared directed acyclic graph cell alpha_c composed of lightweight 1D standard/dilated convolutions, pooling, skip, and zero operations under the composite objective L = (1 - gamma)*L_CE + gamma*L_KD + beta*L_E, where L_KD is an Attentive Hierarchical Transfer loss distilled from frozen layer-wise teacher probe classifiers P_j^T on BERT_t and L_E is an efficiency-aware regularizer penalizing normalized parameter size and FLOPs via Gumbel-Softmax Straight-Through Estimator relaxation.
Identity Notes & Concept Scope Distinct from task-independent BERT distillation methods such as DistilBERT (AIMech:DistilBERTKnowledgeDistillationDuringPretraining), BERT-PKD (AIMech:BERTPKDPatientKnowledgeDistillationForBERTModelCompression), and TinyBERT (AIMech:TinyBERTTransformerDistillationForNaturalLanguageUnderstanding), which compress BERT into a fixed-structure smaller Transformer for all tasks, and distinct from HAT (AIMech:HATHardwareAwareTransformersForEfficientNLP), which performs evolutionary search over an encoder-decoder SuperTransformer rather than Gumbel-Softmax differentiable search over CNN cells guided by hierarchical teacher probe classifiers.

Mechanism #adabert-task-useful-probe-and-attentive-hierarchical-transfer
AdaBERT trains J frozen-backbone Softmax probe classifiers P_j^T on each hidden layer j of the fine-tuned teacher BERT_t, aligns student layer i with teacher layer j = ceil(i * J / K) via probe KL divergence L_{KD}^{i,m} = -P_j^T(C_{j,m}^T) * log(P_i^S(C_{i,m}^S)/T) (Eq. 3), and aggregates across layers with instance-specific Attentive Hierarchical Transfer weights w_{i,m} = exp[y_m * log P_j^T(C_{j,m}^S)] / sum_{i'} exp[y_m * log P_{j'}^T(C_{j',m}^S)] (Eq. 4).
  • supports Source: AdaBERT: Task-Adaptive BERT Compression with Differentiable Neural Architecture Search · Locator: Section 2.3 (Task-oriented Knowledge Distillation), Equations 3-4, pp. 2-3
  • supports Source: AdaBERT: Task-Adaptive BERT Compression with Differentiable Neural Architecture Search · Locator: proportional_layer_index and attentive_hierarchical_weights
Mechanism #adabert-efficiency-aware-loss-and-gumbel-softmax-ste-search
AdaBERT regularizes architecture search with the Efficiency-Aware Loss L_E = (K / K_max) sum_{o_{i,j} in alpha_c} [SIZE(o_{i,j}) + FLOPs(o_{i,j})] (Eq. 5) and relaxes categorical sampling of the macro layer count K and cell operations o_{i,j} using Gumbel-Softmax continuous proxies y^K and y^o (Eq. 6) with Straight-Through Estimator one-hot argmax in the forward pass.
  • supports Source: AdaBERT: Task-Adaptive BERT Compression with Differentiable Neural Architecture Search · Locator: Section 2.4-2.5, Equations 5-6, pp. 3-4
  • supports Source: AdaBERT: Task-Adaptive BERT Compression with Differentiable Neural Architecture Search · Locator: efficiency_aware_loss and gumbel_softmax_sample
Application #adabert-glue-speedup-and-cross-task-specialization
Across six GLUE benchmark tasks (SST-2, MRPC, QQP, MNLI, QNLI, RTE), AdaBERT discovers task-specialized architectures (from K=3 layers and 6.4M parameters on SST-2 to K=7 layers and 9.5M parameters on MNLI) that are 12.7x to 29.3x faster in inference and 11.5x to 17.0x smaller than BERT-base while maintaining comparable accuracy.
  • supports Source: AdaBERT: Task-Adaptive BERT Compression with Differentiable Neural Architecture Search · Locator: Section 3.2 (Overall Results), Tables 1-3 and Figure 3, pp. 4-5
Limitation #adabert-cross-task-transfer-degradation-and-per-task-search-limitation
Because AdaBERT prunes task-redundant capacity into a task-specialized CNN cell and depth K, applying an architecture searched for a simple single-sentence task (such as SST-2) to a complex sentence-pair entailment task (such as MNLI or RTE) causes severe accuracy degradation (e.g., 64.0% vs 81.3% on MNLI), requiring a separate 80-epoch NAS run per downstream task.
  • supports Source: AdaBERT: Task-Adaptive BERT Compression with Differentiable Neural Architecture Search · Locator: Section 3.2 (Adaptiveness Study / Cross-Task Validation), Table 3, p. 5

⚠️ Curated Limitations & Negative Results

  • Searched architectures are highly task-specific and degrade substantially when transferred across dissimilar NLP task types (e.g., single-sentence sentiment to sentence-pair textual entailment).
  • Requires fine-tuning a teacher BERT, training layer-wise probe classifiers, and running 80 epochs of differentiable architecture search for each target downstream task.
