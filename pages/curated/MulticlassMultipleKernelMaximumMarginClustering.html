Multiclass Multiple Kernel Maximum Margin Clustering

Algorithms AIMech:MulticlassMultipleKernelMaximumMarginClustering DRAFT
Aliases: Multi-Class Multiple Kernel Clustering
A multiclass unsupervised clustering procedure that jointly fits shared nonnegative multiple-kernel weights and latent class-score functions using winner-margin cutting planes and repeated convex conic fits.
Identity Notes & Concept Scope This record denotes the multiclass Zhao-Kwok-Zhang2009 procedure for a supplied class count m. Its displayed class scores have no intercept, and its margins compare a winning class with competing classes; it is not simply the binary intercept-bearing implementation run unchanged. Shared learned kernel weights differ from fixed kernels, observed-label supervised SVMs and multiview variance criteria. The shared source acronym MKC is not used as a unique alias. Claims & Grounded Evidence

4 Claims
Mechanism #kernel-weight-geometry
Given supplied PSD base kernels K_k and feature maps Phi_k, learn nonnegative weights beta_k with sum_k beta_k^2<=1, not a simplex constraint. The resulting mixed kernel is sum_k beta_k*K_k, consistently represented by concatenated sqrt(beta_k)*Phi_k blocks. The paper introductory sum of feature maps must not be read as an arbitrary vector sum that adds cross terms, especially when feature dimensions differ. Its reparameterization v_k=beta_k*w_k gives a quadratic-over-linear regularizer. At beta_k=0 the closed perspective has cost zero for v_k=0 and infinite cost otherwise. Kernel scaling affects the optimization.

Mechanism #shared-kernel-class-scores
For m supplied classes, set g_ip=sum_k (v_k^p)^T*Phi_k(x_i) with no displayed bias term and one shared beta vector. Minimize 0.5*sum_k,p ||v_k^p||^2/beta_k+(C/n)*sum_i xi_i with winning-class-versus-competitor margins, nonnegative slacks and the nonnegative L2 kernel-weight bound. For every class pair p,q impose |sum_i(g_ip-g_iq)|<=l. These aggregate score constraints are not class-count balance constraints and do not ensure that every class is occupied.
  • supports Source: Multiple Kernel Clustering · Locator: Section 4.1, PDF pp. 8-9 / pp. 645-646, Equations 4.29-4.34
Mechanism #multiclass-working-set
For a unique winning class p_i and runner-up r_i, the per-observation slack is max(0,1-(g_i,p_i-g_i,r_i)). Aggregate slacks with masks c_i drawn from the zero vector or one-hot class vectors. The separation step uses the runner-up mask when the top-versus-runner-up gap is below 1, and the zero mask otherwise. The outer cutting-plane loop alternates restricted fitting with adding the most violated mask until violation is at most epsilon. The inner procedure freezes winning-class indicators at previous scores and solves the convex quadratic-over-linear problem by SOCP, repeating under its stopping rule.
  • supports Source: Multiple Kernel Clustering · Locator: Sections 4.1-4.2, PDF pp. 9-10 / pp. 646-647, Equations 4.33-4.35 and Algorithms 3-4
Limitation #winner-ties-and-optimization
The displayed z_ip indicator requires class p to score strictly above every other class. At a tied maximum all indicators are zero, so the displayed label sum_p p*z_ip equals zero, outside the class set {1,...,m}. A one-hot argmax tie policy is therefore needed, but no particular repair is silently treated as part of the printed algorithm. Freezing winners gives a convex inner fit; it does not by itself prove global optimality or unconditional convergence and monotonicity across changes of winning labels. The binary bias and multiclass score parameterizations and margin scales also preclude an unqualified claim that m=2 is the identical implementation.

⚠️ Curated Limitations & Negative Results

  • The full problem is nonconvex. Solving convex second-order cone subproblems does not establish a globally optimal kernel combination, globally optimal labels or universal local-optimum behavior. Initialization, score ties, numeric tolerances and stopping conventions matter.
  • Nonnegative kernel weights preserve PSD when the supplied base kernels are PSD. Feature construction, kernel choice and scaling, regularization C, balance limit l and cutting-plane tolerance epsilon remain supplied choices. No class-count balance or nonempty-cluster guarantee follows solely from aggregate score constraints.
  • All twelve source pages, including experiments and references, were read. The reported comparisons use selected datasets, known class counts, chosen kernels and tuning; their per-cluster majority-label accuracy is not stated as one-to-one cluster matching. The source whole-dataset generalization evaluation includes the fitting subset. No universal performance, independent held-out guarantee, historical implementation or benchmark reproduction is asserted.
