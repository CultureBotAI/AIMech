Tree SHAP

Algorithms AIMech:TreeSHAP DRAFT
A tree-specific algorithm computing Shapley feature attributions through recursive bookkeeping of weighted feature subsets along decision paths.
Identity Notes & Concept Scope This record denotes the original tree-traversal SHAP algorithm, not the TreeExplainer software package, all its later modes, or Independent Tree SHAP.

Claims & Grounded Evidence

2 Claims
Mechanism #explanation-method
The original procedure follows known-feature branches and uses node cover for missing-feature branches, while EXTEND and UNWIND operations track subset sizes and repeated split features to accumulate weighted leaf contributions.
  • supports Source: Consistent Individualized Feature Attribution for Tree Ensembles · Locator: Sections 3.1–3.2, Algorithms 1–2, PDF/printed pp. 3–4
Scope #subset-function-scope
The later method description explicitly defines the exact Tree SHAP calculation relative to the tree-traversal subset function and distinguishes Independent Tree SHAP.
  • supports Source: Explainable AI for Trees: From Local Explanations to Global Understanding · Locator: Methods 10.1–10.2, PDF/printed pp. 21–22

⚠️ Curated Limitations & Negative Results

  • Exact computation is relative to the specified tree-traversal subset-evaluation function; it is not an assertion of exact conditional expectations for arbitrary dependent input distributions.
  • Background/intervention variants and nonlinear output transforms require separate method assumptions.
