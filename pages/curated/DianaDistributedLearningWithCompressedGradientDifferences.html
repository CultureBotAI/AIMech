DIANA Distributed Learning with Compressed Gradient Differences

Algorithms AIMech:DianaDistributedLearningWithCompressedGradientDifferences DRAFT
Aliases: DIANA, Distributed Learning with Compressed Gradient Differences, Compressed Gradient Difference Proximal Stochastic Gradient Descent
A distributed composite and nonconvex stochastic optimization algorithm (DIANA) for minimizing f(x) + R(x) = (1/n) sum_{i=1}^n f_i(x) + R(x) across n workers in which each worker i maintains a local gradient-memory shift vector h_i^k in R^d (with server mean h^k = (1/n) sum_{i=1}^n h_i^k), computes a stochastic gradient g_i^k, compresses only the gradient difference Delta_i^k = g_i^k - h_i^k via an unbiased block l_p quantizer Delta_hat_i^k = Quant_p(Delta_i^k) satisfying E[||Delta_hat_i^k - Delta_i^k||_2^2] <= (1/alpha_p - 1) ||Delta_i^k||_2^2, updates its local memory h_i^{k+1} = h_i^k + alpha * Delta_hat_i^k, and transmits Delta_hat_i^k to the server to form the unbiased global gradient estimator g_hat^k = h^k + (1/n) sum_{i=1}^n Delta_hat_i^k, update h^{k+1} = h^k + alpha * (1/n) sum_{i=1}^n Delta_hat_i^k, and take a momentum/proximal step x^{k+1} = prox_{gamma R}(x^k - gamma * v^k), enabling each h_i^k to converge to the local optimum gradient nabla f_i(x^*) so quantization variance vanishes at the optimum even under arbitrary inter-worker heterogeneity and nonsmooth regularization R != 0.
Identity Notes & Concept Scope Distinct from QSGD (AIMech:QsgdCommunicationEfficientStochasticGradientQuantization, which quantizes raw gradients g_i^k directly without memory shifts h_i^k and therefore suffers non-vanishing quantization variance at x^* whenever nabla f_i(x^*) != 0, recovered as the special case alpha = 0, h_i^0 = 0, p = 2 of DIANA), from EF21 (AIMech:Ef21MarkovCompressorErrorFeedbackForHeterogeneousNonconvexOptimization, which uses biased contractive compressors on deterministic gradients with error state g_i^{t+1} = g_i^t + C(nabla f_i(x^{t+1}) - g_i^t) rather than unbiased l_p quantization with damping step size alpha <= alpha_p and proximal composite support R(x)), and from Sparsified SGD with Error Memory (AIMech:SparsifiedSgdWithErrorMemoryForKContractiveGradientCompression). No pinned AIO class covers DIANA or compressed gradient-difference shift learning.

Claims & Grounded Evidence

4 Claims
Mechanism #r389-block-lp-quantization-contraction-and-unbiased-estimator
Lemmas 4.1, 4.2, and 4.3 prove that the random l_p quantizer Quant_p on a block of size d is unbiased and satisfies E||Quant_p(x) - x||_2^2 <= (1/alpha_p(d) - 1)||x||_2^2 with exact contraction factor alpha_p(d) = inf_{x!=0} ||x||_2^2 / (||x||_1 ||x||_p) given in closed form by alpha_1(d) = 1/d, alpha_2(d) = 1/sqrt(d), and alpha_inf(d) = 2/(1 + sqrt(d)), yielding expected variance E_Q||g_hat^k - g^k||_2^2 <= ((1 - alpha_p) / (n^2 * alpha_p)) sum_{i=1}^n ||g_i^k - h_i^k||_2^2.
  • supports Source: Distributed Learning with Compressed Gradient Differences · Locator: Section 3 Definition 3.1-3.2 and Section 4 Lemmas 4.1, 4.2, and 4.3, pp. 4-7, 15-17
Mechanism #r389-lyapunov-linear-convergence-and-shift-learning
For L-smooth mu-strongly convex functions f_i with proper closed convex regularizer R(x), Theorem 4.4 and Corollary 4.5 prove that the Lyapunov potential V^k = ||x^k - x^*||_2^2 + (c * gamma^2 / n) sum_{i=1}^n ||h_i^k - nabla f_i(x^*)||_2^2 contracts linearly as E[V^k] <= (1 - gamma * mu)^k V^0 + (gamma / mu)(1 + n * c * alpha)(sigma^2 / n), so in the noiseless regime (sigma = 0) both x^k -> x^* and h_i^k -> nabla f_i(x^*) converge geometrically in O(max{1/alpha_p, kappa*(1 + 1/(n * alpha_p))} log(1/eps)) iterations.
  • supports Source: Distributed Learning with Compressed Gradient Differences · Locator: Section 4 Theorem 4.4, Corollary 4.5, and Table 2, pp. 7-9
Limitation #r389-unbiased-compressor-and-stochastic-noise-floor-limitation
Requires an unbiased compression operator (E[Quant_p(Delta)] = Delta) and each worker i to store a d-dimensional shift vector h_i^k; when local gradients have non-zero stochastic variance sigma^2 > 0, constant step size gamma leaves an O(gamma * (1 + 1/alpha_p) * sigma^2 / (mu * n)) neighborhood unless decreasing step sizes (Theorem 4.8) or local variance reduction are used.
  • supports Source: Distributed Learning with Compressed Gradient Differences · Locator: Section 4 Theorem 4.4 & Section 4.1 Theorem 4.8 (Decreasing stepsizes), pp. 7-9
Application #r389-composite-l1-logistic-regression-and-resnet-application
Applied to distributed L1/L2-regularized logistic regression on LIBSVM datasets (mushrooms, a5a, w8a) and distributed momentum training of ResNet-18 on CIFAR-10 and AlexNet on ImageNet with block ternary (p = infinity) and 1-bit L2 (p = 2) gradient difference quantization.
  • supports Source: Distributed Learning with Compressed Gradient Differences · Locator: Section 6 Experiments, Figures 1-4, pp. 10-12

⚠️ Curated Limitations & Negative Results

  • Requires an unbiased quantization operator (E[Quant_p(Delta)] = Delta) with damping factor alpha <= alpha_p(d).
  • Each worker must store a local d-dimensional gradient shift vector h_i^k across iterations.
