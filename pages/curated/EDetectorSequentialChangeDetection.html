E-detector nonparametric sequential change detection

Mathematical Methods AIMech:EDetectorSequentialChangeDetection DRAFT
Aliases: E-Detector, P-e-detector, Shiryaev-Roberts E-Detector (e-SR), CUSUM E-Detector (e-CUSUM), Adaptive Mixture E-Detector
A nonparametric, nonasymptotic sequential changepoint detection framework (Shin, Ramdas, & Rinaldo 2024) defined with respect to a composite pre-change class of distributions P over possibly dependent, non-stationary data streams by any nonnegative adapted process M = {M_n}_{n>=0} satisfying E_{P,infinity}[M_tau] <= E_{P,infinity}[tau] for all P in P and all stopping times tau (Definition 2.2), constructed by summing (Shiryaev-Roberts e-detector M_n^SR = sum_{j=1}^n Lambda_n^(j)) or maximizing (CUSUM e-detector M_n^CU = max_{1<=j<=n} Lambda_n^(j)) sequential e_j-processes Lambda^(j) started at consecutive candidate changepoints j >= 1 (Definitions 2.5–2.6), so that declaring a changepoint at N^* = inf{n >= 1 : M_n >= 1/alpha} provably controls the nonasymptotic Average Run Length (ARL) at E_{P,infinity}[N^*] >= 1/alpha for any alpha in (0, 1) without i.i.d. or parametric likelihood assumptions (Theorem 2.4).

Mechanism #nonasymptotic-arl-control-and-baseline-increment-recursions-for-esr-and-ecusum
For any sequence of e_j-processes {Lambda^(j)}_{j>=1} satisfying E_{P,infinity}[Lambda_tau^(j) | F_{j-1}] <= 1 on {tau >= j}, the Shiryaev-Roberts e-detector M_n^SR = sum_{j=1}^n Lambda_n^(j) and CUSUM e-detector M_n^CU = max_{1<=j<=n} Lambda_n^(j) satisfy 0 <= M_n^CU <= M_n^SR and E_{P,infinity}[M_tau] <= E_{P,infinity}[tau] for every stopping time tau and every P in P (Definitions 2.2, 2.5, 2.6), so the stopping rule N^* = inf{n >= 1 : M_n >= 1/alpha} guarantees nonasymptotic Average Run Length (ARL) E_{P,infinity}[N^*] >= 1/alpha without i.i.d. or stationarity assumptions (Theorem 2.4); when each Lambda_n^(j) = prod_{i=j}^n L_i is formed from a common baseline increment L_n satisfying E_{P,infinity}[L_n | F_{n-1}] <= 1 (Definitions 2.8–2.9), M_n^SR = (M_{n-1}^SR + 1) L_n and M_n^CU = max(M_{n-1}^CU, 1) L_n admit O(1)-time online updates (Definition 2.11), and under stationary post-change observations with E_{0,Q}[log L_1] > 0 their Lorden worst-case average delay satisfies J_L(N_SR^*) <= J_L(N_CU^*) <= log(1/alpha)/E_{0,Q}[log L_1] + E_{0,Q}[(log L_1)_+^2]/(E_{0,Q}[log L_1])^2 (Proposition 2.14).

Mechanism #finite-and-adaptive-infinite-mixtures-with-logarithmic-scheduling-complexity
Any probability mixture int M^a d mu(a) of e-detectors remains a valid e-detector (Proposition 2.3), and for countably infinite families of baseline increments {L_n(k)}_{k>=1} with weights sum_{k>=1} omega_k = 1, introducing a nondecreasing scheduling function K: N -> N with generalized inverse K^(-1)(k) = inf{j >= 1 : K(j) >= k} and adaptive renormalization factor gamma_j = 1 / sum_{k=1}^{K(j)} omega_k >= 1 defines the adaptive SR and CUSUM e-detectors M_n^aSR = sum_{k=1}^{K(n)} omega_k M_n^aSR(k) and M_n^aCU = sum_{k=1}^{K(n)} omega_k M_n^aCU(k) via the O(K(n))-time recursions M_n^aSR(k) = (M_{n-1}^aSR(k) + gamma_n) L_n(k) and M_n^aCU(k) = max(M_{n-1}^aCU(k), gamma_n) L_n(k) for n >= K^(-1)(k) (Equations 29–32), which preserve E_{P,infinity}[M_tau^aSR] <= sum_{j=1}^tau gamma_j sum_{k=1}^{K(j)} omega_k = E_{P,infinity}[tau] (Proposition 3.3) and satisfy worst-case delay bounds min_{j>=1}[E_{0,Q} N_{1/alpha}(j) + m + j - 1] with O(m log_eta n) per-step time and memory when K(n) = K_L + floor(m log_eta n) (Theorem 3.4, Equation 61).

Mechanism #exponential-baseline-convex-conjugate-divergence-and-minimax-rate-optimal-delay
For exponential baseline increments L_n^(lambda) = exp(lambda s(X_n) - psi(lambda) v(X_n)) with strictly convex cumulant-like function psi on Pi subset R (Definition 4.1), the oracle drift under post-change distribution Q with mu = E_{0,Q}[s(X_1)], sigma^2 = E_{0,Q}[v(X_1)], and Delta^op = mu/sigma^2 equals D(Q || P) = max_{lambda in Pi} E_{0,Q}[log L_1^(lambda)] = sigma^2 psi^*(Delta^op) at lambda^op = grad psi^*(Delta^op) where psi^* is the convex conjugate of psi (Proposition 4.2); geometric Chernoff-tangent grid mixtures over known bounds Delta_L < Delta^op < Delta_U (Algorithms 1 & 3) or time-varying poly-stitching boundaries without minimum separation (Algorithm 2, Lemma 4.5, Corollary 4.6) control ARL at >= 1/alpha while bounding Lorden and Pollak worst-case delays by g_alpha / D(Q || P) + E_{0,Q}[(log L_1^(lambda^op))_+^2] / D(Q || P)^2 + 1 = O(log(1/alpha) / D(Q || P)) as alpha -> 0 (Theorem 4.3, Proposition B.2), matching the minimax lower-bound rate O(log(1/alpha)/KL(Q || P)) in exponential families.

Application #nonparametric-bounded-mean-betting-increments-and-generalized-lorden-reduction
For bounded observations X_n in [0, 1] with time-varying dependent pre-change conditional means E_{P,infinity}[X_n | F_{n-1}] <= m, the variational KL_inf representation yields the betting baseline increment L_n^lambda = 1 + lambda(X_n/m - 1) for lambda in (0, 1) (Section 5.2 Eq. 70), which is pointwise lower bounded by the sub-exponential baseline increment L_tilde_n^lambda = exp(lambda(X_n/m - 1) - psi_E(lambda)(X_n/m - 1)^2) with psi_E(lambda) = -log(1 - lambda) - lambda and psi_E^*(u) = u - log(1 + u) (Equations 72–76); furthermore, Lorden's (1971) reduction of change detection to sequential tests {phi^(j)}_{j>=1} is recovered as the special e-detector Lambda_t^Lorden = phi_t / alpha without requiring i.i.d. data or identical tests (Section 6.2, Lemma 6.1), whereas e-SR additively pools evidence across consecutive start times j so that M_n^SR >= M_n^CU deterministically and N_SR^* <= N_CU^* at threshold 1/alpha.

⚠️ Curated Limitations & Negative Results

  • Using the universal threshold c_alpha = 1/alpha for e-CUSUM can be highly conservative compared to e-SR (under trivial e-processes Lambda_n^(j) = 1, M_n^SR = n reaches 1/alpha at ceil(1/alpha) whereas M_n^CU = 1 never stops for alpha < 1), and computing a tighter non-universal threshold c_alpha < 1/alpha requires known parametric pre-change distributions or historical simulation data that are unavailable in general non-stationary composite settings (Section 2.5 and Remark 2.13).
  • Replacing a probability mixture of baseline e-detectors int M_n(lambda) d W(lambda) by an unpenalized supremum sup_{lambda in [lambda_L, lambda_U]} M_n(lambda) violates the e-detector optional-stopping inequality E_{P,infinity}[M_tau] <= E_{P,infinity}[tau] and fails ARL control (Remark 3.1), while no-separation adaptive infinite mixtures (Algorithm 2) require O(m log_eta n) active baseline processes at time n rather than O(1) memory (Section 4.2).
  • General e-detectors built from non-supermartingale e_j-processes (such as universal inference split/running-MLE e-processes for log-concavity) that do not factor through a common 1-step baseline increment L_n require O(n) updates at step n, and directional nonparametric tests (e.g., homogeneity -> non-homogeneity, independence -> dependence, or log-concavity -> non-log-concavity) cannot simply swap P and Q because the reverse composite null admits no nontrivial test supermartingale (Remark 2.10, Section 2.6 Examples 3–6, and Section 6.3).
  • All 1,104 lines of Shin, Ramdas, & Rinaldo (2024, arXiv:2203.03532) were read.
