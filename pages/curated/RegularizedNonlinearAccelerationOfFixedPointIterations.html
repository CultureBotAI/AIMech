Regularized Nonlinear Acceleration of Fixed-Point Iterations

Algorithms AIMech:RegularizedNonlinearAccelerationOfFixedPointIterations DRAFT
Aliases: Scieur-d'Aspremont-Bach Regularized Nonlinear Acceleration (RNA), Tikhonov-Regularized Minimal Polynomial Extrapolation (Regularized MPE / Anderson Acceleration), Black-Box Krylov Sequence Extrapolation for Optimization
Regularized Nonlinear Acceleration of Fixed-Point Iterations (RNA) is a black-box sequence extrapolation algorithm introduced by Scieur, d'Aspremont, and Bach (2016, 2020) that accelerates any fixed-point iteration x_{i+1} = g(x_i) (such as gradient descent g(x) = x - (1/L) grad f(x)) by forming a linear combination sum_{i=0}^k c_i x_i of k + 1 past iterates with sum_{i=0}^k c_i = 1. Given the residual matrix R = [r_0, ..., r_k] in R^{d x (k+1)} with columns r_i = x_{i+1} - x_i = g(x_i) - x_i, Algorithm 2 solves the Tikhonov-regularized constrained least-squares problem c_lambda^* = argmin_{c^T 1 = 1} (||R c||_2^2 + lambda ||c||_2^2) in closed form via c_lambda^* = (R^T R + lambda I)^{-1} 1 / (1^T (R^T R + lambda I)^{-1} 1) (requiring only an O((k+1)^3 + d(k+1)^2) linear system of small window size k << d). On noiseless linear fixed-point iterations x_{i+1} - x^* = G(x_i - x^*) with symmetric Jacobian G (0 <= G <= sigma I, sigma = 1 - mu/L), Proposition 2.1 and Proposition 2.3 prove that unregularized extrapolation (lambda = 0) reduces to a shifted Chebyshev polynomial in G achieving the optimal Nesterov/Chebyshev rate ||sum_{i=0}^k c_i^* x_i - x^*||_2 <= (1 / (1 - sigma)) * (2 beta^k / (1 + beta^{2k})) ||x_0 - x^*||_2 with beta = (1 - sqrt(1 - sigma)) / (1 + sqrt(1 - sigma)) and reaches exact convergence in k = deg(G) steps by Cayley-Hamilton. Under nonlinear/stochastic perturbations, Proposition 3.2 and Theorem 3.4 prove that Tikhonov regularization lambda > 0 prevents Krylov matrix ill-conditioning by bounding ||c_lambda^*||_2 <= sqrt((lambda + ||tilde{R}||_2^2) / (4 lambda)) and ||c_lambda^* - c_{lambda,clean}^*||_2 <= (||P||_2 / lambda)||c_{lambda,clean}^*||_2, yielding an optimal bias-variance tradeoff at lambda = O(||P||_2).
Identity Notes & Concept Scope Distinct from Catalyst Universal Acceleration for First-Order Optimization (`AIMech:CatalystUniversalAccelerationForFirstOrderOptimization`), which modifies the optimization problem inside the loop by adding quadratic proximal terms (kappa/2)||x - y_{k-1}||^2, whereas RNA leaves the inner algorithm's iterate trajectory {x_0, ..., x_{k+1}} completely untouched and extrapolates it post-hoc via regularized residual Gram matrix inversion. Also distinct from Classical Anderson Acceleration / Minimal Polynomial Extrapolation (lambda = 0), which becomes catastrophically unstable under nonlinear perturbations due to exponential condition-number growth of the Krylov matrix R^T R (Section 3.1).

Mechanism #claim-01
For a linear fixed-point iteration x_{i+1} - x^* = G(x_i - x^*) with symmetric matrix 0 <= G <= sigma I (sigma < 1), the unregularized extrapolation residual norm satisfies min_{c^T 1 = 1} ||R c||_2 = min_{p in P_k, p(1)=1} ||p(G) r_0||_2 <= (2 beta^k / (1 + beta^{2k})) ||r_0||_2 where beta = (1 - sqrt(1 - sigma)) / (1 + sqrt(1 - sigma)) via Chebyshev polynomials (Proposition 2.3 and Equation 40), and achieves exact zero error ||sum_{i=0}^k c_i^* x_i - x^*||_2 = 0 as soon as k equals the degree m <= d of the minimal polynomial of G by the Cayley-Hamilton theorem (Proposition 2.1).

Mechanism #claim-02
Under perturbed residuals tilde{R} with Gram perturbation P = tilde{R}^T tilde{R} - R^T R, the regularized weight vector c_lambda^* = (tilde{R}^T tilde{R} + lambda I)^{-1} 1 / (1^T (tilde{R}^T tilde{R} + lambda I)^{-1} 1) satisfies the exact KKT perturbation identity Delta c_lambda^* = -(I - (G_pert^{-1} 1 1^T)/(1^T G_pert^{-1} 1)) G_pert^{-1} P c_{lambda,clean}^* (Equation 23), the norm bound ||c_lambda^*||_2 <= sqrt((lambda + ||tilde{R}||_2^2)/(4 lambda)) (Equation 20), and the sensitivity bound ||Delta c_lambda^*||_2 <= (||P||_2 / lambda)||c_{lambda,clean}^*||_2 (Equation 21), while Proposition A.1 gives the exact worst-case Chebyshev-Tikhonov tradeoff max_{x in [0, sqrt(a/lambda)]}(kappa sqrt(a - lambda x^2) + b x) = sqrt(a) sqrt(kappa^2 + b^2 / lambda).
  • supports Source: Regularized Nonlinear Acceleration · Locator: Section 3.2, Proposition 3.2 (Equations 19-23), pp. 9-10; Appendix A.1, Proposition A.1 (Equation 41), p. 28
  • supports Source: Regularized Nonlinear Acceleration (Crossref metadata) · Locator: Mathematical Programming 179:47-83 (2020): Stability and convergence analysis of regularized nonlinear acceleration
Limitation #claim-03
Without Tikhonov regularization (lambda -> 0), the Krylov residual matrix R^T R becomes exponentially ill-conditioned (or strictly singular once k >= m), causing unregularized MPE/Anderson weights c^* to explode in Euclidean norm (||c^*||_2 >> 1) and amplify small nonlinear or numerical perturbations.
  • supports Source: Regularized Nonlinear Acceleration · Locator: Section 3.1, Instability of Polynomial Extrapolation (Krylov/Hankel conditioning and Figure 1), p. 8

⚠️ Curated Limitations & Negative Results

  • Requires storing k + 1 past d-dimensional iterates in memory (O(d k) storage) and achieves asymptotic optimality only within a local basin where the nonlinear mapping g(x) is well-approximated by its Jacobian G = grad g(x^*).
