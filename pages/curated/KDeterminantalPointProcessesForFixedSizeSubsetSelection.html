k-Determinantal Point Processes for Fixed-Size Subset Selection

Mathematical Methods AIMech:KDeterminantalPointProcessesForFixedSizeSubsetSelection DRAFT
Aliases: k-DPP (Fixed-Size Determinantal Point Process), Kulesza-Taskar Cardinality-Conditioned Determinantal Point Process, Elementary Symmetric Polynomial k-DPP Exact Sampler
k-Determinantal Point Processes for Fixed-Size Subset Selection (k-DPPs) is a probabilistic diverse subset selection model and exact polynomial-time inference framework introduced by Kulesza and Taskar (2011) that conditions a standard L-ensemble Determinantal Point Process on the event that the selected subset Y subseteq {1, ..., N} has exact fixed cardinality |Y| = k. Given an N x N positive semidefinite similarity and quality kernel L = sum_{n=1}^N lambda_n v_n v_n^T, a k-DPP assigns probability P_L^k(Y) = det(L_Y) / e_k(lambda_1, ..., lambda_N) to every k-subset Y (Equation 5 & Proposition 3.1, Equation 10), where the normalization constant sum_{|Y'|=k} det(L_{Y'}) equals the k-th elementary symmetric polynomial e_k(lambda_1, ..., lambda_N) = sum_{|J|=k} prod_{n in J} lambda_n of the eigenvalues of L. Algorithm 2 computes all intermediate polynomials e_l^n = e_l(lambda_1, ..., lambda_n) in O(N k) time via the Newton-Pascal recurrence e_l^n = e_l^{n-1} + lambda_n e_{l-1}^{n-1} (Equation 12), and Algorithm 1 decomposes P_L^k into a mixture of rank-k elementary projection DPPs (Equation 8), first sampling an eigenvector index subset J of size k in O(N k) time with sequential marginal probabilities lambda_n e_{l-1}^{n-1} / e_l^n and then sampling k items Y from the projection DPP spanned by {v_n}_{n in J} in O(N k^2) time via iterative Gram-Schmidt orthogonal projection.
Identity Notes & Concept Scope Distinct from Volume Sampling for Matrix Approximation and Projective Clustering (`AIMech:VolumeSamplingForMatrixApproximationAndProjectiveClustering`), which analyzes the multiplicative (k+1)! ||A - A_k||_F^2 row-span projection error of simplex-volume sampling for low-rank matrix approximation and projective clustering rather than conditional L-ensemble inference, quality-diversity decompositions L_{ij} = q_i phi_i^T phi_j q_j, and the elementary symmetric polynomial DP sampler of Kulesza and Taskar (2011). Also distinct from standard unconditioned DPPs, which cannot enforce a hard cardinality budget |Y| = k.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
For any N x N positive semidefinite L-ensemble kernel L = sum_{n=1}^N lambda_n v_n v_n^T, Proposition 3.1 (Equations 8-10) proves that the k-DPP distribution P_L^k(Y) = det(L_Y) / sum_{|Y'|=k} det(L_{Y'}) decomposes as the mixture of rank-k elementary projection DPPs P_L^k(Y) = (1 / e_k(lambda_1, ..., lambda_N)) sum_{|J|=k} (prod_{n in J} lambda_n) P^{V_J}(Y), where the partition function sum_{|Y|=k} det(L_Y) = e_k(lambda_1, ..., lambda_N) is computed exactly in O(N k) operations via the recurrence e_l^n = e_l^{n-1} + lambda_n e_{l-1}^{n-1} with base cases e_0^n = 1 and e_l^0 = 0 for l > 0 (Algorithm 2, Equation 12).

Scope #claim-02
Given the eigendecomposition of L (or of the dual Gram matrix B^T B when L = B B^T with B in R^{D x N} and D << N), Algorithm 1 draws an exact sample Y ~ P_L^k in O(N k^2) time by first backward-sampling an index subset J subseteq {1, ..., N} of size |J| = k using the conditional inclusion probabilities Pr(n in J | l remaining) = lambda_n e_{l-1}^{n-1} / e_l^n in O(N k) time, and then sequentially selecting k items from the elementary projection DPP P^{V_J} with probabilities (1/|V|) sum_{v in V} (v^T e_i)^2 followed by orthogonal projection of V onto the subspace perpendicular to e_i.

  • supports Source: k-DPPs: Fixed-Size Determinantal Point Processes (Crossref metadata) · Locator: Foundations and Trends in Machine Learning 5(2-3):123-286 bibliographic record
Limitation #claim-03
Exact k-DPP normalization and sampling require full eigendecomposition of the N x N kernel L (costing O(N^3) time, or O(N D^2) when a rank-D feature factorization L = B B^T is available and k <= D), and unlike standard unconditioned DPPs whose marginal kernels K = L(L+I)^{-1} have closed-form subset marginals det(K_A), k-DPPs are scale-invariant (P_{alpha L}^k = P_L^k) and do not admit a single PSD marginal kernel K representing all higher-order inclusion probabilities.
  • supports Source: k-DPPs: Fixed-Size Determinantal Point Processes · Locator: Section 3.2-3.4, Comparison with scaled standard DPPs (Equation 11) and eigendecomposition complexity O(N D^2), pp. 1195-1197

⚠️ Curated Limitations & Negative Results

  • Requires O(N^3) eigendecomposition of the kernel L (or O(N D^2) via dual Gram matrix when L = B B^T has rank D >= k), and returns zero probability for all k > rank(L).
