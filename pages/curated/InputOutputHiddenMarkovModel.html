Input-output hidden Markov model

Model Families AIMech:InputOutputHiddenMarkovModel DRAFT
Aliases: IOHMM, Input-output HMM
A conditional latent sequence-model family whose discrete hidden-state transitions and state-specific observation distributions depend on the current external input.
Identity Notes & Concept Scope The inspected Bengio–Frasconi model maps an input sequence to an output-sequence distribution using a latent Markov state. Its original modular neural implementation supplies input-sensitive transition and output subnetworks, but the model family is identified by the conditional factorization. It differs from a standard autonomous HMM, a factorial multi-chain model, an undirected product of HMMs, a generic recurrent network and an arithmetic mixture without state dynamics. The input sequence is conditioned on rather than assigned its own generative model. Claims & Grounded Evidence

1 Claim
Mechanism #method
Given inputs u_1:T and an initial state distribution, sum over paths in p(s_0) times product_t p(s_t|s_(t-1),u_t) p(y_t|s_t,u_t) to obtain p(y_1:T|u_1:T). The original architecture uses one static transition subnetwork per previous state, with a softmax over allowed successors, and one output subnetwork per current state. Recursively propagating zeta_t(i)=sum_j p(s_t=i|s_(t-1)=j,u_t) zeta_(t-1)(j) gives the state distribution conditional on inputs alone; it is distinct from the posterior after conditioning on observed target outputs. Forward–backward with the observed output factors supplies state and transition posterior responsibilities for conditional-likelihood EM. The expected complete-data log likelihood separates into responsibility-weighted log transition and log emission terms. Neural parameterizations can use generalized EM updates that increase that expected objective. Intermittently missing outputs can be marginalized by replacing their normalized emission factors by one while preserving the latent chain.

⚠️ Curated Limitations & Negative Results

  • Input-conditioned transitions can vary with time even with fixed parameters. Removing input dependence recovers an ordinary HMM special case; no claim is made that an arbitrary recurrent network has this normalized latent-state model.
  • The recurrent probability vector is a distribution over states, not a single sampled state path. Output-conditioned filtering or smoothing must include observed output likelihoods; the input-only recurrence is insufficient for that posterior.
  • The paper’s backward variable includes the current emission, unlike a common future-only convention. Its pair-posterior Equation (11) must be interpreted with that convention to avoid counting the emission twice.
  • The special lookup-table re-estimation display in Equation (12) omits an old transition factor needed by the posterior-count expression in Equation (11). This record uses posterior-weighted EM/GEM semantics and does not certify that display as a general update formula.
  • GEM inherits conditional-likelihood monotonicity when its expected objective is increased with an exact E-step; an arbitrary gradient step, global optimum or unconditional convergence to a local maximum is not guaranteed. Local optima and large state spaces are practical limitations acknowledged by the source.
  • The grammar experiment reports accuracy conditional on successful training runs and selects model size using validation strings. No universal long-memory advantage, benchmark ranking, 1996 full-text claim or author-code behavior is curated.
