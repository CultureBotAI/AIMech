Conformer-Kernel with Query Term Independence for Document Retrieval

Architectures AIMech:ConformerKernelWithQueryTermIndependenceForDocumentRetrieval DRAFT
Aliases: Conformer-Kernel with Query Term Independence, Conformer-Kernel, CK with QTI, Conformer-Kernel Document Retrieval Architecture
An efficient neural document retrieval and ranking architecture (Mitra, Hofstätter, Zamani, & Craswell, 2020) that modifies the Transformer-Kernel (TK) model along three axes: (1) replacing quadratic O(|d|^2) self-attention with linear-complexity separable self-attention Out = Phi(Q)*(Phi(K^T)*V) to process documents thousands of tokens long without sliding windows, (2) combining windowed convolutional layers and separable self-attention in a hybrid Conformer layer, and (3) enforcing a Query Term Independence (QTI) assumption by encoding query terms solely with context-free embeddings while combining an implicit Conformer-Kernel soft-match score and an explicit batch-scaled BM25-like lexical sub-model so that per-(term, document) impact scores can be pre-computed offline and stored in a standard inverted index for full-collection retrieval.
Identity Notes & Concept Scope Distinct from TK (AIMech:TKTransformerKernelRankingModel, which contextualizes both query and document with quadratic self-attention) and TKL (AIMech:TKLTransformerKernelForLongDocuments, which applies TK over overlapping sliding windows of long documents). Conformer-Kernel replaces quadratic self-attention with separable self-attention (Equations 5-6) inside a parallel Convolution+Transformer (Conformer) block and optionally enforces Query Term Independence (CK with QTI) by combining a learned explicit batch-scaled BM25 sub-model s_{t,d}^{(explicit)} (Equations 9-10) with an implicit Conformer-Kernel sub-model s_{t,d}^{(implicit)} (Equations 11-16) whose non-negative combined scores s_{t,d} = ReLU(alpha * s_{t,d}^{(explicit)} + (1 - alpha) * s_{t,d}^{(implicit)} + b_comb) can be pre-computed offline for top-k vocabulary terms per document.

4 Claims
Mechanism #conformer-kernel-separable-self-attention-and-hybrid-layer
To scale document contextualization to thousands of tokens without quadratic O(n^2) intermediate attention matrices, Conformer-Kernel factorizes self-attention into separable self-attention A = Phi(K^T) V in R^{d_key x d_val} and Out = Phi(Q) A in R^{n x d_val} (Equations 5-6, where Phi(.) is row-wise softmax) with O(n * d_key) intermediate memory, and combines a windowed 1D convolution layer and separable Transformer layer in parallel inside a Conformer block (Figure 1c).
  • supports Source: Conformer-Kernel with Query Term Independence for Document Retrieval · Locator: Section 3.2 (Separable Self-Attention) & Section 3.3 (Conformer Layer), pp. 3-4, Figure 1, Equations (5)-(6)
  • supports Source: Conformer-Kernel with Query Term Independence for Document Retrieval · Locator: separable_self_attention verification
Mechanism #conformer-kernel-query-term-independence-and-explicit-implicit-scoring
Under Query Term Independence (QTI), Conformer-Kernel leaves query terms context-free and decomposes document scoring into S_{q,d} = sum_{t in q} s_{t,d}, where s_{t,d} = ReLU(alpha * s_{t,d}^{(explicit)} + (1 - alpha) * s_{t,d}^{(implicit)} + b_comb) combines a learned explicit BM25-like sub-model s_{t,d}^{(explicit)} = IDF_t * BS(TF_{t,d}) / (BS(TF_{t,d}) + ReLU(w_dlen * BS(|d|) + b_dlen) + eps) using batch scaling BS(x) = x / (E[x] + eps) (Equations 9-10) with a length-normalized Conformer-Kernel RBF soft-match sub-model s_{t,d}^{(implicit)} (Equations 11-16), allowing all s_{t,d} values to be pre-computed offline and indexed for retrieval.
  • supports Source: Conformer-Kernel with Query Term Independence for Document Retrieval · Locator: Section 3.4 (Enforcing Query Term Independence), pp. 4-6, Figure 2, Equations (7)-(16)
  • supports Source: Conformer-Kernel with Query Term Independence for Document Retrieval · Locator: explicit_bm25_submodel and batch_scale verification
Application #conformer-kernel-trec-dl-empirical-performance
On the TREC 2019 Deep Learning Track document ranking task (with documents up to |d| = 2000 tokens), Conformer-Kernel achieves 0.680 NDCG@10 and 0.371 MRR (and 0.629 NDCG@10 under QTI) compared to 0.525 NDCG@10 for BM25, while reducing training memory from 10.61 GB (TK at |d|=2000, batch size 8) to 0.83 GB at batch size 32.
  • supports Source: Conformer-Kernel with Query Term Independence for Document Retrieval · Locator: Section 5 (Results), pp. 7-8, Tables 2-3
Limitation #conformer-kernel-qti-query-context-tradeoff
Enforcing Query Term Independence (QTI) removes cross-term query contextualization, reducing NDCG@10 on the TREC DL 2019 test set from 0.680 (full Conformer-Kernel) to 0.629 (CK with QTI), and full-collection inverted-index retrieval requires sparsifying offline document scores to top-k vocabulary terms per document to bound index size.
  • supports Source: Conformer-Kernel with Query Term Independence for Document Retrieval · Locator: Section 3.4 (Figure 2c) & Section 5 (Table 2 & Discussion), pp. 5-8

⚠️ Curated Limitations & Negative Results

  • Enforcing Query Term Independence sacrifices cross-term query contextualization (reducing TREC DL 2019 NDCG@10 from 0.680 to 0.629) and requires top-k vocabulary sparsification to keep offline inverted index sizes tractable.
