Iterative Hessian Sketch for Constrained Least-Squares and Information-Theoretic Classical Sketching Lower Bounds

Mathematical Methods AIMech:IterativeHessianSketchForConstrainedLeastSquares DRAFT
Aliases: Iterative Hessian Sketch (IHS, Pilanci & Wainwright 2016), Hessian Sketch for Constrained Least-Squares, Tangent-Cone Gaussian-Width Sketched Least-Squares Iteration, Fano Information-Theoretic Classical Sketching Lower Bound
Iterative Hessian Sketch for Constrained Least-Squares and Information-Theoretic Classical Sketching Lower Bounds is a randomized sketching and statistical optimization methodology introduced by Pilanci and Wainwright (2016, Journal of Machine Learning Research 17(53):1-38, arXiv:1411.0347v1) for solving large-scale convex-constrained least-squares problems x^{LS} := argmin_{x in C} (1/2) ||A x - y||_2^2 with data matrix A in R^{n x d}, response y in R^n, and convex constraint set C subseteq R^d. First, under noisy observations y = A x^* + w with w ~ N(0, sigma^2 I_n) and any sketching matrix S in R^{m x n} satisfying ||E[S^T (S S^T)^{-1} S]||_op <= eta (m/n) (with eta = 1 for Gaussian and randomized orthonormal system sketches and eta = alpha for alpha-balanced row sampling), Theorem 1 proves via Fano's inequality that any estimator (S A, S y) |-> x^dagger constructed from classically sketched data suffers worst-case prediction risk sup_{x^* in C_0} E[||x^dagger - x^*||_A^2] >= (sigma^2 / (128 eta)) * log(M_{1/2} / 2) / min{m, n} (where ||u||_A^2 := (1/n)||A u||_2^2 and M_{1/2} is the 1/2-packing cardinality of A(C_0) cap B_2(delta sqrt(n))), showing that one-shot classical sketching requires m asymp n to match the statistical rate of x^{LS}. Second, to eliminate this statistical sub-optimality without forming A^T A, the Iterative Hessian Sketch (IHS) sketches only the quadratic Hessian term while retaining exact residual inner products with y: starting from x^0 = 0, iteration t + 1 draws an independent isotropic sketch matrix S^{t+1} in R^{m x n} with E[(S^{t+1})^T S^{t+1} / m] = I_n and updates x^{t+1} = argmin_{x in C} { (1/(2m)) ||S^{t+1} A (x - x^t)||_2^2 - <A^T (y - A x^t), x> } (Equation 24). Over the transformed tangent cone K^{LS} := {t A(x - x^{LS}) : t >= 0, x in C}, Theorem 2 proves the deterministic contraction ||x^N - x^{LS}||_A <= (prod_{t=1}^N Z_2(S^t) / Z_1(S^t)) ||x^{LS}||_A and shows that sketch dimension m >= (c_0 / rho^2) W^2(K^{LS}) (scaling with the squared Gaussian width of K^{LS}, such as O(d), O(s log(ed/s)) for s-sparse l_1 balls, or O(r(d_1 + d_2)) for rank-r nuclear-norm balls) yields geometric convergence ||x^N - x^{LS}||_A <= rho^N ||x^{LS}||_A in N = O(log n) rounds.

Mechanism #fano-information-theoretic-lower-bound-for-classical-sketching
Consider the noisy linear model y = A x^* + w with w ~ N(0, sigma^2 I_n) and x^* in C_0 subseteq C, where accuracy is measured in the normalized prediction semi-norm ||x - x^*||_A^2 := (1/n) ||A(x - x^*)||_2^2 (Equations 3 and 7). For any random sketching matrix S in R^{m x n} independent of w whose projection expectation satisfies ||E[S^T (S S^T)^{-1} S]||_op <= eta (m/n) (Equation 9; satisfied with equality eta = 1 for Gaussian and Hadamard/Fourier ROS sketches because E[S^T (S S^T)^{-1} S] = (m/n) I_n, and with eta = alpha for alpha-balanced row-sampling sketches, Appendix A.1), Lemma 2 (Appendix A.2, p. 24) bounds the conditional Kullback-Leibler divergence between P_{x^j} and P_{x^k} given S by E_S[D(P_{x^j} || P_{x^k} | S)] <= (n eta m / (2 sigma^2 min{m, n})) ||x^j - x^k||_A^2. Applying Fano's inequality over a delta/2-packing of A(C_0) cap B_2(delta sqrt(n)) of cardinality M_{1/2} >= 4, Theorem 1 (Equation 11a) proves that any estimator (S A, S y) |-> x^dagger satisfies sup_{x^* in C_0} E_{S,w}[||x^dagger - x^*||_A^2] >= (sigma^2 / (128 eta)) * log(M_{1/2} / 2) / min{m, n}. Consequently, any one-shot classical sketch incurs risk lower bounds c (sigma^2 / eta) min{d, n} / min{m, n} for unconstrained least squares (Example 1, Equation 12), c (sigma^2 / eta) s log(ed/s) / min{m, n} for s-sparse l_1-constrained regression (Example 2, Equation 14), and c (sigma^2 / eta) r(d_1 + d_2) / min{m, n} for rank-r nuclear-norm matrix regression (Example 3, Equation 15b), all multiplied by n/m relative to the minimax rate of x^{LS}.

Mechanism #hessian-sketch-tangent-cone-contraction-and-iterative-hessian-sketch
Let K^{LS} := {t A(x - x^{LS}) : t >= 0, x in C} cap R^n be the transformed tangent cone at the exact constrained least-squares solution x^{LS} (Equation 17), and define Z_1(S) := inf_{v in K^{LS} cap S^{n-1}} (1/m) ||S v||_2^2 and Z_2(S) := sup_{v in K^{LS} cap S^{n-1}} |<u, ((1/m) S^T S - I_n) v>| for any fixed unit vector u in S^{n-1} (Equations 18a-18b). Proposition 1 (p. 10, Equation 19) proves that the single-step Hessian sketch x_hat = argmin_{x in C} { (1/(2m)) ||S A x||_2^2 - <A^T y, x> } deterministically satisfies ||x_hat - x^{LS}||_A <= (Z_2(S) / Z_1(S)) ||x^{LS}||_A. In the Iterative Hessian Sketch (IHS, Equation 24), starting from x^0 = 0 and solving x^{t+1} = argmin_{x in C} { (1/(2m)) ||S^{t+1} A (x - x^t)||_2^2 - <A^T(y - A x^t), x> } with independent sketches S^1, ..., S^N, Appendix C (Equations 38-39) establishes the per-step contraction ||x^{t+1} - x^{LS}||_A <= (Z_2(S^{t+1}) / Z_1(S^{t+1})) ||x^t - x^{LS}||_A for u_t = A(x^{LS} - x^t) / ||A(x^{LS} - x^t)||_2, yielding Theorem 2 (Equations 26a-26b): ||x^N - x^{LS}||_A <= (prod_{t=1}^N Z_2(S^t) / Z_1(S^t)) ||x^{LS}||_A. By Lemma 1 (p. 11, Equations 22a-22b), for any rho in (0, 1/2), sketch size m >= (c_0 / rho^2) W^2(K^{LS}) for sub-Gaussian sketches (or m >= (c_0 / rho^2) log^4(n) W^2(K^{LS}) for ROS sketches over self-bounding cones) ensures Z_1(S^t) >= 1 - rho >= 1/2 and Z_2(S^t) <= rho/2, so ||x^N - x^{LS}||_A <= rho^N ||x^{LS}||_A with probability at least 1 - N c_1 e^{-c_2 m rho^2}.

Scope #minimax-localized-gaussian-width-statistical-optimality-and-applications
Under the noisy model y = A x^* + w with x^* in C and transformed truth tangent cone K^* := cl conv{t A(x - x^*) : t >= 0, x in C}, let varepsilon_n(K^*) := argmin_{eps >= 0} { sigma W(K^* cap B_2(eps sqrt(n))) <= n eps^2 / 8 } be the localized Gaussian width critical radius (Equation 27a). Proposition 2 (p. 15, Equation 27b) shows that E_w[||x^{LS} - x^*||_A^2] <= c_1 {varepsilon_n^2(K^*) + sigma^2 / n}. Combining Proposition 2 with Theorem 2 via triangle inequality (Appendix C, Equations 40-41b), Corollary 1 (p. 15, Equation 28) proves that running IHS for N >= ceil(log(c_0 ||x^{LS}||_A / varepsilon_n(K^*)) / log(1/rho)) iterations with m >= (c_0 / rho^2) W^2(K^{LS}) achieves E_w[||x^N - x^*||_A^2] <= c_1' {varepsilon_n^2(K^*) + sigma^2 / n} with probability at least 1 - N c_1 e^{-c_2 m rho^2} over the sketches. Specializing to concrete constraint sets in Section 3 yields minimax-optimal prediction error in N = O(log n) rounds with sketch dimension m = (c_0 / rho^2) min{n, d} for unconstrained OLS (Corollary 2, Total Flops O(N n d log m + d^3) with Fast Hadamard sketch vs. O(n d^2)), m = (c_0 / rho^2) (max_j ||a_j||_2^2 / (n gamma_s^-(A))) s log(ed/s) for l_1-constrained s-sparse regression (Corollary 3, Lemma 7, Equation 31), and m = (c_0 / rho^2) (|||A|||_op^2 / gamma_{2r}^-(A)) r(d_1 + d_2) for nuclear-norm constrained rank-r matrix estimation (Corollary 4, Equation 33).

⚠️ Curated Limitations & Negative Results

  • Multi-Pass Access to Matrix-Vector Products with A and A^T: Unlike single-pass classical sketching (S A, S y) which compresses the data in one pass at the expense of an O(n/m) variance inflation factor (Theorem 1), Iterative Hessian Sketch requires N = O(log n) rounds of computing exact residual gradients A^T(y - A x^t) and fresh sketch products S^{t+1} A (Section 2.4, Equation 24).
  • Dependence of Tangent-Cone Gaussian Width on Restricted Eigenvalue and Self-Bounding Cone Conditions: For l_1-constrained and nuclear-norm-constrained regression (Corollaries 3-4, Lemma 7), the O(s log(ed/s)) and O(r(d_1 + d_2)) sketch-size bounds require the tuning parameter R to be binding at the true parameter (||x^*||_1 = R or |||X^*|||_1 = R) and scale inversely with the s-sparse or 2r-rank restricted eigenvalue gamma_s^-(A); moreover, randomized orthonormal system (ROS) sketches require an extra log^4(n) factor and the self-bounding cone property (Lemma 1(b), Definition 1).
