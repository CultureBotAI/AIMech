FedHM: Efficient Federated Learning for Heterogeneous Models via Low-Rank Factorization

Algorithms AIMech:FedHmHeterogeneousFederatedLearningViaLowRankFactorization DRAFT
Aliases: FedHM, Federated Learning for Heterogeneous Models via Low-Rank Factorization, Hybrid Low-Rank Factorized Federated Learning
A model-heterogeneous federated learning framework (FedHM; Yao, Pan, O'Neill, Dai, Wan, Jin, and Sun, 2021) that compresses an L-layer global server network into client-specific [rho, L, gamma_p] hybrid low-rank networks w^{gamma_p} = {W_1, ..., W_rho, U_{rho+1}, V_{rho+1}^T, ..., U_L, V_L^T} by keeping the first rho layers unfactorized and decomposing each later layer l in {rho + 1, ..., L} via truncated SVD at rank r = gamma_p rank(W_l) (unrolling 4D convolution tensors of shape (m, n, k, k) into (m k, n k) matrices and reshaping the rank-r factors into sequential (m, r, k, 1) and (r, n, 1, k) filters with spectral initialization U_t^l sqrt(Sigma_{r,t}^l), V_t^l sqrt(Sigma_{r,t}^l)). Participating clients train their assigned hybrid models for E local epochs with Frobenius decay regularization (lambda / 2) ||U V^T||_F^2, after which the server recovers full-rank shapes via w_{p,t+1} = {W_1, ..., W_rho, U_{rho+1} V_{rho+1}^T, ..., U_L V_L^T} and aggregates them using softmax rank-ratio weights alpha_p = exp(gamma_p / tau) / sum_{q=1}^P exp(gamma_q / tau).
Identity Notes & Concept Scope Distinct from channel width-slimming heterogeneous FL methods such as HeteroFL (AIMech:HeteroFlWidthScaledSubnetworkAggregationForHeterogeneousFederatedLearning; Diao et al., ICLR 2021), FjORD (AIMech:FjordOrderedDropoutAndSelfDistillationForHeterogeneousFederatedLearning; Horvath et al., NeurIPS 2021), and FedRolex (AIMech:FedRolexModelHeterogeneousFederatedLearningWithRollingSubModelExtraction; Alam et al., NeurIPS 2022), which extract subset channels along width rather than factorizing layers via truncated SVD and recovering full matrices U V^T prior to aggregation. Distinct from FedPara (AIMech:FedParaAndPFedParaLowRankHadamardProductParameterization; Hyeon-Woo et al., ICLR 2022), which parameterizes homogeneous client layers via a Hadamard product of two low-rank matrices (W = (X_1 Y_1^T) odot (X_2 Y_2^T)) without server-side SVD redistributions across heterogeneous client ranks.

Claims & Grounded Evidence

4 Claims
Mechanism #fedhm-unrolled-conv-svd-and-shape-aligned-softmax-aggregation-mechanism
For each factorized layer l in {rho + 1, ..., L}, the server unrolls a 4D convolution tensor of shape (m, n, k, k) into a 2D matrix of shape (m k, n k), computes truncated SVD at rank r = gamma_p rank(W_l) with spectral initialization U_t^l sqrt(Sigma_{r,t}^l) and V_t^l sqrt(Sigma_{r,t}^l), and reshapes the factors into two sequential convolution layers of shapes (m, r, k, 1) and (r, n, 1, k) reducing parameters from m n k^2 to r k (m + n) and MACs from m n k^2 H W to r k H W (m + n); after E local epochs with Frobenius decay (lambda / 2) ||U V^T||_F^2, the server reconstructs full-rank matrices U_l V_l^T (Eq. 1) and aggregates w_{t+1} = sum_{p=1}^P alpha_p w_{p,t+1} with alpha_p = exp(gamma_p / tau) / sum_{q=1}^P exp(gamma_q / tau) (Eq. 2).

Scope #fedhm-nonconvex-convergence-with-rank-truncation-error-scope
Under L_{nabla f}-smooth client objectives, unbiased stochastic gradients with bounded second moment kappa_f, bounded factor Frobenius norms ||U_{p,t}^l||_F, ||V_{p,t}^l||_F <= kappa_UV, and bounded SVD rank-truncation discrepancies kappa_{sigma_1} and kappa_{sigma_2} across heterogeneous client ranks (Assumptions 3-5), Theorem 3 (and Theorem 1) proves that the factorized iterates h_hat_t satisfy (1/T) sum_{t=0}^{T-1} E[||nabla g(h_hat_t)||^2] <= (2/(T eta))(f(w_0) - f_low) + 2 L_f (L - rho) kappa_{sigma_1} / (E eta) + 6 eta kappa_g E (eta L_{nabla g}^2 E + 2 L_f kappa_UV^2) + eta L_{nabla g} M_g / P + 6 (L - rho) kappa_{sigma_2} (L_{nabla g}^2 + 2 L_f kappa_UV^2 / (E eta)), where the kappa_{sigma_2} term vanishes when all clients use full-rank models.
  • supports Source: FedHM: Efficient Federated Learning for Heterogeneous Models via Low-rank Factorization · Locator: Section 3.2 Theorem 1, pp. 5-6; Appendix B.2-B.3 Assumptions 3-5, Lemmas 1-3, Theorems 2-3, pp. 15-25
Limitation #fedhm-server-svd-overhead-and-early-layer-factorization-limitation
Performing truncated SVD on the global model at the server at every communication round incurs high server-side matrix decomposition overhead (Section 6, p. 9), and factorizing all early convolution layers (rho = 0) at severe compression (2% parameter ratio) causes cumulative approximation error propagation that drops accuracy from over 90% to below 80% on CIFAR-10 and from 70% to below 55% on CIFAR-100 unless early layers are kept unfactorized (Section 2.2, p. 3; Appendix D.1, Figure 8, p. 27).
  • supports Source: FedHM: Efficient Federated Learning for Heterogeneous Models via Low-rank Factorization · Locator: Section 2.2 Hybrid Network Architecture, p. 3; Section 6 Conclusion and Limitations, p. 9; Appendix D.1, p. 27
Application #fedhm-heterogeneous-device-visual-classification-application
Applied to federated visual classification across dynamic and fixed hardware-capacity client cohorts training hybrid low-rank ResNet-18 and ResNet-34 models (rank ratios gamma in {0.5, 0.25, 0.125, 0.083}) on IID and Dirichlet non-IID partitions of CIFAR-10, CIFAR-100, and Tiny-ImageNet.
  • supports Source: FedHM: Efficient Federated Learning for Heterogeneous Models via Low-rank Factorization · Locator: Section 4 Experiments and Analysis, Tables 2-3, Figures 2-4, pp. 6-9; Appendix C-D, Tables 4-8, pp. 25-28

⚠️ Curated Limitations & Negative Results

  • Re-computing truncated SVD on the global model at the server at every communication round introduces non-trivial server-side matrix decomposition overhead (Section 6, p. 9).
  • Factorizing early network layers (rho = 0) under extreme low-rank compression propagates approximation errors across depth and severely degrades accuracy unless the first rho layers remain unfactorized (Section 2.2, p. 3; Appendix D.1, p. 27).
  • The non-convex stationarity bound in Theorem 3 retains a non-vanishing heterogeneity error floor proportional to (L - rho) kappa_{sigma_1} / (E eta) and (L - rho) kappa_{sigma_2} when clients train rank-truncated sub-models (Appendix B.3, p. 22).
