Frequent-Directions Deterministic Streaming Matrix Sketching

Algorithms AIMech:FrequentDirectionsDeterministicStreamingMatrixSketching DRAFT
Aliases: Frequent-Directions Matrix Sketching, Liberty Deterministic Covariance Matrix Sketching, Spectral Misra-Gries / Space-Saving Matrix Sketch
Frequent-Directions Deterministic Streaming Matrix Sketching is a deterministic one-pass row-streaming matrix sketching algorithm introduced by Liberty (2013) that maintains an l x m sketch matrix B of an n x m input matrix A by generalizing the Misra-Gries / Space-Saving frequent-items counter decrement rule to singular values and right singular vectors. In the basic algorithm (Algorithm 1), each streaming row a_i in R^m is inserted into an all-zero row of B in R^{l x m}; whenever B has no zero rows, the algorithm computes the SVD B = U Sigma V^T, sets delta_i = sigma_l^2, shrinks all l squared singular values uniformly via bar{Sigma} = sqrt(Sigma^2 - I_l delta_i), and updates B <- bar{Sigma} V^T so that the last row of B is guaranteed to be zero. In the amortized fast variant (Algorithm 2), B is zeroed out in its bottom l/2 rows by shrinking at threshold delta_i = sigma_{l/2}^2 only once every l/2 row insertions, reducing the total runtime from O(n m l^2) to O(n m l) at space O(m l). Claims 1 and 2 and Theorems 4.1 and 4.2 prove that for every unit vector x in R^m (||x||_2 = 1), 0 <= ||A x||_2^2 - ||B x||_2^2 <= 2 (||A||_F^2 - ||B||_F^2) / l <= 2 ||A||_F^2 / l (with factor 1 for Algorithm 1 and factor 2 for Algorithm 2), guaranteeing A^T A >= B^T B and ||A^T A - B^T B||_2 <= epsilon ||A||_F^2 for l = ceil(2 / epsilon).
Identity Notes & Concept Scope Distinct from batch Principal Component Analysis (`AIO:PrincipalComponentAnalysis`), which requires storing A or A^T A in O(n m) or O(m^2) memory, and from randomized oblivious subspace embeddings (`AIMech:SubsampledRandomizedHadamardTransformSubspaceEmbedding`) or randomized column sampling (`AIMech:NystromGramMatrixLowRankApproximationWithDiagonalSampling`). Specifically captures Liberty's (2013) deterministic SVD singular-value shrinkage rule bar{Sigma} = sqrt(Sigma^2 - I_l delta_i) (Algorithms 1 and 2), its exact reduction to the Misra-Gries / Space-Saving heavy-hitters counter algorithm on orthogonal basis streams (Section 3, Theorem 3.1), and the deterministic Loewner positive semidefinite covariance bound 0 <= A^T A - B^T B <= (2 / l)(||A||_F^2 - ||B||_F^2) I_m (Claims 1-2, Theorems 4.1-4.2).

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
In each step i of Frequent-Directions (Algorithm 1), shrinking the squared singular values of the l x m sketch by delta_i = sigma_l^2 via bar{Sigma} = sqrt(Sigma^2 - I_l delta_i) zeroes out the l-th row and satisfies ||C_i||_F^2 - ||B_i||_F^2 = l delta_i, which telescopes over all n streaming rows to give the exact identity sum_{i=1}^n delta_i = (||A||_F^2 - ||B||_F^2) / l <= ||A||_F^2 / l (Claim 1), while for every unit vector x in R^m, Claim 2 proves 0 <= ||A x||_2^2 - ||B x||_2^2 <= sum_{i=1}^n delta_i, implying both A^T A >= B^T B and ||A^T A - B^T B||_2 <= (||A||_F^2 - ||B||_F^2) / l (Theorem 4.1).
  • supports Source: Simple and Deterministic Matrix Sketching · Locator: Section 4.1, Algorithm 1, Claims 1 and 2, and Theorem 4.1, p. 583
  • supports Source: Simple and Deterministic Matrix Sketching (Crossref metadata) · Locator: Crossref metadata for KDD 2013 pp. 581-588
Scope #claim-02
By doubling the sketch capacity and shrinking by delta_i = sigma_{l/2}^2 only when all l/2 zero rows are filled (Algorithm 2), Theorem 4.2 proves that the SVD cost O(m l^2) is amortized over l/2 row insertions to achieve total streaming runtime O(n m l) = O(n m / epsilon) for l = ceil(2 / epsilon) while preserving the deterministic guarantee ||A^T A - B^T B||_2 <= 2 (||A||_F^2 - ||B||_F^2) / l <= epsilon ||A||_F^2; moreover, when input rows are indicator vectors e_{j_i}, Frequent-Directions reduces exactly to the Misra-Gries / Space-Saving item frequency estimation algorithm (Section 3, Theorem 3.1).
  • supports Source: Simple and Deterministic Matrix Sketching · Locator: Section 3, Theorem 3.1, p. 582; Section 4.1-4.2, Algorithm 2 and Theorem 4.2, pp. 583-584
Limitation #claim-03
Frequent-Directions does not preserve input sparsity (the sketch B = bar{Sigma} V^T is dense even when the streaming rows a_i are sparse, requiring O(n m l) time rather than input-sparsity time), and its worst-case spectral error bound scales with ||A||_F^2 / l rather than the tail residual ||A - A_k||_F^2 / (l - k) in the original Liberty (2013) analysis when the spectrum of A is completely flat.
  • supports Source: Simple and Deterministic Matrix Sketching · Locator: Section 4.1, Tightness remark on ||A||_F^2 - ||B||_F^2, p. 583; Section 5.2, Comparison with sparse hashing and random projection on sparse inputs, p. 586

⚠️ Curated Limitations & Negative Results

  • Produces a dense l x m sketch matrix B even when the input matrix A is sparse, and requires an O(m l^2) SVD computation every l/2 streaming rows.
