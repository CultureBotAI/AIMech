Procrustes Flow (Factored Gradient Descent with $U^\top U = V^\top V$ Balancing Regularization) for Low-Rank Matrix Recovery

Algorithms AIMech:ProcrustesFlowForLowRankMatrixRecovery DRAFT
Aliases: Procrustes Flow (PF) for Low-Rank Matrix Sensing, Factored Gradient Descent with Factor-Balancing Regularizer ||U^T U - V^T V||_F^2, Tu-Boczar-Simchowitz-Soltanolkotabi-Recht Procrustes Flow
A two-stage non-convex Burer-Monteiro factored optimization algorithm and geometric convergence analysis (introduced by Stephen Tu, Ross Boczar, Max Simchowitz, Mahdi Soltanolkotabi, and Benjamin Recht in 2016) for recovering a rank-$r$ matrix $X^*\in\mathbb{R}^{n_1\times n_2}$ from linear measurements $b = \mathcal{A}(X^*)$. For a symmetric positive semidefinite target $X^* = X_0 X_0^\top$ ($X_0 = \Phi_0\Sigma_0^{1/2}$), *Procrustes Flow* minimizes $f(U) = \frac{1}{4}\|\mathcal{A}(U U^\top) - b\|_2^2$ via gradient descent $U_{\tau+1} = U_\tau - \mu_\tau \mathcal{A}^*(\mathcal{A}(U_\tau U_\tau^\top) - b)U_\tau$ (Equation 2.5) measured in the orthogonal-Procrustes distance $d(U,X_0) = \min_{R\in O(r)}\|U - X_0 R\|_F$ (Equation 2.4). For a general rectangular rank-$r$ matrix $X^* = \Phi_0\Sigma_0\Psi_0^\top$ factored as $X = U V^\top$ with lifted stack $W = \begin{bmatrix} U \\ V \end{bmatrix}\in\mathbb{R}^{(n_1+n_2)\times r}$, asymmetric rescaling $U \mapsto U T, V \mapsto V T^{-\top}$ degrades local curvature; rectangular Procrustes Flow eliminates this degeneracy by adding the factor-balancing regularizer $g(U,V) = \frac{1}{16}\|U^\top U - V^\top V\|_F^2$ to form $F(W) = \frac{1}{2}\|\mathcal{A}(U V^\top) - b\|_2^2 + \frac{1}{16}\|U^\top U - V^\top V\|_F^2$ (Equation 5.2), whose balanced gradient step $U_{\tau+1} = U_\tau - \mu_\tau[\nabla_U f + \frac{1}{4}U_\tau(U_\tau^\top U_\tau - V_\tau^\top V_\tau)]$ and $V_{\tau+1} = V_\tau - \mu_\tau[\nabla_V f + \frac{1}{4}V_\tau(V_\tau^\top V_\tau - U_\tau^\top U_\tau)]$ (Equation 5.3) satisfies the local regularity condition $\langle\nabla F(W), W - W_0 R\rangle \ge \frac{\sigma_r(X^*)}{5}\|W - W_0 R\|_F^2 + \frac{1}{100\sigma_1(X^*)}\|\nabla F(W)\|_F^2$ inside $d(W,W_0) \le \frac{1}{4}\sigma_r(X^*)^{1/2}$ under rank-$6r$ Restricted Isometry $\delta_{6r} \le 1/25$ (Lemma 5.10, Theorem 5.2), guaranteeing linear contraction $d(W_\tau,W_0) \le (1 - \frac{\mu\sigma_r(X^*)}{5})^\tau d(W_0^{\mathrm{init}},W_0)$ from $m \ge C r(n_1+n_2)$ projected-gradient initialization.
Identity Notes & Concept Scope Resolved against all 442 pinned AIO concepts and 699 maintained AIMech concepts. Distinct from `AIMech:ScaledGradientDescentForIllConditionedLowRankMatrixEstimation` (Tong, Ma, & Chi 2021, which replaces Euclidean gradients and the $\|U^\top U - V^\top V\|_F^2$ balancing penalty by right-preconditioned iterates $L_t(Y_t^\top Y_t)^{-1}$ to remove condition-number $\kappa$ slowdown) and `AIMech:NonconvexMatrixCompletionLandscapeWithoutSpuriousLocalMinima` (Ge, Lee, & Ma 2016, which analyzes global saddle-free geometry for matrix completion).

Mechanism #claim-procrustes-distance-spectral-alignment-and-lifted-symmetric-perturbation
For the orthogonal Procrustes distance $d(U,X_0) = \min_{R\in O(r)}\|U - X_0 R\|_F$ with optimal aligner $R = A B^\top$ from the SVD $X_0^\top U = A\Sigma B^\top$ (so $U^\top X_0 R \succeq 0$ is symmetric PSD), Lemma 5.4 establishes the key quadratic perturbation bound $\|U U^\top - X_0 X_0^\top\|_F^2 \ge 2(\sqrt{2}-1)\sigma_r^2(X_0)\|\Delta\|_F^2$ ($\Delta = U - X_0 R$); for rectangular factors $W = [U;V]$ and $W_0 = [X_0;Y_0]$ ($X_0^\top X_0 = Y_0^\top Y_0 = \Sigma_0$), decomposing $W W^\top - W_0 W_0^\top$ shows that off-diagonal product error $\|U V^\top - X^*\|_F^2$ controls $\|W W^\top - W_0 W_0^\top\|_F^2$ once the factor imbalance $\|U^\top U - V^\top V\|_F^2$ is penalized via the algebraic identity $\|W^\top W\|_F^2 - 4\|U V^\top\|_F^2 = \|U^\top U - V^\top V\|_F^2$ (Lemma 5.3, Section 5.6.2).

Mechanism #claim-balanced-objective-local-regularity-condition-and-linear-contraction
Under the rank-$6r$ Restricted Isometry Property $\delta_{6r} \le 1/25$ (Definition 2.1), Lemma 5.10 proves that the balanced rectangular objective $F(W) = \frac{1}{2}\|\mathcal{A}(U V^\top) - b\|_2^2 + \frac{1}{16}\|U^\top U - V^\top V\|_F^2$ satisfies the local regularity condition $\langle\nabla F(W),\Delta\rangle \ge \alpha\|\Delta\|_F^2 + \beta\|\nabla F(W)\|_F^2$ with $\alpha = \frac{\sigma_r(X^*)}{5}$ and $\beta = \frac{1}{100\sigma_1(X^*)}$ for all $d(W,W_0) \le \frac{1}{4}\sigma_r(X^*)^{1/2}$, which implies $d^2(W_{\tau+1},W_0) \le (1 - 2\alpha\mu)d^2(W_\tau,W_0)$ for step size $\mu \le \beta = \frac{1}{100\sigma_1(X^*)}$, giving linear convergence $d(W_\tau,W_0) \le (1 - \frac{1}{500\kappa})^{\tau/2} d(W_0^{\mathrm{init}},W_0)$ and $\|U_\tau V_\tau^\top - X^*\|_F \le \frac{5}{4}\sigma_1(X^*)^{1/2} d(W_\tau,W_0)$ (Theorems 2.3 & 5.2).

Scope #claim-svp-initialization-sample-complexity-saving-kappa-squared-factor
Whereas single-shot spectral initialization $P_r(\mathcal{A}^*(b))$ requires $m \ge C \kappa^2 r(n_1+n_2)$ Gaussian measurements to enter the $O(\sigma_r^{1/2})$ Procrustes contraction basin, running $T = O(\log(r\kappa))$ iterations of Singular Value Projection (projected gradient descent) $Z_{t+1} = P_r(Z_t - \tau_t\mathcal{A}^*(\mathcal{A}(Z_t)-b))$ in Phase I enters the basin using only $m \ge C r(n_1+n_2)$ measurements independent of condition number $\kappa = \sigma_1(X^*)/\sigma_r(X^*)$ (Theorems 3.1, 3.2, 5.1 & Lemma 5.1).
  • supports Source: Low-rank Solutions of Linear Matrix Equations via Procrustes Flow · Locator: Section 3, Theorems 3.1 & 3.2, pp. 5-7; Section 5.1-5.2, Theorem 5.1 & Lemma 5.1, pp. 10-12
Limitation #claim-limitation-condition-number-kappa-dependence-in-iteration-complexity
Although Phase I projected gradient initialization removes $\kappa^2$ from the sample complexity $m = O(r(n_1+n_2))$, the Phase II Procrustes Flow step size $\mu \le \frac{c}{\sigma_1(X^*)}$ and regularity parameter $\alpha = \frac{\sigma_r(X^*)}{5}$ yield a per-iteration contraction factor $1 - O(1/\kappa)$, requiring $O(\kappa\log(1/\epsilon))$ iterations that slows down on severely ill-conditioned matrices.
  • supports Source: Low-rank Solutions of Linear Matrix Equations via Procrustes Flow · Locator: Section 2.2, Theorem 2.3, p. 5; Section 3.1, Remark on computational complexity, p. 7

⚠️ Curated Limitations & Negative Results

  • Iteration complexity scales linearly with the matrix condition number $\kappa = \sigma_1(X^*)/\sigma_r(X^*)$ ($O(\kappa\log(1/\epsilon))$ gradient steps), and theoretical guarantees require the measurement operator $\mathcal{A}$ to satisfy the rank-$6r$ Restricted Isometry Property $\delta_{6r} \le 1/25$.
