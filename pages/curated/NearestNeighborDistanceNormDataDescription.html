Nearest-neighbor distance-norm data description

Algorithms AIMech:NearestNeighborDistanceNormDataDescription DRAFT
Aliases: Nearest neighbor domain description (Angiulli), NNDD distance-norm rule
A one-class decision rule that forms the ordered distances from a query to its first k reference neighbors and accepts the query when the L_r norm of that distance vector is at most a supplied threshold, with self inclusion and infinite padding when fewer than k references exist.
Identity Notes & Concept Scope This is the NNDD distance-norm rule in Angiulli2007, independently of the optional CNNDD reference-condensation procedure. It is not the Tax-Duin ratio between a query distance and a selected reference point's own neighbor spacing, nor supervised neighbor voting. The record uses a qualified alias rather than assigning all uses of NNDD to one concept. The later prototype rule has a narrower reference-data correspondence, not general identity of decision regions. Claims & Grounded Evidence

4 Claims
Mechanism #ordered-distance-rule
For finite reference set D, object-space metric d, integer k>=1 and finite threshold theta>=0, let delta contain the k smallest reference distances from query x, including distance zero to x itself when x is in D. Missing entries when |D|<k are +infinity. Accept iff ||delta||_r<=theta; the published formal scope uses positive integer r or infinity. Thus r=1 sums the k distances, r=infinity uses the kth distance, and k=1 gives the union of radius-theta metric balls around D. This is a distance score, not a normalized density or novelty probability.
  • supports Source: Condensed Nearest Neighbor Data Domain Description · Locator: Section3, authorp2 / PDFp3, definition, sign convention and footnote1
Limitation #parameter-and-training-boundaries
With D, metric and other parameters fixed, increasing theta expands acceptance and increasing k contracts it. For a fixed k-distance vector, increasing r from a finite value toward infinity cannot increase its norm, so it expands or preserves acceptance at the same theta. These are monotonic relations, not proportional error laws. For distances {3/5,4/5} and theta=1, r=1 rejects while r=2 and infinity accept. Every self-included training point is accepted for k=1 and theta>=0, but k>1 can reject training points, and |D|<k rejects every query at finite theta. Equal-distance ordering does not change the norm, although selected neighbor identities can matter to a subsequent condensation algorithm.
  • supports Source: Condensed Nearest Neighbor Data Domain Description · Locator: Section3, authorpp2-3 / PDFpp3-4; Section5.3, authorp12 / PDFp13; exact curator checks in research/discovery/neighbor-domain-boundaries.py
Limitation #reference-subset-scope
An NNDD reference-consistent subset S of D preserves the decisions of the full D rule on every observation in D, including observations originally rejected. Removing references cannot decrease an ordered neighbor distance, so the acceptance region under S is contained in that under D at fixed k, theta, r and metric. Agreement on D does not establish identical decisions everywhere: with D={0,1}, S={0}, k=1 and theta=1, both reference observations are accepted by both rules, but query2 is accepted only using D. This can help or harm future error depending on the query's true class.
  • supports Source: Condensed Nearest Neighbor Data Domain Description · Locator: Section3 reference consistency, authorp3 / PDFp4; Section4 subset-distance inequality, authorp4 / PDFp5; curator finite example
Limitation #prototype-correspondence-boundary
The later PDD paper associates a prototype x with radius equal to its kth-reference-neighbor distance, retaining prototypes with radius<=theta. Its Theorem2.4 establishes agreement with infinity-norm NNDD on reference observations D; it does not assert global equality of acceptance regions. For D={0,2}, k=2 and theta=2, both prototype radii are2, so PDD accepts only its two prototype locations, whereas infinity-norm NNDD also accepts midpoint1. This exact example qualifies the abstract's equivalence wording; it does not review CPDD or FastCPDD algorithms.

⚠️ Curated Limitations & Negative Results

  • The source's printed neighbor-rank wording is not a complete tie implementation; this record follows its ordered-distance-vector definition. Reference membership, distance representation, scaling, k, r and threshold are part of the procedure.
  • Section5.3 experimentally includes r<1 outside the formal norm scope. Its tuned compression comparisons do not override fixed-parameter norm inequalities, and no universal parameter or calibrated false-alarm probability is inferred.
  • All15 pages of the2007 author PDF were visually read; only the specifically cited two pages of the later manuscript were visually inspected. The2005 proceedings version was not compared in full. No trained model or historical benchmark was executed.
