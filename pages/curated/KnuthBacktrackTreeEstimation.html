Knuth backtrack-tree estimation

Algorithms AIMech:KnuthBacktrackTreeEstimation DRAFT
Aliases: Knuth tree-size estimator
A randomized estimator of additive properties of a fixed backtracking tree that follows a sampled root-to-terminal path and weights each visited node contribution by the inverse probability of reaching it.

Claims & Grounded Evidence

5 Claims
Mechanism #uniform-path-weights
In the uniform form, start at the root with weight one, choose one eligible child uniformly at each step, and multiply the path weight by the number of eligible children. Accumulate the current weight times the node contribution, including the root, until the path terminates. The target backtracking program traverses the feasible tree, while a sampling trial follows only one path.
  • supports Source: Estimating the Efficiency of Backtrack Programs · Locator: Sections 2–3, PDF pp. 4–7 / printed pp. 124–127, Algorithm E1–E4 and Theorem 1
Mechanism #positive-probability-variant
The importance-sampling variant selects a child using specified positive probabilities and divides the path weight by the actual probability of the selected child. Retaining ordinary degree weights after a nonuniform choice generally changes the expectation. The zero-variance characterization uses probabilities proportional to true nonnegative subtree costs; it requires information normally unknown to the estimator and appropriate treatment of zero-cost branches.
  • supports Source: Estimating the Efficiency of Backtrack Programs · Locator: Section 5, PDF pp. 9–11 / printed pp. 129–131, E4-prime and Theorem 2
Scope #fixed-tree-additive-scope
For a finite fixed tree and defined node contributions with the required sampling support, the expectation equals the additive tree total. Constant-one contributions estimate node count, and terminal or level indicators estimate corresponding profiles. Node count does not by itself determine runtime when work varies across nodes. The paper explicitly excludes direct application to branch-and-bound with changing bounds, while allowing work estimates for testing a specified bound.
  • supports Source: Estimating the Efficiency of Backtrack Programs · Locator: Sections 3 and 7, PDF pp. 6–7 and 15 / printed pp. 126–127 and 135
Scope #relationship-to-stratified-estimation
Chen’s later weighted-stratum estimator includes uniform single-path tree sampling as its depth-only specialization. Grouping additional nodes into ordered strata and merging weighted representatives extends that mechanism. This record retains the earlier path estimator and its positive-probability variant; arbitrary stratum-merging rules belong to the later method.
  • supports Source: Heuristic Sampling: A Method for Predicting the Performance of Tree Searching Programs · Locator: Sections 2–3.2, PDF pp. 2–4 / printed pp. 296–298
Limitation #finite-trial-and-cost-limits
Unbiasedness is an expectation statement, not a guarantee that a finite set of probes finds rare deep nodes or produces a precise estimate. The reported knight-tour table includes zero estimated counts at deep levels with nonzero actual counts. Generating eligible children, evaluating costs and choosing probabilities require work, so a path-length bound is not a universal runtime bound. Contracting nodes preserves an additive target only if absorbed contributions remain included.
  • supports Source: Estimating the Efficiency of Backtrack Programs · Locator: Sections 4–7, PDF pp. 8–15 / printed pp. 128–135, Table 1 and node-contraction discussion

⚠️ Curated Limitations & Negative Results

  • A node in an implicit search tree denotes its path occurrence. Repeated graph states are not automatically deduplicated, and adaptive pruning can change the target tree.
  • Sampling probabilities must preserve support for contributions to the target and must be used in the actual weight update. Oracle subtree-cost probabilities are a characterization, not a practical exact-counting procedure for an unknown tree.
  • The source variance bound has nonnegative-cost, bounded-ratio and finite-depth assumptions. No universal finite-sample relative-error or confidence guarantee is asserted.
  • Constructed examples distinguish a five-node tree from an additive cost total of fifteen, and show that biased child selection with unchanged degree weights estimates six rather than five. These are finite boundary checks, not author-code execution.
  • All sixteen Knuth journal pages and twenty-one Chen journal pages were visually inspected. Other versions, source implementations and modern benchmark replication were not inspected or executed.
