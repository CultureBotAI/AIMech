Bootstrap classifier-instability novelty detection

Algorithms AIMech:BootstrapClassifierInstabilityNoveltyDetection DRAFT
Aliases: Outlier detection using classifier instability, Bootstrap output-variance novelty detection
A novelty-detection procedure that trains classifiers on bootstrap resamples of reference data, estimates the variance of their outputs at a query, and rejects queries with unusually high variability relative to a chosen reference-score threshold.
Identity Notes & Concept Scope This is the Tax-Duin1998 instability-based detector. Its novelty signal is variability of classifier outputs across bootstrap training sets, not the mean prediction used for ordinary bagging, nearest-neighbor spacing, a density estimate, vote entropy or a Bayesian posterior uncertainty. The published experiment uses labels among normal digit classes to train its base classifiers; target-versus-abnormal detection does not imply that the entire fitting procedure is label-free. The source's threshold notation is ambiguous, so the record preserves the procedure and that uncertainty rather than declaring an exact executable reference implementation. Claims & Grounded Evidence

4 Claims
Mechanism #bootstrap-output-variance
Draw bootstrap training sets of the original reference-set size, fit the chosen classifier to each, and compare their output values at the same query. The source defines rho(x)=E_b[out_b(x)^2]-(E_b[out_b(x)])^2, where the expectation is over bootstrap fits. Repeated fitted outputs estimate this variance; a large score indicates sensitivity to the sampled training set. It is not itself the probability that the query is novel. Base learner, output scaling, resampling and finite-ensemble variance-estimation conventions affect the result.
  • supports Source: Outlier Detection using Classifier Instability · Locator: Section 2.1, PDF p.3, Equation 4 and bootstrap paragraph
Mechanism #published-multiclass-configuration
The digit experiment uses a linear classifier based on Fisher's criterion, with a normalized sigmoid of distance to its decision boundary as output. It fits one-versus-rest classifiers for nine retained digit classes, produces 25 bootstrap classifier sets and averages output variances over the nine class outputs to obtain one novelty score. The withheld tenth digit class supplies abnormal examples for evaluation. These counts and learner choices describe that experiment, not fixed requirements for every use of the variance-gating procedure.
  • supports Source: Outlier Detection using Classifier Instability · Locator: Section 3, PDF pp.3-4, feature, class-split and classifier paragraphs
Limitation #threshold-ambiguity
Section2.2 motivates a threshold at the reference-score mean plus three standard deviations under a rough Gaussian-score assumption, but Equation6 writes mean plus three times var. These are different numerical rules unless var is being used for a different convention; the paper does not resolve that notation here. For reference scores {0,1/4}, the two thresholds are 1/2 and 11/64 respectively, so a query score of 1/4 receives different decisions. Doubling all classifier outputs multiplies variance scores by four; the literal mean-plus-three-variance threshold does not generally scale in the same way. The record does not select a hidden implementation convention or infer an exact false-alarm probability.
  • supports Source: Outlier Detection using Classifier Instability · Locator: Section 2.2, PDF p.3, prose and Equation 6; curator exact score calculations in research/discovery/novelty-score-boundaries.py
Limitation #stable-outliers-and-evaluation
Outliers can receive low variance when all bootstrap classifiers extrapolate stably, and difficult normal observations can receive high variance. More bootstrap replicates can improve estimation of a fixed variability signal but do not guarantee that stable outliers acquire a detectable signal. The reported digit comparisons depend on representation and training-set size; the normal evaluation population includes training examples, and rotation-invariant features can make withheld digits indistinguishable from retained ones. The source itself reports stable-region failures and weaker results at larger sample sizes. This supports a bounded instability indicator, not a universal novelty detector or general performance advantage.
  • supports Source: Outlier Detection using Classifier Instability · Locator: Sections 3.1 and 4, PDF pp.5-8, Figures 2-3 and conclusion

⚠️ Curated Limitations & Negative Results

  • The source does not fully resolve its threshold notation, finite-sample variance divisor or all bootstrap implementation conventions. No precise historical implementation is certified.
  • A low score can reflect shared stable extrapolation rather than familiar input. Output variance, class probability, predictive accuracy and novelty are different quantities.
  • The training labels, base classifier and output transformation used in the reported experiment are retained explicitly. No new model was trained and no reported benchmark result was reproduced.
  • All nine primary manuscript pages were visually read. Plot captions and the text-defined corrected rejection metric are not silently equated; no numerical benchmark result is curated.
