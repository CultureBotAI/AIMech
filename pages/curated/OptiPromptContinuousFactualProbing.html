OptiPrompt Continuous Factual Probing

Algorithms AIMech:OptiPromptContinuousFactualProbing DRAFT
Aliases: OptiPrompt, OptiPrompt Continuous Prompt Factual Probing, Continuous Input-Embedding Factual Probing
A continuous prompt optimization and factual probing method for pretrained language models that replaces discrete template tokens with dense trainable vectors directly in the model's input embedding space, optimizing those continuous vectors via gradient ascent on the log-likelihood of gold object entities over relational fact triples while holding all pretrained language model parameters frozen.
Identity Notes & Concept Scope Distinct from discrete prompt search methods such as AutoPrompt (AIMech:AutoPromptGradientGuidedDiscretePromptSearch) and mining/paraphrasing relational prompts (LPAQA) because OptiPrompt optimizes unconstrained continuous vectors v_i in R^d directly in the input embedding layer of a frozen masked language model, optionally initialized from the embeddings of manual prompt tokens. Also distinct from multi-layer deep continuous prefix tuning (AIMech:PTuningV2DeepContinuousPromptTuning), which injects trainable key-value prefixes across every transformer layer for downstream NLU supervision rather than probing factual relational knowledge and analyzing spurious target-distribution exploitation in masked language models.

Claims & Grounded Evidence

4 Claims
Mechanism #optiprompt-continuous-input-embedding-formulation
OptiPrompt represents a relational prompt as a sequence of dense continuous vectors [v]_1, ..., [v]_m Surrounding the subject entity placeholder [X] and masked object token [MASK] in the input embedding space R^d, and optimizes only those vectors by maximizing the conditional log-likelihood P([MASK] = o | [x]) over relational fact pairs while keeping all pretrained language model weights fixed.
  • supports Source: Factual Probing Is [MASK]: Learning vs. Learning to Recall · Locator: Section 3.1, pp. 5019-5020, Equation 3
Mechanism #optiprompt-manual-template-embedding-initialization
To incorporate linguistic prior structure while permitting continuous gradient optimization, OptiPrompt can initialize the number and values of its continuous vectors [v]_i directly from the pretrained input word embeddings of a manual relational prompt template.
  • supports Source: Factual Probing Is [MASK]: Learning vs. Learning to Recall · Locator: Section 3.1 & Section 3.3, pp. 5019-5021, Table 1
Application #optiprompt-factual-knowledge-probing-application
OptiPrompt is applied to factual knowledge probing on the LAMA and LAMA-UHN relational benchmarks across BERT, RoBERTa, and ALBERT models, substantially increasing Precision@1 over manual prompts and discrete AutoPrompt triggers.
  • supports Source: Factual Probing Is [MASK]: Learning vs. Learning to Recall · Locator: Section 3.2 & Section 3.3, pp. 5020-5022, Tables 1-2
  • supports Source: Factual Probing Is [MASK]: Learning vs. Learning to Recall (Crossref metadata) · Locator: DBLP bibliographic record conf/naacl/ZhongFC21
Limitation #optiprompt-spurious-regularity-exploitation-limitation
Optimizing prompts on supervised relational fact splits can exploit dataset-specific object distribution priors and surface lexical regularities of subject entities to predict answers that were never stored during pretraining, confounding estimates of genuine pretrained factual recall.
  • supports Source: Factual Probing Is [MASK]: Learning vs. Learning to Recall · Locator: Section 4 & Section 5, pp. 5022-5026, Tables 3-5 & Figures 2-4

⚠️ Curated Limitations & Negative Results

  • Learned continuous vectors do not correspond to human-readable vocabulary tokens and cannot be directly interpreted as natural language relational templates.
  • Because continuous prompt parameters are fit on supervised relational triples, they can memorize target object priors and shallow subject-surface correlations, inflating apparent factual recall.
