SCAFFOLD Stochastic Controlled Averaging for Heterogeneous Federated Learning

Algorithms AIMech:ScaffoldStochasticControlledAveragingForFederatedLearning DRAFT
Aliases: SCAFFOLD, Stochastic Controlled Averaging for Federated Learning, Control-Variate Drift-Corrected Federated Averaging
A federated optimization algorithm (SCAFFOLD) that eliminates client drift across N heterogeneous clients by maintaining a local control variate c_i on each client i and an aggregate server control variate c = (1/N) sum_{i=1}^N c_i, correcting each of the K local mini-batch steps on sampled clients S subseteq [N] via y_i <- y_i - eta_l * (g_i(y_i) - c_i + c), updating the client control variate via c_i^+ = g_i(x) (Option I) or c_i^+ = c_i - c + (1 / (K * eta_l)) * (x - y_i) (Option II), and updating the global model x <- x + eta_g * (1/|S|) sum_{i in S} (y_i - x) and server control variate c <- c + (1/N) sum_{i in S} (c_i^+ - c_i), achieving convergence rates invariant to arbitrary client gradient dissimilarity.
Identity Notes & Concept Scope Distinct from uncorrected periodic local SGD (AIMech:LocalSgdPeriodicAveragingParallelStochasticGradientDescent, which Theorem II proves suffers an unavoidable Omega(G^2 / (mu^2 * R^2)) client-drift lower bound when K >= 2 under gradient dissimilarity G > 0), from proximal penalty stabilization without control variates (AIMech:FedProxProximalHeterogeneousFederatedOptimization), and from single-machine or every-step compressed variance reduction (AIMech:PageProbabilisticGradientEstimatorForNonconvexOptimization and AIMech:Ef21MarkovCompressorErrorFeedbackForHeterogeneousNonconvexOptimization). Narrower than AIO:FederatedLearning, which covers the general federated learning paradigm without specifying stateful client/server control-variate drift correction.

Claims & Grounded Evidence

4 Claims
Mechanism #r384-fedavg-client-drift-lower-bound-and-fixed-point-invariance
Theorem I and Theorem II prove that under (G, B)-bounded gradient dissimilarity with K >= 2 local steps, FedAvg suffers an unavoidable Omega(G^2 / (mu^2 * R^2)) error floor from client drift even with full participation (S = N) and zero stochastic noise (sigma = 0); by contrast, SCAFFOLD's drift-corrected local step y_i <- y_i - eta_l * (g_i(y_i) - c_i + c) satisfies grad f_i(x*) - c_i* + c* = 0 when c_i* = grad f_i(x*) and c* = grad f(x*) = 0, making the global optimum x* an exact fixed point of the K-step local trajectory for any K >= 1.
  • supports Source: SCAFFOLD: Stochastic Controlled Averaging for Federated Learning · Locator: Section 3 Theorem I, Theorem II, Section 4 Equations (2)-(5), and Section 5 Theorem III, pp. 3-6
Mechanism #r384-heterogeneity-independent-convergence-and-hessian-similarity-speedup
Theorem III proves that SCAFFOLD converges in R = O_tilde(sigma^2 / (mu * S * K * epsilon) + N / S + beta * N / (mu * S)) communication rounds for mu-strongly convex functions (reducing to SAGA when sigma = 0, K = 1, S = 1) and O((beta * N / S)^{2/3} * D^2 / epsilon + ...) for nonconvex functions without any dependence on gradient dissimilarity (G, B); moreover, under delta-bounded Hessian dissimilarity ||nabla^2 f_i(x) - nabla^2 f(x)|| <= delta, Theorem IV proves a true local-step communication reduction R = O_tilde(beta * sigma^2 / (mu * K * N * epsilon) + beta / (mu * K) + delta / mu).
  • supports Source: SCAFFOLD: Stochastic Controlled Averaging for Federated Learning · Locator: Section 5 Theorem III, Corollary I, and Theorem IV, pp. 5-7
Limitation #r384-stateful-client-control-variate-and-2x-communication-limitation
SCAFFOLD requires stateful clients that persist local control variates c_i across rounds (causing control-variate staleness of factor N/S when S << N clients are sampled per round) and doubles the per-round communication payload (sending both Delta y_i and Delta c_i).
  • supports Source: SCAFFOLD: Stochastic Controlled Averaging for Federated Learning · Locator: Section 4 Algorithm 1 and Section 5 Theorem III Discussion (Lag Term N/S), pp. 4-6
Application #r384-non-iid-federated-classification-application
Applied to federated logistic regression and 2-layer neural network classification on non-IID partitioned EMNIST across heterogeneous clients with partial participation.
  • supports Source: SCAFFOLD: Stochastic Controlled Averaging for Federated Learning · Locator: Section 6 Experiments, Figures 2-4 and Table 3, pp. 7-8

⚠️ Curated Limitations & Negative Results

  • Requires stateful clients capable of storing a d-dimensional control variate c_i across communication rounds, making it unsuitable for purely stateless cross-device settings where each client participates only once.
  • Doubles bidirectional communication volume per participating client (transmitting both model updates and control-variate updates) and incurs an N/S staleness lag when client sampling fraction S/N is very small.
