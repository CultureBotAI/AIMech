Rennala SGD and Malenia SGD

Algorithms AIMech:RennalaSgdAndMaleniaSgdMinimaxOptimalParallelStochasticOptimization DRAFT
Aliases: Rennala SGD, Malenia SGD, Accelerated Rennala SGD, Time Multiple Oracles Protocol Parallel SGD
A pair of minimax time-optimal semi-asynchronous parallel stochastic gradient algorithms — Rennala SGD (Method 4, for homogeneous i.i.d. worker distributions) and Malenia SGD (Method 6, for heterogeneous worker distributions f(x) = (1/n) sum_{i=1}^n E[f_i(x; xi_i)]) — analyzed under the Time Multiple Oracles Protocol (Protocol 3) where worker i in [n] requires tau_i seconds (0 < tau_1 <= ... <= tau_n) to compute an unbiased sigma^2-variance-bounded stochastic gradient. At each outer step k, workers continuously compute gradients at the current iterate x^k while the server discards any stale gradient whose iteration tag k' != k: Rennala SGD accumulates S = max{ceil(sigma^2 / epsilon), 1} fresh gradients g^k = (1/S) sum_{s=1}^S hat{nabla} f(x^k; xi_s) and attains the homogeneous minimax wall-clock time complexity Theta(min_{m in [n]} ((1/m) sum_{i=1}^m 1/tau_i)^{-1} (L Delta / epsilon + sigma^2 L Delta / (m epsilon^2))) without prior knowledge of tau_1, ..., tau_n, whereas Malenia SGD accumulates per-worker counts B_i until ((1/n) sum_{i=1}^n 1/B_i)^{-1} >= S/n and updates with the unweighted worker-mean average g^k = (1/n) sum_{i=1}^n (1/B_i) sum_{j=1}^{B_i} hat{nabla} f_i(x^k; xi_{i,j}), attaining the heterogeneous minimax time complexity Theta(tau_n L Delta / epsilon + ((1/n) sum_{i=1}^n tau_i) sigma^2 L Delta / (n epsilon^2)).
Identity Notes & Concept Scope Distinct from classical Asynchronous SGD (which applies delayed gradients hat{nabla} f(x^{k - delta_k}) computed at stale iterates and suffers suboptimal wall-clock complexity when slow stragglers inject large delays) and from synchronous Minibatch SGD (which waits for the slowest worker tau_n at every batch). Rennala SGD and Malenia SGD run workers in an asynchronous loop but strictly filter for current-iterate gradients (k' = k), automatically excluding slow stragglers i > m^* in the homogeneous regime and balancing harmonic sample sizes in the heterogeneous regime.

Mechanism #time-multiple-oracles-protocol-and-homogeneous-minimax-lower-bound
Under the Time Multiple Oracles Protocol (Protocol 3) and wall-clock complexity measure m_{time}(A_{zr}, F_{Delta,L}) (Equation 6), Theorem 6.4 proves using a zero-chain worst-case function F_T and parallel Bernoulli-gated stateful delay oracles O_{tau_i}^{hat{nabla} f} that any zero-respecting parallel algorithm requires at least Omega(min_{m in [n]} ((1/m) sum_{i=1}^m 1/tau_i)^{-1} (L Delta / epsilon + sigma^2 L Delta / (m epsilon^2))) seconds to find an epsilon-stationary point E[||nabla f(hat{x})||^2] <= epsilon, even if the algorithm is allowed to interrupt ongoing worker computations (Protocol 8, Section F).

Mechanism #rennala-sgd-automatic-straggler-truncation-and-optimal-time-rate
With batch size S = max{ceil(sigma^2 / epsilon), 1} and stepsize gamma = min{1/L, epsilon S / (2 L sigma^2)}, Rennala SGD (Method 4) requires K >= 24 Delta L / epsilon outer iterations (Theorem 7.4) and completes each batch in at most 2 min_{j in [n]} (sum_{i=1}^j 1/tau_i)^{-1} (S + j) seconds (Proof of Theorem 7.5, Lemma D.7), automatically assigning B_i = 0 to all slow workers i > j^* whose latency tau_i exceeds the active harmonic threshold without knowing tau_1, ..., tau_n in advance.

Application #malenia-sgd-harmonic-batch-condition-and-heterogeneous-minimax-optimality
In the heterogeneous data regime, Theorem A.2 establishes the lower bound Omega(tau_n L Delta / epsilon + ((1/n) sum_{i=1}^n tau_i) sigma^2 L Delta / (n epsilon^2)), and Malenia SGD (Method 6, Theorems A.3-A.4) attains this bound within a constant factor of 96 by waiting at each outer step k until the harmonic mean of per-worker fresh sample counts B_i satisfies ((1/n) sum_{i=1}^n 1/B_i)^{-1} >= S/n with S = max{ceil(sigma^2 / epsilon), n}, which bounds the aggregated gradient variance by (1/n^2) sum_{i=1}^n sigma^2 / B_i <= sigma^2 / S.
  • supports Source: Optimal Time Complexities of Parallel Stochastic Optimization Methods Under a Fixed Computation Model · Locator: Appendix A, Table 2, Method 6, Theorems A.2-A.4, pp. 16-18; Appendix E.3-E.4, pp. 40-41
Limitation #worst-straggler-bottleneck-in-heterogeneous-deterministic-regime
In the heterogeneous regime where workers hold distinct local distributions D_i without data-similarity assumptions, Theorem A.2 proves that the optimization term tau_n L Delta / epsilon depends unavoidably on the slowest worker's delay tau_n, because the non-zero objective component can reside entirely on the n-th worker.
  • supports Source: Optimal Time Complexities of Parallel Stochastic Optimization Methods Under a Fixed Computation Model · Locator: Appendix A.1-A.2, Theorem A.2, pp. 16-17; Appendix E.1, Part 1, p. 36

⚠️ Curated Limitations & Negative Results

  • Wall-clock optimality proofs assume the fixed computation model where worker i takes deterministic time tau_i per stochastic gradient evaluation (assuming negligible communication delay).
  • In the heterogeneous regime without data similarity, Malenia SGD must collect at least one gradient per outer step from every worker, so the deterministic term scales with the slowest worker's latency tau_n.
