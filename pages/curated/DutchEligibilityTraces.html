Dutch eligibility traces

Mathematical Methods AIMech:DutchEligibilityTraces DRAFT
An eligibility-trace update that propagates prior feature credit and adds a current-feature contribution adjusted by the prior trace’s projection onto that feature, using the source-specified step-size scaling convention.
Identity Notes & Concept Scope Selects the vector-valued Dutch eligibility update as a mathematical component, not a complete TD, Sarsa or GTD algorithm. Scaled and constant-step-size unscaled conventions are explicitly related, while variable step sizes and arbitrary feature geometries retain their limits. Claims & Grounded Evidence

5 Claims
Scope #named-trace-component
Dutch eligibility traces are a named feature-credit component. The 2014 UAI source applies this name to its general trace recurrence, and the 2016 journal source explicitly distinguishes the Dutch trace update from the separate changing-prediction correction in true online TD(lambda). The trace recurrence alone does not specify a reward target, weight update or action-selection rule.
  • supports Source: Off-policy TD(λ) with a true online equivalence · Locator: Section 3, PDF pp. 3–4, Theorem 1 Equation 3 and the paragraph naming the general recurrence Dutch traces.
  • supports Source: True Online Temporal-Difference Learning · Locator: Section 4.1, PDF p. 12, Equations 11–12 and the separate names for the trace and delta-correction; Section 7.1, p. 26, naming attribution.
Mechanism #scaled-vector-recurrence
In the general step-size-weighted convention, initialize E_0=eta_0*phi_0. For t>0, update E_t=c_(t-1)*E_(t-1)+eta_t*(1-c_(t-1)*phi_t^T*E_(t-1))*phi_t, where E and phi are compatible real feature vectors and eta and c are scalars. The inner product uses the old trace E_(t-1). Equivalently, the update is c_(t-1)*(I-eta_t*phi_t*phi_t^T)*E_(t-1)+eta_t*phi_t; this rank-one form is an algebraic rewrite of the same recurrence.
  • supports Source: Off-policy TD(λ) with a true online equivalence · Locator: Section 3, PDF p. 3, Theorem 1 Equation 3, initialization and final trace-recursion derivation; naming on PDF p. 4. The rank-one expression follows directly by expansion.
Mechanism #td-step-size-conventions
With q=gamma*lambda, the original 2014 TD convention and the 2016 time-dependent-step-size convention use E_t=q*E_(t-1)+alpha_t*phi_t-alpha_t*q*(E_(t-1)^T*phi_t)*phi_t, starting from E_(-1)=0. The 2016 constant-alpha unscaled convention instead uses e_t=q*e_(t-1)+phi_t-alpha*q*(e_(t-1)^T*phi_t)*phi_t, starting from e_(-1)=0. For a constant alpha and the same feature sequence, the compatible traces satisfy E_t=alpha*e_t. Time-varying step sizes remain inside the scaled recurrence.
  • supports Source: True Online TD(lambda) · Locator: Section 4.1, PDF p. 5, Equation 11 and Algorithm 2, scaled trace and zero initialization.
  • supports Source: True Online Temporal-Difference Learning · Locator: Section 4.1, PDF p. 12, Equation 11 and Algorithm 2; Section 6.1, PDF pp. 22–23, Equation 16 and Algorithm 4. Constant-alpha rescaling is the corresponding algebraic identity.
Mechanism #one-hot-specialization
For one-hot features and the unscaled TD convention, inactive coordinates obey e_t(j)=q*e_(t-1)(j), while the active coordinate i obeys e_t(i)=1+(1-alpha)*q*e_(t-1)(i), where q=gamma*lambda. From the same old trace this update map equals (1-alpha) times the accumulating update plus alpha times the replacing update. It is a convex combination only when alpha is in [0,1]; at alpha=1 the one-hot trace update becomes replacing.
  • supports Source: True Online Temporal-Difference Learning · Locator: Section 6.3, PDF p. 25, displayed tabular trace cases and accumulating/replacing comparison; Algorithm 6 uses an equivalent shifted decay timing. The convexity restriction follows from the displayed coefficients.
Scope #rank-one-memory-cost
For n dense feature coordinates, the trace recurrence can be evaluated using the old trace, the current feature vector, one inner product and vector operations, with O(n) arithmetic and O(n) trace storage per update. It does not require constructing the n-by-n rank-one matrix explicitly. These are costs of the trace recurrence; feature construction, action selection and the host learning rule have their own costs.
  • supports Source: Off-policy TD(λ) with a true online equivalence · Locator: Section 3, PDF pp. 3–4, Equation 3, its factored trace derivation and O(n) backward-view discussion. Trace-only arithmetic/storage follows from the displayed recurrence.
  • supports Source: True Online Temporal-Difference Learning · Locator: Section 4.1, PDF p. 12, Equation 11 and vector-update complexity discussion.

⚠️ Curated Limitations & Negative Results

  • The component is distinct from complete true online TD or Sarsa, the general eligibility family and an entire forward-view learning algorithm. In the UAI theorem, forward/backward weight equality also requires its linear weight updates, companion correction and horizon-independent target-difference relation; inserting only this trace into an arbitrary host does not establish that equality.
  • The scaled and unscaled conventions must be matched to the host update. Constant-alpha rescaling E=alpha*e does not justify the substitution E_t=alpha_t*e_t for varying step sizes. Division by alpha is undefined at alpha=0. A current zero alpha_t in the scaled recurrence leaves the decayed previous trace when earlier step sizes produced nonzero credit.
  • The accumulating/replacing relation is an identity between one-hot update maps evaluated from the same old trace, not a mixture of separately evolved trace histories. It does not extend as a coordinatewise replacing rule to arbitrary overlapping binary or real features. Coincident one-hot trace updates do not make the complete learning algorithms identical.
  • Dutch traces are not coordinatewise clipping and need not remain nonnegative or within [0,1]. In the general scaled recurrence, if z=c*phi^T*E_old and h=eta*||phi||^2, then phi^T*E_new=z+h*(1-z). For any starting projection, h in [0,1] keeps the new projection between its old value and one; unrestricted feature norms or step sizes can overshoot or amplify the deviation. The source phrase toward one does not imply exact unit attainment.
  • The general UAI coefficient c is a scalar independent of the data horizon, not necessarily a number in [0,1]. Its description as shrinking requires additional magnitude conditions. The transition c*(I-eta*phi*phi^T) has feature-direction factor c*(1-eta*||phi||^2), so the recurrence supplies no unconditional numerical stability, contraction, convergence, variance reduction or performance guarantee.
  • The source forward-view derivations concern linear prediction in the learned weights with the specified feature/target sequence and matching initialization. The vector trace formula can be evaluated on supplied features, but generic nonlinear or parameter-dependent feature learning does not automatically inherit those derivations. Dense O(n) bookkeeping does not imply cost proportional only to the current number of nonzero features or a universal wall-clock advantage.
  • The 2014 PMLR paper supplies the earlier scaled recurrence; the 2014 UAI paper explicitly names the general form Dutch traces; the 2016 journal article presents unscaled, time-dependent and tabular conventions and attributes the name to van Hasselt and colleagues. This is inspected source lineage, not an exhaustive priority claim. The UAI proof locally omits +x_k in its first F_k restatement although the theorem and later expansion retain those terms, and the 2016 prose after Equation 17 points to Algorithm 2 although the local time-dependent box is Algorithm 4. These bounded display observations are not a certified defect of the trace recurrence, an official erratum or a full proof audit. No author implementation or benchmark reproduction is certified.
