Neural variational inference and learning

Algorithms AIMech:NeuralVariationalInferenceAndLearning DRAFT
Aliases: NVIL
A method for jointly training a directed latent-variable model and an amortized stochastic inference network by maximizing a variational log-likelihood bound, using score-function inference gradients with learned baselines and adaptive learning-signal normalization.
Identity Notes & Concept Scope This is Mnih and Gregor’s NVIL method, not all variational inference, a particular trained belief network, the wake-sleep recognition update, or the reparameterization-gradient approach used in stochastic gradient variational Bayes. It uses a shared feedforward inference model across observations and does not require a separate optimized set of local variational parameters for every observation. Exact sampling refers to its chosen variational distribution, not automatically to the true posterior. 3 Claims
Mechanism #method
Let P_theta(x,h) be the generative joint model and Q_phi(h|x) an inference-network distribution that can be sampled and evaluated efficiently. For each observed x, maximize the bound E_Q[log P_theta(x,h)-log Q_phi(h|x)]. Draw latent samples from Q. The raw model-gradient estimator averages d log P_theta(x,h)/d theta; the raw inference-gradient estimator averages the learning signal l=log P_theta(x,h)-log Q_phi(h|x) times d log Q_phi(h|x)/d phi. Its score expectation is zero, so baselines independent of the current latent sample conditional on x can be subtracted without changing the raw gradient expectation. The method fits an input-dependent neural baseline and maintains a scalar running center. It also divides the centered signal by max(1,sqrt(v)), where v is a running variance estimate, to adapt the update scale. In the supplement’s concrete minibatch ordering, subtract the input baseline, compute batch signal mean and variance, update the running center and variance using those batch statistics, then form centered/scaled inference updates and baseline updates; the model gradient remains unweighted by this signal. For layered factorizations, local learning signals omit terms that are independent of the relevant sampled descendants under the conditional score expectation, with separate baselines and variance estimates.

Scope #batch-ordering
The supplementary algorithm first samples the minibatch and computes baseline-adjusted learning signals, then updates the running mean and variance from that same minibatch before using them to center and scale its inference gradients. This practical order is distinct from the main-text identity for a baseline independent of the sampled latent value.

Scope #objective-distinction
The inference network is trained from observations and its own latent samples toward the variational objective. The source contrasts this with wake-sleep’s recognition update from model-generated samples and with pathwise gradients for continuous-variable variational methods. These distinctions do not make NVIL synonymous with every use of REINFORCE.

⚠️ Curated Limitations & Negative Results

  • A sample from Q is exact for Q while posterior inference remains approximate unless Q matches the model posterior. The variational-family capacity and optimization outcome affect the gap to the marginal log likelihood.
  • Unbiasedness of the raw score estimator and subtraction of a conditionally sample-independent baseline do not automatically certify the final adaptive update. The supplement updates running statistics with the same minibatch before applying them, and normalization changes the update scale. Current-batch centering can introduce finite-sample bias; no blanket unbiasedness claim is made for that full practical procedure.
  • The input baseline is trained using a squared-signal objective, which the source explicitly distinguishes from maximum variance reduction that accounts for score magnitude. A learned baseline need not improve variance in every setting.
  • The method needs tractable sampling and evaluation of Q, evaluation of the joint P and differentiable log-probability parameters. It does not require differentiating the sampled discrete latent value, but support, zero probabilities and differentiation-under-expectation conditions still matter.
  • Local-signal simplifications require the stated conditional independences. Arbitrarily dropping latent-dependent log terms can change the expected gradient.
  • The variational bound and stochastic gradient formulation do not guarantee global optimization, exact posterior recovery or universally faster inference. Reported dataset comparisons and the complete author implementation are not certified here.
