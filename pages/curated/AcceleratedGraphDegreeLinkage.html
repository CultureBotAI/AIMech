Accelerated graph degree linkage

Algorithms AIMech:AcceleratedGraphDegreeLinkage DRAFT
Aliases: AGDL
An approximate graph degree linkage algorithm that selects merges from maintained cluster-neighbor sets and updates those sets locally instead of searching every current cluster pair.
Identity Notes & Concept Scope AGDL is Zhang et al.’s named candidate-restricted approximation to GDL, not merely the exact additive-update implementation GDL-U. It retains the GDL affinity but can omit the globally best pair after approximate neighbor-set updates. It is distinct from JULE’s representation-learning procedure. Claims & Grounded Evidence

1 Claim
Mechanism #method
Use the same fixed directed neighbor graph, weak-component initialization and symmetric product-of-degree affinity as GDL. Initialize a Kc-nearest cluster set for each cluster. Search only pairs for which at least one cluster belongs to the other’s maintained neighbor set, and merge the highest-affinity eligible pair A,B. For any existing cluster whose set contains A or B, add A union B and compute the new pair affinity. Build the merged cluster’s set by choosing Kc nearest clusters from the union of the two old neighbor sets. Remove A and B from remaining neighbor sets and delete their sets. Repeat until the target cluster count. These local updates rely on heuristic persistence of cluster-neighbor relationships, rather than recomputing every nearest-cluster set exactly.
  • supports Source: Graph Degree Linkage: Agglomerative Clustering on a Directed Graph · Locator: Section 3.4, PDF p. 8, Accelerated GDL; supplement Section 6, p. 15, Algorithm 3; Section 7, p. 16, AGDL complexity assumptions

⚠️ Curated Limitations & Negative Results

  • The method approximates global merge selection, not the defining degree-product formula. It has no asserted guarantee of reproducing exact GDL merges or recovering a globally optimal partition.
  • Kc and the initial neighbor sets affect which pairs remain eligible. The source’s local-update assumptions can fail; an omitted pair need not re-enter through an exhaustive search.
  • The supplement’s quadratic complexity argument assumes small initial clusters, fixed K/K0/Kc and a bound on how many other clusters include a merged cluster in their neighbor sets. A universal worst-case quadratic guarantee is not inferred from that argument.
  • Graph construction, initialization, irreversibility and prescribed cluster count have the same scope limitations as GDL. No implementation, speedup measurement or clustering benchmark was reproduced.
