Simple recursive best-first search

Algorithms AIMech:SimpleRecursiveBestFirstSearch DRAFT
Aliases: SRBFS
A recursive best-first search procedure that initializes generated children from their static evaluation values, explores the best child within an alternative-derived bound, and backs up returned values to decide which subtree to revisit.
Identity Notes & Concept Scope SRBFS is Korf’s simple recursive algorithm, not an alias for the full RBFS refinement. It resets regenerated children to their static values instead of conditionally inheriting a previously backed-up parent value. This distinction can cause additional regeneration. Mechanism #search-procedure
Initialize each child’s stored value from its static evaluation and keep the children ordered by those values. Recurse into the best child with the smaller of the current bound and the next-best sibling’s value, then replace that child’s stored value with the returned value and reorder. Backtrack when the best available child exceeds the bound; a dead end returns infinity.
  • supports Source: Linear-Space Best-First Search: Summary of Results · Locator: Simple Recursive Best-First Search, printed pp. 534–535 / PDF pp. 2–3; SRBFS pseudocode and Figure 3
Scope #refinement-boundary
The full RBFS refinement preserves previously backed-up information when regenerating children. The paper distinguishes ordering all SRBFS expansions from ordering first-time RBFS expansions, because RBFS traverses previously expanded paths in depth-first order.

⚠️ Curated Limitations & Negative Results

  • Resetting regenerated child values can repeat already explored work before reaching a previously established frontier. Full RBFS adds a conditional inheritance rule to mitigate this.
  • Path cycles and termination require appropriate graph and evaluation assumptions or explicit path checks; the displayed procedure is not a complete production implementation for every graph.
  • The recursive representation retains the path and sibling alternatives. Linear-in-depth memory is conditional on bounded branching and fixed-size node information; it is not full-frontier storage.
