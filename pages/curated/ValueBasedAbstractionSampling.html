Value-based abstraction functions for abstraction sampling

Mathematical Methods AIMech:ValueBasedAbstractionSampling DRAFT
Aliases: Value-based abstraction sampling
A family of graphical-model sampling abstractions that assigns a positive scalar value to each current search node and partitions nodes in value order into abstract states used by the surrounding importance-weighted representative sampler.

Retain one parameterized family of ordered value-based abstraction functions. HB, HRB and QB choose different scalar node values, while seven schemes determine groups. These are components used by AOAS, not an alias for its traversal/weight-backup estimator. Generic tree sampling describes weighted representative estimation rather than this partition catalog. K-means uses iterative centroid assignment, CURE uses scattered representatives and agglomeration, and neither identifies this sampling-abstraction family. Claims & Grounded Evidence

6 Claims
Mechanism #three-node-value-classes
The three specified value functions are HB: mu=h, HRB: mu=h*r, and QB: mu=w*g*h*r. Here h estimates the remaining subtree value, r estimates ancestral off-path branching mass, g is accumulated path cost, and w is the current inherited importance weight. The abstraction groups nodes; representative selection and inverse-probability correction remain operations of the surrounding AS algorithm. QB is the unnormalized proposal mass, not a learned reinforcement-learning action value.

Mechanism #ordered-partition-catalog
The paper combines each value class with seven partition schemes. simpleVB sorts and makes groups whose cardinalities differ by at most one. minVarVB uses greedy Ward agglomeration. equalDistVB greedily fills ascending-value groups against cumulative total-mass thresholds; equalDistVB2 reverses the sort; equalDistVB3 also forces one node into each new group; equalDistVB4 recomputes a threshold from remaining mass and remaining groups. randVB selects distinct cut positions uniformly in the value-sorted node sequence. The supplement first returns singletons when the node count does not exceed the positive integer state cap. The seven schemes and three value functions specify 21 configurations of this family.

Scope #exactness-versus-proxy-similarity
Theorem 4.1 gives a sufficient exactness condition for AOAS: within each state h*r is a common positive multiple of the true Z*R for positive contributions, with zero estimated product for zero true product. This uses unknown subtree and ancestral-branching masses. Grouping similar h, h*r or proposal values is an implementable heuristic inspired by that condition, and does not establish that the unknown ratios agree. Actual representative probabilities must retain support for positive contributions.

Limitation #partition-boundaries
Mass-threshold groups need not have exactly equal mass or use all available states. The paper’s skewed eight-node example leaves three empty groups for equalDistVB and two for equalDistVB2. Greedy Ward merging is not a general certificate of the globally best fixed-count partition, and minimizing within-group proxy dispersion does not certify minimum variance of the final estimator. randVB preserves value order; the separate simpleRand procedure shuffles nodes before balanced grouping and belongs to a different random-only family.

Scope #partition-cost-scope
For N current nodes and constant-cost value evaluation, the paper states O(N log N) time and O(N) space for the sorting-based schemes, and O(N squared) time and space for its described accelerated minVarVB approach. These are abstraction-step costs under the stated implementation assumptions. They exclude heuristic construction, child generation and the full cost of producing enough probes; fixed state cap or sample count does not equal fixed runtime.

Limitation #evaluation-and-source-limits
The empirical study compares these configurations within AOAS on five graphical-model benchmark families, using weighted mini-bucket heuristics. For large problems without exact Z, it uses an estimated reference from long RAND runs. Tables select abstraction granularity by benchmark error, and a weighted mini-bucket value substitutes for runs without a positive estimate. Main text describes a 10-hour reference, while appended time-series legends label it 100 hours; an exact-DBN supplementary table also labels a different time budget from the main exact-problem setting. These inconsistencies and the estimated reference prevent treating the results as a uniform independently verified accuracy guarantee. No universal winning configuration or fresh direct comparison against all historical external samplers is asserted.

⚠️ Curated Limitations & Negative Results

  • The maintained identity is the parameterized abstraction-function family, not the complete AOAS estimator, all clustering methods, or a trained model. HB, HRB and QB are value choices; their 21 combinations are not asserted as aliases or 21 separate additions.
  • The record uses finite positive value inputs and a positive integer state cap. Ties require a consistent sorting convention; zero/all-zero values and numerical overflow need implementation treatment. The literal iff in Definition 4.1 does not handle equal state indices or tied values as written. The maintained description follows the ordered grouping procedures and does not certify that biconditional.
  • A finite pair with true contributions 1 and 9 and equal proposal masses has mean 10 and variance 64, despite zero dispersion of the proxy. Proposals proportional to 1 and 9 give constant estimate 10. These examples illustrate the difference between proxy similarity and the source’s exact proportionality condition.
  • For values 1, 2, 3, 4, 6, a specified greedy Ward tie order yields groups {1,2,3,4}/{6} with squared-deviation sum 5, while {1,2,3}/{4,6} gives 4. This refutes a universal global-optimum interpretation of greedy merging; it is not a run of the authors’ minVar implementation or a claim about its tie policy. The source’s use of Var does not fully specify normalization.
  • All 41 pages of the proceedings file, including the 30-page appended supplement, were visually read. Author-hosted main/supplement text was compared after ignoring page-number lines; only the first-page proceedings footer differed. The separate 19-page extended background and OpenReview revisions were not fully read. Partial earlier static code reading is documented separately; no author program, training run or benchmark was executed.
