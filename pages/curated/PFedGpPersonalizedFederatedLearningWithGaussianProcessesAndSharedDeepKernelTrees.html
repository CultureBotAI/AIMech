pFedGP (Personalized Federated Learning with Gaussian Processes and Shared Deep Kernel Trees)

Algorithms AIMech:PFedGpPersonalizedFederatedLearningWithGaussianProcessesAndSharedDeepKernelTrees DRAFT
Aliases: pFedGP, Personalized Federated Learning with Gaussian Processes, pFedGP-IP-data, pFedGP-IP-compute
A Bayesian personalized federated learning algorithm (Achituve, Shamsian, Navon, Chechik, & Fetaya 2021, Sections 3-4, Equations 1-14, Theorem 1, Algorithm 1) that learns a shared deep neural network feature extractor g_theta across all clients while fitting a separate personalized Gaussian Process (GP) classifier with Pólya-Gamma (PG) data augmentation on each client's latent embeddings z_i = g_theta(x_i), extending binary PG-augmented GP classification to C-class classification via a full binary decision tree of C - 1 internal GP nodes (where node m models p(y_m = 1 | x, omega_m) with conditionally Gaussian posterior p(f_m | X, y_m, omega_m) = N(f_m | mu_m, Sigma_m), Sigma_m = (K_m^{-1} + Omega_m)^{-1}, mu_m = Sigma_m kappa_m, kappa_m = y_m - 1/2, Equations 1-6), and introducing two inducing-point extensions — pFedGP-IP-data (which optimizes local inducing inputs X_bar in input space to regularize zero-shot adaptation) and pFedGP-IP-compute (which applies the Fully Independent Training Conditional (FITC) approximation K_{NN} approx Q_{NN} + diag(K_{NN} - Q_{NN}), Q_{NN} = K_{NM} K_{MM}^{-1} K_{MN} to reduce cubic O(N^3) matrix inversion to O(M^2 N + M^3), Equations 9-12).
Identity Notes & Concept Scope Distinct from pFedBayes (AIMech:PFedBayesPersonalizedFederatedLearningViaVariationalBayesianInference, Zhang et al. 2022), which places factorized Gaussian variational posteriors over neural network weights rather than non-parametric Gaussian Processes with Pólya-Gamma augmentation over a shared deep kernel; and distinct from FedPA (AIMech:FedPaFederatedPosteriorAveragingViaLocalMcmcAndShrinkageCovariance, Al-Shedivat et al. 2021), which aggregates approximate client parameter posteriors into a single global parameter vector.

Claims & Grounded Evidence

4 Claims
Mechanism #r472-polya-gamma-gp-tree-predictive-marginal-mechanism
Conditioned on Pólya-Gamma auxiliary variables omega_i ~ PG(1, f(x_i)), each binary GP node m in the C-class hierarchical tree yields an exact Gaussian posterior N(f_m | Sigma_m(y_m - 1/2), Sigma_m) with Sigma_m = (K_m^{-1} + diag(omega_m))^{-1}, Gaussian predictive latent distribution N(f_* | mu_*, sigma_*^2) (Equations 4-5), and factorized class probability P(y_* = c | x_*, X, y, Omega) = prod_{m in Path_c} (int Psi(f_m^*) N(f_m^* | mu_m^*, sigma_m^{*2}) df_m^*)^{y_{c,m}} (1 - int ...)^{1 - y_{c,m}} (Equation 7) (Achituve et al. 2021, Section 4.1).
  • supports Source: Personalized Federated Learning with Gaussian Processes · Locator: Sections 3.2 & 4.1 (Equations 1-7), pp. 3-5
Mechanism #r472-pac-bayes-generalization-and-fitc-inducing-points-mechanism
Theorem 1 establishes a PAC-Bayes generalization bound for each client's GP tree scales with (1 / m_i) sum_{j in Y} KL(Q_i(f_j) || P(f_j)), motivating shared deep kernel optimization via predictive marginal likelihood; pFedGP-IP-compute further replaces K_{NN} with the FITC low-rank-plus-diagonal covariance Q_{NN} + diag(K_{NN} - Q_{NN}) over M << N inducing points to achieve O(M^2 N + M^3) complexity (Achituve et al. 2021, Sections 4.2-4.3, Equations 9-14, Theorem 1).
  • supports Source: Personalized Federated Learning with Gaussian Processes · Locator: Sections 4.2-4.3 (Equations 9-14, Theorem 1), pp. 5-7
Application #r472-uncertainty-calibrated-personalized-classification-application
Applied to personalized federated classification, novel-client adaptation without gradient updates, and out-of-distribution uncertainty calibration (Expected Calibration Error) on CIFAR-10, CIFAR-100, and CINIC-10 (Achituve et al. 2021, Section 5, Tables 1-4).
  • supports Source: Personalized Federated Learning with Gaussian Processes · Locator: Section 5 (Experiments, Tables 1-4, Figure 2), pp. 7-9
Limitation #r472-tree-node-scaling-and-gibbs-sampling-overhead-limitation
Requires fitting C - 1 binary GP classifiers along the class hierarchy tree and running block Gibbs sampling over Pólya-Gamma variables omega_m and Gaussian latents f_m during local updates, which increases per-step computational cost when the number of classes C or local dataset size N_i is large without inducing-point approximation (Achituve et al. 2021, Sections 4.1-4.2).
  • supports Source: Personalized Federated Learning with Gaussian Processes · Locator: Sections 4.1-4.2, pp. 4-6

⚠️ Curated Limitations & Negative Results

  • Full GP inference scales cubically O(N_i^3) in local dataset size N_i per tree node unless the FITC inducing-point variant (pFedGP-IP-compute) is used.
  • Multi-class classification requires constructing and evaluating C - 1 binary GP classifiers arranged in a hierarchical tree.
