MELoRA

Algorithms AIMech:MELoRA DRAFT
Aliases: Mini-Ensemble Low-Rank Adapters, Block-Diagonal Mini-Ensemble LoRA, MELoRA Parameter-Efficient Fine-Tuning
A parameter-efficient fine-tuning algorithm that partitions the input and output feature dimensions of a frozen linear layer into n disjoint sub-vectors and trains n mini-LoRA adapters arranged as a block-diagonal weight update matrix, preserving a cumulative matrix rank of r while reducing trainable parameters and adapter FLOPs by a factor of n relative to a single rank-r LoRA adapter.
Identity Notes & Concept Scope Distinct from AIMech:LowRankAdaptation (LoRA), which applies a single dense low-rank update B A in R^{d_{out} x d_{in}} of rank r using r(d_{in} + d_{out}) parameters, and from multi-head or mixture-of-LoRA architectures that sum multiple full-dimension low-rank matrices across the entire feature space. MELoRA (Pengjie Ren, Chengshun Shi, Shiguang Wu, Mengqi Zhang, Zhaochun Ren, Maarten de Rijke, Zhumin Chen, and Jiahuan Pei, ACL 2024, pp. 3052-3064, arXiv:2402.17263) splits the input vector x in R^{d_{in}} into n contiguous segments x_i in R^{d_{in}/n} and applies an independent mini-LoRA module B_i A_i of inner rank r/n (with A_i in R^{(r/n) x (d_{in}/n)} and B_i in R^{(d_{out}/n) x (r/n)}) to each segment, concatenating the outputs. Equivalently, the overall weight update is the block-diagonal matrix Delta_W = diag(B_1 A_1, ..., B_n A_n) in R^{d_{out} x d_{in}}. Because the rank of a block-diagonal matrix equals the sum of the ranks of its diagonal blocks, rank(Delta_W) = sum_{i=1}^n rank(B_i A_i) <= n * (r/n) = r, while the total number of trainable parameters is n * (r/n) * (d_{in}/n + d_{out}/n) = r(d_{in} + d_{out}) / n.

Claims & Grounded Evidence

4 Claims
Mechanism #melora-block-diagonal-mini-adapter-concatenation
MELoRA partitions input activations x in R^{d_{in}} into n sub-vectors x_i in R^{d_{in}/n}, passes each sub-vector through a distinct mini-LoRA adapter B_i A_i with inner dimension r/n, and concatenates the resulting n sub-vectors of dimension d_{out}/n, which is algebraically equivalent to adding a block-diagonal update Delta_W = diag(B_1 A_1, ..., B_n A_n) to the frozen weight matrix W_0.
  • supports Source: MELoRA: Mini-Ensemble Low-Rank Adapters for Parameter-Efficient Fine-Tuning · Locator: Section 3.1 (MELoRA Architecture) & Equations (2)-(4), pp. 3054-3055
Mechanism #melora-additive-block-rank-with-one-over-n-parameter-cost
Because the rank of a block-diagonal matrix is the sum of the ranks of its diagonal blocks, n mini-LoRA blocks of rank r/n achieve a total update rank up to r using only r(d_{in} + d_{out}) / n trainable parameters—or equivalently achieve an n-fold higher rank n r under the same parameter budget as a rank-r LoRA adapter.
  • supports Source: MELoRA: Mini-Ensemble Low-Rank Adapters for Parameter-Efficient Fine-Tuning · Locator: Section 3.2 (Theoretical Analysis: Rank, Parameters, and Complexity), p. 3055, Table 1
Application #melora-application-glue-and-llm-instruction-tuning
Evaluated on RoBERTa-base across GLUE tasks and LLaMA-2-7B across instruction-following, commonsense reasoning, and mathematical reasoning benchmarks, MELoRA consistently outperforms LoRA while using 8x fewer trainable parameters on GLUE and 2x to 4x fewer parameters on LLM instruction tuning.
  • supports Source: MELoRA: Mini-Ensemble Low-Rank Adapters for Parameter-Efficient Fine-Tuning · Locator: Section 4 (Experiments), Tables 2-4, pp. 3056-3058
Limitation #melora-limitation-zero-off-diagonal-cross-block-feature-coupling
Because Delta_W = diag(B_1 A_1, ..., B_n A_n) is strictly block-diagonal, the adapter update cannot directly couple an input feature in block i with an output feature in block j != i within a single linear layer, relying instead on the frozen dense base matrix W_0 and subsequent layers for cross-block mixing.
  • supports Source: MELoRA: Mini-Ensemble Low-Rank Adapters for Parameter-Efficient Fine-Tuning · Locator: Section 3.1 & Limitations section, pp. 3054, 3061

⚠️ Curated Limitations & Negative Results

  • The block-diagonal structure zeroes out off-diagonal adapter entries between distinct feature slices (i != j), preventing direct cross-slice adaptation within a single linear projection.
  • The input dimension d_{in}, output dimension d_{out}, and cumulative rank r must all be divisible by the number of mini-LoRA blocks n (or require uneven block partitioning).
