MOON (Model-Contrastive Federated Learning)

Algorithms AIMech:MoonModelContrastiveFederatedLearning DRAFT
Aliases: MOON, Model-Contrastive Federated Learning, Model-Level Contrastive Learning for Federated Optimization
A federated learning algorithm for non-IID data (Li, He, & Song 2021, Algorithm 1) that corrects local representation drift by augmenting each client's supervised cross-entropy loss l_sup(w_i^t; (x, y)) with a model-level InfoNCE contrastive loss l_con(w_i^t; w^t, w_i^{t-1}, x) = -log(exp(sim(z, z_glob) / tau) / (exp(sim(z, z_glob) / tau) + exp(sim(z, z_prev) / tau))) weighted by mu > 0, where z = R_{w_i^t}(x), z_glob = R_{w^t}(x), and z_prev = R_{w_i^{t-1}}(x) are the projection-head feature representations extracted from the current local model w_i^t, the current global server model w^t (positive pair), and the client's own previous-round model w_i^{t-1} (negative pair) using cosine similarity sim(., .) and temperature tau > 0.
Identity Notes & Concept Scope Distinct from parameter-space drift regularization methods such as FedProx (AIMech:FedProxProximalHeterogeneousFederatedOptimization, which penalizes the Euclidean parameter distance (mu / 2) ||w_i^t - w^t||_2^2 without using feature representations or previous-round negative models w_i^{t-1}) and SCAFFOLD (AIMech:ScaffoldStochasticControlledAveragingForFederatedLearning, which applies gradient control variates), and from data-level contrastive learning methods such as SimCLR and MoCo, which contrast augmented views of different input samples rather than representations of the same input x across three distinct models (w_i^t, w^t, w_i^{t-1}).

Claims & Grounded Evidence

4 Claims
Mechanism #r413-model-level-infonce-representation-alignment-and-fedavg-boundary
For each local input x, MOON pulls the current local projection representation z = R_{w_i^t}(x) toward the global representation z_glob = R_{w^t}(x) and pushes it away from the previous-round local representation z_prev = R_{w_i^{t-1}}(x) via l_con = -log(exp(sim(z, z_glob)/tau) / (exp(sim(z, z_glob)/tau) + exp(sim(z, z_prev)/tau))) (Eq. 3); in the ideal no-drift limit z_glob = z_prev, l_con equals the constant -log(1/2) = log 2 with zero gradient, recovering standard FedAvg (Section 3.3).
  • supports Source: Model-Contrastive Federated Learning · Locator: Section 3.2-3.3 Method & Connections with Contrastive Learning (Eqs. 1-4, Table 1), pp. 10715-10717
Mechanism #r413-mlp-projection-head-representation-quality-and-non-iid-skew-robustness
Inserting a 2-layer MLP projection head before the output classification layer to compute z, z_glob, and z_prev increases inter-class t-SNE representation margins on non-IID Dirichlet partitions and consistently outperforms FedAvg, FedProx, SCAFFOLD, and L2 representation-distance penalties without negative pairs w_i^{t-1}.
  • supports Source: Model-Contrastive Federated Learning · Locator: Section 3.1 Motivation (Figure 1) & Section 4.2-4.6 Ablation Studies (Tables 2-7, Figures 3-5), pp. 10714-10720
Limitation #r413-three-model-forward-pass-and-stateful-client-memory-limitation
Each local training step requires three forward passes through the feature encoder and projection head (for w_i^t, w^t, and w_i^{t-1}) and requires clients to store both the global model w^t and their previous-round local model w_i^{t-1} in memory.
  • supports Source: Model-Contrastive Federated Learning · Locator: Section 3.2 (Algorithm 1, Figure 2) & Appendix A Overhead Analysis
Application #r413-non-iid-cifar10-cifar100-and-tiny-imagenet-vision-application
Applied to federated image classification on Dirichlet-partitioned CIFAR-10, CIFAR-100, and Tiny-ImageNet with CNN and ResNet-50 backbones.
  • supports Source: Model-Contrastive Federated Learning · Locator: Section 4 Experiments (Tables 2-5, Figures 3-4), pp. 10717-10719

⚠️ Curated Limitations & Negative Results

  • Requires three encoder/projection forward passes per local training batch (current local, global, and previous local models).
  • Relies on persistent client participation state to access the previous-round local model w_i^{t-1}.
