Globally Convergent Regularization Homotopy and Nyström Newton Method for Generalized Self-Concordant Losses

Mathematical Methods AIMech:GloballyConvergentRegularizationHomotopyAndNystromNewtonForGeneralizedSelfConcordantLosses DRAFT
Aliases: Globally Convergent Newton Methods for Ill-Conditioned Generalized Self-Concordant Losses (Marteau-Ferey, Bach, & Rudi 2019), Two-Phase Dikin-Ellipsoid Regularization Continuation Approximate Newton Scheme, Nyström Preconditioned Conjugate Gradient Approximate Newton Method for Generalized Self-Concordant Kernel Learning
Globally Convergent Regularization Homotopy and Nyström Newton Method for Generalized Self-Concordant Losses is a second-order convex optimization and non-parametric kernel learning methodology introduced by Marteau-Ferey, Bach, and Rudi (2019, NeurIPS 32, arXiv:1907.01771v2) for minimizing regularized empirical and Hilbert-space objectives f_lambda(x) = f(x) + (lambda/2)||x||^2 where (f, G) is generalized self-concordant: nabla^{(3)} f(x)[h, k, k] <= sup_{g in G} |g . h| nabla^2 f(x)[k, k] with R = sup_{g in G} ||g|| < infinity (covering logistic regression, softmax regression, bounded-feature GLMs, and log-cosh robust regression). Defining the regularized Hessian H_lambda(x) = nabla^2 f(x) + lambda I, the Newton decrement nu_lambda(x) = ||nabla f_lambda(x)||_{H_lambda^{-1}(x)}, the local Dikin radius r_lambda(x) = 1 / sup_{g in G} ||g||_{H_lambda^{-1}(x)} >= sqrt(lambda)/R, and the Dikin ellipsoid D_lambda(c) = {x : nu_lambda(x) <= c r_lambda(x)}, Lemma 2 (Lemma 11) establishes that inside D_lambda(1/7), (1/4) nu_lambda(x)^2 <= f_lambda(x) - f_lambda(x_lambda^*) <= nu_lambda(x)^2, exact Newton steps converge quadratically nu_lambda(x_t) <= 2^{-(2^t - 1)} nu_lambda(x_0), and rho-relative approximate Newton steps tilde_Delta_t in LinApprox(H_lambda(x_t), nabla f_lambda(x_t), rho) with ||tilde_Delta_t - Delta_lambda(x_t)||_{H_lambda(x_t)} <= rho nu_lambda(x_t) and rho <= 1/7 converge linearly nu_lambda(x_t) <= 2^{-t} nu_lambda(x_0). To enter the small Dikin ellipsoid D_lambda(1/7) without polynomial condition-number dependence sqrt(L/lambda), Lemma 3 (Lemma 13) proves the continuation inclusion D_mu(c/3) subseteq D_{q mu}(c), motivating a two-phase globalization scheme (Theorem 1): Phase I starts at x_0 = 0 and mu_0 = 7 R ||nabla f(0)|| in D_{mu_0}(1/7) and performs t = 2 steps of rho-relative approximate Newton per stage followed by the adaptive regularization decrease mu_{k+1} = q_{k+1} mu_k with q_{k+1} = (1/3 + 7 R ||x_{k+1}||) / (1 + 7 R ||x_{k+1}||), reaching D_lambda(1/7) in K <= floor((3 + 11 R ||x_lambda^*||) log(7 R ||nabla f(0)|| / lambda)) stages; Phase II performs T = ceil(log_2 sqrt(1 vee (lambda epsilon^{-1} / R^2))) steps at lambda to guarantee f_lambda(x_hat) - f_lambda(x_lambda^*) <= epsilon. In non-parametric reproducing kernel Hilbert space learning (Section 4, Algorithm 1, Theorems 3-4 and 6-7), combining Nyström projection onto M = O_tilde(df_lambda) leverage-score landmarks with Q = O_tilde(df_lambda) Hessian subsampling and tau = 3 iterations of Cholesky-preconditioned conjugate gradient achieves minimax optimal excess risk L(g_{Q,M,lambda}) - L(g^*) <= c_0(df_lambda/n + b_lambda^2 + epsilon) log(1/delta) in O_tilde(n df_lambda) time and O_tilde(df_lambda^2) memory, completely independent of the condition number L/lambda.

Mechanism #generalized-self-concordant-dikin-ellipsoid-and-three-approximate-newton-regimes
For a generalized self-concordant function (f, G) on a Hilbert space H satisfying nabla^{(3)} f(x)[h, k, k] <= t_f(h) nabla^2 f(x)[k, k] with t_f(h) := sup_{g in G} |g . h| <= R ||h|| (Definitions 1 and 3-4), the regularized objective f_lambda(x) = f(x) + (lambda/2) ||x||^2 with Hessian H_lambda(x) = nabla^2 f(x) + lambda I satisfies e^{-t(h)} H_lambda(x) <= H_lambda(x + h) <= e^{t(h)} H_lambda(x) (Eq. 17), gradient bracketing phi_under(t(h)) ||h||_{H_lambda(x)} <= ||nabla f_lambda(x + h) - nabla f_lambda(x)||_{H_lambda^{-1}(x)} <= phi_over(t(h)) ||h||_{H_lambda(x)} (Eq. 18), and function bracketing with psi(t) = (e^t - t - 1)/t^2 (Proposition 2). Inside the Dikin ellipsoid D_lambda(c) := {x : nu_lambda(x) <= c r_lambda(x)} with c <= 1/7, Lemma 5 and Lemma 6 (Lemma 2) prove t(x - x_lambda^*) <= -log(1 - c) and (1/4) nu_lambda(x)^2 <= f_lambda(x) - f_lambda(x_lambda^*) <= nu_lambda(x)^2. For an approximate Newton increment tilde_Delta satisfying ||tilde_Delta - Delta_lambda(x)||_{H_lambda(x)} <= rho nu_lambda(x) + epsilon_0 with rho <= 1/7 and tilde_epsilon_0 = epsilon_0 / r_lambda(x) <= 1/21, Lemmas 8-11 and Propositions 4-5 establish three regimes: quadratic contraction (10/3) tilde_nu_lambda(x - tilde_Delta) <= ((10/3) tilde_nu_lambda(x))^2 when tilde_nu_lambda(x) >= rho and tilde_nu_lambda(x)^2 >= tilde_epsilon_0 (yielding nu_lambda(x_t) <= 2^{-(2^t - 1)} nu_lambda(x_0) for exact Newton); linear contraction tilde_nu_lambda(x - tilde_Delta) <= (10 rho / 3) tilde_nu_lambda(x) <= (10/21) tilde_nu_lambda(x) <= (1/2) tilde_nu_lambda(x) when rho >= tilde_nu_lambda(x) and rho tilde_nu_lambda(x) >= tilde_epsilon_0 (yielding nu_lambda(x_t) <= 2^{-t} nu_lambda(x_0) for rho-relative ANM); and limiting precision nu_lambda(x - tilde_Delta) <= 3 epsilon_0. Moreover, Lemma 12 proves that inside D_lambda(1/30), a single 1/20-relative Hessian approximation at x_0 yields 1/7-relative approximate Newton steps for all x in D_lambda(1/30).

Mechanism #two-phase-regularization-homotopy-dikin-inclusion-and-global-convergence
Lemma 3 and Lemma 13 prove the Dikin-ellipsoid continuation inclusion: if nu_mu(x) <= (c/3) sqrt(mu)/R (or x in D_mu(c/3)) for c < 1, then setting tilde_mu = q mu with q >= (1/3 + R sqrt(mu) ||x||_{H_mu^{-1}(x)} / c) / (1 + R sqrt(mu) ||x||_{H_mu^{-1}(x)} / c) (and in particular q >= (1/3 + R ||x|| / c) / (1 + R ||x|| / c)) guarantees nu_{tilde_mu}(x) <= c sqrt(tilde_mu)/R (or x in D_{tilde_mu}(c)). Combining this with Lemma 14 and Corollary 3 (7 R ||x|| <= 7 R ||x_mu^*|| + 1 for c = 1/7), Proposition 6 and Theorem 1 establish that Phase I of the Proposed Globalization Scheme — initialized at x_0 = 0 and mu_0 = 7 R ||nabla f(0)|| so R nu_{mu_0}(x_0)/sqrt(mu_0) <= 1/7 (Remark 2) and executing t = 2 steps of rho-relative ANM (rho <= 1/7) followed by mu_{k+1} = q_{k+1} mu_k with q_{k+1} = (1/3 + 7 R ||x_{k+1}||) / (1 + 7 R ||x_{k+1}||) — maintains the invariant R nu_{mu_k}(x_k)/sqrt(mu_k) <= 1/7 for all k and enters D_lambda(1/7) in K <= floor((3 + 11 R ||x_lambda^*||) log(7 R ||nabla f(0)|| / lambda)) stages (or K <= (9/2 + 15 sup_{lambda <= mu <= mu_0} R sqrt(mu) ||x_mu^*||_{H_mu^{-1}(x_mu^*)}) log(mu_0/lambda) under the Hessian-norm variant of Proposition 7), after which Phase II performs T = ceil(log_2 sqrt(1 vee (lambda epsilon^{-1} / R^2))) steps of ANM on f_lambda to achieve f_lambda(x_hat) - f_lambda(x_lambda^*) <= epsilon.

Mechanism #nystrom-subspace-projection-and-projector-capacity-excess-risk-preservation
For an orthogonal projector P: H -> H_P with projector capacity C_P(x, lambda) := ||H(x)^{1/2}(I - P)||^2 / lambda and source term s_lambda := lambda ||x_lambda^*||_{H_lambda^{-1}(x_lambda^*)}, Proposition 15 (Appendix G.2, p. 55) proves that if s_lambda / r_lambda(x_lambda^*) <= 1/4, C_P(x_lambda^*, lambda) <= 1/120, and nu_{P,lambda}(x) <= r_{P,lambda}(x)/2, then the full-space Newton decrement is bounded by nu_lambda(x) <= 3(nu_{P,lambda}(x) + s_lambda) and ||x - x_lambda^*|| <= 7 lambda^{-1/2}(nu_{P,lambda}(x) + s_lambda). Scope #preconditioned-conjugate-gradient-approximate-newton-and-condition-free-kernel-complexity
To compute 1/7-relative approximate Newton steps on the Nyström-projected objective L_hat_{M,mu}(beta) without forming the O(n M^2) Hessian H_hat_{M,mu}(beta) = (1/n) T^{-T} K_{Mn} D_n(beta) K_{nM} T^{-1} + mu I_M, Proposition 12 (Appendix D.5.1, pp. 42-44) subsamples Q points (Q = O_tilde(1/lambda) uniformly or Q = O_tilde(df_lambda) via leverage scores) to build the Cholesky preconditioner B^T B = (1/Q) T^{-T} K_{MQ} D_Q K_{QM} T^{-1} + mu I_M satisfying (1/2) B^T B <= H_hat_{M,mu}(beta) <= (3/2) B^T B (condition number <= 3, Equation 34), so that tau = 3 iterations of preconditioned conjugate gradient achieve relative error rho <= 2((sqrt(3) - 1)/(sqrt(3) + 1))^3 approx 0.03896 <= 1/7 in O(n M + M^2 Q + M^3) time and O(n + M^2) memory. ⚠️ Curated Limitations & Negative Results

  • Dependence of Phase-I Stage Count on R ||x_lambda^*|| When No Unregularized Minimizer Exists: In Theorem 1 and Remark 1, the number of Phase-I regularization-decrease stages scales as O((1 + R ||x_lambda^*||) log(R ||nabla f(0)|| / lambda)) (or with sup_{mu >= lambda} R sqrt(mu) ||x_mu^*||_{H_mu^{-1}(x_mu^*)} in Proposition 7). While ||x_lambda^*|| is bounded by a lambda-independent constant whenever an unregularized minimizer x^* exists (as in well-specified RKHS learning under source condition r > 0), in separable parametric logistic regression where no finite unregularized minimizer exists, R ||x_lambda^*|| can grow up to O(R / sqrt(lambda)) in the worst case.
  • Conservative Proof Constants in Indirect Empirical-to-Projected Statistical Decomposition: As noted in Remark 5 (Appendix H.3, p. 67), decomposing the statistical excess risk into separate blocks (population to empirical ERM, and empirical ERM to Nyström-projected approximate ERM) inflates the theoretical constants (K_1 <= 6.0e4, K_2 <= 6.0e6, K_3 <= 810 in Propositions 10 and 18), and in practice (Section 5, Appendix F, p. 51) the safe theoretical factor q_{k+1} is replaced by a fast geometric cooling factor (dividing mu by 1000 per stage).
