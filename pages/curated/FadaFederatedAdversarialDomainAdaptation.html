FADA (Federated Adversarial Domain Adaptation)

Algorithms AIMech:FadaFederatedAdversarialDomainAdaptation DRAFT
Aliases: FADA, Federated Adversarial Domain Adaptation
FADA (Federated Adversarial Domain Adaptation) is a privacy-preserving multi-source unsupervised domain adaptation algorithm for federated learning that transfers knowledge from N decentralized labeled source clients {D_{S_i}}_{i=1}^N to an unlabeled target client D_T without sharing raw client data by combining (1) a dynamic attention mechanism that weights each source client's gradients via softmax over K-means target feature clustering gap-statistics gains I_i^{gain} = I_i^{p-1} - I_i^p, (2) decoupled adversarial domain alignment between each source extractor G_i and target extractor G_t using extracted feature vectors rather than raw samples, and (3) adversarial feature disentanglement with Mutual Information Neural Estimation (MINE) to separate domain-invariant features f_{di} from domain-specific features f_{ds}.
Identity Notes & Concept Scope Introduced by Xingchao Peng, Zijun Huang, Yizhe Zhu, and Kate Saenko in 'Federated Adversarial Domain Adaptation' (ICLR 2020; arXiv:1911.02054). Distinct from centralized multi-source domain adaptation methods (DCTN, Xu et al. CVPR 2018; M3SDA, Peng et al. ICCV 2019; MDAN, Zhao et al. NeurIPS 2018), which require direct co-location of source and target domain examples on a single machine; and distinct from FedBN (Li et al. ICLR 2021), which handles feature shift across labeled federated clients via local batch normalization rather than adapting multiple labeled source clients to an unlabeled target client via dynamic attention and MINE feature disentanglement.

Mechanism #fada-weighted-federated-domain-adaptation-generalization-bound
Theorem 2 (and Theorem 3 in Appendix G) proves that for a target classifier h_T = sum_{i=1}^N alpha_i h_{S_i} formed as a convex combination of N decentralized source hypotheses (alpha_i >= 0, sum_i alpha_i = 1) of VC dimension d with sample size m per domain, the target error is bounded with probability at least 1 - delta by epsilon_T(h_T) <= hat_epsilon_{tilde_S}(sum_i alpha_i h_{S_i}) + sum_{i=1}^N alpha_i ((1/2) hat_d_{H Delta H}(hat_D_{S_i}, hat_D_T) + lambda_i) + 4 sqrt((2 d log(2 N m) + log(4/delta)) / (N m)) (Equations 2 and 9), showing that target generalization depends on the alpha_i-weighted empirical H Delta H divergences between each source client and the target.
  • supports Source: Federated Adversarial Domain Adaptation · Locator: Section 3.1, Theorem 2, Equation (2), pages 3-4; Appendix G, Theorem 3, page 18
Mechanism #fada-dynamic-attention-via-kmeans-gap-statistics-gain
To suppress negative transfer from irrelevant source domains while updating the target model, FADA clusters unlabeled target features into k K-means clusters {C_r}_{r=1}^k, measures intra-cluster dispersion I = sum_{r=1}^k (1 / (2 n_r)) sum_{i,j in C_r} ||f_i^t - f_j^t||_2 (Equation 3), computes each source domain's gap-statistic improvement I_i^{gain} = I_i^{p-1} - I_i^p across training steps, and weights source gradients by Softmax(I_1^{gain}, ..., I_N^{gain}).
  • supports Source: Federated Adversarial Domain Adaptation · Locator: Section 3.1, Equation (3), page 4
Mechanism #fada-decoupled-adversarial-alignment-and-mine-feature-disentanglement
Because source and target data cannot be shared across nodes, FADA aligns each source generator G_i and target generator G_t through a domain identifier DI_i operating solely on extracted feature representations (Equations 4-5), while locally disentangling domain-invariant features f_{di} = D_{di}(G(x)) from domain-specific features f_{ds} = D_{ds}(G(x)) by training class identifier CI_i on f_{di} (Equation 6), adversarially confusing CI_i on f_{ds} via negative entropy L_{ent} = -(1/K) sum_k log CI_i(f_{ds})_k (Equation 7), and minimizing the Mutual Information Neural Estimator (MINE) lower bound I(P, Q) = (1/n) sum_{i=1}^n T(p, q, theta) - log((1/n) sum_{i=1}^n exp(T(p, q', theta))) (Equation 8) between f_{di} and f_{ds}.
  • supports Source: Federated Adversarial Domain Adaptation · Locator: Section 3.2-3.3, Equations (4)-(8) and Figure 2, pages 4-6
Application #fada-empirical-performance-on-digit-five-office-caltech-and-domainnet
Across federated multi-source adaptation benchmarks, FADA improves average target accuracy over the bare FedAvg baseline from 70.6% to 78.9% on Digit-Five (Table 1), from 89.5% to 92.0% on Office-Caltech10 (Table 2), from 67.9% to 75.3% on Office-31 (Table 4), and from 41.2% to 45.2% on DomainNet (Table 3).

⚠️ Curated Limitations & Negative Results

  • Exchanges extracted feature vectors and domain-identifier gradients between each source domain and the target domain during adversarial alignment (Section 3.2), which hides raw images but still exposes intermediate feature activations unless combined with cryptographic or differential-privacy protections.
  • Remains below centralized multi-source domain adaptation upper bounds that have joint access to raw source and target samples (e.g., 78.9% for FADA vs. 85.0% for centralized f-DANN on Digit-Five, Table 1).
