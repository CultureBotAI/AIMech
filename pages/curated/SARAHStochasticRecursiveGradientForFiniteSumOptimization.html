SARAH Stochastic Recursive Gradient for Finite-Sum Optimization

Algorithms AIMech:SARAHStochasticRecursiveGradientForFiniteSumOptimization DRAFT
Aliases: StochAstic Recursive grAdient algoritHm (SARAH), SARAH and SARAH+ Recursive Variance-Reduced Gradient Method, Nguyen-Liu-Scheinberg-Takac Stochastic Recursive Gradient
SARAH Stochastic Recursive Gradient for Finite-Sum Optimization is a variance-reduced first-order stochastic optimization algorithm and practical adaptive variant (SARAH+) introduced by Nguyen, Liu, Scheinberg, and Takac (2017) for finite-sum minimization min_{w in R^d} P(w) = (1/n) sum_{i=1}^n f_i(w) with L-smooth component functions. At the start of each outer loop s, SARAH (Algorithm 1) computes the exact full gradient v_0 = grad P(w_0) and takes one gradient step w_1 = w_0 - eta v_0; in each inner iteration t = 1, ..., m-1, it samples i_t uniformly from [n] and updates the stochastic gradient estimate recursively via v_t = grad f_{i_t}(w_t) - grad f_{i_t}(w_{t-1}) + v_{t-1} followed by w_{t+1} = w_t - eta v_t. Unlike SVRG (which anchors its control variate to the static outer snapshot w_0 and is conditionally unbiased), SARAH's recursive estimator v_t is conditionally biased given F_t — E[v_t | F_t] = grad P(w_t) - grad P(w_{t-1}) + v_{t-1} != grad P(w_t) — while remaining unbiased in total expectation E[v_t] = E[grad P(w_t)] and requiring O(d) memory (no O(n d) gradient table as in SAG/SAGA). Lemma 2 proves the exact variance decomposition E[||grad P(w_t) - v_t||^2] = sum_{j=1}^t E[||v_j - v_{j-1}||^2] - sum_{j=1}^t E[||grad P(w_j) - grad P(w_{j-1})||^2], which guarantees that the step norm E[||v_t||^2] converges linearly to zero within a single inner loop under strong convexity (Theorems 1a-1b) and enables the self-tuning practical variant SARAH+ (Algorithm 2) that terminates the inner loop as soon as ||v_{t-1}||^2 <= gamma ||v_0||^2.
Identity Notes & Concept Scope Distinct from SVRG, which uses the conditionally unbiased snapshot difference grad f_{i_t}(w_t) - grad f_{i_t}(w_0) + v_0 whose inner-loop step variance does not vanish as t -> infinity within a single outer loop, from SAG/SAGA, which require O(n d) storage of n past component gradients, and from SPIDER (`AIMech:SPIDERStochasticPathIntegratedDifferentialEstimatorForNonConvexOptimization`), which couples recursive path-integrated differential estimation with normalized gradient descent (stepsize proportional to epsilon / ||v^k||) and negative-curvature search for non-convex first- and second-order stationarity. Specifically captures the SARAH recursive estimator (Equation 2), the exact martingale variance identity (Lemma 2) and convex error bound (Lemma 3), the inner-loop linear contraction of E[||v_t||^2] (Theorems 1a-1b), the outer-loop linear rate sigma_m < alpha_m (Theorem 4 and Remark 1), and the adaptive SARAH+ inner stopping rule ||v_{t-1}||^2 > gamma ||v_0||^2 (Algorithm 2).

Claims & Grounded Evidence

3 Claims
Mechanism #claim-sarah-recursive-estimator-exact-variance-identity
For the recursive stochastic gradient update v_t = grad f_{i_t}(w_t) - grad f_{i_t}(w_{t-1}) + v_{t-1} with v_0 = grad P(w_0), the estimator is conditionally biased (E[v_t | F_t] = grad P(w_t) - grad P(w_{t-1}) + v_{t-1}) yet satisfies the exact variance identity E[||grad P(w_t) - v_t||^2] = sum_{j=1}^t E[||v_j - v_{j-1}||^2] - sum_{j=1}^t E[||grad P(w_j) - grad P(w_{j-1})||^2] for any L-smooth functions without convexity (Lemma 2), and when each f_i is convex and L-smooth with learning rate eta < 2/L, E[||grad P(w_t) - v_t||^2] <= (eta*L / (2 - eta*L)) (E[||v_0||^2] - E[||v_t||^2]) <= (eta*L / (2 - eta*L)) E[||v_0||^2] (Lemma 3).

  • supports Source: SARAH: A Novel Method for Machine Learning Problems Using Stochastic Recursive Gradient (arXiv abstract) · Locator: Abstract: recursive framework for updating stochastic gradient estimates without storing past gradients
Mechanism #claim-sarah-inner-loop-and-outer-loop-linear-convergence
Unlike SVRG, SARAH's stochastic step norm E[||v_t||^2] converges linearly to zero within a single inner loop under mu-strong convexity of P with convex f_i at rate (1 - (2/(eta*L) - 1)*mu^2*eta^2)^t for eta < 2/L (Theorem 1a) and at rate (1 - 2*mu*L*eta/(mu + L))^t when each f_i is mu-strongly convex for eta <= 2/(mu + L) (Theorem 1b); across outer loops, Theorem 4 and Corollary 3 prove E[||grad P(w_tilde_s)||^2] <= (sigma_m)^s ||grad P(w_tilde_0)||^2 with contraction factor sigma_m = 1/(mu*eta*(m+1)) + eta*L/(2 - eta*L) < 1 for any eta < 1/L, which is strictly smaller than SVRG's contraction factor alpha_m = 1/(mu*eta*(1 - 2*L*eta)*m) + 2*eta*L/(1 - 2*eta*L) for identical eta < 1/(4L) and m (Remark 1), achieving O((n + kappa) log(1/epsilon)) total complexity.
  • supports Source: SARAH: A Novel Method for Machine Learning Problems Using Stochastic Recursive Gradient · Locator: Section 3.1, Theorems 1a and 1b, p. 4; Section 3.2.2, Theorem 4, Remark 1, and Corollary 3, p. 6; Supplementary Material B.5-B.6 and B.9, pp. 12-14
  • supports Source: SARAH: A Novel Method for Machine Learning Problems Using Stochastic Recursive Gradient (Crossref metadata) · Locator: PMLR 70:2613-2621 abstract: linear convergence rate proven in the strongly convex case for both outer and inner loops
Limitation #claim-sarah-general-convex-residual-and-sarah-plus-threshold
For general non-strongly convex functions with multiple outer loops and fixed inner loop size m, SARAH converges only to a neighborhood Delta = delta*(1 + eta*L/(2*(1 - eta*L))) where delta = max_{0<=k<s} 2*E[P(w_tilde_k) - P(w^*)] / (eta*(m+1)), requiring m = O(1/epsilon) to reach E[||grad P(w_tilde_s)||^2] <= epsilon in O((n + 1/epsilon) log(1/epsilon)) complexity (Theorem 3 and Corollary 2); in the practical variant SARAH+ (Algorithm 2), choosing the inner stopping threshold gamma too large (e.g., gamma -> 1) terminates the inner loop prematurely and degenerates to full gradient descent, whereas choosing gamma too small (gamma << 1/8) performs excessive inner steps once the inner convergence slows down.
  • supports Source: SARAH: A Novel Method for Machine Learning Problems Using Stochastic Recursive Gradient · Locator: Section 3.2.1, Theorem 3 and Corollary 2, pp. 5-6; Section 4, Algorithm 2 (SARAH+) and sensitivity to gamma, p. 7

⚠️ Curated Limitations & Negative Results

  • Each inner-loop step requires two stochastic gradient evaluations (grad f_{i_t}(w_t) and grad f_{i_t}(w_{t-1})), and the theoretical outer-loop convergence guarantee in Algorithm 1 requires selecting w_tilde_s uniformly at random from {w_0, ..., w_m} rather than the last iterate.
