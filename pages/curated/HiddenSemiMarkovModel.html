Hidden semi-Markov model

Model Families AIMech:HiddenSemiMarkovModel DRAFT
Aliases: HSMM, Explicit-duration hidden Markov model, Variable-duration hidden Markov model
A latent-state sequence-model family that assigns explicit distributions to state sojourn durations, with state changes governed by an embedded transition process and observations conditioned on the hidden states.
Identity Notes & Concept Scope The inspected construction is a discrete-time, finite-state hidden semi-Markov model with state-specific duration distributions and conditionally independent emissions. It separates entry into a state from persistence within that state, rather than obtaining every dwell time from repeated self-transitions of an ordinary time-homogeneous HMM. The record is a model family, not the Yu–Kobayashi forward–backward algorithm. General continuous-time, duration-dependent destination and hybrid variants require their own evidence; they are not automatically covered by the detailed mechanism here. Claims & Grounded Evidence

1 Claim
Mechanism #method
In the inspected formulation, let q_t be one of M hidden states and let r_t be its remaining duration, including the current time step. On entry into state m, draw d from a normalized state-specific distribution p_m(d), with d in 1,...,D, and set r_t=d. If r_t>1, the next state remains m and the residual duration decreases by one. If r_t=1, choose a different state n using the normalized entry-transition row a_mn, with a_mm=0, and draw its duration from p_n. Emit each observation independently conditional on the hidden path using b_m(o_t). The pair (q_t,r_t) is a first-order Markov state; q_t alone need not be. The source starts a new sojourn at t=1, giving alpha_1(m,d)=pi_m*p_m(d)*b_m(o_1). Forward recursion sums deterministic countdown paths and new entries; grouping incoming entry mass once per state avoids repeating that transition sum for each duration. Its terminal backward value beta_T(m,d)=1 sums over all remaining durations, so the finite observation window can end inside a sojourn. Likelihoods and smoothed state marginals follow by summing duration states with this endpoint convention.

⚠️ Curated Limitations & Negative Results

  • An explicit duration distribution is not required to be non-geometric, but it permits duration laws whose exit hazard changes with elapsed dwell time. A finite maximum D is a modeling restriction; truncating an unbounded geometric law changes it.
  • The new-sojourn initial law is different from sampling at an arbitrary time in a stationary process, which needs an appropriate residual-life distribution. Requiring a sojourn to end at T is also a different observation/endpoint event from the source’s right-censored window.
  • The source excludes self-transitions at segment boundaries. Allowing adjacent same-labeled segments changes the interpretation and identifiability of the duration law, and needs explicit conventions.
  • The printed parameter re-estimation sums use transition/entry quantities at t=1 although their displayed definitions refer to t-1. Initial-sojourn duration responsibilities need a separate boundary term; transitions between observed time steps start at t=2. This record does not certify the literal printed re-estimation formulas as a complete implementation.
  • The statewise posterior maximizer in Equation(14) is marginal decoding, not a globally most probable hidden path. Numerical scaling, impossible observations and zero expected-count parameter rows require handling in an implementation.
  • The paper’s one-day web-traffic example, choices of M and D and reported initialization behavior are application-specific. No universal convergence, predictive-accuracy or runtime guarantee for all semi-Markov variants is asserted.
