Measured Continuous Greedy Algorithm for Constrained Monotone and Non-Monotone Submodular Maximization

Algorithms AIMech:MeasuredContinuousGreedySubmodularMaximization DRAFT
Aliases: Measured Continuous Greedy, Unified Continuous Greedy Algorithm, Feldman-Naor-Schwartz Measured Continuous Greedy
Measured Continuous Greedy is a unified continuous relaxation algorithm for maximizing the multilinear extension F(y) = E[f(R(y))] of a non-negative (monotone or non-monotone) submodular set function f: 2^N -> R_+ over any down-monotone solvable polytope P subseteq [0, 1]^N up to a configurable stopping time T >= 0, introduced by Feldman, Naor, and Schwartz (2011). Starting from y(0) = 1_emptyset with time step delta = T * ceil(n^5 * T)^{-1}, at each time t < T the algorithm evaluates the residual marginal gains w_e(t) = F(y(t) vee 1_e) - F(y(t)) = (1 - y_e(t)) * partial_e F(y(t)) for all e in N, solves the linear program I(t) = argmax_{x in P} (x . w(t)), and updates each coordinate via the distorted differential step y_e(t + delta) = y_e(t) + delta * I_e(t) * (1 - y_e(t)) (Algorithm 1, Line 8), compensating for the factor 1 - y_e(t) between residual increase and partial_e F(y(t)) while bounding every coordinate by y_e(t) <= 1 - e^{-t} + O(delta) (Lemma III.6).
Identity Notes & Concept Scope Distinct from AIMech:ContinuousGreedyAndMultilinearExtensionForMatroidSubmodularMaximization (Round 349, Calinescu et al. 2011), which updates y_e(t + delta) = y_e(t) + delta * I_e(t) without the (1 - y_e(t)) damping factor—causing coordinates to reach 1 too quickly and failing on non-monotone submodular functions where F(y(t) vee 1_{OPT}) requires bounding max_e y_e(t) <= 1 - e^{-t} via Lemma III.5—and which cannot run past stopping time T = 1 on high-density monotone packing polytopes.

Claims & Grounded Evidence

3 Claims
Mechanism #r368-claim-nonmonotone-exponential-coordinate-cap-and-one-over-e-approximation
For any non-negative submodular function f, down-monotone solvable polytope P subseteq [0, 1]^N, and stopping time T in [0, 1], Measured Continuous Greedy (Algorithm 1) produces y(T) with y(T)/T in P (Lemma III.1) and y_e(t) <= 1 - (1 - delta)^{t/delta} <= 1 - e^{-t} + O(delta) for all e in N and 0 <= t <= T (Lemma III.6); because F(x vee 1_S) >= (1 - max_e x_e) * f(S) for any non-negative submodular function (Lemma III.5), each step satisfies F(y(t + delta)) - F(y(t)) >= delta * [e^{-t} * f(OPT) - F(y(t))] - O(n^3 * delta^2) * f(OPT) (Corollary III.7), which integrates to F(y(T)) >= [T * e^{-T} - o(1)] * f(OPT) (Theorem I.1, Corollary III.10) and yields a (1/e - o(1))-approximation at T = 1 for non-monotone submodular maximization subject to a matroid constraint (via pipage rounding, Theorem IV.1) or O(1) knapsack constraints (Corollary IV.3).

Mechanism #r368-claim-monotone-polytope-density-stopping-time-and-partition-welfare-tightness
For any normalized monotone submodular function f and packing polytope P defined by constraints sum_{e in N} a_{i,e} * x_e <= b_i with density d(P) = min_{1<=i<=m} b_i / sum_{e in N} a_{i,e}, the distorted update guarantees y_e(T) <= 1 - e^{-I_e^T} + O(delta)*T where sum_{e in N} a_e * I_e^T <= T * b (Lemmas III.16-III.17) and worst-case concavity occurs when all active I_e^T are equal (Lemmas III.18-III.19), ensuring y(T) in P for all stopping times T <= T_P = -ln(1 - d(P) + n*delta) / d(P) > 1 with F(y(T)) >= [1 - e^{-T} - o(1)] * f(OPT) (Theorem I.2, Corollary III.15, Corollary III.20); on binary polytopes this yields a [1 - (1 - d(P))^{1/d(P)}]-approximation (Theorem I.3), giving a polynomial-time (1 - (1 - d/r)^{r/d})-approximation for the (d, r)-Submodular Partition problem (Lemma IV.5), the tight (1 - (1 - 1/k)^k)-approximation for k-player Submodular Welfare (Corollary IV.7), and a tight 3/4-approximation for Submodular Max-SAT (Corollary IV.9).

Application #r368-claim-merged-stopping-time-contention-resolution-extension
When combined with a monotone (b, c)-balanced contention resolution scheme for a constraint family I, running Measured Continuous Greedy up to stopping time T = b directly produces a re-normalized fractional point y(b) in b * P(I) (by Lemma III.1) with F(y(b)) >= [b * e^{-b} - o(1)] * f(OPT) for non-monotone f and F(y(b)) >= [1 - e^{-b} - o(1)] * f(OPT) for monotone f, improving the black-box contention resolution approximation ratio from alpha * b * c to (e^{-b} * b * c - o(1)) for non-monotone submodular functions and ((1 - e^{-b}) * c - o(1)) for monotone submodular functions (Theorem I.4).

⚠️ Curated Limitations & Negative Results

  • Requires O(n^5 * T) discretization steps and Monte Carlo sampling of the multilinear extension gradient w_e(t) = F(y(t) vee 1_e) - F(y(t)) unless F admits closed-form evaluation, and requires a separate rounding procedure (such as pipage rounding or a contention resolution scheme) to convert y(T) in P into a feasible integral subset (Section III, p. 575).
