FedPAGE Probabilistic Local Stochastic Gradient Method for Federated Learning

Algorithms AIMech:FedPageProbabilisticLocalGradientMethodForFederatedLearning DRAFT
Aliases: FedPAGE, Federated Probabilistic Gradient Estimator, FedPAGE Local Stochastic Gradient Algorithm
A communication-efficient local stochastic gradient method for federated convex and nonconvex optimization (Algorithm 1) that generalizes the optimal Probabilistic Gradient Estimator (PAGE) to multiple local update steps K >= 1: in each round r, with probability p_r = S/N the server queries all N clients for minibatch gradients of size b_1, and with probability 1 - p_r the server broadcasts (x^r, x^{r-1}, g^{r-1}) to a sampled subset S^r of size S where each client i initializes g_{i,0}^r = nabla_{I_2} f_i(x^r) - nabla_{I_2} f_i(x^{r-1}) + g^{r-1} and runs K - 1 local SARAH/PAGE recursive steps g_{i,k}^r = nabla_{I_3} f_i(y_{i,k}^r) - nabla_{I_3} f_i(y_{i,k-1}^r) + g_{i,k-1}^r, achieving O(L(sqrt(N) + S) / (S eps^2)) communication rounds in nonconvex settings and O(N^{3/4} L / (S eps)) in convex settings.
Identity Notes & Concept Scope Distinct from single-step centralized PAGE (Li et al., ICML 2021; recovered when K = 1), SCAFFOLD (Karimireddy et al., ICML 2020; which requires O(N^{2/3} L / (S^{2/3} eps^2)) nonconvex and O(N L / (S eps)) convex rounds and maintains per-client states across rounds), and FedAvg / Local-SGD. FedPAGE (Zhao, Li, & Richtarik, 2021, arXiv:2108.04755) is stateless on clients and improves SCAFFOLD's communication complexity by factors N^{1/6} S^{1/3} (nonconvex) and N^{1/4} (convex) for S <= sqrt(N).

Claims & Grounded Evidence

4 Claims
Mechanism #fedpage-probabilistic-full-client-reset-and-local-recursive-gradient-step-mechanism
At round r (Algorithm 1), FedPAGE samples q ~ Bernoulli(p_r) with p_0 = 1 and p_r = S/N; when q = 1, all N clients compute minibatch gradients nabla_{I_1} f_i(x^r) to reset g^r = (1/N) sum_{i=1}^N nabla_{I_1} f_i(x^r); when q = 0, S sampled clients receive (x^r, x^{r-1}, g^{r-1}), form the initial local recursive gradient g_{i,0}^r = nabla_{I_2} f_i(x^r) - nabla_{I_2} f_i(x^{r-1}) + g^{r-1}, execute K - 1 local steps y_{i,k+1}^r = y_{i,k}^r - eta_l g_{i,k}^r with g_{i,k}^r = nabla_{I_3} f_i(y_{i,k}^r) - nabla_{I_3} f_i(y_{i,k-1}^r) + g_{i,k-1}^r, and return Delta y_i^r = x^r - y_{i,K}^r for server aggregation g^r = (1 / (K eta_l S)) sum_{i in S^r} Delta y_i^r.
  • supports Source: FedPAGE: A Fast Local Stochastic Gradient Method for Communication-Efficient Federated Learning · Locator: Section 3 Algorithm 1 pp. 6-7 & Appendix D Lemmas D.1-D.2 pp. 23-25
Scope #fedpage-nonconvex-and-convex-communication-complexity-improvement-scope
Under L-smoothness (Assumption 2.1) and bounded local variance sigma^2 (Assumption 2.3), with p = S/N and Expected communicated clients per round p N + (1 - p) S < 2 S, FedPAGE achieves E[||nabla f(x)||_2] <= eps in R = O(L(sqrt(N) + S) / (S eps^2)) communication rounds in the nonconvex setting (Theorem 4.2) and E[f(x) - f^*] <= eps in R = O(N^{3/4} L / (S eps)) rounds for S <= sqrt(N) in the convex setting (Theorem 5.2), without requiring bounded inter-client gradient dissimilarity.
  • supports Source: FedPAGE: A Fast Local Stochastic Gradient Method for Communication-Efficient Federated Learning · Locator: Table 1 p. 2, Section 4.2 Theorem 4.2 p. 8 & Section 5.2 Theorem 5.2 p. 10
  • supports Source: FedPAGE: A Fast Local Stochastic Gradient Method for Communication-Efficient Federated Learning (arXiv abstract) · Locator: Abstract
Limitation #fedpage-occasional-full-client-broadcast-and-triple-vector-downlink-limitation
Requires occasional full-client synchronization rounds (with probability p_r = S/N) to reset the global gradient estimator g^r, and during partial-participation rounds (q = 0) the server broadcasts three d-dimensional vectors (x^r, x^{r-1}, g^{r-1}) to each selected client.
  • supports Source: FedPAGE: A Fast Local Stochastic Gradient Method for Communication-Efficient Federated Learning · Locator: Section 3 Algorithm 1 Lines 3-4 & Line 11 p. 6
Application #fedpage-nonconvex-robust-linear-regression-and-regularized-logistic-regression-application
Applied to federated nonconvex robust linear regression and logistic regression with nonconvex regularizers across thousands of partitioned LIBSVM client datasets.
  • supports Source: FedPAGE: A Fast Local Stochastic Gradient Method for Communication-Efficient Federated Learning · Locator: Section 6 Numerical Experiments pp. 11-14

⚠️ Curated Limitations & Negative Results

  • Requires occasional full-client synchronization rounds with probability p_r = S/N to reset the global gradient estimator.
  • Broadcasts three d-dimensional vectors (x^r, x^{r-1}, g^{r-1}) to sampled clients during local-update rounds.
