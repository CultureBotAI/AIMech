Recurrent temporal restricted Boltzmann machine

Architectures AIMech:RecurrentTemporalRestrictedBoltzmannMachine DRAFT
Aliases: RTRBM
A recurrent neural sequence architecture whose deterministic state is a conditional RBM hidden-probability vector and sets the next step’s hidden bias, with visible observations drawn from that step’s RBM marginal.
Identity Notes & Concept Scope This is Sutskever, Hinton and Taylor’s 2008 RTRBM, with a real-valued recurrent state and separate binary within-step RBM hidden variables. Replacing a sampled TRBM hidden state by a deterministic probability vector changes the generative model; exact inference in RTRBM is not exact inference in the original stochastic TRBM. The recurrent update and conditional RBM share weights in this architecture. The real-valued state must not be conflated with the binary hidden variables integrated out of each output RBM. Claims & Grounded Evidence

1 Claim
Mechanism #method
Use column vectors, visible-by-hidden weights W and recurrent hidden-by-hidden weights U. Given r_(t-1), let the current binary RBM have joint mass proportional to exp(v_t^T W z_t+a^T v_t+(b+U r_(t-1))^T z_t), with binary z_t marginalized for the visible distribution. After observing or sampling v_t, set r_t=sigmoid(W^T v_t+b+U r_(t-1)); the first step uses the specified initial bias contribution. This update is deterministic by definition, so a fully observed visible sequence fixes the recurrent trajectory exactly and later observations cannot alter its already determined states. The visible-sequence log likelihood is the sum of the conditional RBM log marginals. Differentiate that objective through the recurrence and through each RBM’s direct parameter dependence. In particular, a recurrent weight affects the current output distribution through its hidden bias as well as later recurrent states. Backpropagation through time propagates these dependencies, while the paper approximates conditional RBM model expectations with contrastive divergence. A Gaussian-visible version replaces the binary visible base measure with a quadratic Gaussian term.

⚠️ Curated Limitations & Negative Results

  • Exact deterministic-state inference requires the visible sequence to be observed. Missing observations require marginalizing uncertainty in visible values and induced recurrent states; the exact-inference statement does not automatically extend to that problem.
  • Within-step binary hidden variables are stochastic even though the recurrent summary is deterministic. Exact state reconstruction does not make RBM partition functions, equilibrium sampling or finite-CD gradients exact or generally tractable.
  • The printed Equation (12) local-score index differs from its surrounding next-step prose. Equation (13) displays a recurrence contribution but omits the direct current-RBM dependence through its dynamic hidden bias; a complete objective derivative must include it. The curated description follows the normalized generative definition and chain rule, checked by original finite differences, rather than treating Equations (12)–(14) as a verified implementation. No author-code defect or official erratum is asserted.
  • A finite recurrent vector permits temporal dependence but does not guarantee successful learning of arbitrarily long dependencies. The source’s sample-quality comparisons do not establish universal superiority or exact likelihood learning.
  • The source shares parameters between recurrence and output RBMs. A separate recurrent network that independently controls RBM parameters is a distinct neighboring construction; this record does not equate every RNN–RBM hybrid to RTRBM.

Restricted Boltzmann Machine
 related_match Each time step uses a conditional RBM with undirected visible–hidden interactions. The entire sequence construction additionally has directed history connections and a separate conditional normalizer per step; a related mapping records the component relationship without equating the whole temporal architecture to one unconditioned symmetric RBM.
