One-stage and two-stage adaptive step-up procedures for false discovery rate control under independence and dependence

Mathematical Methods AIMech:OneAndTwoStageAdaptiveStepUpFDRUnderDependence DRAFT
Aliases: Blanchard-Roquain One-Stage and Two-Stage Adaptive Step-Up FDR Procedures, BR-1S-lambda and BR-2S-lambda Adaptive Step-Up FDR Procedures, Piecewise Inverse-Volume and Markov Two-Stage Adaptive FDR Control
A family of one-stage and two-stage adaptive multiple hypothesis testing procedures developed by Gilles Blanchard and Etienne Roquain (2009, Journal of Machine Learning Research 10:2837-2871, arXiv:0707.0536v3) that adapt step-up thresholds to the unknown null proportion pi_0 = m_0 / m while controlling the finite-sample False Discovery Rate under independent, positively dependent (PRDS), or arbitrarily dependent p-values: (1) the one-stage piecewise inverse-volume procedure BR-1S-lambda with threshold collection Delta(i) = min(lambda, alpha (1 - lambda) i / (m - i + 1)) (default lambda = alpha), which modifies the asymptotically optimal Finner-Dickhaus-Roters rejection curve to guarantee exact finite-sample FDR <= alpha for any coordinate-wise non-increasing self-consistent procedure under independence (Theorem 3.1); (2) the two-stage plug-in procedure BR-2S-lambda using estimator G_4(p) = (1 - lambda) m / (m - |R_{BR-1S-lambda}(p)| + 1), which dominates the Benjamini-Krieger-Yekutieli (2006) estimator G_3 while satisfying the unified self-consistent plug-in bound FDR(R) <= (alpha / m) sum_{h in H_0} E[G(p_{0,h})] <= alpha under independence (Theorem 3.2 and Corollary 1); (3) the tuning principle lambda = alpha that prevents catastrophic FDR inflation under comonotonic/strong positive dependence (Proposition 1); and (4) two-stage adaptive step-up procedures for PRDS and arbitrary dependence using either an FWER-controlled first stage Delta(i) = alpha_1 (m - |R_0|)^{-1} beta(i) (Theorem 4.1) or an FDR-controlled first stage with the Markov-inequality transformation F_kappa(x) = 2 / (kappa - sqrt((kappa^2 - 4 kappa (1 - x))_+)) for x >= 1/kappa (Theorem 4.2).
Identity Notes & Concept Scope Distinct from all 442 pinned AIO concepts and all 594 previously curated AIMech concepts. While AIMech:SelfConsistencyAndDependencyControlFDRFramework (Blanchard & Roquain 2008, Electronic Journal of Statistics 2:963-992) establishes the general non-adaptive Self-Consistency SC(alpha, pi, beta) and Dependency Control DC(beta) framework on volume-measured spaces, Blanchard & Roquain (2009, Journal of Machine Learning Research 10:2837-2871, arXiv:0707.0536v3) specifically formulate and analyze pi_0-adaptive threshold collections: the one-stage piecewise inverse-volume step-up procedure BR-1S-lambda with Delta(i) = min(lambda, alpha (1 - lambda) i / (m - i + 1)) (Theorem 3.1) and its Gaussian signal threshold mu* (Lemma 2), the unified coordinate-wise non-increasing plug-in theorem FDR(R) <= (alpha / m) sum_{h in H_0} E[G(p_{0,h})] and two-stage procedure BR-2S-lambda with G_4(p) = (1 - lambda) m / (m - |R_{BR-1S-lambda}(p)| + 1) (Theorem 3.2, Corollary 1), the exact comonotonic maximal-dependence FDR formulas showing that lambda = 1/2 inflates Storey-1/2 FDR to min(alpha m, 1)/2 = 10 alpha whereas lambda = alpha preserves exact FDR = alpha (Proposition 1), and the Markov-inequality transformation F_kappa(x) for two-stage FDR-to-FDR adaptation under PRDS and arbitrary dependence (Theorem 4.2).

Mechanism #one-stage-piecewise-inverse-volume-step-up-and-gaussian-signal-threshold
Modifying the asymptotically optimal Finner-Dickhaus-Roters (2009) rejection curve alpha i / (m - (1 - alpha) i) to obtain non-asymptotic finite-sample control, Theorem 3.1 proves via the inverse-binomial expectation bound E[(Y + 1)^{-1}] = (1 - (1 - q)^k)/(k q) <= 1/(k q) for Y ~ Binomial(k, q) (Lemma 7) that for any tuning parameter lambda in (0, 1), any coordinate-wise non-increasing procedure R self-consistent with respect to the one-stage piecewise inverse-volume threshold collection Delta_{BR-1S-lambda}(i) = min(lambda, alpha (1 - lambda) i / (m - i + 1)) controls the False Discovery Rate at level alpha under independent conservative p-values; furthermore, at lambda = alpha, Delta_{BR-1S-alpha}(i) strictly exceeds the linear step-up threshold alpha i / m whenever i / m > alpha + 1/m, and Lemma 2 proves that in the one-sided Gaussian location model with signal strength mu > 0, the asymptotic linear step-up rejection proportion exceeds alpha + 1/m with probability tending to 1 if and only if mu > mu* = Phi_bar^{-1}(alpha^2) - Phi_bar^{-1}(alpha (1 - pi_0 alpha) / (1 - pi_0)) (e.g., mu* = 1.511105 at pi_0 = 0.5, alpha = 0.05).

Mechanism #unified-plug-in-self-consistency-theorem-and-br-2s-dominance
For any inverse null-proportion estimator G: [0, 1]^m -> (0, infty] that is coordinate-wise non-increasing in each p_h, Theorem 3.2 proves that any coordinate-wise non-increasing procedure R satisfying the adaptive self-consistency condition R(p) subset {h in H : p_h <= (alpha / m) G(p) |R(p)|} under independent p-values satisfies FDR(R) <= (alpha / m) sum_{h in H_0} E[G(p_{0,h})] where p_{0,h} sets p_h = 0; since E[G_1(p_{0,h})] <= m / m_0 for the Storey (2002) estimator G_1(p) = (1 - lambda) m / (m - |R^0_{lambda}(p)| + 1) and the estimator hierarchy satisfies G_3(p) <= G_4(p) <= G_1(p) whenever |R_{LSU,lambda}(p)| <= |R_{BR-1S-lambda}(p)| <= |R^0_{lambda}(p)|, Corollary 1 establishes that the two-stage adaptive step-up procedure BR-2S-lambda using G_4(p) = (1 - lambda) m / (m - |R_{BR-1S-lambda}(p)| + 1) achieves finite-sample FDR <= alpha under independence while strictly dominating the Benjamini-Krieger-Yekutieli (2006) procedure BKY06-lambda (G_3) whenever the first stage BR-1S-lambda rejects more hypotheses than linear step-up at level lambda.

Mechanism #maximal-comonotonic-dependence-fdr-and-lambda-alpha-robustness
Under the maximal comonotonic positive dependence boundary p_1 = ... = p_m ~ Uniform[0, 1] with m_0 = m true nulls, Proposition 1 derives exact closed-form False Discovery Rates demonstrating that standard constant tuning lambda = 1/2 causes severe FDR inflation: Storey-1/2 has FDR = min(alpha m, 1) / 2 (reaching 0.50 = 10 alpha for m >= 20 at alpha = 0.05) and the median quantile procedure Quant-1/2 has FDR = 2 alpha / (1 + 2 alpha + 2/m) approx 2 alpha, whereas for any lambda in [lambda_1, lambda_2] with lambda_1 = alpha / (1 + alpha + 1/m) and lambda_2 = alpha / (alpha + 1/m) — in particular the canonical choice lambda = alpha — BR-1S-alpha, BR-2S-alpha, BKY06-alpha, and Storey-alpha all achieve exact FDR = min(lambda, alpha (1 - lambda) / (1 - lambda + 1/m)) = alpha (and Quant-k_0 achieves FDR = alpha for k_0 <= (1 - alpha) m + 1).

Mechanism #two-stage-fwer-and-markov-fdr-adaptive-step-up-under-dependence
For general p-value dependency structures without stage independence, Lemma 3 establishes the distribution-free and PRDS tail-probability decomposition FDR(R) <= alpha pi_0 t + P(G(p) > t, |R| > 0) for any t > 0 (requiring G(p) to be coordinate-wise non-decreasing under PRDS with beta(i) = i, and no monotonicity on G under arbitrary dependence with prior-integrated beta_nu(i) = sum_{j=1}^i j nu({j})), from which Theorem 4.1 proves that a first-stage alpha_0-FWER procedure R_0 paired with second-stage thresholds Delta(i) = alpha_1 (m - |R_0|)^{-1} beta(i) controls FDR <= alpha_0 + alpha_1, and Theorem 4.2 proves via Markov's inequality on FDP(R_0) that a first-stage alpha_0-FDR procedure R_0 paired with the transformation F_kappa(x) = 2 / (kappa - sqrt((kappa^2 - 4 kappa (1 - x))_+)) for x >= 1/kappa (with inverse F_kappa^{-1}(t) = kappa^{-1} t^{-2} - t^{-1} + 1 satisfying (1 - t^{-1}) F_kappa^{-1}(t) = (kappa t)^{-1}) and second-stage thresholds Delta_1(i) = alpha_1 beta(i) F_kappa(|R_0|/m) / m controls FDR <= alpha_1 + kappa alpha_0 while dominating non-adaptive step-up whenever |R_0|/m > F_2^{-1}(2) = 0.625 (at kappa = 2, alpha_0 = alpha/4, alpha_1 = alpha/2).

⚠️ Curated Limitations & Negative Results

  • For the one-stage procedure BR-1S-alpha with thresholds Delta(i) = min(alpha, alpha (1 - alpha) i / (m - i + 1)), the first threshold Delta(1) = alpha (1 - alpha) / m is slightly smaller than the standard linear step-up threshold alpha / m by a factor of (1 - alpha), and BR-1S-alpha only strictly exceeds linear step-up when the rejection fraction satisfies i / m > alpha + 1/m; by Lemma 2, in sparse or low-signal regimes where the Gaussian signal strength satisfies mu < mu* = Phi_bar^{-1}(alpha^2) - Phi_bar^{-1}(alpha (1 - pi_0 alpha) / (1 - pi_0)), BR-1S-alpha and two-stage procedures using lambda = alpha provide negligible power gain over non-adaptive Benjamini-Hochberg (Section 3.1 and Section 5.1).
  • While Theorem 3.2 proves finite-sample FDR <= alpha for plug-in procedures G_1..G_4 under independent p-values (where G(p) must be coordinate-wise non-increasing so that G(p_{0,h}) can be bounded via inverse-binomial expectations), positive regression dependency (PRDS) reverses the required monotonicity direction in Lemma 3 to coordinate-wise non-decreasing G(p); consequently, standard one-stage and two-stage adaptive procedures (Storey-lambda, BKY06-lambda, BR-1S-lambda, BR-2S-lambda) do not have a theoretical PRDS guarantee for arbitrary correlation matrices and can exceed nominal FDR when lambda = 1/2 under strong positive correlation (Section 3.3, Proposition 1, and Section 4).
  • The provably valid two-stage adaptive procedures under PRDS and arbitrary dependence (Theorems 4.1 and 4.2) must split the error budget across two stages on the same p-value set (alpha = alpha_0 + alpha_1 in Theorem 4.1 or alpha = alpha_1 + kappa alpha_0 in Theorem 4.2), which makes them conservative when pi_0 is moderate or large: for instance, Theorem 4.2 with kappa = 2, alpha_0 = alpha/4, alpha_1 = alpha/2 only produces second-stage thresholds larger than non-adaptive step-up when the first-stage rejection fraction exceeds F_2^{-1}(2) = 0.625 (requiring pi_0 < 0.375; Section 4).
