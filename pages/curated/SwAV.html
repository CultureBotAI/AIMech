SwAV

Algorithms AIMech:SwAV DRAFT
Aliases: Swapping assignments between views
An online self-supervised visual representation-learning procedure that predicts soft prototype assignments of one augmented image view from other views, using entropy-regularized balanced assignment and jointly learned features and prototypes.
Identity Notes & Concept Scope SwAV means swapping assignments between views. It uses online soft prototype codes rather than offline full-dataset k-means labels, direct pairwise feature negatives, or an exponential-moving-average teacher. Its prototype assignments are learned training targets, not verified semantic class labels. Claims & Grounded Evidence

1 Claim
Mechanism #method
Encode augmented views into nonzero features and L2-normalize them; compare them with K trainable prototype columns C. For a group of B features Z with positive integer B and K and epsilon>0, approximately maximize Tr(Q^T C^T Z)+epsilon H(Q) over nonnegative Q with row sums 1/K and column sums 1/B, where H(Q)=−sum_(k,b) Q_kb log Q_kb. Compute the soft transport assignment by Sinkhorn row/column rescaling of exp(C^T Z/epsilon), then normalize each column into a probability code q_b (q_b=B Q_:b at exact column balance). Stop gradients through codes. For each image, predict a global view’s code from the other views using p(v)=softmax(C^T z(v)/tau), tau>0, and cross-entropy −sum_k q_k log p_k, averaged over images and valid cross-view pairs. In multicrop training codes are computed from the two global crops; predictions use global and smaller crops while excluding the same crop as its code target. Update encoder/projection parameters and prototypes by gradients and normalize prototype columns, as in the supplement. The small-batch variant augments assignment features with a recent-feature queue but uses only current-image codes in the loss.

⚠️ Curated Limitations & Negative Results

  • Finite Sinkhorn iterations approximate the balanced transport solution. Probability codes must sum to one per image; the mass-1 transport matrix with column sums 1/B is not already that probability matrix. Exponential scores need numerically stable evaluation.
  • The source describes equipartition as preventing identical codes, but also reports uniform collapse with strong entropy regularization. Uniform soft assignments satisfy the balance constraints, so balance alone is not a general noncollapse theorem.
  • The source motivates a feature queue when B is small relative to K. This is an empirical assignment-quality issue; the continuous transport polytope is not mathematically empty merely because B<K. Queued features can be stale and are not a momentum encoder.
  • The main equations and supplement pseudocode use different compact sum/mean conventions. This record states averaged cross-entropy explicitly and does not transfer optimizer coefficients between differently scaled losses.
  • Prototype number, assignment regularization, crop distribution, initial prototype freezing and optimization schedule are experimental choices. No semantic clustering guarantee, universal batch-size independence or reproduced benchmark is asserted.
