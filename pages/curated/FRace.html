F-Race

Algorithms AIMech:FRace DRAFT
A statistical racing method for configuring metaheuristics that evaluates a finite candidate set on shared problem-instance blocks and eliminates candidates judged worse through a Friedman rank test followed by comparisons with the best-ranked candidate.
Identity Notes & Concept Scope This record covers the original 2002 F-Race method. It uses a fixed starting candidate pool and nested survivor sets, not iterative resampling of configurations as in later iterated racing methods. It differs from ROAR’s challenger-incumbent heuristic comparisons, fixed-fraction successive halving and a standalone Friedman test without sequential resource allocation. Claims & Grounded Evidence

1 Claim
Mechanism #method
Start with a finite set of candidate configurations and draw a sequence of training instances independently from the selected instance distribution. At each racing step, evaluate every surviving candidate on the same new instance and append its observed solution cost. Rank surviving candidates by cost within each accumulated instance block, using average ranks for ties. Apply the paper’s Friedman aggregate rank statistic to the accumulated blocks. If its null is not rejected, retain all survivors; if rejected, compare each candidate with the best-ranked one using the stated post-hoc rank-difference test and discard candidates found worse. Repeat with the reduced candidate set until one remains or the prescribed total computation budget stops further evaluation.
  • supports Source: A Racing Algorithm for Configuring Metaheuristics · Locator: Sections2–3.3, PDF pp.2–5, especially Section3.1 racing and Section3.2 Friedman/post-hoc comparisons; Section6, PDFp.8

⚠️ Curated Limitations & Negative Results

  • The method assumes independent instance blocks and appropriate within-block comparability. The aggregate test uses an approximate chi-square reference distribution, followed by the paper’s Student-t-based pairwise rule. No implementation-level small-sample correction or sequential family-wise error guarantee was verified.
  • Rank comparisons discard cost magnitudes. Better rank sums need not identify the lowest arithmetic mean cost, so the method is not asserted to certify the minimizer of the expected-cost objective stated in Section2. Repeated significance decisions and early elimination do not ensure that the best configuration survives.
  • A finite initial candidate pool limits what can be selected, and the time budget can expire with multiple survivors. The inspected method does not establish a unique returned configuration in every such case. No general superiority over parametric racing methods or replicated TSP result is claimed.
