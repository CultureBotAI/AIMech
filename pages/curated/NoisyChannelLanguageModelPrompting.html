Noisy Channel Language Model Prompting

Algorithms AIMech:NoisyChannelLanguageModelPrompting DRAFT
Aliases: Noisy Channel Prompting, Channel Prompt Tuning, Noisy Channel Language Model Prompting for Few-Shot Classification, Generative Channel Model Prompting and Ensemble Demonstrations
A few-shot language model prompting and prompt-tuning method for text classification that applies Bayes' rule under a uniform class prior P(c_i) = 1/|C| to reparameterize class prediction arg max_{c_i in C} P(c_i | x) as maximizing the conditional probability of generating the entire input text x given the verbalized label v(c_i): P_LM(x | v(c^1), x^1, ..., v(c^K), x^K, v(c_i)) in concatenation-based demonstrations, prod_{j=1}^K P_LM(x | v(c^j), x^j, v(c_i)) in ensemble-based demonstrations, or P_LM(x | u_1...u_n, v(c_i)) in channel prompt tuning with trainable prefix embeddings u_1...u_n and frozen causal LM weights.
Identity Notes & Concept Scope Distinct from direct prompting and direct Prompt Tuning (AIMech:InContextLearning, AIMech:PromptTuning), which compute P_LM(v(c_i) | x) and collapse when training labels are imbalanced or when test labels are unseen during training, and from zero-shot Domain Conditional PMI (Holtzman et al., EMNLP 2021, AIMech:PMIDCDomainConditionalPointwiseMutualInformation), which reweights zero-shot direct continuations by a domain premise rather than training continuous channel prompts u_1...u_n or multiplying K reversed demonstration likelihoods.

Claims & Grounded Evidence

4 Claims
Mechanism #r729-claim-input-token-amplification-and-ensemble
By computing P_LM(x | v(c_i)) = prod_{t'=1}^{t_x} P_LM(x_{t'} | v(c_i), x_{1..t'-1}), noisy channel prompting requires the language model to explain every token in the input x rather than only the label verbalizer token(s), amplifying supervision signals in low-data regimes; furthermore, ensemble-based demonstrations prod_{j=1}^K P_LM(v(c_i)|x^j, v(c^j), x) or prod_{j=1}^K P_LM(x|v(c^j), x^j, v(c_i)) reduce self-attention memory from O(K^2) to O(K) and eliminate sensitivity to demonstration ordering.
  • supports Source: Noisy Channel Language Model Prompting for Few-Shot Text Classification · Locator: Section 1, Section 3, and Section 4.1.1-4.1.3, Table 1, pp. 1, 3-4
Mechanism #r729-claim-imbalance-and-unseen-label-robustness
Because the verbalized label v(c_i) appears only in the conditioning prefix rather than the target output space of the LM head, channel prompt tuning P_LM(x | u_1...u_n, v(c_i)) does not overfit to the unconditional training label distribution: it remains accurate under extreme training label imbalance (including p^- = 0 where negative examples are completely absent from training) and generalizes to unseen test labels and cross-dataset label spaces where all direct tuning methods fail (50.0% random accuracy on binary tasks).
  • supports Source: Noisy Channel Language Model Prompting for Few-Shot Text Classification · Locator: Section 6.3-6.4 & Section 7, Figures 4-5, Table 5, pp. 7-9
Application #r729-claim-eleven-dataset-few-shot-application
Across 11 text classification benchmarks with GPT-2 Large at K = 16 examples, channel demonstration methods outperform the strongest calibrated direct baseline (Direct++) by +3.1% average and +7.2% worst-case accuracy (58.9%/50.8% vs. 55.8%/43.6%), and channel prompt tuning outperforms direct prompt tuning by +13.3% average and +23.5% worst-case accuracy (61.7%/53.0% vs. 48.4%/29.5%).
  • supports Source: Noisy Channel Language Model Prompting for Few-Shot Text Classification · Locator: Section 6.1-6.2, Tables 3-4, pp. 5-6
Limitation #r729-claim-inference-cost-and-large-k-limitation
At inference time, noisy channel prompting requires |C| separate forward passes over the full input sequence x (one per candidate class c_i in C), cannot be directly applied to non-classification generation tasks without an external prior model or to bidirectional masked language models without modifying pretraining objectives, and is surpassed by direct head tuning or full fine-tuning when training data is abundant (K >= 64 or Full) or when the task is far from language modeling (such as TREC question-type classification).
  • supports Source: Noisy Channel Language Model Prompting for Few-Shot Text Classification · Locator: Section 6.2-6.3 & Section 7, Table 4, Figure 3, pp. 6-7, 9

⚠️ Curated Limitations & Negative Results

  • Inference cost scales linearly with the number of classes |C| because computing P_LM(x | v(c_i)) requires running a separate forward pass over the input sequence x for every candidate label c_i.
  • Restricted to causal language models and closed-set classification tasks (not directly applicable to masked LMs or open-ended generation), and trails direct head tuning when K >= 64 or on tasks whose label structure diverges from natural text continuation (such as TREC).
