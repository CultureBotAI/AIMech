FedAMP (Federated Attentive Message Passing for Personalized Cross-Silo Federated Learning)

Algorithms AIMech:FedAmpFederatedAttentiveMessagePassingForPersonalizedCrossSiloFederatedLearning DRAFT
Aliases: FedAMP, HeurFedAMP, Federated Attentive Message Passing, Personalized Cross-Silo Federated Learning via Attentive Message Passing
A personalized cross-silo federated learning algorithm (Huang et al. 2021, Sections 3-6, Definition 1, Equations 1-8, Algorithm 1, Theorems 1-2) that jointly optimizes client models W = [w_1, ..., w_m] under a pairwise attention-inducing regularizer min_W G(W) = sum_{i=1}^m F_i(w_i) + lambda sum_{1 <= i < j <= m} A(||w_i - w_j||^2) where A : [0, infty) -> R is a concave, strictly increasing attention-inducing function with A(0) = 0 and bounded right derivative lim_{t -> 0+} A'(t) < infty (such as A(t) = 1 - exp(-t / sigma), Equations 1-2), alternating between (1) a server-side attentive message passing step U^k = W^{k-1} - alpha_k nabla A(W^{k-1}) that forms each client's personalized cloud model u_i^k = sum_{j=1}^m xi_{i,j} w_j^{k-1} with pairwise attention weights xi_{i,j} = alpha_k A'(||w_i^{k-1} - w_j^{k-1}||^2) for j != i and self-weight xi_{i,i} = 1 - sum_{j != i} xi_{i,j} (Equations 3, 5, 7) and (2) client-side proximal point optimization w_i^k = argmin_w {F_i(w) + (lambda / (2 alpha_k)) ||w - u_i^k||^2} (Equations 4, 6), together with the cosine-similarity variant HeurFedAMP (Equation 8) for high-dimensional deep networks.
Identity Notes & Concept Scope Distinct from pFedMe (AIMech:PFedMePersonalizedFederatedLearningWithMoreauEnvelopes, T. Dinh et al. 2020), which penalizes distance to a single shared global model ||w_i - w||^2 rather than pairwise concave attention functions sum_{i < j} A(||w_i - w_j||^2) producing personalized cloud models u_i^k; and distinct from FedFomo (AIMech:FedFomoFirstOrderModelOptimizationForPersonalizedFederatedLearning, Zhang et al. 2021), which computes weights on the client side using local validation loss evaluations of downloaded peer models rather than server-side attentive message passing.

Claims & Grounded Evidence

4 Claims
Mechanism #r465-concave-attention-inducing-cloud-model-and-proximal-update-mechanism
Computes each client's personalized cloud model u_i^k via gradient descent on the concave pairwise regularizer A(W), yielding the convex combination u_i^k = (1 - alpha_k sum_{j != i} A'(||w_i^{k-1} - w_j^{k-1}||^2)) w_i^{k-1} + alpha_k sum_{j != i} A'(||w_i^{k-1} - w_j^{k-1}||^2) w_j^{k-1} (Equations 5 & 7) where non-increasing slope A'(t) assigns strictly larger collaboration weights to clients with closer parameter vectors, followed by local proximal minimization of F_i(w) + (lambda / (2 alpha_k)) ||w - u_i^k||^2 (Equation 6).
  • supports Source: Personalized Cross-Silo Federated Learning on Non-IID Data · Locator: Section 3 Definition 1 & Equations 1-2, pp. 2-3, and Section 4 Method of FedAMP (Equations 3-7, Algorithm 1), pp. 3-4
Scope #r465-convex-and-nonconvex-convergence-and-heurfedamp-scope
Establishes O(1 / sqrt(K)) convergence to the global minimum for convex objectives (Theorem 1, O(epsilon^{-2}) iterations) and O(1 / sqrt(K)) squared-gradient stationarity min_{0 <= k <= K} ||nabla G(W^k)||^2 for smooth non-convex objectives under incremental alternating optimization with inexact local proximal steps e_i^k (Theorem 2, O(epsilon^{-4}) iterations), and introduces softmax cosine-similarity weights xi_{i,j} propto exp(sigma cos(w_i, w_j)) in HeurFedAMP (Equation 8) to prevent Euclidean distance saturation in deep neural networks.
  • supports Source: Personalized Cross-Silo Federated Learning on Non-IID Data · Locator: Section 5 Convergence of FedAMP (Theorems 1-2), pp. 4-5, and Section 6 Heuristic Improvement of FedAMP on Deep Neural Networks (Equation 8), p. 5
Limitation #r465-cross-silo-server-memory-and-pairwise-distance-limitation
Requires the cloud server to store all m client parameter vectors W = [w_1, ..., w_m] in R^{d x m} and compute O(m^2 d) pairwise distances or cosine similarities per round, making it tailored to cross-silo federated learning with stateful clients rather than massive stateless cross-device federations.
  • supports Source: Personalized Cross-Silo Federated Learning on Non-IID Data · Locator: Section 1 Introduction & Section 4 Algorithm 1, pp. 1, 3-4
Application #r465-personalized-cross-silo-benchmark-application
Applied to personalized cross-silo federated learning under pathological and cluster-skewed non-IID partitions on MNIST, FMNIST, EMNIST, and CIFAR-100, outperforming FedAvg, FedProx, and pFedMe in personalized client test accuracy.
  • supports Source: Personalized Cross-Silo Federated Learning on Non-IID Data · Locator: Section 7 Experiments (Tables 1-2, Figures 2-3), pp. 5-7

⚠️ Curated Limitations & Negative Results

  • Requires O(m d) server memory to maintain personalized models for all m silos and O(m^2 d) server computation per round for pairwise similarity weights.
  • In high-dimensional deep neural networks, Euclidean distance exp(-||w_i - w_j||^2 / sigma) can saturate, requiring the cosine-similarity heuristic HeurFedAMP.
