Soft-Impute Iterative Soft-Thresholded SVD for Large Matrix Completion

Aliases: Soft-Impute Nuclear-Norm Regularized Matrix Completion (Mazumder-Hastie-Tibshirani), Iterative Soft-Thresholded SVD EM/MM Algorithm for Incomplete Matrices, Sparse-Plus-Low-Rank Decomposition Soft-Impute Path
Soft-Impute Iterative Soft-Thresholded SVD for Large Matrix Completion is a convex spectral-regularization and majorization-minimization (EM-style) algorithm introduced by Mazumder, Hastie, and Tibshirani (2010) for solving the nuclear-norm regularized least-squares matrix completion problem min_{Z in R^{m x n}} f_lambda(Z) = (1/2) ||P_Omega(X) - P_Omega(Z)||_F^2 + lambda ||Z||_* across a warm-started path of regularization parameters lambda_1 > lambda_2 > ... > lambda_K. At each iteration, Algorithm 1 forms the surrogate completed matrix W^{old} = P_Omega(X) + P_Omega^perp(Z^{old}) by filling in missing entries with the current low-rank estimate Z^{old} and updates Z^{new} = S_lambda(W^{old}) = U D_lambda V^T via the singular value soft-thresholding operator D_lambda = diag(max(d_i - lambda, 0)) (Lemma 1). To scale to Netflix-sized matrices without destroying sparsity, Section 3.1 exploits the exact sparse-plus-low-rank decomposition W^{old} = [P_Omega(X) - P_Omega(Z^{old})] + Z^{old}, where the first term has |Omega| << m n nonzeros and the second term has low rank r << min(m, n), allowing Lanczos/PROPACK matrix-vector products in O(|Omega| r + (m + n) r^2) time per SVD step. Lemmas 2-5 and Theorem 1 prove that the Soft-Thresholded SVD operator S_lambda is non-expansive in Frobenius norm (||S_lambda(W_1) - S_lambda(W_2)||_F <= ||W_1 - W_2||_F), generates monotonically decreasing objectives f_lambda(Z^{k+1}) <= f_lambda(Z^k) - (1/2)||P_Omega(Z^{k+1} - Z^k)||_F^2, satisfies ||Z^{k+1} - Z^k||_F -> 0, and converges from any starting point to a global minimizer Z_lambda^* of f_lambda(Z).

Identity Notes & Concept Scope Distinct from Singular Value Thresholding Algorithm for Matrix Completion (`AIMech:SingularValueThresholdingAlgorithmForMatrixCompletion`), which solves the equality-constrained Uzawa dual subgradient iteration Y^k = Y^{k-1} + delta_k P_Omega(X - Z^k) on sparse dual matrices rather than the unconstrained majorization-minimization update Z^{k+1} = S_lambda(P_Omega(X) + P_Omega^perp(Z^k)) with sparse-plus-low-rank Lanczos decomposition and warm-started regularization paths. Also distinct from AltMinSense and AltMinComplete Alternating Minimization for Low-Rank Matrix Sensing and Completion (`AIMech:AltMinSenseAndAltMinCompleteAlternatingMinimizationForLowRankMatrixSensingAndCompletion`), which performs non-convex fixed-rank alternating least squares without nuclear-norm soft-thresholding.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
For any matrix W = U D V^T in R^{m x n} and regularization parameter lambda >= 0, the unique global minimizer of (1/2)||W - Z||_F^2 + lambda ||Z||_* is given by the soft-thresholded SVD operator S_lambda(W) = U D_lambda V^T with D_lambda = diag(max(d_i - lambda, 0)) (Lemma 1), and by the von Neumann trace inequality tr(A^T B) <= sum_i sigma_i(A) sigma_i(B) (Lemma 6), S_lambda is globally non-expansive in Frobenius norm: ||S_lambda(W_1) - S_lambda(W_2)||_F^2 <= ||W_1 - W_2||_F^2 for all W_1, W_2 (Lemma 3).
  • supports Source: Spectral Regularization Algorithms for Learning Large Incomplete Matrices · Locator: Section 2, Lemma 1, p. 2290; Section 4, Lemma 3, p. 2296; Appendix A.2, Proof of Lemma 3 and Lemma 6 (Equations 16-22), pp. 2313-2317
  • supports Source: Spectral Regularization Algorithms for Learning Large Incomplete Matrices (arXiv abstract) · Locator: Abstract: Soft-thresholded SVD iteratively replaces missing elements with current low-rank guesses and solves nuclear-norm regularized least squares
Mechanism #claim-02
Each Soft-Impute update Z^{k+1} = S_lambda(P_Omega(X) + P_Omega^perp(Z^k)) minimizes the quadratic majorizer Q_lambda(Z | Z^k) = (1/2)||P_Omega(X) + P_Omega^perp(Z^k) - Z||_F^2 + lambda ||Z||_*, satisfies the monotonic descent bound f_lambda(Z^k) - f_lambda(Z^{k+1}) >= (1/2)||P_Omega(Z^k - Z^{k+1})||_F^2 (Lemma 2 and Proof of Lemma 4), satisfies the non-increasing step-difference property ||Z^{k+1} - Z^k||_F <= ||Z^k - Z^{k-1}||_F with ||Z^{k+1} - Z^k||_F -> 0 (Lemma 4), and converges to a global solution Z_lambda^* of min_Z f_lambda(Z) (Theorem 1).
  • supports Source: Spectral Regularization Algorithms for Learning Large Incomplete Matrices · Locator: Section 4, Lemmas 2, 4, 5 and Theorem 1 (Equations 12-15), pp. 2295-2298; Appendix A.1 and A.3-A.5, pp. 2313, 2317-2319
  • supports Source: Spectral Regularization Algorithms for Learning Large Incomplete Matrices (Crossref metadata) · Locator: Bibliographic record for Mazumder, Hastie, & Tibshirani (JMLR 2010, Vol. 11, pp. 2287-2322)
Limitation #claim-03
Because nuclear-norm penalization shrinks all positive singular values by the same additive amount lambda (soft-thresholding d_i -> max(d_i - lambda, 0)), large signal singular values suffer shrinkage bias on noisy matrices, motivating post-processing unshrunk least-squares refitting on the active singular vectors or non-convex hard-thresholding.
  • supports Source: Spectral Regularization Algorithms for Learning Large Incomplete Matrices · Locator: Section 5, Post-Processing of Selectors and Comparison with Hard-Thresholding (Equations 23-24), pp. 2298-2301

⚠️ Curated Limitations & Negative Results

  • Uniform singular-value shrinkage max(d_i - lambda, 0) biases large singular values downward, and the first-order EM/MM convergence rate is sublinear O(1/k) without Nesterov momentum or post-processing refits.
