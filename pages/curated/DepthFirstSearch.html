Depth-first search

Algorithms AIMech:DepthFirstSearch DRAFT
Aliases: DFS, Depth first traversal
A graph or state-space traversal that follows a newly chosen successor down the current search branch and backtracks when that branch has no eligible unvisited successor or reaches a stopping boundary.
Identity Notes & Concept Scope DFS denotes depth-first traversal, not depth-first iterative deepening or a shortest-path cost ordering. The visited-vertex graph traversal and a path-only tree search share the depth-first order but have different duplicate handling and memory requirements. No normalized identity match was found across the 442 AIO and 119 prior native records; ignored-inclusive text hits in the main checkout were dependency-package documentation and an unrelated package-metadata substring, not existing concept records.

Claims & Grounded Evidence

2 Claims
Mechanism #search-procedure
A recursive call or explicit stack continues down a successor branch before resuming the remaining successors of its ancestors. In the cited graph traversal, discovered vertices are marked and skipped on later encounters; an outer traversal can restart at an undiscovered vertex after a reachable component is exhausted.
  • supports Source: Boost Graph Library: Depth-First Search · Locator: Opening traversal description and DFS(G)/DFS-VISIT(G, u) pseudocode
Limitation #tree-search-limitations
The paper’s path-only depth-first search can revisit states along different paths, and an unbounded search without duplicate checks may fail to terminate. A chosen depth cutoff can miss a goal or permit a nonshortest first solution.
  • supports Source: Depth-First Iterative-Deepening: An Optimal Admissible Tree Search · Locator: Sections 3–4, printed pp. 99–100 / PDF pp. 3–4

⚠️ Curated Limitations & Negative Results

  • Depth-first order alone does not guarantee that the first goal has a shortest path.
  • A tree expansion can follow an infinite branch or repeat states indefinitely unless appropriate limits or duplicate controls are applied.
  • The graph implementation retains vertex marks; the linear-in-depth memory description of a path-only search is not a universal memory bound for all DFS implementations.
