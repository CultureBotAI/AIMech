Aliases: Non-local neural-network block
A neural-network component that aggregates input-dependent pairwise contributions from positions across a representation, projects the aggregate and adds it to the original features through a residual connection.

Identity Notes & Concept Scope This record denotes the residual non-local block introduced in the 2018 paper, not an entire non-local network, classical non-local-means denoiser, fixed dense layer or a particular trained video classifier. Its operator family includes softmax and non-softmax pairwise functions; an embedded-Gaussian instance overlaps self-attention without making every family member identical to a Transformer layer. Claims & Grounded Evidence

1 Claim
Mechanism #method
At each output position, evaluate a pairwise scalar function between that position and source positions across space, time or spacetime. Use those scalars to aggregate learned value embeddings of source features, with a normalizer chosen for the pairwise function. The paper’s Gaussian and embedded-Gaussian variants exponentiate dot products and normalize each query over source positions, yielding softmax weights. Its raw embedded dot-product and ReLU-on-concatenated-embeddings variants divide by the number of source positions instead. Project the aggregate back to the input channel count and add the original feature at the output position. A zero residual branch can initialize the block as identity. The source reduces embedding width and optionally max-pools the projected source branches to reduce pairwise work while retaining the output query grid; this changes the sampled context but retains long-range aggregation.

⚠️ Curated Limitations & Negative Results

  • Non-softmax weights need not sum to one, and raw dot-product weights can be negative. Their aggregate need not be a convex average or calibrated attention distribution. The paper’s Gaussian terminology refers to its exponential dot-product formula, not a required Euclidean radial-basis kernel.
  • The embedded-Gaussian formula lacks an explicit inverse-square-root dimension factor and is not a complete multi-head Transformer architecture. Subsampling projected source branches does not generally reproduce the full-resolution all-pairs result or commute with projection and pooling.
  • Zero output projection in the stated residual formula gives identity only when all residual contributions vanish. In the source’s batch-normalized implementation, zero scale also needs zero offset to make the branch zero; later training changes this state.
  • Explicit pairwise computation can require a query-by-source matrix and becomes expensive at high resolution. Bottleneck width, subsampling, placement and the chosen implementation determine costs; global reach does not imply linear complexity or universal speedup. No benchmark replication, source-code execution or proof of causal interpretability is asserted.
