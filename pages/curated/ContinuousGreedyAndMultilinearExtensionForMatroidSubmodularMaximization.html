Continuous Greedy and Multilinear Extension for Matroid-Constrained Monotone Submodular Maximization

Aliases: Calinescu-Chekuri-Pal-Vondrak Continuous Greedy Algorithm, Multilinear Extension and Matroid Pipage Rounding, Continuous Greedy Process for Submodular Welfare and Matroid Maximization
Continuous Greedy and Multilinear Extension for Matroid-Constrained Monotone Submodular Maximization is a two-stage continuous relaxation and rounding paradigm introduced by Calinescu, Chekuri, Pal, and Vondrak (2007, 2008, 2011) that achieves the optimal (1 - 1/e)-approximation for maximizing any monotone submodular set function f : 2^X -> R_+ subject to an arbitrary matroid constraint M = (X, I) in the value oracle model (Theorem 1.1), overcoming the tight 1/2-approximation barrier of the classical discrete greedy algorithm on general matroids (Fisher, Nemhauser, & Wolsey 1978). First, the discrete objective f is lifted to its canonical smooth monotone submodular multilinear extension F(y) = E[f(hat{y})] = sum_{R subseteq X} f(R) prod_{i in R} y_i prod_{j notin R} (1 - y_j) on [0, 1]^X (Section 2.1), which satisfies dF/dy_j = E[f(R + j) - f(R)] >= 0 (monotonicity), d^2F/(dy_i dy_j) <= 0 (submodularity, implying concavity along any nonnegative direction v >= 0), and d^2F/dy_j^2 = 0 (multilinearity, implying convexity along every swap direction e_i - e_j). Second, the Continuous Greedy algorithm integrates the flow dy/dt = v_max(y) = argmax_{v in P(M)} <v, grad F(y)> over t in [0, 1] starting from y(0) = 0 by iteratively finding a maximum-weight base I(t) in M with respect to sampled marginal gain estimates omega_j(t) = hat{E}[f_{R(t)}(j)] and updating y(t + delta) = y(t) + delta * 1_{I(t)} (Section 3.1), guaranteeing dF(y(t))/dt >= OPT - F(y(t)) and F(y(1)) >= (1 - 1/e) OPT in the matroid base polytope B(M) (Lemma 3.1, Lemma 3.3, Appendix A). Finally, matroid Pipage Rounding (Section 3.2, Lemma 3.5)—or independent per-block sampling for simple partition matroids (Section 3.3, Lemma 3.7)—exploits the convexity of F(y + t(e_i - e_j)) along tight-set swap directions to round y(1) to an integral independent base S in I with E[f(S)] >= F(y(1)) >= (1 - 1/e) OPT.

Identity Notes & Concept Scope Distinct from Stochastic-Greedy Linear-Time Monotone Submodular Maximization (`AIMech:StochasticGreedyLinearTimeMonotoneSubmodularMaximization`), which accelerates discrete greedy under a simple cardinality constraint |S| <= k via random candidate subset sampling of size (n/k) log(1/epsilon) and still suffers a 1/2 approximation barrier on general matroids, and from Away-Step and Pairwise Frank-Wolfe Linear Convergence on Polytopes (`AIMech:AwayStepAndPairwiseFrankWolfeLinearConvergenceOnPolytopes`), which minimizes strongly convex smooth objectives over polytopes rather than maximizing the non-concave multilinear extension F(y) of a monotone submodular set function via upward-monotone direction dominance and pipage rounding.

Claims & Grounded Evidence

3 Claims
Mechanism #r349-claim-multilinear-extension-directional-concavity-and-swap-convexity
For any monotone submodular set function f : 2^X -> R_+, its multilinear extension F(y) = E[f(hat{y})] is smooth monotone submodular (Definition 2.1) with first partial derivatives dF/dy_j = E[f(hat{y}) | hat{y}_j = 1] - E[f(hat{y}) | hat{y}_j = 0] >= 0, mixed second partial derivatives d^2F/(dy_i dy_j) <= 0 for i != j, and pure second partial derivatives d^2F/dy_j^2 = 0, which simultaneously makes F(y + xi * v^*) concave along any nonnegative direction v^* >= 0 and F_{ij}^y(t) = F(y + t(e_i - e_j)) convex along every coordinate swap direction e_i - e_j with second derivative -2 d^2F/(dy_i dy_j) >= 0.
  • supports Source: Maximizing a Monotone Submodular Function Subject to a Matroid Constraint · Locator: Section 2.1, Definition 2.1 and Multilinear Extension derivatives, p. 6; Section 2.4, Pipage Rounding Claim, p. 10
Mechanism #r349-claim-continuous-greedy-differential-inequality-and-approximation
For any fractional point y in [0, 1]^X and random subset R ~ hat{y}, submodularity implies OPT <= F(y) + max_{I in I} sum_{j in I} E[f_R(j)] (Lemma 3.1), so moving along the maximum-weight independent base I(t) in M with step size delta = 1 / (9 d^2) (or delta = 1 / (40 d^2 n) in Appendix A) satisfies OPT - F(y(t + delta)) <= (1 - delta)(OPT - F(y(t))) up to sampling error and produces a fractional point y(1) in the matroid base polytope B(M) with F(y(1)) >= (1 - 1/e) OPT with high probability (Lemma 3.3 and Appendix A).
  • supports Source: Maximizing a Monotone Submodular Function Subject to a Matroid Constraint · Locator: Section 2.3, Equation 5, p. 9; Section 3.1, Lemmas 3.1-3.3, pp. 11-13; Appendix A, pp. 25-26
Mechanism #r349-claim-matroid-pipage-rounding-lossless-conversion
Given any fractional solution y^* in the matroid base polytope B(M), oblivious randomized PipageRound(M, y^*) iteratively updates pairs of fractional variables (i, j) inside minimal tight sets along e_i - e_j or e_j - e_i until hitting a matroid rank constraint r_M(A) = y(A) (Proposition 3.4), preserving E[y' | y] = y and guaranteeing by convexity of F_{ij}^y(t) an integral independent set S in I with E[f(S)] >= F(y^*) in at most O(n^2) rounding steps (Lemma 3.5), while for simple partition matroids independent per-block sampling achieves E[f(T)] >= F(y^*) in a single step (Lemma 3.7).
  • supports Source: Maximizing a Monotone Submodular Function Subject to a Matroid Constraint · Locator: Section 3.2, Proposition 3.4, Algorithm PipageRound, and Lemma 3.5, pp. 14-16; Section 3.3, Lemma 3.7, pp. 16-17

⚠️ Curated Limitations & Negative Results

  • Evaluating the gradient of the multilinear extension in the general value oracle model requires Monte Carlo sampling at each discretized time step (yielding a high-degree polynomial O~(n^8) runtime in the baseline analysis), and continuous greedy requires monotonicity of f to guarantee dF/dt >= OPT - F(y(t)) (Section 5).
