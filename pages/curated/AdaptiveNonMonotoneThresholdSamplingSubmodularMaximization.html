Adaptive Non-Monotone Threshold Sampling for Low-Adaptivity Submodular Maximization

Aliases: ADAPTIVE-NONMONOTONE-MAX, NON-MONOTONE-THRESHOLD-SAMPLING, Fahrbach-Mirrokni-Zadimoghaddam Non-Monotone Low-Adaptivity Submodular Maximization
Adaptive Non-Monotone Threshold Sampling (ADAPTIVE-NONMONOTONE-MAX and its core subroutine NON-MONOTONE-THRESHOLD-SAMPLING) is a parallel low-adaptivity algorithm for maximizing a non-negative (possibly non-monotone) submodular set function f: 2^N -> R_>=0 subject to a cardinality constraint |S| <= k, introduced by Fahrbach, Mirrokni, and Zadimoghaddam (2019). For each parallel threshold guess tau = c_1 * (1 + eps_hat)^i * Delta^* / k, NON-MONOTONE-THRESHOLD-SAMPLING (Algorithm 1) iteratively filters candidates A <- {x in A : Delta(x, S) >= tau}, terminates early if |A| < c_3 * k (ensuring every element x in N is selected with probability at most 1 / c_3), finds the largest batch size t = min{floor((1 + eps_hat)^i), |A|} via REDUCED-MEAN (Algorithm 2) on the Bernoulli indicator I_t = 1[Delta(x, S cup T) >= tau], samples T ~ U(A, min{t, k - |S|}), and applies a random-permutation post-filtering step S' <- S' cup {x_i in T : Delta(x_i, S cup {x_1, ..., x_{i-1}}) >= tau} (Lines 14-15) before updating S <- S cup T; if the loop breaks early because |A| < c_3 * k, ADAPTIVE-NONMONOTONE-MAX (Algorithm 4) runs unconstrained submodular maximization on A, uniformly downsamples to cardinality k if |U| > k, takes the highest-valued prefix U'' of a random permutation, and returns argmax_{X in {R, S', U''}} f(X).

Identity Notes & Concept Scope Distinct from AIMech:AmortizedFilteringForLogarithmicAdaptivitySubmodularMaximization (Round 360, Balkanski, Rubinstein, & Singer 2019) and AIMech:ParallelGreedySubmodularMaximizationInLogarithmicAdaptivityAndNearlyLinearTime (Round 362, Ene & Nguyen 2019), which require monotone submodular objectives where adding an eps-fraction of below-threshold elements cannot reduce objective value, whereas NON-MONOTONE-THRESHOLD-SAMPLING enforces early candidate-pool termination |A| < c_3 * k (to bound element inclusion probability <= 1/c_3 for Lemma 2.1), adds prefix post-filtering (to prevent negative-marginal elements from degrading S'), and couples threshold sampling with unconstrained maximization and uniform downsampling when |A| < c_3 * k.

Claims & Grounded Evidence

3 Claims
Mechanism #r370-claim-post-filtered-nonmonotone-threshold-sampling-invariants
For any non-negative submodular function f, threshold tau, and candidate scale factor c >= 1, NON-MONOTONE-THRESHOLD-SAMPLING (Algorithm 1) runs in O(log(n/delta)/varepsilon) adaptive rounds and O(n/varepsilon) expected oracle queries, and conditioned on the high-probability event Z that all REDUCED-MEAN calls (Algorithm 2, Lemma 2.4) succeed (with Pr[Z] >= 1 - delta/2), guarantees that (1) if |S| < k upon termination then |A| < c*k with probability at least 1 - delta/2, and (2) the post-filtered set S' satisfies E[|S'| | Z] >= (1 - varepsilon_hat)*E[|S| | Z]; furthermore, unconditionally (for every realization), the prefix post-filtering step (Lines 14-15) guarantees f(S') >= tau * |S'| (Property 4) and the early stopping rule |A| < c*k (Line 7) guarantees Pr[x in S'] <= Pr[x in S] <= 1/c for every x in N (Property 5, Lemma 2.3).
  • supports Source: Non-monotone Submodular Maximization with Nearly Optimal Adaptivity and Query Complexity · Locator: Section 2.1, Definition 2.2, Algorithms 1-2, and Lemmas 2.3-2.4, pp. 4-5; Appendix A, Proof of Lemma 2.3 (Properties 1-5), pp. 16-18
Mechanism #r370-claim-complementary-event-tradeoff-and-downsampling-bound
For threshold tau approx c_1 * OPT / k, if event A_{>= c_3 k} occurs (so |S| = k conditioned on Z), then E[ALG] >= (1 - varepsilon)*(1 - delta)*c_1*OPT*Pr[A_{>= c_3 k} | Z] (Lemma 3.5); if the complementary event A_{< c_3 k} occurs (so |A| < c_3*k), then running an alpha-approximate unconstrained submodular maximization subroutine on A followed by uniform downsampling D ~ U(U, k) (which preserves E[f(D)] >= (k/|U|)*f(U) >= (1/c_3)*f(U) by Lemma 3.3) and applying Lemma 2.1 to g(S) = f(S^* cup S) with Pr[x in S' | Z] <= 1/c_3 yields E[ALG] >= ((1 - varepsilon)*(1 - delta)*alpha / c_3) * [(1 - c_1)*OPT*Pr[A_{< c_3 k} | Z] - OPT/c_3 - 2*E[f(S') | Z]] (Lemma 3.6).
  • supports Source: Non-monotone Submodular Maximization with Nearly Optimal Adaptivity and Query Complexity · Locator: Section 2, Lemma 2.1, p. 4; Section 2.2, Algorithm 3 and Lemmas 2.5-2.6, p. 6; Section 3.1-3.2, Algorithm 4, Definition 3.4, and Lemmas 3.3, 3.5, 3.6, pp. 7-9; Appendix B, Proofs of Lemma 3.3 and Lemma B.1, pp. 18-19
Mechanism #r370-claim-logarithmic-adaptivity-and-nearly-linear-query-complexity
Balancing the two complementary bounds of Lemmas 3.5 and 3.6 via max_{c_1,c_3,c_4,beta} min{c_4, (alpha/((1+beta)*c_3))*(1 - c_1 - 1/c_3 - 2*c_4)} subject to beta*c_1*c_3/alpha = 1 - c_1 yields E[ALG]/OPT >= (1 - varepsilon)*(1 - delta)*alpha*(1 - (1 + beta*c_3/alpha)^{-1} - c_3^{-1}) / ((1 + beta)*c_3 + 2*alpha) (Eq. 6); instantiating with 1-round random-subset UNCONSTRAINED-MAX (alpha = 1/4, c_3 = 3, beta = 1/2, c_1 = 1/7) achieves an expected (11/420)*(1 - varepsilon)*(1 - delta) >= 0.026*(1 - varepsilon)*(1 - delta) approximation in O(log(n/delta)/varepsilon) adaptive rounds and O(n*log(k)/varepsilon^2 + delta*n^2) expected oracle queries (Theorem 3.1), while instantiating with (1/2 - varepsilon)-approximate low-adaptivity unconstrained maximization (alpha = 1/2, c_3 = 3.556, beta = 0.5664, c_1 = 0.198989) achieves a 0.039*(1 - varepsilon)*(1 - delta) approximation in O(log(n/delta)/varepsilon) adaptive rounds and O(n*log(k)*log^3(1/varepsilon)/varepsilon^5 + delta*n^2) expected queries (Theorem 3.2).
  • supports Source: Non-monotone Submodular Maximization with Nearly Optimal Adaptivity and Query Complexity · Locator: Section 3-3.2, Theorems 3.1 and 3.2, and Equations (5)-(6), pp. 6-7, 10

⚠️ Curated Limitations & Negative Results

  • Achieves a small constant approximation ratio of 0.026 (with 1-round random unconstrained maximization) or 0.039 (with multi-round unconstrained maximization), well below the centralized 1/e - varepsilon approximation ratio, and applies only to cardinality constraints |S| <= k rather than general matroid or knapsack constraints (Table 1 and Section 5, pp. 2, 12).
