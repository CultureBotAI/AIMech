Breadth-first search

Algorithms AIMech:BreadthFirstSearch DRAFT
Aliases: BFS, Breadth first traversal
A graph or state-space traversal that expands vertices in nondecreasing shortest-path distance from a start vertex, where distance counts edges.
Identity Notes & Concept Scope BFS denotes breadth-first search in this record, not the abbreviation sometimes used for generic best-first search. FIFO layer traversal is distinct from a cost-priority queue for weighted paths and from depth-first traversal. No normalized identity match was found across the 442 AIO and 119 prior native records; ignored-inclusive text hits in the main checkout were dependency-package documentation and an unrelated package-metadata substring, not existing concept records.

Claims & Grounded Evidence

2 Claims
Mechanism #search-procedure
A FIFO queue holds discovered vertices awaiting expansion. Remove its front vertex, inspect its outgoing edges, mark each previously undiscovered neighbor when it is enqueued, and continue until the queue is empty or a goal-search stopping condition is met.
  • supports Source: Boost Graph Library: Breadth-First Search · Locator: Opening traversal description; BFS(G, s) pseudocode; buffer(Buffer& Q) parameter
Scope #edge-count-scope
Unit-edge paths are within breadth-first search’s shortest-path scope; general nonnegative weighted paths require a cost-sensitive method such as Dijkstra’s algorithm.
  • supports Source: Boost Graph Library: Dijkstra’s Shortest Paths · Locator: Opening description comparing nonnegative weighted shortest paths with unit-edge breadth-first search

⚠️ Curated Limitations & Negative Results

  • Shortest distance means number of edges; arbitrary unequal edge costs are not minimized by FIFO traversal.
  • The cited graph implementation tracks discovered vertices. Its visited-state storage and frontier memory must not be confused with a path-only tree-search implementation.
  • Traversal from a single start reaches only its reachable component; the documentation describes separate visits for disconnected components.
