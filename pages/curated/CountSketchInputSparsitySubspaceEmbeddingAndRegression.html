CountSketch Input-Sparsity Subspace Embedding and Regression

Aliases: Clarkson-Woodruff Input-Sparsity Transform (CW Sketch), Sparse CountSketch Oblivious Subspace Embedding, Input-Sparsity Time Low-Rank Approximation and Regression
CountSketch Input-Sparsity Subspace Embedding and Regression is an oblivious sparse random projection and numerical linear algebra framework introduced by Clarkson and Woodruff (2013, 2017) that constructs an O(n)-column, t-row sketching matrix S = Phi D in R^{t x n} with exactly ONE nonzero entry per column (S_{h(i), i} = sigma_i in {-1, +1}, where h: [n] -> [t] and sigma: [n] -> {-1, +1} are random hash and sign maps) so that S A can be computed in true input-sparsity time O(nnz(A)) for any matrix A in R^{n x d}, where nnz(A) is the number of nonzero entries of A. Theorem 2.3 and Lemma 2.5 prove that for t = O(d^2 / epsilon^2) (or t = O(k^2 / epsilon^2) for a k-dimensional subspace), S is a (1 +/- epsilon)-l_2 subspace embedding satisfying ||S A x||_2 = (1 +/- epsilon)||A x||_2 simultaneously for all x in R^d by decomposing the basis U of range(A) into heavy rows (||u_i||_2^2 >= tau, which are isolated into distinct hash buckets without collision and preserved isometrically) and light rows (bounded via high-moment trace inequalities), yielding O(nnz(A) + d^3 epsilon^{-2} log(d/epsilon)) algorithms for (1+epsilon)-approximate overconstrained least-squares regression (Theorem 2.6) and O(nnz(A) + n poly(k/epsilon)) low-rank matrix approximation.

Identity Notes & Concept Scope Distinct from Subsampled Randomized Hadamard Transform Subspace Embedding (`AIMech:SubsampledRandomizedHadamardTransformSubspaceEmbedding`), which requires O(n d log t) dense Walsh-Hadamard butterfly operations regardless of matrix sparsity, and from Frequent Directions Deterministic Streaming Matrix Sketching (`AIMech:FrequentDirectionsDeterministicStreamingMatrixSketching`), which uses O(n d l) deterministic SVD shrinkage. Specifically captures the Clarkson-Woodruff single-nonzero-per-column CountSketch matrix S = Phi D, the heavy/light leverage row decomposition (Lemma 2.5), and the O(nnz(A)) input-sparsity time algorithms for subspace embedding, least-squares regression, and rank-k approximation.

Claims & Grounded Evidence

3 Claims
Mechanism #claim-01
For the sparse embedding matrix S = Phi D in R^{t x n} with a single uniformly hashed bucket h(i) in [t] and random Rademacher sign sigma_i in {-1, +1} per column i, the matrix product S A is computable in O(nnz(A)) arithmetic operations, satisfies the exact unbiased second-moment identity E[(S^T S)_{ij}] = delta_{ij} (so E[||S x||_2^2] = ||x||_2^2 and E[||S A||_F^2] = ||A||_F^2), and preserves the Euclidean norm of any subset of heavy rows isolated into distinct hash buckets with exact isometry.
  • supports Source: Low Rank Approximation and Regression in Input Sparsity Time · Locator: Section 1.2, Construction of S = Phi D, p. 6; Section 2.1, Theorem 2.3 and Lemma 2.5 (heavy/light row decomposition), pp. 13-16
  • supports Source: Low Rank Approximation and Regression in Input Sparsity Time (arXiv abstract) · Locator: Abstract: sparse subspace embeddings running in O(nnz(A)) input-sparsity time
Scope #claim-02
Theorem 2.3 and Theorem 2.6 prove that for t = O(d^2 / epsilon^2) rows, S = Phi D is a (1 +/- epsilon)-l_2 subspace embedding for any d-dimensional subspace V in R^n with constant probability, and combining CountSketch preconditioning with iterative refinement solves min_x ||A x - b||_2 to (1 + epsilon) relative residual error in O(nnz(A) log(1/epsilon) + d^3 log^2 d + d^2 log(1/epsilon)) time.
  • supports Source: Low Rank Approximation and Regression in Input Sparsity Time · Locator: Section 2.1, Theorem 2.3, p. 14; Section 2.2, Theorem 2.6 (Overconstrained Least Squares), pp. 16-17
  • supports Source: Low Rank Approximation and Regression in Input Sparsity Time (Crossref metadata) · Locator: STOC 2013 bibliographic record, pp. 81-90
Limitation #claim-03
Because S = Phi D hashes each row of A to a single bucket without prior Hadamard spreading, avoiding collisions among up to d high-leverage (spiky canonical basis) rows by the birthday paradox requires target dimension t = Omega(d^2 / epsilon^2) rather than O(d / epsilon^2), and hash collisions between two heavy basis rows with opposite effective signs cause destructive cancellation that breaks the subspace embedding property.
  • supports Source: Low Rank Approximation and Regression in Input Sparsity Time · Locator: Section 2.1, Proof of Lemma 2.5 (perfect hashing of heavy rows W requires t = Omega(|W|^2) = Omega(d^2)), pp. 15-16

⚠️ Curated Limitations & Negative Results

  • Single-pass sparse CountSketch subspace embedding requires O(d^2 / epsilon^2) target rows (quadratic in subspace dimension d due to birthday-paradox collision avoidance on high-leverage rows) unless composed in a two-stage sketch with SRHT.
