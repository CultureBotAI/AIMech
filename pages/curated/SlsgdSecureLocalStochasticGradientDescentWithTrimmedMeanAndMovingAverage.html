SLSGD Secure Local Stochastic Gradient Descent with Trimmed Mean and Moving Average

Algorithms AIMech:SlsgdSecureLocalStochasticGradientDescentWithTrimmedMeanAndMovingAverage DRAFT
Aliases: SLSGD, Secure Local Stochastic Gradient Descent, Secure Local SGD
A Byzantine-resilient communication-efficient distributed on-device optimization algorithm proposed by Xie, Koyejo, and Gupta (ECML-PKDD 2019) that generalizes Federated Averaging and Local SGD to non-IID data, heterogeneous local iteration counts, and data-poisoned or compromised workers by aggregating sampled local models with a coordinate-wise b-trimmed mean and updating the global model via a server-side exponential moving average.
Identity Notes & Concept Scope Distinct from single-step synchronous Coordinate-Wise Median and Trimmed Mean Gradient Aggregation (AIMech:CoordinateWiseMedianAndTrimmedMeanByzantineRobustGradientAggregation, which aggregates single-step gradients without multi-step local SGD updates or server-side moving-average variance reduction) and from standard Federated Averaging / Local SGD (which corresponds to SLSGD Option I with b = 0 and alpha = 1). SLSGD (Xie et al., ECML-PKDD 2019, pp. 213-228 / arXiv:1903.06996, Algorithm 1, p. 6) samples a subset S_t of k workers in each global epoch t, runs H_t^i >= H_{min} heterogeneous local SGD iterations x_{t,h}^i <- x_{t,h-1}^i - gamma nabla f(x_{t,h-1}^i; z_{t,h}^i) from x_{t,0}^i = x_{t-1} on each device i in S_t, aggregates the resulting local models via coordinate-wise b-trimmed mean x_t' = Trmean_b({x_{t,H_t^i}^i : i in S_t}) = (1 / (k - 2b)) sum_{i=b+1}^{k-b} u_{i:k} (Option II, Definition 3), and updates the global model via the moving average x_t <- (1 - alpha) x_{t-1} + alpha x_t' (with alpha in (0, 1]).

Claims & Grounded Evidence

4 Claims
Mechanism #slsgd-two-level-trimmed-mean-model-aggregation-and-moving-average-update
In each global epoch t, SLSGD activates k randomly sampled devices S_t to perform H_t^i >= H_{min} local SGD steps and applies two levels of server-side defense: (1) Option II aggregates the pushed local models via the coordinate-wise b-trimmed mean x_t' = Trmean_b({x_{t,H_t^i}^i : i in S_t}) = (1/(k-2b)) sum_{i=b+1}^{k-b} u_{i:k}, and (2) updates the global model via a moving average x_t <- (1 - alpha) x_{t-1} + alpha x_t' that simultaneously dampens robust-aggregation error and local-update drift.
  • supports Source: SLSGD: Secure and Efficient Distributed On-device Machine Learning · Locator: Section 4, Algorithm 1, Lines 4-15 and Section 4.1, Definition 3 & Remark 2, pp. 6-7
Scope #slsgd-non-iid-convergence-and-poisoning-error-bound-theorem
Whereas standard Local SGD / FedAvg (Option I with alpha = 1) suffers unbounded expected error under model replacement by q_1 poisoned workers (Proposition 1), Theorem 2 proves that for 2q <= 2b < k and step size gamma <= min(1/L, 2), SLSGD with Option II converges on L-smooth mu-lower-bounded Taylor functions at rate (1 - alpha + alpha(1 - gamma/2)^{H_{min}})^T [F(x_0) - F(x_*)] up to an error neighborhood O(V_1) + O(beta V_2) with beta = 1 + 1/(k-q) - 1/n + k(k+b)/(k-b-q)^2.
  • supports Source: SLSGD: Secure and Efficient Distributed On-device Machine Learning · Locator: Section 5.2-5.3, Theorem 1, Proposition 1, and Theorem 2, pp. 8-9, 23-28
Limitation #slsgd-per-epoch-sampled-byzantine-minority-and-trimmed-variance-limitation
SLSGD requires that the number of poisoned workers q among the k sampled devices in each epoch satisfy 2q <= 2b < k, and increasing the trimming parameter b or decreasing the moving-average weight alpha trades off convergence speed against variance and poisoning tolerance through the factor k(k+b)/(k-b-q)^2.
  • supports Source: SLSGD: Secure and Efficient Distributed On-device Machine Learning · Locator: Section 5.3, Theorem 2 & Remark 5, p. 9; Section 6.3-6.5, pp. 12-15
Application #slsgd-on-device-federated-vision-and-language-modeling-application
Applied to attack-tolerant on-device distributed training of convolutional neural networks on balanced and unbalanced non-IID CIFAR-10 partitions and LSTM language models on WikiText-2 under label-flipping and label-permutation data poisoning.
  • supports Source: SLSGD: Secure and Efficient Distributed On-device Machine Learning · Locator: Section 6.1-6.4, Figures 1-6, pp. 10-14; Appendix Section 8, Figures 7-13, pp. 17-23

⚠️ Curated Limitations & Negative Results

  • Requires 2q <= 2b < k in each communication epoch so that the b-trimmed mean can filter all q compromised workers among the k sampled devices.
  • Because trimming operates independently on each coordinate of the local parameter vectors, high-dimensional non-IID parameter drift increases the error neighborhood O(beta V_2) when b is large.
