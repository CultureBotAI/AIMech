NovoGrad

Algorithms AIMech:NovoGrad DRAFT
Aliases: Layer-Wise Adaptive Moments for Deep Network Training, Stochastic Gradient Methods with Layer-wise Adaptive Moments, Layer-Wise Normalized Adam with Decoupled Weight Decay
A layer-wise adaptive stochastic gradient optimization algorithm that computes a single scalar second-moment exponential moving average per network layer l from the squared Euclidean norm of the layer gradient, v_t^l = beta_2 v_{t-1}^l + (1 - beta_2) ||g_t^l||_2^2 (initialized directly at v_1^l = ||g_1^l||_2^2), normalizes the current layer gradient by sqrt(v_t^l) + epsilon and adds decoupled weight decay d * w_t^l prior to first-moment accumulation m_t^l = beta_1 m_{t-1}^l + (g_t^l / (sqrt(v_t^l) + epsilon) + d * w_t^l), and updates layer weights via w_{t+1}^l = w_t^l - alpha_t m_t^l.
Identity Notes & Concept Scope Distinct from Adam and AdamW (which maintain a full per-parameter second-moment tensor v_t of dimension p^l per layer and normalize the first moment after accumulation), from LaProp (AIMech:LaProp, which normalizes coordinates before momentum using per-coordinate second moments), and from LARS/LAMB (AIMech:LARSAndLAMBLayerWiseAdaptiveRateScaling, which rescale updates by the weight-to-update trust ratio ||w^l||_2 / ||u^l||_2). NovoGrad requires only one scalar v_t^l per layer, reducing optimizer state memory from 2P to P + L floats.

Claims & Grounded Evidence

4 Claims
Mechanism #novograd-layerwise-second-moment-and-pre-momentum-normalization
For each layer l with stochastic gradient g_t^l at iteration t, NovoGrad updates a single scalar second moment v_t^l = beta_2 v_{t-1}^l + (1 - beta_2) ||g_t^l||_2^2 initialized at v_1^l = ||g_1^l||_2^2, normalizes the gradient and adds decoupled weight decay d * w_t^l inside the momentum recurrence m_t^l = beta_1 m_{t-1}^l + (g_t^l / (sqrt(v_t^l) + epsilon) + d * w_t^l), and updates weights via w_{t+1}^l = w_t^l - alpha_t m_t^l, reducing to Stochastic Normalized Gradient Descent when beta_2 = 0 and d = 0.

  • supports Source: Stochastic Gradient Methods with Layer-wise Adaptive Moments for Training of Deep Networks (Crossref metadata) · Locator: Bibliographic metadata for Ginsburg et al. 2019
Scope #novograd-memory-footprint-and-outlier-gradient-robustness
Because NovoGrad stores only one scalar second-moment estimate v_t^l per layer instead of one float per parameter, it cuts auxiliary optimizer state memory in half compared to Adam/AdamW (from 2P to P + L floats for a model with P parameters and L layers) while bounding any single-step pre-momentum gradient contribution in Euclidean norm by at most 1 / sqrt(1 - beta_2).
  • supports Source: Stochastic Gradient Methods with Layer-wise Adaptive Moments for Training of Deep Networks · Locator: Abstract and Section 1, p. 1-2
  • supports Source: Stochastic Gradient Methods with Layer-wise Adaptive Moments for Training of Deep Networks (arXiv abstract) · Locator: Abstract
Application #novograd-large-batch-vision-speech-and-translation-applications
NovoGrad is applied to large-batch and mixed-precision training of ResNet-50 on ImageNet (reaching 76.94% top-1 accuracy at batch size 1024 and 76.36% at batch size 32K), Jasper speech recognition on LibriSpeech (11.9% WER on test-other, outperforming SGD by 1.3% relative), Transformer neural machine translation on WMT 2014 English-to-German (28.3 BLEU without warmup), and OpenAI GPT-2 language modeling on WikiText-103.
  • supports Source: Stochastic Gradient Methods with Layer-wise Adaptive Moments for Training of Deep Networks · Locator: Section 2 (Experiments), Tables 1-4 and Figures 1-2, p. 2-4
Limitation #novograd-within-layer-isotropic-scaling-limitation
Because NovoGrad normalizes all parameters within a layer l by a single shared scalar sqrt(v_t^l), it does not adaptively rescale individual coordinates within the same layer that have heterogeneous curvature or sparse feature frequencies, and its effective update scale depends on how parameters are partitioned into layers or parameter groups.
  • supports Source: Stochastic Gradient Methods with Layer-wise Adaptive Moments for Training of Deep Networks · Locator: Section 1 (Algorithm), Equations 1-2, p. 1-2

⚠️ Curated Limitations & Negative Results

  • Applies a single isotropic scalar step-size normalization across all coordinates of a given layer l, lacking per-coordinate diagonal preconditioning for sparse embedding tables or layers with highly heterogeneous within-layer feature scales.
  • Update magnitudes depend on the user-defined partitioning of parameters into layers (e.g., separating biases and BatchNorm parameters from weight tensors).
