Information maximizing self-augmented training

Algorithms AIMech:InformationMaximizingSelfAugmentedTraining DRAFT
Aliases: IMSAT, Information maximising self-augmented training
A discrete representation-learning procedure that combines self-augmentation consistency with an information objective, using categorical outputs for clustering or a pairwise approximation for multi-bit hashing.
Identity Notes & Concept Scope IMSAT is the named Hu et al. procedure with explicitly different clustering and hashing configurations. It learns discrete output variables, unlike continuous embedding dependence estimators. Its information between input and output, plus consistency to a fixed current prediction, differs from IIC information between two assignment variables. This umbrella record does not equate the categorical, nonuniform-prior and hash objectives. Claims & Grounded Evidence

1 Claim
Mechanism #method
For a current network snapshot, hold the original-input output distribution fixed and minimize cross-entropy against the network prediction on a transformed input, summed over discrete output components and averaged over samples. Transformations include random perturbations or virtual adversarial perturbations approximately chosen to maximize local prediction change. For categorical clustering use R_SAT−lambda[H(Y)−H(Y|X)], with the marginal obtained by averaging conditional predictions. The nonuniform-prior variant instead minimizes R_SAT+lambda H(Y|X) subject to KL(p(Y)||q(Y))≤delta, implemented with an increasing positive-part penalty. For binary hashing the factorized conditional model uses the truncated information objective sum_d I(X;Y_d)−sum_(d≠e) I(Y_d;Y_e), with ordered distinct bit pairs. The pinned hash code enumerates unordered pairs and multiplies their mutual-information sum by two, confirming that convention. Its clustering code detaches the teacher and implements epsilon-stabilized KL consistency. Ideal KL and cross-entropy have the same parameter gradient for a fixed teacher; the code adds epsilon inside the logarithm and therefore only approximates that unstabilized identity. That code defaults to H(Y|X)−4H(Y), a weighted entropy variant rather than the unit-weight information expression.

⚠️ Curated Limitations & Negative Results

  • Hashing truncates the information expansion; pairwise penalties do not establish joint independence or exact information for the full bit vector. The ordered-pair convention affects its relative regularization strength.
  • The minibatch KL inequality is an expectation bound from convexity, not a bound for every batch or a guarantee that finite stochastic optimization satisfies the prior constraint. Penalty-method idealizations do not certify the trained nonconvex network.
  • Consistency depends on suitable transformations and perturbation radii. A transformation can preserve a nuisance factor or change desired semantics. Balanced marginal entropy can conflict with genuinely imbalanced classes.
  • The pinned clustering code uses a weighted marginal entropy default; it must not be silently described as exact unit-weight mutual information. Epsilon stabilization and approximate virtual perturbations further distinguish numerical loss from ideal formulas.
  • Some reported image experiments use features from an ImageNet-pretrained ResNet and hyperparameter selection uses labeled clustering accuracy. Unsupervised final training does not mean every source of representation or model-selection information is label-free. No model was run.
