Dispatch-dependent value functional

Mathematical Methods AIMech:DispatchDependentValueFunctional DRAFT
A dispatch-prefix-conditioned mathematical rule that returns, as a function of a contemplated search start time t, the modeled probability of finishing remaining search no later than a latest-start deadline estimated from the undispatched path and a relaxed goal plan: V(H_d,H_c)(t)=Pr_{m~M_i}[t+m<=d(i)].
Identity Notes & Concept Scope This record denotes the Section 3 dispatch-prefix-conditioned mathematical rule, with empty aliases and a scope distinct from the dual-queue controller. It maps planning/dispatch context to a function of contemplated search start time and models completion no later than the estimated deadline. Claims & Grounded Evidence

6 Claims
Mechanism #prefix-conditioned-success-event
For a node i, partition its path H_i into an already committed prefix H_d and a remaining undispatched suffix H_c. Section 3 defines V(H_d,H_c)(t)=Pr_{m~M_i}[t+m<=d(i)], where M_i models remaining search time and d(i)=latest_start(H_c,pi_i) depends on the undispatched path and a relaxed goal plan. The path-conditioned object returns a function of contemplated search start time; it is a modeled success probability with an inclusive deadline event.
  • supports Source: Concurrent Planning and Execution Using Dispatch-Dependent Values · Locator: Author PDF p.4, Section 3, footnote 1 and Eq.3; official p.8486.
Mechanism #path-and-relaxed-plan-deadline
The deadline construction takes the smaller of the latest-start bounds from the remaining path and the relaxed goal plan. The relaxed-plan bound uses the tightest action deadline slack relative to its estimated earliest time. When the remaining path is empty its path latest-start bound is taken as infinity, leaving the relaxed-plan bound to determine d(i). The latter bound is a heuristic estimate in this source.
  • supports Source: Concurrent Planning and Execution Using Dispatch-Dependent Values · Locator: Author PDF p.3, latest_start formulas; p.4, all-actions-dispatched limit following Eq.3; official pp.8485–8486.
Mechanism #family-of-assumed-dispatch-prefixes
Each prefix H_p of the remaining path H_c defines a different assumed-commitment context: move H_p to the end of H_d and compute the rule on the residual suffix. Thus a path with |H_c| remaining actions defines |H_c|+1 such functionals, including the none-dispatched and all-dispatched cases. These are hypothetical value evaluations, not commands to execute those actions.
  • supports Source: Concurrent Planning and Execution Using Dispatch-Dependent Values · Locator: Author PDF p.4, Section 3 prefix construction; official p.8486.
Scope #fixed-model-monotonicity-and-endpoint
With M and d fixed, increasing t can only shrink the event {m<=d−t}, so V is nonincreasing, not necessarily strictly decreasing. If m is nonnegative and d finite, V(d)=Pr[m=0] and V(t)=0 for t>d. These endpoint statements follow directly from Eq.3; they are curator deductions with explicit premises, not a claim that zero is reached at t=d or that refreshed estimates remain monotonic.
  • supports Source: Concurrent Planning and Execution Using Dispatch-Dependent Values · Locator: Author PDF p.4 Eq.3 and following monotonicity paragraph; p.5 refresh description; official pp.8486–8487.
Scope #frozen-prefix-relaxation
If the node’s remaining-search law and relaxed-plan bound are held fixed, removing assumed-dispatched actions from the minimum over remaining path constraints cannot lower that path bound. Consequently the combined deadline and inclusive success probability cannot decrease in this frozen comparison. This mathematical comparison does not establish that actual irreversible dispatch improves achievable success when the frontier, model or feasible alternatives change.
  • supports Source: Concurrent Planning and Execution Using Dispatch-Dependent Values · Locator: Author PDF p.3 minimum latest_start definitions; p.4 prefix discussion; p.5 irreversible-dispatch warning; official pp.8485–8487.
Scope #conditional-none-all-context-correspondence
The source motivates evaluating only the none-dispatched and all-dispatched cases across a forward search when a reasonable relaxed plan at an ancestor has a successor whose relaxed plan is the matching suffix. Under that structural assumption, an intermediate assumed commitment at the successor can correspond to an all-dispatched commitment context at the ancestor. This is a conditional correspondence of action contexts, not a proof of equal node-specific probabilities or an optimal policy over all prefixes.
  • supports Source: Concurrent Planning and Execution Using Dispatch-Dependent Values · Locator: Author PDF p.4, final Section 3 argument continuing on p.5; official pp.8486–8487.

⚠️ Curated Limitations & Negative Results

  • The probability is conditional on estimated remaining search time and an estimated deadline. Expansion-delay statistics and relaxed-plan length inform M_i, and the relaxed-plan deadline is explicitly inadmissible. No calibration, error bound or certainty that the chosen plan remains executable follows from Eq.3.
  • The background deadline-CDF notation conflicts with its later decreasing deterministic step: Eq.1 uses 1−D_i after calling D_i a CDF, while the next page assigns one before/on the deadline and zero afterward. Eq.3’s inclusive success event is retained on its own terms. No silent repair of the background convention or identity between its strict survival event and Eq.3 at atoms is asserted.
  • The planner’s pf is described as a failure tail although Eq.3 defines success. The interface pf=1−V=Pr[m>d−t] is an explicit complementary interpretation, not a separately printed executable formula. Equality belongs to success; a >= failure event can differ when the law has atoms. The functional alone does not prescribe that queue interface or its numerical implementation.
  • Monotonicity requires the distribution and deadline to remain fixed. With nonnegative remaining time and finite d, vanishing is assured for t>d, while V(d)=Pr[m=0] can be positive. Updating M_i, the relaxed plan or deadline can increase a later recomputed value; infinite/no global deadlines and negative remaining times are outside the stated endpoint deduction.
  • Removing path constraints in a frozen hypothetical comparison is not the same as performing an irreversible action. Actual dispatch restricts accessible subtrees and can invalidate alternatives or make a goal unreachable. The source’s background abstract action exclusivity also must not be transferred unqualified to the concurrent multi-robot planner.
  • The none/all argument assumes matching ancestor/successor relaxed-plan structure. It does not prove equality of M_i laws, equal probabilities, retention of the requisite ancestors in OPEN, or sufficiency for arbitrary prefix policies and changed temporal constraints. It is a heuristic reduction argument rather than a general optimal metareasoning theorem.
  • This rule does not specify an estimator-training procedure, full search algorithm, scheduler, dispatch threshold, stopping test or duplicate-state policy. The source’s dual planner adds alternating queues, tie-breaking and periodic refresh, and uses an earlier dispatch integration. Those control rules and their reported performance are not properties of the mathematical functional alone.
  • The simulated RCLL coverage and queue-agreement results assess complete configured planners rather than isolated correctness or calibration of this functional. Their repeated scenario/rate combinations, chosen weights and thresholds, and absent table uncertainty measures do not establish a universal benefit of the rule in other domains.
  • Evidence comes from the byte-distinct author and official PDFs of one 2025 work, not independent replications. Name-form, institutional-date and OPTIC/COLIN citation differences remain in research context. No referenced original algorithm or implementation is newly certified here, and all 38 bibliography occurrences and original follow-up objects remain unchanged in the retained ledger.
