Evidence Governance & Epistemic Boundaries

Strict Curation Contract

Ontology membership does not establish algorithmic superiority, universal convergence, benchmark victory, safety, or real-world efficacy without inspected experimental bounds:

  • Primary Sources: Every curated claim is anchored to peer-reviewed primary papers, author technical reports, or official implementation documentation with explicit page/section locators.
  • Negative & Boundary Claims: Curation records document non-convergence proofs, counterexamples, computational complexities, and domain limitations alongside positive mechanisms.
  • Pinned Provenance: AIO classes track exact upstream git commit hashes, source release snapshots, and cryptographic checksums for transparent reproducible alignment.
